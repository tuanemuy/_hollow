# 画面一覧

Hollow がシナリオを実現するために必要な画面を一覧化する。
画面は「未ログイン領域」「個人領域（ログイン後）」「公開領域」「管理者領域」の 4 グループに分かれる。

凡例:
- (auth) ログイン必須
- (admin) 管理者ロール必須
- (public) 未ログインで閲覧可能

---

## レイアウト共通要素

すべての画面が以下のレイアウト要素に依拠する。

### ヘッダー
- 個人領域（auth）: ロゴ / 検索ボックス（自分のノート横断、結果は P10 を絞り込み表示）/ 新規作成 CTA / アップロード CTA（クリックでアップロードモーダルを開く、ページ遷移しない） / ユーザーメニュー（プロフィール / 設定 / ログアウト / 管理者の場合は管理メニュー）
- 公開領域（public）: ロゴ / 検索ボックス（公開ノート横断、結果は P32）/ サインアップ・ログイン導線
- 管理者領域（admin）: 個人領域ヘッダー + 管理ナビ

### サイドバー
- 個人領域のみ常駐: ディレクトリツリー（P19 機能を内包）/ 保存ビューへのショートカット / タグ管理・ゴミ箱・エクスポートジョブへのリンク
- 公開領域・管理者領域では非表示またはセクション固有のナビに置換

### フッター
- 公開領域: 利用規約 / プライバシー / インスタンス情報
- 個人領域: 軽量（バージョン情報）

### モーダル / ダイアログ
- 確認ダイアログ、公開設定（P14）、エクスポート（P15）、メディアアップロード進捗などは画面遷移を伴わずモーダル化する設計余地を残す
- アップロード（P13）はヘッダー／サイドバー／ノート一覧ツールバーから開く共通モーダルとして提供し、開閉状態は URL hash（`#upload`）に反映する。`/upload` ページ自体は直リンク用フォールバック兼取り込みキュー全件閲覧画面として残す

## 未ログイン領域

### P01 サインアップ画面 (public)
- 目的: 新規ユーザーが登録するための入口
- 機能:
  - ユーザー名 / メール / パスワード入力、表示名は任意
  - 利用規約への同意チェック
  - 登録実行 → 確認メール送信案内
  - インスタンスが登録停止中の場合は停止状態を表示
- 関連シナリオ: A1

### P01b 初期管理者セットアップ画面 (public)
- 目的: Setup Token を提示して admin ユーザーを登録する（[ADR 007](../adr/007-admin-setup-token.md)）
- アクセス制御:
  - 環境変数 `ADMIN_SETUP_TOKEN` が未設定の場合は 404 を返す（presentation 層で `SetupTokenVerifier.isEnabled()` を確認）
  - 未ログイン / ログイン中いずれもアクセス可（ログイン中でも別アカウントとして admin を作れる）
- 機能:
  - ユーザー名 / メール / パスワード / 表示名（任意）/ Setup Token 入力
  - 利用規約への同意チェック
  - 登録実行 → 確認メール送信案内（通常 SignUp と同じ）
  - Setup Token 不一致 / env 未設定時は「Setup Token が正しくありません」をフォーム下に表示
- 関連シナリオ: I0
- 注: `registration.open === false` でもこのページは機能する（運用者特権）

### P02 メール確認画面 (public)
- 目的: サインアップ確認リンクの着地点
- 機能:
  - トークン検証結果（有効 / 期限切れ / 使用済み）の表示
  - 期限切れ時の再送導線
  - 成功時の自動ログイン + ホームへのリダイレクト
- 関連シナリオ: A1

### P03 ログイン画面 (public)
- 目的: 既存ユーザーがセッションを取得する
- 機能:
  - メール + パスワード認証
  - 「パスワードを忘れた方」リンク
  - 認証失敗時のメッセージ
  - 未認証アカウントへの確認メール再送導線
  - ログイン後の遷移先 URL を保持
- 関連シナリオ: A2

### P04 パスワード再設定リクエスト画面 (public)
- 目的: パスワードを忘れたユーザーの再設定起点
- 機能:
  - メールアドレス入力 → 再設定リンク送信（列挙攻撃対策のため成否を区別しない案内）
- 関連シナリオ: A3

### P05 パスワード再設定実行画面 (public)
- 目的: 再設定リンクからの新パスワード入力
- 機能:
  - トークン検証
  - 新パスワード入力 + 強度バリデーション
  - 完了後の自動ログイン
- 関連シナリオ: A3

### P06 メールアドレス変更確認画面 (public)
- 目的: メアド変更確認リンクの着地点
- 機能:
  - トークン検証結果の表示
  - 変更完了通知 + 旧アドレスでのログイン不能化
- 関連シナリオ: A6

### P07 ランディング画面 (public)
- 目的: 未ログイン訪問者へのサービス紹介と CTA
- 機能:
  - Hollow の概要説明
  - サインアップ / ログイン導線
  - インスタンス全体の公開検索への導線
- 関連シナリオ: F4（公開検索）への入口

## 個人領域（ログイン後）

### P10 ホーム / ノート一覧画面 (auth)
- 目的: 自分のノートを横断的に把握・操作する起点
- 機能:
  - 表示形式切替（リスト / タイル / カレンダー）
  - ディレクトリツリー（サイドバー）からのフィルタ
  - 自分のノート横断の全文検索結果表示（キーワードハイライト + ファセット: タグ / ディレクトリ / 期間 / 公開状態 / 0 件時の推奨検索語・近いタグ提案 / クエリ長過大時の切り詰め警告 / クエリが短すぎる場合は trigram 索引の制約で 0 件扱い・UI ヒントはフォロー Issue 候補）。共通ヘッダーの検索ボックスからの遷移先を兼ねる
  - フィルタバー（タグ / 期間 / 公開状態 / 内部リンク参照）
  - ノートの複数選択と一括操作（移動 / 削除 / エクスポート / 公開設定）
  - 「新規作成」「アップロード」CTA
  - 現在のフィルタ + 表示形式の「ビューとして保存」
- 関連シナリオ: E1, E3, E4, D2, H1, G2, F1

### P11 ノート詳細画面 (auth)
- 目的: 1 件のノートを閲覧・操作する画面
- 機能:
  - レンダリングされた HTML をデフォルトスタイル + デザイントークンで表示
  - メタ情報パネル（作成 / 更新日、タグ、ディレクトリ、公開状態、バックリンク）
  - FrontMatter パネル（ノートに書かれているキーの一覧表示）。タグ操作は別パネル（ハッシュタグ／タグチップ）で行う
  - 操作（編集 / 公開設定 / 移動 / 複製（コピーして新規ノートとして開く）/ URL コピー（公開状態に応じて公開 URL or 内部 URL）/ エクスポート / 削除 / 履歴）
  - 公開・限定公開時の URL プレビュー
  - 内部リンク先 / バックリンクのナビゲーション
- 関連シナリオ: E2, C2, F1, G1, H1, D4, D5

### P11h ノート履歴一覧画面 (auth)
- 目的: 1 件のノートの過去版（`NoteRevision`）を一覧する画面 (Issue #158)
- 起動経路: P11 操作メニューの「履歴」リンクから遷移
- 機能:
  - 過去版を新しい順 (`created_at DESC`) に一覧表示
  - 各行: 保存時のタイトル + 作成日時 + 「閲覧」リンク（P11h-detail へ）
  - ページネーション
  - 「履歴がありません」空状態（一度も SaveNote が呼ばれていないノート）
  - 親ノートへ戻るリンク
- 関連シナリオ: C5

### P11h-detail ノート過去版閲覧画面 (auth)
- 目的: 個別の過去版を読み取り専用で閲覧し、必要なら復元する (Issue #158 ADR-005, ADR-006)
- 機能:
  - 過去版本文の HTML レンダリング（`.note-detail-content` 共有スタイル）
  - メタ情報（保存日時、タイトル）
  - 「この版に復元」ボタン（confirm ダイアログ付き）
  - 親ノートが trashed 状態の場合、復元ボタンは disabled + 補足テキスト「ゴミ箱に入っているノートには復元できません」
  - 「履歴一覧に戻る」リンク
- 関連シナリオ: C5

### P12 ノートエディタ画面 (auth)
- 目的: ノートの新規作成 / 編集
- 機能:
  - WYSIWYG モード（新規 + 既存）
  - HTML モード（生 HTML 編集 + サニタイズプレビュー）
  - 同一ノートでのモード切替（未保存変更がある場合は確認）
  - タイトル入力、ディレクトリ選択（既存ツリーから選択 or 新規ディレクトリ名を入力すると自動作成）
  - メタデータパネル（FrontMatter の任意 key-value 編集 / 生 JSON 編集モード切替 / schema 検証 / 内部リンク補完）。タグ操作は本文ハッシュタグまたはタグチップ入力で行う
  - メディアアップロード（画像・動画）と挿入、進捗 / 失敗ハンドリング
  - 自動保存ステータス、明示保存 / キャンセル
  - 編集ロック / 衝突警告（同時編集）
- 関連シナリオ: C1, C2, C3, C4, C5, C6, D4

### P13 アップロード（取り込み）画面 (auth)
- 目的: ファイルから新規ノートを作る
- 主動線: グローバルヘッダー／サイドバー／ノート一覧ツールバーの「アップロード」CTA から開く**アップロードモーダル**で完結する
  - モーダルの開閉状態は URL hash（`#upload`）で表現し、リロード／共有で復元可能
  - モーダルからは「取り込みキューを見る」リンクで本ページ（フォールバック）に遷移できる
- 本画面の役割: 直リンク／ブックマーク用フォールバック、および取り込みキュー全件の閲覧と個別操作
- 機能:
  - 単一 / 複数ファイルのドラッグ&ドロップ、ファイル選択（モーダル・本画面共通）
  - 取り込みキュー（待機 / 処理中 / 完了 / 失敗）— 本画面で全件表示
  - 形式別の処理結果プレビュー（HTML / Markdown / Office / PDF / 画像 / 音声）
  - LLM 提案（タイトル / 保存先ディレクトリ / メタデータ）の採用・修正
  - 保存前の再生成（保存後は不可）
  - 一括保存・個別保存・破棄
  - 対応外形式 / サイズ超過 / LLM 失敗のフィードバック
- 関連シナリオ: B1, B2, B3, B4, B5

### P14 公開設定モーダル / 画面 (auth)
- 目的: ノートの公開ステータス管理
- 起動経路: P11 ノート詳細から単体起動 / P10 ノート一覧から複数選択時の一括起動（一括時はラジオ + 影響範囲表示）
- 機能:
  - 非公開 / 限定公開 / 公開 のラジオ
  - 限定公開リンクの発行 / 失効 / パスワード設定 / 最終アクセス確認
  - パスワード再設定（旧値は保存しない）
  - 公開時の URL プレビュー
  - 公開可能性のセーフティチェック表示（他人メディア参照、未保存変更）
- 関連シナリオ: F1, F2

### P15 エクスポート画面 / モーダル (auth)
- 目的: ノートを HTML / Markdown / PDF で書き出す
- 機能:
  - 単体・複数選択・現在のビュー全件
  - 形式選択、オプション（FrontMatter / メディア埋め込み）
  - 即時 DL or 非同期ジョブ
  - 進捗確認、再試行
- 関連シナリオ: G1, G2, G3

### P16 エクスポートジョブ一覧画面 (auth)
- 目的: エクスポートジョブ状態の監視
- 機能:
  - ジョブ一覧（進行中 / 完了 / 失敗）
  - 完了ジョブのダウンロードリンク（有効期限付き）
  - 失敗ジョブの再試行・キャンセル
- 関連シナリオ: G3

### P17 ゴミ箱画面 (auth)
- 目的: 論理削除されたノートを管理
- 機能:
  - ゴミ箱内ノート一覧（残日数表示）
  - 個別 / 一括の復元
  - 完全削除（個別 / 一括「ゴミ箱を空にする」）
  - 復元時の復元先選択
- 関連シナリオ: H1, H2, H3, H4

### P18 タグ管理画面 (auth)
- 目的: タグの統合・リネーム・削除
- 機能:
  - 全タグ + 利用件数一覧
  - リネーム（参照ノート全体への伝播）
  - 統合（既存タグへのマージ）
  - 削除（再抽出防止のブラックリスト化）
  - 一括処理ジョブの進捗表示
- 関連シナリオ: D3, D6

### P19 ディレクトリ管理（インライン）
- 目的: ディレクトリツリーの構造編集
- 機能: P10 のサイドバーから直接操作（作成 / リネーム / 移動 / 削除）
  - 削除時の中身ハンドリング（ゴミ箱へ）
  - 公開ノートが含まれる場合の警告
- 関連シナリオ: D1, D2
- 注: 専用ページではなくサイドバーのインライン UI として実装

### P20 ビュー管理画面 (auth)
- 目的: 保存済みビューの編集・削除
- 機能:
  - 保存ビュー一覧（フィルタ条件 / 表示形式 / 名前）
  - 既定ビュー指定
  - 壊れた条件（削除済みタグ / ディレクトリ参照）の警告 + 修復
  - 公開ビュー / 個人ビューの分離管理
- 関連シナリオ: E5

### P21 設定: プロフィール画面 (auth)
- 目的: 自分のプロフィール情報を編集
- 機能:
  - 表示名 / 自己紹介 / アバター画像
  - ユーザー名（URL 識別子）変更（別タブ確認 + レート制限）
  - 公開プロフィールページのプレビュー
- 関連シナリオ: A4

### P22 設定: セキュリティ画面 (auth)
- 目的: パスワード / メアド / 他端末セッション管理
- 機能:
  - パスワード変更
  - メールアドレス変更（確認メール送信）
  - アクティブセッション一覧 + 個別ログアウト
- 関連シナリオ: A3, A6

### P23 設定: カスタムプロンプト画面 (auth)
- 目的: ユーザー個別の LLM カスタムプロンプト編集
- 機能:
  - 取り込み構造化 / タイトル生成 / ディレクトリ提案の各プロンプトを編集
  - インスタンスデフォルトとの継承表示
  - プレビュー（サンプル入力 → 出力）
- 関連シナリオ: I2（ユーザー側）

### P24 設定: アカウント削除画面 (auth)
- 目的: アカウント削除の安全な実行
- 機能:
  - 削除によって失われるものの明示
  - 確認語 / ユーザー名入力での最終確認
  - 実行後の自動ログアウト + 公開ノート非公開化
- 関連シナリオ: A5

## 公開領域

### P30 ユーザー公開トップ `/<username>` (public)
- 目的: 特定ユーザーの公開ノート一覧と公開プロフィール
- 機能:
  - 公開プロフィール（表示名 / アバター / 自己紹介）
  - 公開ノート一覧（リスト / タイル / カレンダー切替、公開ノートのみが対象）
  - フィルタバー（タグ / 期間）
  - ユーザー単位の検索ボックス
  - 個別ノートへの遷移
- スコープ外: RSS / sitemap 配信は MVP では実装しない
- 関連シナリオ: F3, F4

### P31 公開ノート画面 `/<username>/<note-slug>` (public)
- 目的: 公開ノートの閲覧
- 機能:
  - レンダリングされた HTML 表示
  - メタ情報（作成日 / 更新日 / タグ）
  - 公開ノート同士のバックリンク
  - 個別エクスポート（HTML / Markdown / PDF）
  - 旧 URL からのリダイレクト（ユーザー名変更時）
  - 410 Gone（非公開化 / 削除）/ 404
- 関連シナリオ: F3, F5, G1

### P32 全インスタンス公開検索画面 (public)
- 目的: 同一インスタンスのすべての公開ノートを横断検索
- 機能:
  - キーワード入力 + ハイライト
  - ファセット（ユーザー / タグ / 期間）
  - クエリが短すぎる場合は trigram 索引の制約で 0 件扱い（UI ヒント追加はフォロー Issue 候補）
  - レート制限の案内
- スコープ外: RSS / sitemap 配信は MVP では実装しない
- 関連シナリオ: F4

### P33 限定公開ノート閲覧画面 `/share/<token>` (public)
- 目的: 限定公開リンクからの閲覧
- 機能:
  - パスワード入力（設定されている場合）
  - 失敗回数による一時ロック
  - 失効済み / 削除済みリンクのエラー表示
  - 認証通過後のノート閲覧（個別エクスポートは可、一括は不可）
- 関連シナリオ: F2, F5

### P34 エラー画面群 (public/auth 共通)
- 目的: 404 / 403 / 410 / 5xx をユーザーフレンドリーに表示
- 適用領域: 公開領域・個人領域・管理者領域すべてで共通利用。表示するレイアウト要素（ヘッダー / サイドバー）はアクセスコンテキストによって切り替わる
- 機能:
  - エラー種別ごとのメッセージ
  - 関連導線（ホーム / 検索 / 戻る）
- 関連シナリオ: A2, F3, F5

## 管理者領域

### P40 管理: ダッシュボード画面 (admin)
- 目的: インスタンス全体の状態把握
- 機能:
  - ユーザー数 / ストレージ消費 / 当日アップロード数 / LLM 呼び出し回数
  - しきい値超過時のアラート
  - 障害ステータスバナー（LLM プロバイダ / R2 等）
- 関連シナリオ: I5

### P41 管理: LLM 設定画面 (admin)
- 目的: LLM API キー / モデルの設定
- 機能:
  - 環境変数優先 + DB 暗号化保管
  - 接続テスト
  - クォータしきい値設定
- 関連シナリオ: I1

### P42 管理: プロンプト設定画面 (admin)
- 目的: インスタンスデフォルトのカスタムプロンプト管理（上書きモデル）
- 機能:
  - 5 種 (`structure` / `title` / `directory` / `metadata` / `ocr_assist`) のプロンプト編集
  - 各カードに「上書き中」バッジ。未上書きカードは「LLM プロバイダの既定指示を使用」のヒントを表示
  - 「この項目をリセット」ボタンで単一の上書きを削除
  - 「すべてのプロンプトをリセット」ボタン + 確認モーダルで一括リセット
  - サンプル実行プレビュー
  - 変更後のエラー率モニタ導線
- 関連シナリオ: I2
