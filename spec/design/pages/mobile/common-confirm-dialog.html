ConfirmDialog — 共通確認ダイアログ（モバイル）

app/components/common/ConfirmDialog.tsx の代表モック。 role="alertdialog" + 警告アイコン（AlertTriangle・装飾のため aria-hidden）+ タイトル + 任意の説明文 + 任意の in-dialog role="alert" エラー + フッター（「キャンセル」／danger 確認ボタン）。 モバイルでは各ダイアログを下端から立ち上がるボトムシート（上端角丸・下部フルワイドCTA）で描く。

素の構造（rest / loading / error）
rest（説明あり）

このノートを完全に削除

このノートを完全に削除しますか？この操作は取り消せません。
loading（isPending）

すべてのデザイントークンをリセットしますか？

すべての上書きが削除され、ビルトインの既定値に戻ります。この操作は取り消せません。
error（in-dialog role=alert）

「移行/旧資料」を削除しますか？

このディレクトリを削除します。配下のノートはゴミ箱へ移動し、配下のディレクトリも再帰的に削除されます。
