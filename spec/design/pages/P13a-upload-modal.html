P13a — アップロードモーダルの 3 ステート

Issue #226 で導入する新フロー。ファイル選択 → 推論待ち → プレビュー編集 → 登録 までを 1 つのモーダル内で完結させる。 複数ファイル時はキュー画面に誘導する集計表示に切り替わる。本文 HTML は読み取り専用プレビューで、編集はフォローアップ Issue に切り出した（ADR-002）。

State 1 — select

アップロード

ファイルから新規ノートを作成します。HTML / Markdown / Office / PDF / 画像 / 音声に対応しています。

ファイルをドラッグ&ドロップ またはクリックして選択 複数選択にも対応
取り込みキューを見る
State 2 — waiting

アップロード

LLM がタイトルとメタデータを提案中...

この処理には数十秒かかることがあります

180 秒で諦めて「キュー画面で続きを確認できます」と誘導してモーダルを閉じる。
