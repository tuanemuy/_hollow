Q2 の重点テーマ

Q1 の振り返りを踏まえ、Q2 は次の 3 つに集中する方針です。

  1. パブリック検索のパフォーマンス改善（P95 300ms → 150ms）
  2. 限定公開リンクの管理 UI 拡張（パスワード回転 / 失効通知）
  3. ストレージ消費の可視化（ユーザーダッシュボードに月次グラフを追加）

マイルストーン

四月末までに技術検証、五月末までに UI 統合、六月で本番投入を目標とします。

Done is better than perfect — ただし回帰テストは省略しない。

リスクと対策

  • D1 のクエリ性能上限に達した場合 → Read Replica の有効化を検討
  • リンク失効通知のメール量増加 → バッチ配信に切り替え
