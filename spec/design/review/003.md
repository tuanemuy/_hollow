# レビュー 003 — チェックボックスの方針転換と縦位置補正

## 観点

ユーザー指摘:

1. チェックボックスはやはりブラウザのネイティブで良い。
2. ただしノート選択（マルチセレクト）にフォーム用のチェックボックスを置くのは違和感がある。
3. アイコン・チェックボックスと**複数行のテキスト**が横並びになる UI で、`align-items: center` だと見た目のバランスが悪い。

## 1. チェックボックスの役割分離

`spec/design/tokens.md` の §10.5 を方針転換に合わせて全面書き換え。**フォーム用とリスト選択用を視覚的に分離する**ことを原則化。

### A. フォーム用 — ネイティブのまま

利用規約同意、ログイン保持、削除確認など「フォーム入力の一項目として on/off」を扱う場合、ブラウザのネイティブ描画を維持。`accent-color: var(--color-accent)` でブランドカラーに寄せるだけに留め、`appearance: none` のフルカスタム描画はしない。

理由:
- OS のアクセシビリティ機能（ハイコントラスト、フォーカス、VoiceOver 等）に乗れる
- 慣れた操作感を維持
- 実装・メンテナンスコスト最小

| `pages/P03-login.html` | 同上 |

| `pages/P32-public-search.html` (`.facet-checkbox`) | 検索ファセットフィルタ。カスタム `<span>` を `<input type="checkbox">` に置換 |

### B. リスト複数選択用 — 円形インジケータ（カスタム）

ノート一覧・ファイル一覧など「複数項目を選んで一括操作する」場面では、フォーム用とは違う **円形の選択インジケータ** を使う（Apple Mail / Photos / Files のパターン）。

仕様:
- 円形 20px
- 未選択 + 非ホバー: `opacity: 0`（行に集中できる）
- ホバー時: hairline 枠の空円が表示
- 選択時: アクセントカラーで塗りつぶし + 白いチェック SVG（常時表示）
- 「全選択」など**ヘッダ行の操作系**チェックボックスは `opacity: 1`（常時表示）

#### 影響ファイル

| ファイル | 旧 | 新 |
|----------|-----|-----|
| `pages/P10-home.html` (`.note-check`) | 18px 四角チェックボックス風 | 20px 円形セレクションインジケータ |
| `pages/P17-trash.html` (`.checkbox` in trash-row) | 18px 四角チェックボックス、常時表示 | 20px 円形、行ホバー時のみ表示（ヘッダ・選択中は常時） |
| `pages/P13-upload.html` (`.queue-checkbox`) | 16px 四角チェックボックス | 20px 円形、行ホバー時のみ表示（ヘッダ・選択中は常時） |

### 例外条項

管理画面の密なテーブル（P45 など）は、テーブル UI コンベンションに合わせて A（四角ネイティブ + accent-color）を維持。リストカード型 UI（P10）は B（円形カスタム）。

## 2. アイコン / 視覚要素 + 複数行コンテンツの整列

`spec/design/tokens.md` §10.6（前ラウンドで追加済み）。「**複数行になる可能性がある場合は `align-items: flex-start`（grid なら `start`）**」を原則化。

### 修正箇所

| ファイル | クラス | コンテンツ | 修正 |
|----------|--------|------------|------|
| `pages/P10-home.html` | `.note-row` | 円形選択UI + タイトル/抜粋/メタ | `center` → `start`、`.note-check` に `margin-top: 1px`、`.note-date` を `align-self: start` + `margin-top: 3px` |
| `pages/P11-note-detail.html` | `.task-list li` | チェックボックス + タスク文 | `center` → `flex-start`、checkbox に `margin-top: 3px` |
| `pages/P16-export-jobs.html` | `.job-row` | ジョブ名（2行）+ 各種メタ | `center` → `start`、ヘッダのみ `center` 保持、各列に `margin-top: 2px`（actions 除外） |
| `pages/P20-views.html` | `.view-row` | ビューアイコン + タイトル/チップ + アクション | `center` → `start`、アクションのみ `align-self: center` |
| `pages/P22-settings-security.html` | `.session-row` | デバイスアイコン + 3 行のセッション情報 + ボタン | `center` → `start`、ボタンのみ `align-self: center` |
| `pages/P45-admin-users.html` | `.user-cell` | アバター + ハンドル/メール | `center` → `flex-start`、アバターに `margin-top: 1px` |

### 据え置き

- `pages/P03-login.html` `.checkbox-row` — ラベルが単一行のため `center` のまま
- `pages/P14-publish-settings.html` `.radio-card` — ラジオドットに `margin-top: 2px` で個別補正済み
- `pages/P30-user-public-top.html` `.profile-hero` — ヒーロー（大型アバター）は中央寄せが意図
- `pages/P31-public-note.html` `.author-mini` — ピル型単一行
- `pages/P13-upload.html` `.file-cell` — ファイル名 `nowrap`
- 各種ヘッダー・ツールバー・ピル — 単一行

## 確認

agent-browser で以下を確認:

- P01 / P10 / P11 / P16 / P22 / P45 — 全て意図どおり

- P45 のテーブルはネイティブチェックボックス（accent-color）
- 整列はすべて 1 行目で揃う
