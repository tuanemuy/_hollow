## 確認観点と結果（agent-browser 視覚確認 + 実装突き合わせ）

### P48 文字起こし設定（デスクトップ / モバイル）
- ✅ 管理シェル（ヘッダー・admin-nav・page-title・form-section）が P41-admin-llm.html と同型。admin-nav は「文字起こし設定」を LLM 設定の直後に配置し P48 を active 化。
- ✅ 3 セクション構成（プロバイダ → API キー → モデル）が `SpeechSettingsForm` と一致。provider select は OpenAI 1 択だが select 構造を維持（将来 #738 で選択肢追加）。
- ✅ **baseURL 欄を持たない**（P41 との差分、ADR-013）。P41 の base-url コメントは非継承。
- ✅ env 固定表現: モデルフィールドを env 固定の可視例（disabled + lock-badge「環境変数で固定中」+ `ADMIN_SPEECH_MODEL` ロックヒント）として実体表示。provider / API キーの env 固定・全固定バナーは HTML コメントで変種明示。
- ✅ API キー現在状態の 3 分岐（環境変数から読み込み中 / DB マスク / 未設定）、provider 変更警告（`.alert .alert-warning`）+ 必須バッジをコメント併記で網羅。
- ✅ 接続テスト結果は実装の `BANNER_BASE` に忠実化（塗り背景・単一行「接続成功 · 応答 682ms」/「接続失敗 · …」）。案D `.alert` ではない（Round 1 W-003 修正）。
- ✅ `:root` は P41 を逐語コピーし `--opacity-disabled: 0.55` を追加（P41 は同変数を使用するのに :root 未定義だった潜在バグを P48 で解消）。モバイルはデスクトップ P48 の `:root` を逐語コピー。

### P13 録音 UI（`AudioRecorder`、デスクトップ / モバイル）
- ✅ DropZone 直後に録音カード（`.recorder-card`、実装 `rounded-xl border-hairline bg-surface-elevated p-4` 相当）を配置。`UploadForm`（フォールバックページ）・`UploadDialog` SelectView（モーダル）双方に対応する P13-upload / P13-upload-modal / P13a に反映。
- ✅ 状態機械を網羅: idle（「録音を開始」+「最大 30 分・24 MB」）/ requesting-permission（補助文）/ recording（赤ドット pulse + 経過時間 mono + MB + 上限間近 warning + 「録音を停止」）/ stopped（自動停止 alert + `<audio controls>` + 「この録音を取り込む」「録り直す」「取り消す」）/ permission-denied（権限拒否 + ファイルアップロード誘導）。モックは全状態を並べて見せ、HTML コメントで「実装は 1 状態ずつ排他表示」と明示。
- ✅ role 使い分けが実装に忠実: 上限間近 = `role="status"`、自動停止 / permission-denied = `role="alert"`。sr-only の `aria-live="polite"` status 領域も踏襲。
- ✅ ボタン配色を実装に忠実化: 「録音を停止」= filled danger（`error-surface` 塗り + `error` 文字、Round 1 W-001 修正）、「取り消す」= ghost-danger（rest は `ink-secondary`、hover で `error-surface`+`error`、Round 1 W-002 修正）。変更は `.recorder-card` scoped に限定し、job-actions の破棄/キャンセル等 既存ボタンには非波及。

### 既存との一貫性
- ✅ 新規 CSS は正式トークンのみ使用（`.recorder-card` / `.test-result` / `.required-badge` 等）。独自カラー・スペーシング値の発明なし。
- ✅ admin-nav は全 admin モック（P40〜P47、mobile 含む）で「文字起こし設定」を LLM 設定直後に統一追加。desktop は全リンク正常。
- ℹ️ モバイル admin モックの既存 nav には `-mobile` サフィックスの実在しないリンク（例 `P41-admin-llm-mobile.html`）が #739 以前から混在している。本 PR では各ページの整合は崩さず、P48 リンクは実在する `P48-admin-speech.html` で追加した。この既存不整合の解消は本 Issue のスコープ外（別 Issue 候補）。
- ℹ️ P48 は `.alert` セマンティックファミリー（info/success/warning/error）を P41 同様フルセットで定義する。接続テスト忠実化で `.alert-success`/`.alert-error` は未使用となるが、デザインシステムの一貫性のため家族定義を温存する（意図的、デッドコードではない）。

### モバイル
- ✅ P48 モバイルは単カラム構成・タッチ床 44px・`:root` 逐語コピー。CSS 上 横溢れリスク要素なし（固定幅テーブル等を未使用）。横スクロールの機械測定は agent-browser のビューポート縮小制約により未実施だが、視覚確認と CSS 精読で破綻なしを確認。
