## 問題

### 1. モバイルでボタンラベルが縦方向に折り返される

複数画面で、横並びボタンが mobile (375px) 幅に収まらず、各ボタン内のラベルが**文字単位で縦に折り返される**現象が発生している。

#### 影響画面
- **P10 home** (mobile): 一括アクションバー「移動 / 公開設定 / エクスポート / 削除 / ×」が unreadable に縦書きになっている
- **P12 editor** (mobile): 編集ロック banner 内の「確認して続行」ボタンが縦書き
- **P18 tags** (mobile): 各タグ行のインライン操作ボタン「リネーム / 統合 / 削除 (ブラックリスト化)」が縦書き

#### 根本原因
ボタン内ラベルに `white-space: nowrap` がないこと、加えて 375px に複数ボタンが詰め込まれる前提のレイアウトが mobile 用に組まれていないこと。

#### 対応
- 該当ファイル各所のボタンに `white-space: nowrap` を強制
- mobile 専用のレイアウト切替:
  - **P10 bulk bar**: モバイルではアイコンのみ表示 (またはオーバーフロー時に水平スクロール `overflow-x: auto`)
  - **P12 編集ロック banner**: ボタンをモバイル時はバナーの下に full-width で配置
  - **P18 タグ行**: モバイルでは行末の「⋯」メニュー (ドロップダウンふう) に集約し、リネーム/統合/削除はそのメニュー内に隠す

### 2. ノートタイトルがモバイルで右端切れ・改行で詰まる

H1 のフォントサイズ `clamp(28px, 4vw, 40px)` の最小値 28px が、375px viewport で長い日本語タイトルとぶつかる。

#### 影響画面
- **P11 note-detail** (mobile): 「静かなインターフェースについての覚書」のうち「覚書」が右にはみ出す気味、改行位置が不格好
- **P12 editor** (mobile): 「Q2 計画 — プロダクトレビュー…」が右切れ

#### 根本原因
- `clamp(28px, 4vw, 40px)` の min が 28px と高すぎる
- 加えて H1 要素の親コンテナに `min-width: 0` または `overflow-wrap: anywhere` が指定されていないため、長い未分かち書きトークンが幅を突き抜けている可能性

#### 対応
- 該当 H1 に `font-size: clamp(22px, 5vw, 40px)` 程度に min を下げる (`--text-3xl` を使っている場合はそのトークン自体を `clamp(22px, 4vw, 40px)` に微調整するかページ側で上書き)
- H1 とその親に `overflow-wrap: anywhere; word-break: break-word; min-width: 0;` を入れる
- 影響範囲を `--text-3xl` 全体に広げてしまって良いか判断: P11/P12/設定タイトル等で使用 → `tokens.md` 側で `--text-3xl: clamp(22px, 4vw, 40px)` に統一して波及させる方が早い

### 3. ヘッダーの search bar が tablet (768px) でロゴと衝突しないか確認したい

P10 や P17 の tablet 表示で、サイドバーが drawer (lg 未満) でハンバーガー化されつつ search bar がやや窮屈に見える箇所がある。致命的な破綻はないが、tablet 中央寄りで search bar が短くなりすぎないかを再確認したい。

#### 対応
- header の grid template: search bar が `max-width: 460px` で `margin: 0 auto` 中央寄せされる現在の設計のままで OK だが、tablet 時に header padding を `--space-4` から `--space-5` に増やして余裕を持たせる

- **P40 admin-dashboard**: メトリクスカードが落ち着いた配色で密度感とのバランスが良い。
- **P43 admin-tokens**: トークンエディタとライブプレビューの左右配置が説得力がある。
