# デザインレビュー 006 — P18 タグ管理 検索・ソート・最終使用列の追従（Issue #569）

**対象:** `spec/design/pages/P18-tags.html`（既存モックへの合成）
**日付:** 2026-06-07
**文脈:** #542 で「別Issue引き渡し」として省略された A.検索 / B.ソート / C.最終使用列 を既存デザイン言語へ合成。

## 観点1: 既存コンポーネントの忠実再利用（issue-implement 固有チェック）

- **検索フォーム** — 既存ヘッダ `.search` / `.search input` / `.search-icon`（surface 背景・pill・focus shadow）のマークアップとトークンをそのまま流用。`.tag-toolbar .search` で中央寄せ（`margin:0 auto`）のみ左寄せに上書きし、視覚は完全継承。✅ 新規 UI パターンの発明なし。
- **ソート切替** — CSS定義済みだが body 未使用だった `.segmented` / `.segmented-item(.active)` を初めて使用。軸4種（名前/ノート数/作成日時/最終使用）、デフォルト「名前」を `.active`。方向トグルは `.icon-btn icon-btn-ghost` の密度派生 `.icon-btn-sm`。✅ 既存コンポーネントの正しい活用。
- **最終使用列** — `.tag-lastused` は `.tag-count` と同じ `var(--text-sm)` / `var(--color-ink-tertiary)`、`@media (max-width:1023px)` で同列畳み。見た目・レスポンシブとも `.tag-count` と完全同型。✅

## 観点2: デザイントークン整合（リテラル px 回避）

- spacing/color/radius/text はすべて `var(--space-*)` / `var(--color-*)` / `var(--radius-*)` / `var(--text-*)` 経由。新規トークン追加なし。
- 残る px は `max-width:320px` / `flex-basis:240px`（既存 `.search` の `max-width:460px` と同種のレイアウト上限）、`.icon-btn-sm` 32px（既存 `.icon-btn` 36px から派生）、`.tag-lastused margin-top:2px`（`.segmented` padding:2px と同オーダー）のみ。いずれも既存パターンに準拠した寸法で、新規の浮いた値ではない。✅ 許容。

## 観点3: レスポンシブ規約の維持

- `max-width:1023px` で `.tag-lastused` を `.tag-count` と一緒に畳む（既存 `.tag-count` の規約に整合）。
- `max-width:639px` で `.tag-toolbar` を縦積み（`flex-direction:column`）、検索を全幅化。
- 既存の行アクション（hover/focus 表示・狭幅ケバブ）・inline rename ブロックは無変更。✅

## 観点4: 構造健全性

- div 開閉均衡（80/80）。`.tag-lastused` 9件 = データ行9件（editing block 除く）一致。
- 未使用タグ行（`quote` を「0 件のノート」+「未使用」フォールバックに変更）を1行用意し、C の null フォールバック表示を視覚化。✅
- a11y: 検索 `role="search"` + `aria-label`、ソート `role="tablist"`/`role="tab"`/`aria-selected`、方向トグル `aria-label`/`aria-pressed`/`title`。✅
