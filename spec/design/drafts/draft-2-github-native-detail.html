Q2 戦略メモ

このノートは Hollow プロジェクトの第2四半期戦略を整理するためのドラフトです。 関連する議論は 前期レビュー や 市場リサーチ.md を参照してください。

#spec #design #q2-2026

背景と前提

前四半期の振り返りに基づき、以下の3点をコア戦略として設定する。 これらは strategic-priority として全社共有資料にも展開する。

  1. 既存ユーザーの定着率を改善する（KPI: D30 retention ≥ 35%）
  2. 新しい import 経路 を整備し、流入を 2x にする
  3. パートナーシップ経由のシード獲得チャネルを評価する

Note. 本稿の数値は社内ダッシュボードのスナップショット（2026-05-15）に基づく。 以後の更新はバックリンク経由で同期される。

技術的な決定

Outbox dispatch の lease 取得は SQL 側で完結させる。 以下のクエリで claim を行い、lease 期限を持たせる。 

-- claim up to N rows that are not yet leased
UPDATE outbox_event
SET
  leased_by  = ?1,
  leased_at  = ?2,
  lease_until = ?3
WHERE id IN (
  SELECT id FROM outbox_event
  WHERE status = 'pending'
    AND (lease_until IS NULL OR lease_until < ?2)
  ORDER BY created_at LIMIT 100
)
RETURNING id, payload, kind;

TypeScript 側の使い方

import { runUnitOfWork } from "@/core/application/uow";

export async function publishNote(input: PublishNoteInput) {
  return runUnitOfWork(async (ctx) => {
    const note = await ctx.notes.requireById(input.id);
    note.publish(input.publishedAt);
    await ctx.notes.save(note);
    ctx.enqueue(note.pullEvents());
    return note.toView();
  });
}
