# G. エクスポート テスト

## 概要

このドキュメントは Hollow のノートエクスポート機能（個別 / 一括 / 非同期ジョブ）に関するマニュアルテストの手順書です。

対応シナリオ: `spec/scenario/export.md`

## 前提条件

### 環境
- Hollow のローカル環境または検証環境が起動している
- 既存ユーザー `existing-user` でログイン済み
- R2 と PDF 生成基盤（HTML → PDF）が利用可能

### テストデータ
- ノート: `Export-Single`（本文に画像 1 件と FrontMatter を含む）
- ノート: `Export-Huge`（PDF タイムアウトを誘発するための大量本文を持つノート）
- ノートが多数含まれるディレクトリ: `Bulk-Source`（10 件以上）

### 事前準備
1. 各テストケースは独立して実行可能とすること。テスト開始前にエクスポートジョブをクリアし、テストノートを初期状態に戻すこと
2. ログイン済みであること
3. `P11 ノート詳細画面` で `Export-Single` を開けること

## TC-G1-01: 1 件のノートを HTML でエクスポート

**種別**: 正常系
**目的**: HTML 形式で即時ダウンロードできること

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | `P11 ノート詳細画面` で `Export-Single` を開き「エクスポート」を選ぶ | `P15 エクスポート画面 / モーダル` が表示される |
| 2 | 形式 `HTML` / 「FrontMatter を含める」を ON / 「画像を埋め込む」を ON にして実行する | 即時に `.html` ファイルがダウンロードされる |
| 3 | ダウンロードした HTML をブラウザで開く | FrontMatter がコメント等で出力され、画像が data URL またはインライン埋め込みされている |

## TC-G1-02: 1 件のノートを Markdown でエクスポート

**種別**: 正常系
**目的**: Markdown 形式での出力

| # | 操作 | 期待結果 |

**種別**: 異常系
**目的**: メディア取得失敗箇所がプレースホルダ化され、失敗一覧が示されること

| # | 操作 | 期待結果 |
|---|---|---|
