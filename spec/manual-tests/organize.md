# D. 整理 テスト

## 概要

このドキュメントは Hollow のディレクトリ・タグ・FrontMatter・内部リンクによるノート整理機能に関するマニュアルテストの手順書です。

対応シナリオ: `spec/scenario/organize.md`

## 前提条件

### 環境
- Hollow のローカル環境または検証環境が起動している
- 既存ユーザーでログイン済み（`existing@example.com`）

### テストデータ
- ルート直下のディレクトリ: `Inbox` / `Projects` / `Archive`（事前作成）
- ディレクトリ `Projects/SubProject`（事前作成、`Projects` 配下）
- ディレクトリ `Doomed-Dir`（D1-05 用に毎回再作成。配下に使い捨てのノート `Doomed-Note` を 1 件配置）
- ノート: `NoteA`（`Inbox` 配下 / 公開状態 非公開）
- ノート: `NoteB`（`Projects` 配下 / 公開状態 公開）
- ノート: `Note-Link-Target`（`Projects` 配下 / 内部リンクの参照先用）
- ノート: `Note-Link-Source`（`Inbox` 配下 / 本文に `Note-Link-Target` へのリンクを保有）
- タグ: `urgent`（複数ノートに付与済み）/ `idea`（数件のノートに付与済み）

### 事前準備
1. 各テストケースは独立して実行可能とすること。テスト開始前にテストデータを初期状態へリセットすること（特に D1-05, D6-02〜04, D5-04 のように破壊的な変更を伴うテストの前後ではリセットが必要）
2. ログイン後、`P10 ホーム / ノート一覧画面` を表示している
3. サイドバーのディレクトリツリーに上記ディレクトリが見えていることを確認する
