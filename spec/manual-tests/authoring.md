# C. ノート作成・編集 テスト

## 概要

このドキュメントは Hollow の WYSIWYG / HTML エディタを使ったノートの作成・編集機能に関するマニュアルテストの手順書です。

対応シナリオ: `spec/scenario/authoring.md`

## 前提条件

### 環境
- Hollow のローカル環境または検証環境が起動している
- メディアアップロード用 R2 が利用可能
- 既存ユーザーでログイン済み（`existing@example.com`）

### テストデータ
- 既存ノート: `EditMe`（ディレクトリ `Inbox` / 公開状態 非公開 / 本文に `<h1>EditMe</h1><p>本文</p>` を含む）
- 既存ノート: `LockTarget`（同時編集テスト用）
- 画像: `media1.png`（200KB）、`media2.png`（500KB）
- 対応外メディア: `media-bad.exe`
- サイズ超過メディア: `huge-media.png`（上限超過）

### 事前準備
1. 各テストケースは独立して実行可能とすること。テスト開始前に既存ノート `EditMe` / `LockTarget` を初期内容に戻すこと
2. ログイン後、`P10 ホーム / ノート一覧画面` を表示している
3. テストデータの既存ノートを事前に作成しておく

## TC-C1-01: 空のノートを WYSIWYG で新規作成

**種別**: 正常系
**目的**: 新規作成 → 自動保存 → 明示保存までの基本フロー

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | ヘッダーの「新規作成」CTA を押す | `P12 ノートエディタ画面` の WYSIWYG モードが開き、空のタイトル / 本文 / FrontMatter パネルが表示される |
| 2 | タイトル欄に `初めてのノート` を入力する | タイトルがエディタ上部に反映される |
| 3 | 本文に `これは新規作成のテストです` を入力する | 本文に反映され、エディタ上部の自動保存ステータスが「保存中」→「保存しました（ドラフト）」に変化する |
| 4 | 「保存」を押す | 「保存しました」と表示され、ヘッダーの公開状態に「非公開」と表示される |
| 5 | ヘッダーから `P10 ホーム / ノート一覧画面` に戻る | ノート一覧の先頭に `初めてのノート` が出現する |
