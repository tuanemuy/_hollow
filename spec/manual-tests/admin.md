# I. 管理者設定 テスト

## 概要

このドキュメントは Hollow の管理者向け機能（初期管理者登録、LLM 設定、プロンプト、デザイントークン、登録制御、利用状況確認）に関するマニュアルテストの手順書です。

対応シナリオ: `spec/scenario/admin.md`

## 前提条件

### 環境
- Hollow のローカル環境または検証環境が起動している
- 管理者ロールを持つユーザー `admin-user` を作成済み（I0 以外のテスト用）
- I0 テストのみ別途、新規セットアップ用環境を用意する

### テストデータ
- Setup Token（I0 用）: `setup-token-with-enough-entropy-32chars+`
- LLM API キー: 検証用に有効なキー / 不正キー / 期限切れキーを準備
- カスタムプロンプト: `structure` 取り込み構造化 / `title` タイトル生成 / `directory` ディレクトリ提案 / `metadata` メタデータ抽出 / `ocr_assist` OCR 補助 の 5 種（Issue #218 で SSOT を domain 5 値に統一）
- デザイントークン: 検証用に `--color-primary` を変更可能

### 事前準備
1. 各テストケースは独立して実行可能とすること。テスト開始前に管理者設定（LLM / プロンプト / デザイントークン / 登録制御）を初期状態へリセットすること
2. I0 以外: `admin-user` でログイン済み
3. I0: `ADMIN_SETUP_TOKEN` を `wrangler secret put` で設定し、`/setup` にアクセス可能な状態

## TC-I0-01: 初期管理者登録（Setup Token 有り）

**種別**: 正常系
**目的**: Setup Token を使った初期 admin 登録が通常 SignUp と同様の体験で完了すること

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | 未ログインで `/setup` を開く | `P01b 初期管理者セットアップ画面` が表示される |
| 2 | ユーザー名 `admin-user` / メール `admin@example.com` / パスワード `Password123!` / 表示名 `管理者` / Setup Token `setup-token-with-enough-entropy-32chars+` を入力する | 入力が反映される |
| 3 | 利用規約に同意し「登録」を押す | 「確認メールを送信しました」案内が表示される |
| 4 | メール内の確認リンクを開く | `P02 メール確認画面` に遷移し、自動ログインで `P10 ホーム / ノート一覧画面` に到達する |
| 5 | ヘッダーのユーザーメニューに「管理メニュー」が表示されることを確認する | role=admin で登録できている |

**確認ポイント**:
- 確認メール内容は通常 SignUp と同様であること
- 登録後、`wrangler secret delete ADMIN_SETUP_TOKEN` を実行して env を削除する運用が推奨されることを記録に残す

**種別**: 異常系
**目的**: `SessionService.issue` が失敗してもアカウントは active 化されており、手動ログインで復帰できること

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | 事前準備: `SessionService` を一時的に失敗させる検証フラグを ON にする | 自動ログインが失敗する |
| 2 | I0-01 と同じ手順で確認リンクまで到達する | アカウントは active になる |
| 3 | 確認画面に「メール確認は完了しました。ログイン画面からサインインしてください」相当のメッセージが表示される | 案内が出る |
| 4 | `P03 ログイン画面` から手動ログインする | ホームに到達する |
