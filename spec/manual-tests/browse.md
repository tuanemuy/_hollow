# E. 閲覧・検索 テスト

## 概要

このドキュメントは Hollow のノート一覧 / 詳細表示 / 検索 / 絞り込み / ビュー保存に関するマニュアルテストの手順書です。

対応シナリオ: `spec/scenario/browse.md`

## 前提条件

### 環境
- Hollow のローカル環境または検証環境が起動している
- 既存ユーザーでログイン済み（`existing@example.com`）

### テストデータ
- ノート 10 件以上を異なる更新日 / タグ / ディレクトリで作成済み
- ノート: `Searchable-Note`（本文に `hollow-search-keyword` を含む）
- ノート: `Empty-Date-Note`（FrontMatter の `date` キーが欠落 / 更新日も意図的に古い）
- タグ: `urgent` / `idea` を複数ノートに付与
- 削除済みディレクトリ: `Removed-Dir`（テスト用に作成 → 削除）

### 事前準備
1. 各テストケースは独立して実行可能とすること。テスト開始前に保存ビューやフィルタ状態を初期化（クエリパラメータを外し、保存ビューを削除）すること
2. ログイン後、`P10 ホーム / ノート一覧画面` を表示している
3. サイドバーのディレクトリツリーが見える状態であること
