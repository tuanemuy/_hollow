# B. ノート取り込み テスト

## 概要

このドキュメントは Hollow のファイルアップロード経由のノート生成機能に関するマニュアルテストの手順書です。

対応シナリオ: `spec/scenario/ingest.md`

## 前提条件

### 環境
- Hollow のローカル環境または検証環境が起動している
- LLM プロバイダ（Anthropic Claude 等）への接続が成立しており、`P41 管理: LLM 設定画面` の接続テストが成功している
- R2（または互換ストレージ）が利用可能で、メディアアップロードが疎通する

### テストデータ
- HTML サンプル: `sample.html`（5KB）— `<h1>Sample</h1><p>Hello</p>` を含む
- Markdown サンプル: `sample.md`（5KB）— `# Sample\n\nHello world` を含む
- Word サンプル: `sample.docx`（200KB）— 見出しと段落を含む
- PDF（テキスト層あり）: `sample-text.pdf`（500KB）
- PDF（テキスト層なし）: `sample-scan.pdf`（2MB、スキャン画像）
- 画像: `sample.png`（300KB、テキストを含む）
- 音声: `sample.mp3`（1MB、日本語音声）
- 対応外形式: `sample.zip`
- サイズ超過: `huge.bin`（インスタンス上限を超えるファイル。例 50MB）

### 事前準備
1. 各テストケースは独立して実行可能とすること。テスト開始前にテストデータを初期状態へリセットすること（特に B2-04 のアップロード上限テスト前後は残量を戻す）
2. 既存ユーザーでログイン済みであること（`existing@example.com`）
3. `P10 ホーム / ノート一覧画面` を表示している

## TC-B1-01: 単一 HTML ファイルのアップロード

**種別**: 正常系
**目的**: HTML ファイルをそのまま取り込んで詳細画面に到達できること

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | ヘッダーの「アップロード」CTA を押す | `P13 アップロード（取り込み）画面` に遷移する |
| 2 | `sample.html` をドラッグ&ドロップする | アップロードキューに `sample.html` が「処理中」として表示される |
| 3 | 処理完了後、プレビュー画面に切り替わる | LLM 提案によるタイトル（例: `Sample`）と保存先ディレクトリ提案、抽出されたタグ / FrontMatter が表示される |
| 4 | 提案をそのまま受け入れて「保存」を押す | `P11 ノート詳細画面` に遷移し、`Sample` の本文が表示される |

**確認ポイント**:
- ノート詳細のプロパティに「元ファイル」行が表示され、`sample.html` のファイル名と「閲覧」「ダウンロード」リンクがあること（Issue #452）
- 「閲覧」を押すと新規タブで元ファイルがブラウザのネイティブビューアで開くこと
- 「ダウンロード」を押すと元のファイル名で保存されること
- 別ユーザーでログインして同じ `/media/<id>` を直接開くと閲覧/DL できないこと（所有者のみ可）
- ノート本文 HTML には `/media/<id>` リンクが含まれないこと（元ファイルは UI 要素としてのみ描画）
- ノート本文が HTML のままレンダリングされていること
