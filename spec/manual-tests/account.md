# A. アカウント テスト

## 概要

このドキュメントは Hollow のアカウント関連機能（新規登録 / ログイン / パスワード変更 / プロフィール / メアド変更 / アカウント削除）に関するマニュアルテストの手順書です。

対応シナリオ: `spec/scenario/account.md`

## 前提条件

### 環境
- Hollow のローカル環境または検証環境が起動している
- 環境変数 `ADMIN_SETUP_TOKEN` が未設定（通常 SignUp の動作確認のため。Setup Token 関連は `admin.md` の I0 で扱う）
- 確認メールの内容を取得できる手段がある（メール送信ログを覗ける環境、もしくはローカルメールサーバー）

### テストデータ

**ベースライン**（どの TC でも改名・削除・メアド変更しない。ログインと衝突対象としてのみ使用）:
- `existing-user` / `existing@example.com` / `Password123!`（member、有効化済み）
- `mailowner` / `existing-new@example.com` / `Password123!`（member、メアド衝突対象）
- `admin-user` / `admin@example.com` / `Password123!`（admin）

**スローアウェイ**（破壊的 TC ごとに専用に用意。1 TC 1 アカウントで使い切る）:
- `tc-rename-a` / `tc-rename-a@example.com` / `Password123!` — TC-A4-02 で改名
- `tc-rename-b` / `tc-rename-b@example.com` / `Password123!` — TC-A4-03（衝突）でログイン
- `tc-rename-c` / `tc-rename-c@example.com` / `Password123!` — TC-A4-05（レート制限）
- `tc-delete-a` / `tc-delete-a@example.com` / `Password123!` — TC-A5-01 で削除
- `tc-email-a` / `tc-email-a@example.com` / `Password123!` — TC-A6-01 でメアド変更
- `tc-email-b` / `tc-email-b@example.com` / `Password123!` — TC-A6-04（レート制限）
- `tc-password-a` / `tc-password-a@example.com` / `Password123!` — TC-A3-01 でパスワード変更

**事前状態を持つアカウント**:
- `tc-unverified` / `tc-unverified@example.com` / `Password123!`（`email_verified=0`、TC-A2-03 用）
- `tc-suspended` / `tc-suspended@example.com` / `Password123!`（`banned=1`、TC-A2-04 用）

**新規登録に使うアイデンティティ**:
- ユーザー名: `testuser1`〜`testuser9`（テストケースごとに使い分け）
- メール: `tester+{連番}@example.com`

これらは `.manual-test/2026-05-17/seed.sql` から投入される。実行カテゴリの境界で `.manual-test/2026-05-17/reseed.sh` を回せば初期状態に戻る。

### 事前準備
1. 各テストケースは独立して実行可能とすること。テスト開始前にテストデータを初期状態へリセット（または別アカウント / 別データで実施）すること。**破壊的 TC（改名・削除・メアド変更・パスワード変更）は必ず指定されたスローアウェイアカウントを使う**こと。ベースライン 3 アカウントは絶対に変更しないこと
2. ブラウザのプライベートウィンドウを開く（既存セッションの影響を避けるため）
3. ヘッダーから明示的にログアウト状態であることを確認する
4. `P07 ランディング画面` （`/`）が表示されることを確認する

## TC-A1-01: 新規ユーザー登録（最小入力で成功）

**種別**: 正常系
**目的**: 表示名を省略した最小入力でサインアップから自動ログインまで通り抜けられること

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | `P07 ランディング画面` のヘッダーから「サインアップ」を押す | `P01 サインアップ画面` に遷移する |
| 2 | ユーザー名 `testuser1` / メール `tester+1@example.com` / パスワード `Password123!` を入力（表示名は空のまま）し、利用規約に同意するチェックを ON にして「登録」を押す | 「確認メールを送信しました」案内が表示される |
