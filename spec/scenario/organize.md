# D. 整理

## D1: ディレクトリの作成・リネーム・移動・削除

### 正常系
1. サイドバーのディレクトリツリー上で右クリック / 専用ボタンから「新規ディレクトリ」を作成
2. 名前を入力すると即時に反映される
3. ドラッグ&ドロップでディレクトリを別ディレクトリ配下へ移動
4. リネームは選択 → 名前変更操作で実施。配下ノートのパス表示も追従する
5. 空ディレクトリの削除はそのまま実行、ノートを含む場合は「中身も含めてゴミ箱へ」または「キャンセル」を選ばせる

### 異常系
- 同階層に同名ディレクトリが存在する: エラー
- 自身の子孫ディレクトリへ移動しようとする: エラー
- 禁止文字（`/` など）を含む名前: バリデーションで弾く
- ディレクトリ削除時に配下に公開ノートが含まれる: 公開ノートが非公開化される旨を警告
- 階層が一定の深さを超える: 深さ上限と現在の階層を提示してエラー

## D2: ノートをディレクトリ間で移動

### 正常系
- 一覧画面でノートを選択し、ディレクトリツリーへドラッグ
- 詳細画面で「移動」ボタンからディレクトリを指定
- 複数選択での一括移動も可能

### 異常系
- 移動先が現在地と同一: 操作を無視
- 移動先ディレクトリが削除済み: エラー、移動先を選び直す案内
- 一括移動中に一部失敗: 失敗分の一覧を表示し、再試行可能

## D3: タグの付与・除去

### 正常系
- 詳細画面のタグパネル、または FrontMatter から付与
- 本文中の `#hashtag` は保存時に自動抽出されてタグとしても登録される
- タグ補完（既存タグの候補表示）が効く
- タグの一括リネーム / 削除はタグ管理画面から実行

### 異常系
- 1 ノートあたりのタグ数上限を超過
- タグ名に無効文字
- タグの一括リネーム結果が既存タグと衝突した場合の統合 or キャンセル選択

## D6: タグ管理

### 正常系
1. 設定 or サイドバーから「タグ管理」画面を開く
2. すべてのタグが利用回数とともに一覧表示される
3. タグをクリックすると関連ノート一覧へ遷移
4. リネーム: タグ名を変更すると、参照しているすべてのノート本文中 `#hashtag` と FrontMatter の tags が一括更新される
5. 統合: 別タグへマージできる（重複は自動排除）
6. 削除: タグを削除すると、関連ノートから外される。本文中の `#hashtag` は文字列としては残るが、自動抽出で再登録されないようブラックリスト化される

### 異常系
- リネーム結果が既存タグと衝突: 「統合する / キャンセル」を選ばせる
- 大量ノートに紐づくタグの一括更新中: 非同期ジョブとして進捗表示
- 削除取り消し（数秒以内の Undo）対応

## D4: FrontMatter の編集

### 正常系
- 詳細画面の FrontMatter パネルで構造的に編集（既知キー: title / aliases / created / updated / tags / publish / ...）
- 「生 YAML を編集」モードに切替して直接書ける
- 保存時に schema 検証

### 異常系
- 不正な YAML: パース失敗エラーを行番号付きで表示
- 既知キーの値型違反（例: tags が配列でない）: バリデーションで弾く
- 公開ステータス（publish）を FrontMatter で書き換えると公開状態が即時変化する点を保存前に注意表示

## D5: 内部リンクの作成・追従、バックリンク閲覧

### 正常系
- エディタ中で `[[` を入力するとノートタイトル / ID の補完候補が表示される
- 既存ノートを選ぶとリンクが挿入される
- 存在しないタイトルを入力すると「未作成リンク」として保存され、後で作成可能（クリックで新規作成ダイアログ）
- ノート詳細にバックリンクパネルがあり、自分を参照しているノート一覧を表示
- ノートタイトルを変更すると、ID 参照リンクは自動追従し、タイトル参照リンクは「タイトル変更の伝播」確認後にバルクで書き換え

### 異常系
- 循環リンク: 許容するが、グラフ表示時に視覚的に区別
- リンク先がゴミ箱に入った: 表示時に「ゴミ箱内」表示し、クリックで復元導線を提示
- リンク先がアクセス権限の無い他人のノート: 別ユーザーのノートは内部リンクできない（補完候補にも出さない）
