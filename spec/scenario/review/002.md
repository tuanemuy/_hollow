# シナリオレビュー 002

各カテゴリのシナリオを、チェックリストに従いゼロベースで再評価する。

## 観点別チェック結果

### 網羅性
- account.md: 登録 / ログイン / パスワード / メアド変更 / プロフィール / 削除がそろっている
- ingest.md: 単一 / 一括 / 再生成 / メタデータ修正 / エラー全般 OK
- authoring.md: 新規 / ビジュアル / HTML / メディア / 保存 / 衝突。モード切替もカバー
- organize.md: ディレクトリ / 移動 / タグ / FrontMatter / 内部リンク / タグ管理 全部カバー
- browse.md: 一覧 / 詳細 / 検索 / フィルタ / ビュー / ツリー閲覧 全部カバー
- publish.md: 切替 / 限定公開リンク / 公開ページ / 公開検索 / 認可エラー / 訪問者エクスポート 全部カバー
- export.md: 個別 / 一括 / ジョブ / 退会後挙動 全部カバー
- trash.md: 削除 / 復元 / 完全削除 / 自動パージ 全部カバー
- admin.md: LLM / プロンプト / トークン / 登録制御 / 利用状況 全部カバー

### フローの自然さ
- 主要シナリオはいずれも 3〜6 ステップ内に収まり、迂回は見当たらない

### 異常系
- 認証、リソース不在、権限不足、入力エラー、上限超過、外部依存失敗、競合などはいずれも分散して記述されており抜けは目立たない
- B5 と B1 の異常系で対応外形式の扱いが重複気味だが、B5 が「アップロード前後の防御」の総括として置かれているため許容
- C5 の自動保存衝突と C6 の同時編集衝突は内容が一部重複するが、観点が異なる（後勝ち vs 別タブ警告）ため両方残してよい

### アーキテクチャ・トレーサビリティ
- 全シナリオが idea.md の MVP 決定事項に整合
- ADR 001/002/003/004 と矛盾なし

## 判定

クリーン。修正不要。Phase 2 へ進む。
