# A. アカウント

## A1: 新規ユーザー登録

### 正常系
1. 訪問者がトップページから「サインアップ」を開く
2. ユーザー名（URL に使う一意な識別子）、メールアドレス、パスワードを入力する。表示名は任意（未入力時はユーザー名を流用）
3. 利用規約に同意してサインアップを実行する
4. 登録が完了し、確認メールが送られる
5. メール内の確認リンクを開くとアカウントが有効化され、自動的にログイン状態でホーム（自分のノート一覧）へ遷移する

### 異常系
- ユーザー名がすでに存在する: 入力欄にエラーを表示する
- メールアドレス形式が不正: 即時にエラーを表示する
- パスワードが強度要件を満たさない: 強度要件を提示してエラー表示
- メールアドレスがすでに登録済み: 「ログインするか、パスワード再発行をご利用ください」と案内
- 管理者が新規登録を停止している: サインアップ画面に「現在新規登録は停止中」と表示し、操作不可
- 確認メールのリンクが期限切れ: 再送ボタンを表示し、もう一度送信できる

## A2: ログイン / ログアウト

### 正常系
1. 訪問者がログイン画面を開く
2. メールアドレスとパスワードを入力してログイン
3. ホームへ遷移する
4. 任意のタイミングでヘッダーから「ログアウト」を選択してセッションを終了する

### 異常系
- 認証失敗（メール or パスワード不一致）: 「メールアドレスまたはパスワードが違います」とだけ表示し、どちらが誤りかは明かさない
- アカウント未認証（確認メール未クリック）: 確認メール再送導線を表示
- アカウント停止 / 削除済み: 専用メッセージを表示
- セッション期限切れ: 操作時にログイン画面へリダイレクトし、復帰後の URL を記憶する

## A3: パスワード変更・リセット

### 正常系（ログイン中の変更）
1. 設定 → セキュリティ画面で現在のパスワードと新パスワードを入力
2. 変更完了後、他端末のセッションを失効させるかを選択

### 正常系（パスワードリセット）
1. ログイン画面から「パスワードを忘れた方」を選択
2. メールアドレスを入力
3. 登録済みなら再設定リンクを送る（未登録でも UI 上は同じ案内を出して列挙攻撃を避ける）
4. メール内リンクから新パスワードを設定

### 異常系
- 現在のパスワードが不一致
- リセットリンクの期限切れ
- リセットリンクが既に使用済み

## A4: アカウント設定

### 正常系
1. 設定画面でプロフィール情報を編集（表示名、自己紹介、アバター画像）
2. ユーザー名（URL 識別子）の変更は別タブで明示的に確認後に実施し、過去 URL からのリダイレクト方針を提示
3. 公開プロフィールページのプレビューを確認できる

### 異常系
- ユーザー名が既存と衝突
- アバター画像がサイズ・形式超過
- ユーザー名変更の連続実施を一定期間制限

## A6: メールアドレス変更

### 正常系
1. 設定 → セキュリティ画面で新しいメールアドレスと現在のパスワードを入力
2. 新メールアドレスへ確認リンクが送信される（旧メールアドレスにも変更通知が届く）
3. 確認リンクを開くと変更が確定し、旧メールアドレスではログインできなくなる

### 異常系
- 新メールアドレスが既存ユーザーと衝突
- 確認リンク期限切れ: 設定画面から再送可能
- 旧アドレスを失っており通知が届かない: 不正変更時は管理者へ問合せ可能と明記
- 同じメールへの変更を連発: レート制限

## A5: アカウント削除

### 正常系
1. 設定 → アカウント削除を選択
2. 削除によって失われるもの（ノート、公開リンク、メディア）を明示する確認画面を表示
3. ユーザー名 or 確認語を入力して最終確認
4. 削除を実行し、ログアウト・公開ノートも非公開化される

### 異常系
- 確認入力が一致しない場合は実行不可
- 削除実行中に予期しないエラーが発生した場合は元の状態を維持し、再試行可能であることを伝える
