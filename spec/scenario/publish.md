# F. 公開

## F1: 非公開 ↔ 限定公開 ↔ 公開 の切替

### 正常系
1. ノート詳細 → 「公開設定」を開く
2. 3 つのラジオから選ぶ
   - 非公開（デフォルト）: 本人のみ
   - 限定公開: 共有リンクを知っている人だけ。任意でパスワードを設定
   - 公開: 同一インスタンス内のユーザー名ネームスペース URL で誰でも閲覧可能、検索対象になる
3. 切替は即時反映。設定保存後にプレビュー URL を表示
4. 公開ステータスは FrontMatter にも書き戻され、整合する

### 異常系
- 限定公開でパスワードが弱い: 強度要件提示
- ノート内に他人のメディア参照（権限なし）が含まれる場合: 公開できない理由を提示
- 公開した直後に下書きを保存しなおして非公開要素が混入: 公開前のセーフティチェック（外部 URL でないメディアリンク、未保存変更の有無）を表示

## F2: 限定公開リンクの発行・パスワード保護・失効

### 正常系
- 限定公開を選ぶとトークン付き URL が生成される
- 任意でパスワードを設定。閲覧者はパスワード入力後に閲覧できる
- リンクは複数発行可能。それぞれ個別に失効・パスワード変更ができる
- リンクごとに最終アクセス日時を確認できる

### 異常系
- 失効済みリンクへアクセス: 「このリンクは無効です」と表示
- パスワード総当たり防止のため、失敗回数で一時的にロック
- リンク発行数上限超過
- パスワードを失念した訪問者にはオーナーが連絡する必要がある。オーナーは公開設定画面からリンクのパスワードを再設定 / 失効可能（過去のパスワードは保存せず、新規発行のみ）

## F3: 公開ページからの閲覧

### 正常系
- 訪問者は `/<username>` でユーザーの公開ノート一覧ページにアクセス
- `/<username>/<note-slug>` で個別ノートを閲覧
- 公開ページにも一覧表示切替（リスト / タイル / カレンダー）とフィルタを用意（公開ノートのみが対象）
- バックリンク表示も公開ノート同士のみで構築
- 訪問者（未ログイン）は個別の公開ノートを HTML / Markdown / PDF でエクスポート可能。一括エクスポートはログインユーザーのみ（レート制限・容量上限の管理対象とするため）

### 異常系
- 存在しないユーザー名 / スラッグ: 404
- ユーザー名変更後の旧 URL: 一定期間 301 リダイレクト
- アカウント削除後の URL: 410 Gone
- ユーザーがノートを非公開化: 404 ではなく 410 Gone（リンク切れの事実を訪問者に伝える）

## F4: 公開ノートの全文検索（外部訪問者）

### 正常系
- 公開ページのヘッダーに検索ボックス
- 同一インスタンスの公開ノート全体を横断検索する公開検索
- ユーザー指定（`/<username>` 内のみ）での絞り込みも可能
- 検索結果のレンダリングは公開ページのレイアウトを踏襲

### 異常系
- レート制限超過: 静的な再試行案内を表示（API 詳細は出さない）
- 不適切な内容のノートが検索結果に出る場合の通報導線（MVP 範囲外、将来拡張のため UI 余地のみ残す）

## F5: 認可エラー

### 正常系
- アクセス権のないユーザーに対しては 403 / 404 を返す（404 を優先し、存在を漏らさない）

### 異常系
- 限定公開ノートのトークン URL を別ユーザーが共有し、パスワードを知らない: パスワード画面で止まる
- ログイン中の他ユーザーが直接 API 経由で他人ノートを参照しようとする: 403
- 限定公開だがトークン無しで `/<username>/<slug>` にアクセス: 404 を返す（公開のみ閲覧可能 URL のため）
