# E. 閲覧・検索

## E1: ノート一覧をリスト / タイル / カレンダー切替で閲覧

### 正常系
- サイドバーに自分のディレクトリツリーが常駐し、ディレクトリをクリックするとその配下のノート一覧が表示される（ルート選択ですべてのノート）
- デフォルトはリストビュー
- 画面右上の表示形式切替で「タイル」「カレンダー」へ切替可能
- リスト: タイトル・更新日時・タグ・ディレクトリ・公開状態
- タイル: サムネイル（最初の画像 or LLM 生成プレースホルダ）+ タイトル + 要約
- カレンダー: 月表示。基準日（既定: 更新日、選択可で作成日 or FrontMatter date）でドットを置く
- 切替・並び順・絞り込みは URL に反映されシェア可能

### 異常系
- ノートが 0 件: ガイダンスとアップロード / 新規作成への CTA を表示
- カレンダー表示で基準日キーが欠落しているノート: 「日付不明」列にまとめて表示
- ビューの計算（サムネイル等）が間に合わない: プレースホルダで表示しつつバックグラウンドで更新

## E2: ノート詳細をレンダリング表示

### 正常系
- ノートの HTML をデフォルトスタイル（GitHub Markdown 風）+ デザイントークンで装飾して表示
- 装飾済み HTML はそのスタイルを尊重し、デフォルトの上書きを抑える
- メタ情報パネル（作成日 / 更新日 / タグ / バックリンク / 公開状態）が右側に表示される
- 詳細から「編集」「移動」「公開設定」「エクスポート」「削除」が可能

### 異常系
- ノートが存在しない / 削除済み / 権限なし: 404 / 403 ページへ
- HTML レンダリングで例外: 安全モード（プレーンテキストフォールバック）で表示

## E3: 全文検索

### 正常系
- ヘッダー検索ボックスでキーワード入力、即時に候補を提示
- 検索結果ページではキーワードハイライト + ファセット（タグ / ディレクトリ / 期間 / 公開状態）で絞り込める
- N-gram（trigram）ベースの部分一致 + メタデータ（タイトル / タグ）を優先するランキング

### 異常系
- 検索エンジンがビジー / 一時失敗: バックエンドエラーは握りつぶさず、再試行可能なメッセージを表示
- 0 件ヒット: 推奨検索語・近いタグの提案
- 検索クエリ長過大: 切り詰めて警告
- クエリ短すぎ（全トークンが 3 Unicode codepoint 未満）: trigram 索引では拾えないため、host テーブルを直接 LIKE 部分一致（title / body_plain / tag_names_json 対象）で代替検索する。bm25 ランキング・ハイライトは無く、note_id 安定ソート・body 先頭抜粋になる

## E4: タグ・内部リンク・ディレクトリでの絞り込み

### 正常系
- 一覧画面のフィルタバーで「タグ」「ディレクトリ」「内部リンクで参照しているノート」「期間」を AND 指定
- タグはチップ表示、クリックで除外切替（- 指定で除外）
- 内部リンクフィルタ: 指定ノートを参照しているノートを引ける

### 異常系
- フィルタ結果 0 件: 適用中フィルタを 1 件ずつ外す導線を出す
- 不正なタグ / 削除済みディレクトリを参照する URL を開いた: フィルタを自動で外し、警告を表示

## E5: ビューとして保存・呼び出し・削除

### 正常系
- フィルタ + 並び順 + 表示形式 + 基準日キーの組み合わせを名前付きビューとして保存
- ビュー一覧から呼び出し / 編集 / 削除可能
- 既定ビュー（保存していないがアプリ起動時に開かれる）の指定が可能
- 公開ビュー（公開ノートのみを対象としたビュー）と個人ビューは別管理

### 異常系
- ビュー名重複: リネームを促す
- ビューが参照するタグ / ディレクトリが削除された: ビュー側に「壊れた条件」マークを付け、開いた時に該当条件を外せる
