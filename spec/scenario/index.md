# 利用シナリオ一覧

Hollow を利用者視点で操作する代表シナリオを、カテゴリーごとに整理する。
各カテゴリーの詳細は同階層の `${category}.md` を参照。

## カテゴリー

### A. アカウント
ユーザー登録・ログイン・アカウント設定を扱う。
→ [account.md](./account.md)

- A1: 新規ユーザー登録
- A2: ログイン / ログアウト
- A3: パスワード変更・リセット
- A4: アカウント設定（ユーザー名・表示名・公開プロフィール）
- A5: アカウント削除

### B. ノート取り込み
ファイルアップロードによるノート生成を扱う。
→ [ingest.md](./ingest.md)

- B1: 単一ファイルをアップロードしてノート化
- B2: 複数ファイルを一括アップロード
- B3: アップロード直後の再生成（LLM 構造化のやり直し）
- B4: アップロード直後のタイトル・保存先ディレクトリ修正
- B5: アップロード失敗・対応外形式・サイズ超過

### C. ノート作成・編集
WYSIWYG 新規作成、既存ノートの編集を扱う。
→ [authoring.md](./authoring.md)

- C1: 空のノートを新規作成（WYSIWYG）
- C2: 既存ノートをビジュアル編集（レンダリング済みテキストノード編集）
- C3: 既存ノートを生 HTML で編集
- C4: 編集中の画像・動画アップロード挿入
- C5: 編集の保存・自動保存・キャンセル
- C6: 同時編集衝突（別タブ・別デバイス）

### D. 整理
ディレクトリ・タグ・FrontMatter・内部リンクによる整理を扱う。
→ [organize.md](./organize.md)

- D1: ディレクトリの作成・リネーム・移動・削除
- D2: ノートをディレクトリ間で移動
- D3: タグの付与・除去
- D4: FrontMatter の編集
- D5: 内部リンクの作成・追従、バックリンク閲覧

### E. 閲覧・検索
一覧・詳細閲覧・検索・ビュー保存を扱う。
→ [browse.md](./browse.md)

- E1: ノート一覧をリスト / タイル / カレンダー切替で閲覧
- E2: ノート詳細をレンダリング表示
- E3: 全文検索
- E4: タグ・内部リンク・ディレクトリでの絞り込み
- E5: フィルタ + 表示形式をビューとして保存・呼び出し・削除

### F. 公開
公開ステータスの切替、限定公開リンク、公開ページからの閲覧・検索を扱う。
→ [publish.md](./publish.md)

- F1: 非公開 ↔ 限定公開 ↔ 公開 の切替
- F2: 限定公開リンクの発行・パスワード保護・失効
- F3: 公開ページ（ユーザー名ネームスペース）からの閲覧
- F4: 公開ノートの全文検索（外部訪問者）
- F5: 認可エラー（権限のないノートにアクセス）

### G. エクスポート
個別・一括エクスポートを扱う。
→ [export.md](./export.md)

- G1: 1 件のノートを HTML / Markdown / PDF でエクスポート
- G2: 検索結果・ディレクトリ単位での一括エクスポート
- G3: エクスポートジョブの進捗確認・失敗時の再試行

### H. ゴミ箱
論理削除と復元を扱う。
→ [trash.md](./trash.md)

- H1: ノートを削除（ゴミ箱に移動）
- H2: ゴミ箱からの復元
- H3: ゴミ箱の完全削除（個別・一括）
- H4: ゴミ箱の自動パージ確認

### I. 管理者設定
LLM API キー設定、カスタムプロンプト、デザイントークン、登録制御を扱う。
→ [admin.md](./admin.md)

- I1: LLM API キーの設定・差し替え
- I2: カスタムプロンプトの設定（インスタンスデフォルト・ユーザー個別）
- I3: デフォルトスタイル / デザイントークンの確認・更新
- I4: 新規ユーザー登録の許可・停止
