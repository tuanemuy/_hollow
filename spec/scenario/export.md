# G. エクスポート

## G1: 1 件のノートをエクスポート

### 正常系
1. ノート詳細 → 「エクスポート」を選ぶ
2. 形式（HTML / Markdown / PDF）と、オプション（FrontMatter を含めるか、画像を埋め込むか / リンクのみか）を選択
3. 生成完了後に即時ダウンロード
4. PDF は HTML レンダリング + 印刷スタイルから生成

### 異常系
- メディア取得失敗（R2 障害）: 失敗箇所をプレースホルダ化して生成、失敗一覧を結果に含める
- 巨大ノートで PDF 生成タイムアウト: 非同期ジョブに切り替え、完了通知
- 未保存変更がある状態でエクスポート: 「最新の保存版を使います」と明示

## G2: 一括エクスポート

### 正常系
1. 一覧画面 / 検索結果から複数選択（または「現在のビュー全件」を選ぶ）
2. 形式を選択。ZIP にまとめてダウンロード
3. ディレクトリ構造を保ったままアーカイブ。FrontMatter は形式に応じて出力
4. 件数が多い場合は非同期ジョブとして実行され、完了後にダウンロードリンクが通知される

### 異常系
- 一括エクスポート中のキャンセル: 部分結果は破棄
- 容量上限超過: 上限を提示し、フィルタ絞り込みを案内
- ジョブが期限切れ: 通知から再実行できる

## G3: ジョブの進捗確認・失敗時の再試行

### 正常系
- エクスポートジョブはユーザーごとのジョブ画面で確認可能
- 進捗、対象件数、所要時間、完了時のダウンロード URL（一時的に有効）を表示
- 失敗ジョブは再試行ボタンを表示

### 異常系
- 同時実行数の上限超過: キュー待ちで表示
- ダウンロード URL を共有された場合のセキュリティ: 認証必須にし、URL を共有しても他人は開けない
- ジョブ完了前にユーザーがアカウントを削除: ジョブはキャンセル扱いとなり、ダウンロード URL も無効化される（既に発行済みの URL も 410 を返す）
