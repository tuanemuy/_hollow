# ADR — Issue #510: design: 各画面の UX 最適化（デザインモック改善）

実装中に下した非自明な設計判断を記録する。確定済みのユーザー決定（plan.md 表）はここでは繰り返さない。

## ADR-001: index.md §2.1 を「ノート詳細=単一カラム」へ改訂（SSOT 変更）

### Status
Accepted

### Context
旧 §2.1 は「ノート詳細系は lg+ で3カラム（サイドバー + 主コンテンツ + 右メタレール）」を定義していたが、実装(#356 ADR-002/003)は既に単一カラム + 本文下メタへ移行済みで、モック/SSOT と矛盾していた（decisions-pending 横断#2）。

### Decision
§2.1 を「2つのレイアウトモード」に改訂し、ノート詳細は単一カラム + 本文下メタ + バックリンクをカード型リスト1箇所に集約する原則に変更。§3 のレスポンシブ・スティッキー記述も整合。`--meta-rail-width` トークンは tokens.md/`app/styles/tokens.css` に残存するため**削除せず「現状未使用」と注記**（SSOT だけ削ると実装と乖離するため）。

### Consequences
- 良い点: 読書集中に資する。実装と SSOT・モックが一貫。P11/P31 が単一カラムで揃う。
- トレードオフ: `--meta-rail-width` が未使用トークンとして残る（将来の右レール用途のため意図的に残置）。

## ADR-002: P14 公開設定はモーダルシェルを維持し body のみ2セクション化

### Status
Accepted

### Context
plan.md は「2セクション構成 + inline 適用」を指示。実装 `PublishSettings/index.tsx` を確認すると、実体は依然 `Dialog`（モーダル）で、その内部が2セクション + inline だった。

### Decision
シェル（modal）は据え置き、モーダル body を実装同様の2セクション（公開ステータス + 限定公開リンク）+ inline 適用に再構成。フッターは「閉じる」のみ。バルク文脈表示は撤去し正本を単一ノートに統一。

### Consequences
- 良い点: 実装の実態（モーダル + 2セクション）と一致。密度過多を回避。
- トレードオフ: なし（plan の意図はモーダルか否かでなく body 構造だった）。

## ADR-003: P17 の state バリアントを「復元先選択」→「完全削除確認」へ

### Status
Accepted

### Context
P17 のモック state バリアントは「復元先ディレクトリ選択モーダル」を描いていたが、実装の復元は `restoreDirectoryId: null` を即時実行し選択モーダルを持たない。一方、完全削除は ConfirmDialog で確認する。

### Decision
見せる状態を「完全削除の確認ダイアログ」（対象再掲 + 「取り消せません」明記 + danger 確定、`role="alertdialog"`）に差し替え。plan の「破壊操作の確認・安全性が伝わる見せ方」に最も資する状態を採用。

### Consequences
- 良い点: 実装挙動と整合し、破壊操作の安全性が伝わる。
- トレードオフ: 復元先選択 UI のショーケースは失われる（実装に無いため妥当）。

## ADR-004: P31 バックリンクは軽量リスト維持（P11 のカード化と差別化）

### Status
Proposed（レビューで P11 との整合を確認する）

### Context
§2.1 改訂で「バックリンクはカード型リスト1箇所に集約」を原則化。P11 はカード型に統一したが、P31（公開ノート）は領域5エージェントが「バックリンク（被リンク=軽量リスト）と関連ノート（カードグリッド）を視覚的に差別化した方が回遊 UX 上有利」と判断し、バックリンクを軽量リストのまま維持した。

### Decision
P31 はバックリンク=軽量リスト、関連ノート=カードグリッドの差別化を維持。ただし §2.1 の「カード型リスト1箇所」原則と P11 の表現と齟齬があるため、**Phase 3 レビューで P11/P31 の整合（カード化に揃えるか、§2.1 の文言を「1箇所に集約」主眼へ緩めるか）を決める**。

### Consequences
- 良い点（差別化維持の場合）: 「参照元」と「他のノート」の意味差が伝わる。
- トレードオフ: P11 と P31 でバックリンク表現が分かれる。§2.1 の文言調整が必要になる可能性。

## ADR-005: P12 の FrontMatter 常時パネルを削除（タブ排他へ）

### Status
Accepted

### Context
P12 モックは WYSIWYG ビューに FrontMatter パネル（`.meta-panel` / `.fm-*`）を常時同居させていたが、確定方針「FrontMatter は常時パネル同居ではなくタブ排他」と矛盾していた。

### Decision
常時同居の FrontMatter パネルを削除し、モードタブ（WYSIWYG/FrontMatter/HTML）の排他切替に一本化。`[[` 補完ポップオーバー（`.link-suggest`）は WYSIWYG 編集補助として残置・再配置。壊れていた `.saved-dot` の CSS ネストも修復。

### Consequences
- 良い点: 確定方針と一致。WYSIWYG ビューが本文集中型に。
- トレードオフ: なし。
