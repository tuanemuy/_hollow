- 初回: PASS 9 / FAIL 6（FAIL はすべてモバイル390px幅の横スクロール、デスクトップは全PASS）
- 修正後: **全PASS**（横スクロール対象7画面すべて overflow=0）

## 検出した不具合と修正（すべて変更箇所起因・即時修正）

横スクロールは index.md §3「ページ全体の横スクロールは絶対に発生させない」違反のため必須修正。原因は2系統:

| 画面 | 390px overflow（前→後） | 原因 | 修正 |
|---|---|---|---|
| P11-note-detail | +70 → 0 | `.layout` グリッド内 `.main` に `min-width:0` 欠落で `<pre>` がトラックを押し広げ | `.main { min-width:0 }` 付与（`<pre>` は既に `overflow-x:auto`） |
| P13a-upload-modal | +70 → 0 | `.grid` `minmax(440px,1fr)` が390px超過 | `minmax(min(440px,100%),1fr)` |
| P13-upload | +19 → 0 | 共通ヘッダー `.header-right` がモバイルで非縮退 | P11 のヘッダー縮退ルール展開 |
| P14-publish-settings | +39 → 0 | 同上 | 同上 |
| P17-trash | +15 → 0 | 同上 | 同上 |
| P18-tags | +23 → 0 | 同上（ボタンが `.btn` 系のため `.header-right .btn span` で縮退） | ヘッダーボタンラベルを隠す（本文 `.btn-xs` ラベルは保持） |
| P20-views | +15 → 0 | 共通ヘッダー由来 | P11 のヘッダー縮退ルール展開 |

## 構造確認（PASS 詳細）

- **P11**: 右メタレール廃止・単一カラム・本文下に「プロパティ + バックリンクカード」。`<pre>` はブロック内スクロール（ページ波及なし）。
- **P21/P24**: 左サイドバーが設定ナビに差し替え、コンテンツ内サブナビ列廃止、モバイルで drawer 化。P24 多段確認フォーム（理解チェック + DELETE 入力 + ユーザー名 + パスワード）表示。
- **P12**: モードタブ + borderless タイトル + ツールバー。FrontMatter 常時パネル廃止。
- **P13**: カード型 + 進捗バー/形式バッジ/保存先。
- **P14**: 2セクション + QR。
- **P17/P18**: DATA_ROW 化。
- **P31**: 単一カラム + 回遊導線。
- **P33**: 解錠後の成功状態カード。
- **P34**: バリアント別アクション（404）。
- **P40/P46**: ヘッダーに検索・通知。
- **P20**: 空状態（破線枠 + アイキャッチ + CTA）。

フォーカスリング/コントラストに明らかな問題なし。
