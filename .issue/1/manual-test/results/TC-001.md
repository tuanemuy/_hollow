## 検出された問題

### 問題: ホーム（`/`）ルートの loader が "System error" を throw（新規 / ブロッカー）

- **症状**: 認証成功後にリダイレクトされる `/?page=1&limit=20` で、route loader（または server function）が例外を throw。presentation 層が `SerializedError { kind: "system", message: "System error" }` にシリアライズしてクライアントへ返却し、`CatchBoundaryImpl` がエラー画面を表示する。
- **再現性**: 100%。ログイン直後・URL 直アクセスのいずれでも同症状。
- **証跡（クライアント console）**:

  ```
  [error] Route error: {message: "System error",
           stack: "Error: System error
              at Object.deserialize (.../client-rpc/serverFnFetcher.js?v=bc3268a7:168:14)"}
  [warning] Warning: Error in route match: //{"page":1,"limit":20}
  [error] The above error occurred in the <MatchInnerImpl> component.
          React will try to recreate this component tree from scratch using
          the error boundary you provided, CatchBoundaryImpl.
  ```

- **影響範囲**: ホーム経由を前提とする全シナリオが BLOCKED。
  - P10 ノート一覧（本 TC）
  - 一覧由来の表示切替・ページネーション・検索・フィルタ
  - ホームから個別ノートへの導線
- **推定原因（要サーバログ確認）**:
  1. ノート一覧取得ユースケースが D1 クエリで失敗（スキーマ不整合 / NULL 制約 / マイグレーション未適用）
  2. `validateSearch` で `display` 未指定時のデフォルト解決に失敗
  3. RSC 側で repository / unit-of-work の DI 解決に失敗
  4. 認証セッションは通過しているがユーザー紐付きデータ取得で例外

  サーバ側 `pnpm dev` の stdout で実スタックトレース確認が必要。
