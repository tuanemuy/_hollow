# TC-001: コピー失敗パス＋アイコン非切替＋a11y

**結果**: PASS
**セッション**: verify-283

## 概要

headless Chrome では `navigator.clipboard.writeText` が権限拒否で reject されるため、素の操作ではコピー失敗パスを通る。これを利用して「失敗時にアイコンが Check に切り替わらない（Link2 のまま）」「a11y 属性が維持される」ことを実観測で検証した。success パスは TC-002 で検証。
