## 前提データ

`<pre>` を含むノートが必要。次のいずれかで用意する：

- 既存ノートで HTML モードに切替え、本文に以下を入力して保存する：
  ```html
  <p>サンプル段落</p>
  <pre><code>function hello() {
    return "world";
  }</code></pre>
  <p>末尾の段落</p>
  ```
- もしくは `<pre>code text</pre>`（`<code>` ラップ無し）のノートも 1 件用意し、両構造をカバーする。

## 確認項目

### 1. `<pre><code>` 内テキストのインライン編集

- **目的:** Issue ゴール「inline モードのまま `<pre>`（および内包する `<code>`）のテキストを編集可能にする」を確認
- **手順:**
  1. 上記の `<pre><code>` を含むノートの詳細画面で「編集」を押す（既存ノートは inline モードで開く）
  2. コードブロック内の文字（例 `"world"` の `world`）にカーソルを置いて文字を追加・削除する
- **期待結果:**
  - コードブロック内のテキストが編集できる（カーソルが入り、入力が反映される）
  - 段落・見出しなど他のブロックの編集も従来どおり動く
  - 保存ステータスが「保存中 → 保存済み」と更新される
- **確認ポイント:** `<pre>` がモノスペース・背景付きの体裁（読み取り専用ビューと同じ）を保ったまま編集できること

### 2. `<pre>` 内での改行入力（Enter）

- **目的:** ADR-002「`<pre>` 内の `Enter` はリテラル `\n` 挿入」を確認
- **手順:**
  1. コードブロック内の任意の行末にカーソルを置く
  2. `Enter` を押す
  3. 新しい行に文字を入力する
- **期待結果:**
  - 改行が入り、コードブロックが複数行のまま増える（新しい段落 `<p>` やコードブロック外への離脱が起きない）
  - `<br>` 要素ではなく改行として描画される
- **確認ポイント:** `Enter` でコードブロックの外に新規ブロックが生成されないこと

### 3. 保存後の HTML 反映とモード切替

- **目的:** 編集結果が正しい HTML として保存され、`contenteditable` 属性が漏れないことを確認
- **手順:**
  1. 確認項目1・2の編集後に「保存」を押す
  2. ノート詳細（読み取り専用ビュー）に戻り、コードブロックの表示を確認する
  3. 再度「編集」→ モード切替で「HTML を編集」に切替え、生 HTML を確認する
- **期待結果:**
  - 読み取り専用ビューで編集後のコードが正しく表示される（改行・追加文字が反映）
  - HTML モードのソースに `contenteditable` 属性が含まれない
  - `<pre><code>...</code></pre>` の構造が保たれている
- **確認ポイント:** 保存された HTML に編集者専用の `contenteditable` が漏れていないこと

### 4. `<pre>code</pre>`（`<code>` ラップ無し）の編集

- **目的:** `<pre>` 直下テキスト構造でも編集できることを確認
- **手順:**
  1. `<pre>code text</pre>` のノートを inline モードで開く
  2. テキストを編集し、`Enter` で改行する
- **期待結果:** `<pre><code>` と同様に編集・改行できる

## エッジケース・異常系

### 1. `<pre>` 内の構造を壊す操作はロールバックされる

- **目的:** 構造保持の不変条件（Issue #233 ADR-003）が `<pre>` でも維持されることを確認
- **手順:**
  1. コードブロック内のテキストを全選択して `Delete`、または装飾要素境界を跨ぐ削除を試みる
- **期待結果:** コードブロックの構造（`<pre>`/`<code>` タグ）自体は壊れない。テキスト編集は反映されるが、タグの削除・入れ替えは起きない（必要なら `html` モードへ誘導）

### 2. IME（日本語入力）でのコードブロック編集

- **目的:** IME 確定後に構造ドリフト誤検出でロールバックされないことを確認
- **手順:**
  1. コードブロック内で日本語をかな漢字変換して入力・確定する
  2. 改行を含む入力も試す
- **期待結果:** 変換確定後もテキストが正しく残り、コードブロックが消えたり巻き戻ったりしない

## 既存機能への影響確認

- **`<pre>` を含まないノートの inline 編集**: 段落・見出し・リスト・引用・テーブルの編集が従来どおり動くこと（Enter で新規ブロックが生成されないこと）。
- **ペースト**: コードブロック内外でテキストをペーストしても構造が変わらず、プレーンテキストとして挿入されること。
- **disabled 状態**: 編集ロック取得失敗などで disabled になったとき、`<pre>` も編集不可（contenteditable が外れる）になること。

- [ ] 保存後の読み取り専用ビューに編集結果が反映される
- [ ] 保存 HTML に `contenteditable` が漏れていない
- [ ] `<pre>code</pre>`（code ラップ無し）も編集できる

- [ ] `<pre>` を含まないノートの編集・既存ブロックの挙動に回帰がない
