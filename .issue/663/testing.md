# 動作確認計画 — Issue #663: pnpm start でジョブ型エクスポートが完走しない

**Issue:** #663
**作成日:** 2026-06-13

---

## 確認環境

### 検証環境の起動

```bash
pnpm build && pnpm start
```

### デプロイ方法

なし（ローカル dev 環境の変更のみ）

---

## 確認項目

### 1. pnpm start でジョブ型エクスポートが完走する

- **対応する受け入れ基準:** AC-001
- **目的:** `pnpm start` 時に `InlineRelayTrigger` が有効になり、ジョブ型エクスポートが処理されることを確認する
- **手順:**
  1. `pnpm build && pnpm start` でサーバーを起動する
  2. ブラウザで `http://localhost:8787` にアクセスしてログインする
  3. ノートを作成し、エクスポート（ジョブ型 — 複数ノートまとめてエクスポートするシナリオ）を実行する
  4. エクスポートが「処理中」のまま止まらずに「完了」になることを確認する
- **期待結果:** エクスポートジョブが最終的に完了し、ダウンロードリンクが表示される
- **確認ポイント:** サーバーログに `InlineRelayTrigger` 関連のログが出ていること（`[inline-relay]` 等）

### 2. pnpm dev の動作に変化がない

- **対応する受け入れ基準:** AC-002
- **目的:** `pnpm dev`（Vite 経路）が引き続き `InlineRelayTrigger` を使えることを確認する
- **手順:**
  1. `pnpm dev` でサーバーを起動する
  2. 同様にエクスポートを実行し、完走することを確認する
- **期待結果:** 変更前と同じ動作

## エッジケース・異常系

### 1. staging/production toml に IS_LOCAL_DEV が含まれないことを確認

- **目的:** デプロイ環境に `InlineRelayTrigger` が混入しないことを確認する
- **手順:**
  1. `grep IS_LOCAL_DEV wrangler.staging.toml wrangler.production.toml` を実行する
- **期待結果:** 何も出力されない（0 件）

## 既存機能への影響確認

- ジョブ型でないエクスポート（同期エクスポート）が引き続き動作することを確認する
