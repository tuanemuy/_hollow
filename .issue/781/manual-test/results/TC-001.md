# TC-001: 連続矢印キーでフォーカス保持（コア / AC-1）

結果: PASS

環境: http://localhost:5176/tags（dev-admin 認証済み、タグ34件表示）

## 手順と生データ

| ステップ | 操作 | activeElement (tag/role/text/aria-checked) | location.search |
| --- | --- | --- | --- |
| 初期 | checked radio に focus | BUTTON / radio / "名前" / true | "" |
| 1 | ArrowRight #1 | BUTTON / radio / "ノート数" / true | ?sort=noteCount |
| 2 | ArrowRight #2（再フォーカスなし） | BUTTON / radio / "作成日時" / true | ?sort=createdAt |
| 3 | ArrowLeft（逆方向、再フォーカスなし） | BUTTON / radio / "ノート数" / true | ?sort=noteCount |

## 判定

- 1回目・2回目とも sort クエリが1段ずつ変化（名前 → noteCount → createdAt）。**2回目の ArrowRight は無視されず、sort が2段変化した。**
- 各押下後、activeElement は role=radio かつ aria-checked=true の選択中 radio に保持されていた（body に脱落していない）。
- ArrowLeft（逆方向）でも1段戻り（createdAt → noteCount）、focus は選択中 radio に保持。

フォーカス保持・連続操作・双方向ともに agent-browser 上で明確に観測できた。
