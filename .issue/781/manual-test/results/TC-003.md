# TC-003: ホーム表示モード segmented の後方互換（AC-3）

結果: PASS

環境: http://localhost:5176/（dev-admin 認証済み、同セッション cookie 維持）

対象: 表示形式 radiogroup（aria-label="表示形式"、radio 3つ: リスト/タイル/カレンダー、アイコンのみ）

## 手順と生データ

| ステップ | 操作 | activeElement (role/label/aria-checked) | location.search | radiogroup checked 状態 |
| --- | --- | --- | --- | --- |
| 初期 | checked radio に focus | radio / "リスト" / true | - | [true, false, false] |
| 1 | ArrowRight | radio / "タイル" / true | ?display=tile | [false, true, false] |

## 判定

- 従来どおり矢印キーで切替でき（リスト → タイル）、focus は選択中 radio に保持。
- client-only の表示モード切替で挙動差分なし。後方互換が保たれている。
