なし（検証環境のみで確認できる）。

## 確認項目

### 1. ランディングページのロゴ（未ログイン）

- **目的:** ランディングのヘッダー / フッターのロゴが Vesica ロックアップで表示される。
- **手順:**
  1. 未ログイン状態で `/` を開く（ランディングが表示される）。
  2. ヘッダー左のロゴを確認。
  3. ページ最下部フッターのロゴを確認。
- **期待結果:** Vesica マーク + lowercase「hollow」ロックアップが表示される。テキスト「Hollow」ではない。
- **確認ポイント:** ロゴのリンク先が維持されている（クリックで `/` へ）。高さがヘッダー内で崩れていない。

### 2. 認証画面のロゴ

- **目的:** 認証ヘッダーのロゴがロックアップで表示される。
- **手順:**
  1. `/login` を開く。
  2. ヘッダー左のロゴを確認。
- **期待結果:** Vesica ロックアップが表示される。
- **確認ポイント:** 右側「ログイン」リンクとのレイアウトが崩れていない。

### 3. アプリヘッダーのロゴ（ログイン後）

- **目的:** ログイン後のアプリヘッダーのロゴがロックアップで表示される。
- **手順:**
  1. シードした管理者でログインする。
  2. ホーム（`/`）のヘッダー左ロゴを確認。
  3. ウィンドウ幅を狭め（`max-sm`）、ロゴの表示/非表示挙動が従来どおりか確認。
- **期待結果:** Vesica ロックアップが表示される。`max-sm:hidden` の挙動が維持される。
- **確認ポイント:** 検索ボックス・右側アクションとのレイアウトが崩れていない。

### 4. 公開ページのロゴ（ヘッダー + フッター）

- **目的:** 公開レイアウトのヘッダー / フッターのロゴがロックアップで表示される。
- **手順:**
  1. 公開ノート or 公開トップ（例: `/u/{ユーザー}` や `/search`）を開く。
  2. ヘッダー左ロゴ・フッターロゴを確認。
- **期待結果:** Vesica ロックアップが表示される。
- **確認ポイント:** フッターのレイアウト・リンク並びが崩れていない。

### 5. テーマ追従（light / dark）

- **目的:** ロゴが `currentColor` でテーマ色に追従する。
- **手順:**
  1. OS / ブラウザのカラースキームを light → dark に切り替える。
  2. 上記各ロゴの色を確認。
- **期待結果:** マーク・wordmark ともにテキスト色（`text-ink`）に追従し、light/dark で視認できる。

### 6. OG 画像の確認（実装変更なし・確認のみ）

- **目的:** OG 画像が新ブランド（Avenir Next アウトライン）で表示される。
- **手順:**
  1. `public/og-image.png` をプレビューで開く、またはページの `og:image` / `twitter:image` メタを確認。
  2. ページ個別の `ogImage` override がデフォルト（Vesica 版）から逸脱していないか `app/core/presentation/head.ts` の `DEFAULT_OG_IMAGE_PATH` 参照状況を確認。
- **期待結果:** Vesica + 「hollow」(アウトライン) の OG 画像が表示される。

## エッジケース・異常系

### 1. スクリーンリーダー / アクセシビリティ

- **目的:** SVG ロゴの accessible name が適切で、重複読み上げがない。
- **手順:** ロゴ要素のアクセシビリティツリーを devtools で確認。
- **期待結果:** ロゴが「hollow」として1度だけ読まれる（`Link` と SVG で aria が重複しない）。

## 既存機能への影響確認

- ロゴのリンク遷移（各ヘッダー/フッター → `/`）が従来どおり動作する。
- ヘッダーの検索ボックス・アクションボタンのレイアウトに影響がない。
- 文章中の「Hollow」表記（コピー文・コピーライト）は変更されていない。
