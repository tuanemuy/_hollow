# TC-01 /views に AppShell が付く

**結果: PASS**

認証済みセッション（admin）で `/views` にアクセスし、AppShell（Header/Sidebar）の付与と URL・search param 保持を確認した。

| # | 操作 | 期待 | 実際 | 判定 |
|---|------|------|------|------|
| 1 | `/views` を open | Header（サイト名/検索/ユーザーメニュー）が表示 | `banner` に link "Hollow"、searchbox "ノート検索"、button "Dev Admin のメニュー" を確認 | PASS |
| 2 | 同上 | Sidebar（ナビ一覧）が表示 | `complementary "サイドバー"` に「すべてのノート」「保存ビュー」「タグ」「ゴミ箱」「エクスポートジョブ」「アップロード」を確認 | PASS |
| 3 | URL 確認 | `/_app` プレフィックスが付かない | `http://localhost:3000/views?kind=personal`（既定 kind が正規化付与されただけ。`/_app` なし） | PASS |
| 4 | `/views?kind=public` を open | kind=public が保持・エラーなく描画 | URL `http://localhost:3000/views?kind=public`、banner/sidebar/heading「保存ビュー」描画、エラーなし | PASS |

メインコンテンツは heading「保存ビュー」、個人ビュー/共有ビューのセクション（各 0 件）が AppShell 内に描画された。
