# TC-06 SPA 遷移で AppShell 保持

**結果: PASS**

`/`（ホーム）から Sidebar/ユーザーメニューのリンクを **クリック**して SPA 遷移し、各遷移で AppShell（Header/Sidebar）が保持されることを確認した（フルリロードではなくクライアントナビゲーション）。

| # | 遷移 | 操作 | 期待 | 実際 | 判定 |
|---|------|------|------|------|------|
| 1 | `/` → `/views` | Sidebar「保存ビュー」をクリック | AppShell 保持・コンテンツ差し替え | URL `/views?kind=personal`、banner＋sidebar 保持、heading「保存ビュー」 | PASS |
| 2 | `/views` → `/exports` | Sidebar「エクスポートジョブ」をクリック | 同上 | URL `/exports?offset=0`、banner＋sidebar 保持、heading「エクスポートジョブ」 | PASS |
| 3 | `/exports` → `/tags` | Sidebar「タグ」をクリック | 同上 | URL `/tags`、banner＋sidebar 保持、heading「タグ管理」 | PASS |
| 4 | `/tags` → `/settings/profile` | ユーザーメニュー →「設定」をクリック | 同上 | URL `/settings/profile`、banner＋sidebar 保持、heading「プロフィール設定」 | PASS |

すべての遷移で `banner`（Header）と `complementary "サイドバー"`（Sidebar）が消えずに保持され、main 内のコンテンツのみが差し替わった。クリック遷移（href ナビゲーション）が成立しているため SPA 遷移として有効。
