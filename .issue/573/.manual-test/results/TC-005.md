# TC-005: パスワード再検証 — 誤パスワード（AC-1）

- Issue: #573 (P24 アカウント削除強化)
- 種別: 非破壊（削除されない）
- セッション: verify-573-d
- 実行日時: 2026-06-14

## 結果: PASS

## 手順と観測

1. `dev-login@example.com` / `DevPassw0rd!2024` でログイン → `/` へ遷移
2. `/settings/account-delete` を開く
3. 同意チェック ON / 確認語 `DELETE` / ユーザー名 `dev-login` / パスワードに**誤った** `WrongPassw0rd!9999` を入力
4. 入力完了で「アカウントを完全に削除する」ボタンが有効化（`is enabled` => true）
5. ボタンを押下

## 確認

- URL は `http://localhost:3000/settings/account-delete` のまま（**画面非遷移**）
- フォーム内に認証エラー由来の alert が表示:
  - `alert` > StaticText "Current password is incorrect"
- 削除フォーム（heading「アカウント削除」、ボタン「アカウントを完全に削除する」）が引き続き表示されている
- アカウントは削除されていない（次の TC-006 で正パスワードによる削除が成功することから、本 TC 時点で未削除を裏付け）

## PASS 条件

誤パスワードで削除されず、フォーム内エラー表示・画面非遷移 → 満たす。
