# TC-002: 多段確認 UI の構成（AC-6）

**結果: PASS**

影響リストの下に step-num 付き 3 ステップが順番に並び、各入力要素が揃っていることを確認した。

| ステップ | 番号 | 内容 | 入力要素 | 判定 |
| --- | --- | --- | --- | --- |
| ① 同意 | "1" | 「上記のすべてにアクセスできなくなり、復元できないことを理解しました。」 | `input[type=checkbox]` | PASS |
| ② DELETE 入力 | "2" | 「確認のため DELETE と入力してください」 | `input[type=text]`（placeholder `DELETE`） | PASS |
| ③ ユーザー名 + パスワード | "3" | 「ユーザー名 dev-login を入力してください」「現在のパスワード」 | `input[type=text name=confirmation]` + `input[type=password name=currentPassword]` | PASS |

## 確認ポイント

- step-num "1"/"2"/"3" が各ブロックの先頭に表示され、順序どおり。
- 検出した入力要素（検索ボックスを除く）: checkbox / text(placeholder=DELETE) / text(name=confirmation) / password(name=currentPassword)。4 入力すべて存在。
- 「本人確認のため、ユーザー名とパスワードの両方が必要です。」の補足文ありで構成が明確。
