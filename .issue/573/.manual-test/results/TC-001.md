# TC-001: 影響リストの実データ表示（AC-4/5/8）

**結果: PASS**

`/settings/account-delete` の alert 領域に表示された影響リストを実測値と照合した。

| 項目 | 期待 | 実際の表示 | 表現種別 | 判定 |
| --- | --- | --- | --- | --- |
| 所有ノート(active) | 3 件 / 非断定（アクセス不可系） | 「**3 件**のノート（本文・タグ・ディレクトリ構造を含む）にアクセスできなくなります」 | 非断定（アクセス不可） | PASS |
| 添付メディア | 1 件 / 約120KB(123456B) / 非断定 | 「アップロード済みメディア**1 件 / 121 KB**（画像・PDF・音声など）にアクセスできなくなります」 | 非断定（アクセス不可） | PASS |
| 公開中ノート | 約 1 件 / 410 Gone 断定 | 「公開中のノート 約 **1 件**は公開停止され、公開 URL は **410 Gone** を返すようになります」 | 断定 | PASS |
| 限定公開リンク | 1 本 / 失効断定 | 「発行済みの限定公開リンク**1 本**はすべて失効します」 | 断定 | PASS |
| エクスポート + saved view/prompt | 包括表現・個別件数なし | 「進行中のエクスポートジョブはキャンセルされます。保存ビュー・カスタムプロンプトなどアカウントに紐づくデータも利用できなくなります」 | 包括（件数なし） | PASS |
| 復元不可 | 「復元はできません」 | 「削除後のデータ復元は**できません**」 | 断定 | PASS |

## 確認ポイント

- 件数が実測値 3/1/1/1 と完全一致。
- メディア容量: 123456 バイト → 「121 KB」と人間可読表示（123456/1024 ≈ 120.56 KiB → 121 KiB 丸め）。約120KB 範囲内で妥当。
- ノート・メディアは物理削除を断定せず「アクセスできなくなります」系で虚偽表示なし。
- 公開停止/410 Gone・リンク失効・export キャンセルは断定表現。saved view/custom prompt は包括表現で個別件数を出していない。

虚偽表示の懸念なし。
