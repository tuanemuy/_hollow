# TC-004: 確認語の大文字小文字・前後空白（エッジケース3）

**結果: PASS**

ページをリロードして状態リセット後、同意 check + username `dev-login` + 正パスワードを入力した状態で、確認語のみを変えてボタン有効化を確認した。**削除ボタンは押していない（非破壊）。**

| 確認語入力 | button.disabled | 期待 | 判定 |
| --- | --- | --- | --- |
| `Delete`（大小混在） | true | 有効化されない | PASS |
| ` DELETE `（前後空白） | true | 有効化されない | PASS |
| `DELETE`（厳密一致・サニティ） | false | 有効化される | PASS |

## 確認ポイント

- `DELETE` 以外（大小違い・前後空白付き）では有効化されない＝厳密一致のみ通る。
- サニティチェックで `DELETE` 入力時のみ有効化されることを確認（ゲートが正しく機能）。
- **削除ボタンは押していない。**
