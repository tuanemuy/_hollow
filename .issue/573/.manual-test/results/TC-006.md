# TC-006: 削除成功 → 即時ログアウト → 遷移（AC-2/7）

- 種別: 破壊（実削除 — dev-login を soft-delete）
- セッション: verify-573-d
- 実行日時: 2026-06-14

## 結果: PASS

## 手順と観測

1. TC-005 の続き（同セッション・同ページ `/settings/account-delete`）で、パスワード欄を
   誤値からクリアし、正しい `DevPassw0rd!2024`（16文字）に修正
   - マスク表示が 16 ドットになり、正値であることを確認
   - 「アカウントを完全に削除する」ボタンは有効（`is enabled` => true）
2. ボタンを押下 → 削除実行

## 確認

- 削除後、`http://localhost:3000/`（ホーム）へ遷移（`get url` で確認）
- その後、保護ルート `/settings/profile` に手動アクセス（`open`）
  - URL は `/settings/profile` に留まらず `http://localhost:3000/` へリダイレクト
  - ホームは未認証ランディング状態（"ログイン" / "アカウント作成" / "無料でアカウント作成" の
    CTA リンクが表示。認証済みナビは消失）
- => 即時ログアウトが observable。削除済みユーザーで保護ルートへ到達不可。

## PASS 条件

削除後ホームへ遷移し、保護ルート再訪で未認証リダイレクト（即時ログアウトが observable）→ 満たす。

## 補足

AC 文言「ログイン画面等へリダイレクト」に対し、本プロジェクトの auth-guard は保護ルートを
ホーム `/`（未認証ランディング）へ遷移させる挙動。未認証であることが UI 上明示されており、
保護ルートに到達できない点で即時ログアウトは観測可能。
