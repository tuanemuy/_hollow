# TC-003 自分の行（admin-user）にアクションボタンが出ないこと【本Issueの主眼】

**結果: PASS**

## 操作ログ

| # | 操作 | 結果 |
|---|------|------|
| 1 | `snapshot` で `@admin-user` 行を特定 | 行 ref=e30、ロール「管理者」、状態「アクティブ」|
| 2 | アクション列セルを確認 | `- cell`（ラベルなし・子ボタンなし）|
| 3 | `eval` で DOM のアクションセルを検査 | `actionCellText: ""`, `buttons: []` |

## 根拠

ログイン中ユーザー自身の `@admin-user`（admin@example.com）行のアクション列は**空**で、
「一時停止」「管理者を解除」いずれのボタンも存在しない。

accessibility snapshot 抜粋（自分の行）:
```
- row
  - cell "AD @admin-user admin@example.com" [ref=e30]
  - cell "2026/05/17" [ref=e31]
  - cell "管理者" [ref=e32]
  - cell "アクティブ" [ref=e33]
  - cell            ← アクション列。ラベル無し・button 無し
```

DOM 検査結果（`eval`）:
```json
"@admin-user": { "actionCellText": "", "buttons": [] }
```

他行（例 `@existing-user`）のアクションセルは `buttons: ["一時停止","管理者に昇格"]` を持つのに対し、
自分の行のみ空であることが対比で確認できる。Issue #315 の修正は意図どおり機能している。
