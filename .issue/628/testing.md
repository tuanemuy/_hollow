## 確認環境

このIssueはグローバルヘッダーのレイアウト・CTA序列・モバイル導線の変更（見た目と構造）なので、ローカル開発サーバーをブラウザで開き、デスクトップ幅とモバイル狭幅の両方で目視する。

### 検証環境の起動

```bash
pnpm dev
```

`vite dev`（Cloudflare 設定）でローカル開発サーバーが起動する。manual-test スキル経由の場合は空きポートを自動検出して起動する。ヘッダーは認証アプリシェルのグローバルコンポーネントなので、確認にはログイン状態が必要。

### シードデータ

```bash
pnpm db:apply:local
pnpm seed:dev-admin
```

ローカル D1 にマイグレーションを適用し、開発用管理ユーザーを投入してログインできる状態にする。ノート一覧（P10）と選択モードの確認のため、ノートが数件存在することが望ましい（無い場合は UI から新規作成して用意する）。

### 静的ゲート

```bash
pnpm typecheck && pnpm lint:fix && pnpm format
```

受け入れ基準。実装後に必ず通す。特に `BottomCtaBar` / `BottomActionBar` / 3定数の削除による参照漏れを typecheck で拾う。

### 回帰テスト

```bash
pnpm test
```

NoteList 系（`<BottomCtaBar/>` 除去・BulkActionBar）の非回帰を確認。

### デプロイ方法

なし（ローカル検証環境のみで確認できる）。

## 確認項目

各画面は SSOT である `spec/design/pages/P10-home.html`（デスクトップ）/ `spec/design/pages/mobile/P10-home.html`・`mobile/P13-upload.html`（モバイル）と突き合わせる。

### 1. 検索の物理中央配置（デスクトップ ≥lg）— 課題1

- **目的:** 検索が左右要素幅に依存せずビューポート物理中央に来ること
- **手順:**
  1. ログイン後 P10 を lg 幅以上で開く
  2. ヘッダー中央の検索ボックスがビューポート物理中央にあることを確認
  3. 右CTAの数・幅が変わる画面（設定系など別の認証ページ）へ遷移し、検索の水平位置が動かないことを確認
- **期待結果:** `P10-home.html` の検索配置に追従。左右の中身が変わっても検索が物理中央で安定
- **確認ポイント:** `grid-cols-[1fr_auto_1fr]`（確定案）で左右列が対称配分され、中央が固定されているか

### 2. CTA序列（アップロード主役）（デスクトップ ≥lg）— 課題2

- **目的:** アップロードが最も目立つ主役、新規作成が従に見えること
- **手順:**
  1. P10 を lg 幅以上で開く
  2. ヘッダー右のアップロードが accent/primary の視認性、新規作成がそれより弱い視認性であることを確認
- **期待結果:** 確定案（案2-A/2-B）の序列に追従。視覚的優先度と操作重要度（アップロード ≥ 新規作成）が一致
- **確認ポイント:** 色・サイズ・並び順での序列表現。アイコンのみ/アイコン+ラベルの混在が起きていないか（index.md §7.1）

### 3. モバイルのヘッダー集約（base, 390px）— 課題3

- **目的:** モバイルでヘッダーに 検索+アップロード+メニュー+アバター が常時表示されること
- **手順:**
  1. P10 を 390px で開く
  2. ヘッダーにメニュー・検索・アップロード・アバターが常時表示されることを確認
  3. アップロードをタップして取込導線（#upload）が開くことを確認
- **期待結果:** `mobile/P10-home.html`（確定案）に追従。主要導線がヘッダーで到達可能
- **確認ポイント:** 44px タッチ床（アップロードがアイコンのみの場合も 44×44）

### 4. 下部固定CTA（フッター）廃止（base, 390px）— 課題4

- **目的:** モバイルで下部固定CTAバー（フッター）が消えていること
- **手順:**
  1. P10 を 390px で開き、画面下部に固定CTAバーが無いことを確認
  2. P13（upload）を 390px で開き、同様に下部固定CTA（新規作成+アップロード）が無いことを確認
  3. 最終行が見切れず、下端に過剰な余白が残っていないことを確認
- **期待結果:** `mobile/P10-home.html` / `mobile/P13-upload.html` から `.cta-bar` が除去され、`.main` の余白も cta-bar 分が撤回されている
- **確認ポイント:** フッター消失後のスクロール下端の余白（過不足なし）

## エッジケース・異常系

### 1. 極狭幅 320px / 広め 430px

- **目的:** 受け入れ基準「320〜430px で横スクロールなし」
- **手順:** P10 を 320px と 430px で開き、ヘッダーに menu+検索+アップロード+アバターが収まること、`document.documentElement.scrollWidth <= clientWidth` を確認
- **期待結果:** 両端とも横スクロールが発生しない。検索が `min-w-0` で潰れて他要素と衝突しない

### 2. 選択モード（モバイル）での BulkActionBar 非回帰

- **目的:** cta-bar 廃止が BulkActionBar の挙動に影響しないこと
- **手順:** P10 を 390px で開き、ノートを複数選択して BulkActionBar が下端フルワイドシートで表示されることを確認。選択解除で消えることを確認
- **期待結果:** 選択0件↔1件以上の切替で破綻なし。一括操作（エクスポート/可視性/削除）が従来通り動く
- **確認ポイント:** z-index 整理後も選択モードのフルワイドシート挙動が不変

### 3. デスクトップ非回帰

- **目的:** lg 以上で既存挙動が崩れないこと
- **手順:** 各認証ページを lg 幅以上で開く
- **期待結果:** デスクトップレイアウトが従来通り（中央検索/ヘッダーCTA/sticky中央ピル等）。NoteListToolbar のCTAも従来通り

## 既存機能への影響確認

- **グローバル波及**: ヘッダーは全認証ページに出る。grid列構造変更後、設定系・ノート系すべてでヘッダーが崩れないこと
- **アップロード/新規作成導線**: ヘッダーCTAからの遷移（#upload / 新規作成）が従来通り動くこと
- **NoteListToolbar**: モバイルで Toolbar のCTAが `max-lg:hidden` のまま隠れ、ヘッダーと二重表示にならないこと
- **BulkActionBar**: 一括操作が従来通り動くこと
