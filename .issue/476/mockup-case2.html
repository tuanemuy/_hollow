#476 案2 ― 全フィルターをチップ＋ポップオーバーに統一

タグは従来どおりチップ常時表示。期間・公開状態もチップ化し、押すとポップオーバーで入力。ディレクトリ・内部リンク参照は性質が違う（ツリー／ノート検索由来）ため現状維持＝適用時のみチップ表示。各状態を上から順に並べています。

状態A

初期表示（フィルター未適用）

タグは件数つきチップで一覧。期間・公開状態は破線の「トリガーチップ」。最小限の主張で並ぶ。

状態B

「期間」チップを押した状態（ポップオーバー）

プリセット（よく使う範囲）＋ from/to の日付入力。下部に「クリア／適用」。プリセット選択で2つの date input が連動。

プリセット
範囲指定
–

挙動: プリセットを押すと from/to が自動セット。手で日付を変えるとプリセットの選択は外れる。「適用」または範囲確定で URL の from/to を更新（既存スキーマそのまま）。

状態C

「公開状態」チップを押した状態（単一選択）

select の置き換え。状態色（公開=緑／限定公開=橙／非公開=グレー）のスウォッチ付きで選択。選んだ瞬間に適用＆閉じる。

すべて
非公開
限定公開
公開 ✓

挙動: 単一選択なので選んだ瞬間に visibility を更新してポップオーバーを閉じる。「すべて」を選ぶと解除（visibility=undefined）。

状態D

適用後（チップに値が乗り、×で個別解除）

適用中は darkチップになり値を表示。期間: 6/1–6/30 × / 公開状態: 公開 ×。末尾に全解除。ディレクトリ・内部リンク参照も同じ見た目で並ぶ。

限定公開

一貫性: タグ／期間／公開状態／ディレクトリ／内部リンク参照が、すべて同じ「pill チップ＋×解除」の語彙で並ぶ。トリガー方法だけ違う（タグ＝トグル、期間/公開状態＝ポップオーバー、ディレクトリ＝ツリー、参照＝ダイアログ）。

状態E

モバイル幅（折返し）

チップは自然に折り返す。ポップオーバーは幅いっぱい寄りに開く。むき出しの input/select が無いので縦の圧迫が小さい。
