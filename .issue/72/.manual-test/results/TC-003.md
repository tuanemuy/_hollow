# TC-003: 新規登録ページのスモークテスト

## 目的
Issue #72 の CSS 変更により新規登録ページのレンダリングに崩れが発生していないことを確認する。

## 手順
1. 当初指定された `/register` を開く → **404 を確認**（このプロジェクトの新規登録パスは `/signup` であるため）
2. 実際のパス `/signup` を `verify-tc-003b` セッションで開いて検証
3. `wait --load networkidle`
4. `screenshot .issue/72/.manual-test/screenshots/tc-003b-signup.png`

## 結果
- **判定: PASS（`/signup` で検証）**
- `/register` → 404（既存挙動、本 Issue とは無関係）
- `/signup` → ページタイトル `アカウント作成`
- スクリーンショット:
  - `.issue/72/.manual-test/screenshots/tc-003-register.png` （404 ページ・参考用）
  - `.issue/72/.manual-test/screenshots/tc-003b-signup.png` （実際の登録ページ）

## 観察
`/signup` 上で以下を確認:

- 「アカウント作成」見出し・サブテキストが所定のサイズで表示
- 入力欄（ユーザー名・メールアドレス・パスワード・表示名）が `FIELD_INPUT` 定数のスタイルで描画
- ヘルプテキスト（「英数字とハイフン。後から変更できません。」など）も正常
- 既存の入力値プレースホルダ（`yumenaut`, `you@example.com`, `8文字以上`, `ユメナウト`）が想定通り
- ヘッダのログインリンクも崩れなし

## 備考
タスク指示の `/register` は誤りで、実装上は `/signup`。404 ページ自体も Issue #72 のスタイル変更後に問題なく描画されており、レイアウト崩れはなし。
