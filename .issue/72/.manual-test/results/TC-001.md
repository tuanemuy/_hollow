# TC-001: ランディング (`/`) スモークテスト

## 目的
Issue #72 の CSS 変更によりランディングページのレンダリングに崩れが発生していないことを確認する。

## 手順
1. `agent-browser --session verify-tc-001 open http://localhost:3000/`
2. `wait --load networkidle`
3. `screenshot .issue/72/.manual-test/screenshots/tc-001-landing.png`
4. `eval "window.location.href"` で最終 URL を確認

## 結果
- **判定: PASS**
- 最終 URL: `http://localhost:3000/?page=1&limit=20`（landing がそのまま表示）
- ページタイトル: `TanStack Start Template`
- スクリーンショット: `.issue/72/.manual-test/screenshots/tc-001-landing.png`

## 観察
- ヘッダ（ロゴ「Hollow」/ ナビ「機能」「ログイン」「アカウント作成」ボタン）が正しく配置
- ヒーロー見出し「散らかった頭の中に、静かな置き場所を」が正常表示
- CTA「無料でアカウント作成」「ログイン」のボタンが両方とも所定の角丸・色で描画
- 余白・タイポグラフィに崩れなし
- コンソールエラー等は出力なし（agent-browser 標準出力に警告表示なし）

## 備考
ランディングは未認証時に他パスへリダイレクトされず、`/` のまま表示される（query string は loader による pagination 既定値の付与）。
