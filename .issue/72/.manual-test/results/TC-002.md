# TC-002: ログイン (`/login`) スモークテスト

## 目的
Issue #72 の CSS 変更により `/login` のレンダリングに崩れが発生していないことを確認する。

## 手順
1. `agent-browser --session verify-tc-002 open http://localhost:3000/login`
2. `wait --load networkidle`
3. `screenshot .issue/72/.manual-test/screenshots/tc-002-login.png`

## 結果
- **判定: PASS**
- ページタイトル: `ログイン`
- スクリーンショット: `.issue/72/.manual-test/screenshots/tc-002-login.png`

## 観察
- 認証フォーム全体（メールアドレス・パスワード入力欄、ログイン情報を保存するチェックボックス、ログインボタン、サインアップ導線）が正しく描画
- 入力欄の薄いグレー背景・角丸、ボタンの濃色ピル、リンクの配色など、`FIELD_INPUT` / `BTN_PRIMARY` 等の utility 定数の見た目が崩れていない
- 「パスワードを忘れた方」リンクも所定位置に表示
- レンダリングエラー・レイアウト崩れなし

## 備考
今回の変更は `motion-reduce:` バリアントを既存 utility 定数に追加するのみで、デフォルト（`no-preference`）状態の見た目には一切影響しないという計画通りの結果。
