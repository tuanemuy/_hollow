# TC-004: 生成 CSS の `@media (prefers-reduced-motion: reduce)` 検証

## 目的
Issue #72 の `motion-reduce:` バリアント追加により、ブラウザに配信される CSS に `@media (prefers-reduced-motion: reduce)` ブロックが含まれ、`transition-property: none` と `scale 100%` のオーバーライドが生成されていることを確認する。

## 手順
1. `agent-browser --session verify-css open http://localhost:3000/login`
2. `wait --load networkidle`
3. `eval` で全 stylesheet の cssRules を再帰的に走査し、`prefers-reduced-motion: reduce` を含むルールを収集
4. 主要キーの存在を判定

## 結果
- **判定: PASS**

判定 JS の戻り値（要約）:

```json
{
  "count": 12,
  "hasTransitionNone": true,
  "hasScale100": true,
  "hasAfterTransitionNone": true
}
```

- 期待値 `count >= 3` → **12** で合格
- 期待値 `hasTransitionNone === true` → **true**
- 期待値 `hasScale100 === true` → **true**
- ボーナス: `::after` 疑似要素にも `transition-property: none` が生成されていることを確認（`hasAfterTransitionNone: true`）→ RegistrationForm のトグルスイッチつまみのトランジション抑制が実装されている証跡

## 検出されたユーティリティ例

走査結果には以下のユーティリティが含まれていた:

- `.motion-reduce\:transition-none` → `@media (prefers-reduced-motion: reduce) { transition-property: none; }`
- `.after\:motion-reduce\:transition-none` → `&::after { @media (prefers-reduced-motion: reduce) { transition-property: none; } }`
- `.motion-reduce\:after\:transition-none` → `@media (prefers-reduced-motion: reduce) { &::after { transition-property: none; } }`
- `.motion-reduce\:active\:scale-100` → `@media (prefers-reduced-motion: reduce) { &:active { --tw-scale-x: 100%; --tw-scale-y: 100%; scale: var(...) var(...); } }`
- `.motion-reduce\:active\:scale-100\!` （!important 版、Plan B 用も既に生成済み）
- 既存先行例 `.motion-safe\:animate-pulse` も無傷で存在

## 走査スクリプト

Tailwind v4 では `@media (prefers-reduced-motion: reduce)` がトップレベルではなく `.motion-reduce\:xxx { @media (...) { ... } }` の入れ子ルールとして生成されるため、最初に提供された判定スクリプト（`sheet.cssRules` の直下のみを見るもの）では `count: 0` と誤判定する。
そのため、`cssRules` を再帰的に walk するスクリプトで再評価した。

## 備考
- `window.matchMedia('(prefers-reduced-motion: reduce)').matches` は `false`（OS / ブラウザ既定の `no-preference` のため）
- agent-browser CLI からは Playwright の `emulateMedia` に相当する切替手段がないため、reduce 状態の視覚的検証は本テストの範囲外（testing.md に手順あり、ヒトによる目視確認が必要）
