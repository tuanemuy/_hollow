# TC-005: 期間ファセットの楽観的更新

結果: PASS

実行日: 2026-06-11 / セッション: verify-tc-005 / URL: http://localhost:3001

備考: agent-browser にネットワークスロットリング機能はないため、「クリック直後の eval で checked を読む」方式で楽観的更新を検証した（click と eval を同一バッチで連続実行、間隔は CLI オーバーヘッドの数十ms程度）。ローカル環境のため loader 遅延は小さい。

| # | ステップ | 期待 | 実測 | 判定 |
|---|---------|------|------|------|
| 1 | /search?q=テストキーワード を開く | 8件表示 | 「8 件」表示 | OK |
| 2 | 「フィルター」ボタンでドロワーを開く | dialog "フィルター" 表示、期間ラジオ4種（7日:2 / 30日:4 / 1年:7 / すべて:8） | 表示確認 | OK |
| 3 | 「過去 30 日」ラジオをクリック → 直後 eval で checked 読み取り | クリック直後に checked=true | radio[1].checked=true（他は false）。loader 完了前に反映 | OK |
| 4 | 確定後の状態 | 選択維持・件数・URL 更新 | URL に `&period=30d` 付与、件数 8→4 件、radio checked=true 維持 | OK |
| 5 | ドロワー外への反映 | バッジ・chips | フィルターボタンに「1」バッジ、chip「過去 30 日」＋「過去 30 日 を解除」「すべて解除」ボタン表示 | OK |

最終URL: `http://localhost:3001/search?q=...&limit=20&period=30d`
