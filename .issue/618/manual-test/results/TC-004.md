## eval 実測値

全ケースで同一の結果。

- 内側 input の boxShadow（全5層が完全透明 = 視覚的にリングなし、`focus-visible:shadow-none` が有効）:
  `rgba(0, 0, 0, 0) 0px 0px 0px 0px` × 5
- ラッパー div（`relative min-h-10 border border-hairline bg-bg rounded-md ...`）の boxShadow（focus-within リング1本のみ）:
  `..., oklch(0.371 0 0 / 0.28) 0px 0px 0px 4px`

検証ケース:

1. ユーザー入力欄・クリックフォーカス: input=透明 / wrapper=4pxリングあり
2. ユーザー入力欄・キーボードフォーカス（:focus-visible=true）: input=透明 / wrapper=4pxリングあり
3. タグ入力欄・クリックフォーカス: input=透明 / wrapper=4pxリングあり
4. タグ入力欄・"se" 入力で suggestion listbox 表示中: input=透明 / wrapper=4pxリングあり

## 備考

input の computed boxShadow は文字列 `none` ではなく Tailwind の shadow 変数スタック（全層 `rgba(0,0,0,0) 0 0 0 0`）として解決されるが、全層透明・オフセット/拡散 0 のため視覚的に none と等価。リングはラッパーの 1 本のみで、二重リングは発生していない。
