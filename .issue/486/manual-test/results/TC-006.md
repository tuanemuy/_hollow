# TC-006: モバイル幅での設定サブナビ drawer 表示

- 対象 Issue: #486（設定画面を共通シェルに寄せ、モバイルで設定サブナビを共通 drawer として動作させる）
- 実行日: 2026-06-05
- 環境: dev サーバー http://localhost:3000 / agent-browser セッション `verify-mobile`
- viewport: 390 x 844（`agent-browser set viewport 390 844`、< 1024px）
- 認証: cookie `__Host-session=dev-admin-session-token`（Dev Admin としてログイン）

## 結果: PASS

すべての主要手順が期待どおりに動作。Escape による drawer クローズも確認できた。

## 操作ログ

1. viewport を 390x844 に設定（`set viewport` コマンドが利用可能。`resize` ではなく `set viewport <w> <h>`）。
2. `/settings/profile` を開き networkidle 待機。タイトル「プロフィール — TanStack Start Template」。
   - 初期 snapshot では設定サブナビは main 内に出ておらず、ハンバーガー（button "メニューを開く" expanded=false）に畳まれていることを確認。
   - スクショ: tc006-initial.png
3. ハンバーガー「メニューを開く」をクリック → drawer が開く。
   - snapshot 上で `dialog "サイドバー"` が出現し、その中に `navigation "設定ナビゲーション"` が表示。
   - サブナビは縦リスト（list > listitem）で「プロフィール / セキュリティ / プロンプト / アカウント削除」の 4 項目を確認。
   - ハンバーガーは expanded=true、別途「メニューを閉じる」ボタンが出現。
   - これはライブラリ用 Sidebar ではなく「設定ナビゲーション」であることを aria ラベルで確認。
   - スクショ: tc006-drawer-open.png
4. drawer 内の「セキュリティ」リンクをクリック → `/settings/security` に遷移（get url で確認）。
   - 遷移後 snapshot から `dialog "サイドバー"` が消え、ハンバーガー expanded=false。drawer が自動的に閉じたことを確認。
   - 見出し「セキュリティ設定」を確認。
   - スクショ: tc006-after-nav.png
5. （追加検証）再度ハンバーガーをクリックして drawer を開く（dialog "サイドバー" 再出現を確認）→ Escape キーを押下 → drawer が閉じる（expanded=false、dialog 消滅）を確認。
   - スクショ: tc006-escape-closed.png

## 所見

- 設定サブナビが共通 drawer（オフキャンバス）として正しく動作している。aria ラベルが `設定ナビゲーション` であり、ライブラリ向け Sidebar とは別物であることが明確。
- drawer 内ナビは accessibility tree 上 `dialog "サイドバー"` の中に置かれ、フォーカス管理・閉じるボタン・Escape ハンドリングが揃っている。
- 遷移後の drawer 自動クローズが効いており、モバイル操作のフローとして自然。
- バックドロップクリックは未検証だが、Escape での閉じ動作が確認できたため drawer の閉じ機構は機能していると判断。
