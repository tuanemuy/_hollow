# TC-004: コンテナ幅・padding・sticky が他画面と一致

結果: PASS

## 操作ログ

| ページ | 本文 `<main>` の className |
| --- | --- |
| `/settings/profile` | `px-6 pt-8 pb-20 max-w-[1100px] mx-auto w-full min-w-0` |
| `/tags`（`/notes` は単体ルート無しのため代替） | `px-6 pt-8 pb-20 max-w-[1100px] mx-auto w-full min-w-0` |

両画面とも共通 `APP_MAIN`（`app/components/layout/styles.ts:86`）と完全一致。左右 `px-6`、下 `pb-20`、`max-w-[1100px] mx-auto` で中央寄せ。旧設定画面の可変 px（`lg:px-12`）や `pb-24` は使われていない。AppShell（`app/components/layout/AppShell.tsx:25`）が `<main className={APP_MAIN}>` で本文をラップしており、設定も同じシェルに乗っている。
