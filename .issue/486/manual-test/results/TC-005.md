# TC-005: 他の /_app 画面でライブラリ Sidebar が従来どおり

結果: PASS

## 操作ログ

| 操作 | header | サイドバー内容 |
| --- | --- | --- |
| `/`（ホーム）を開く | あり | ライブラリ / すべてのノート / 保存ビュー / ディレクトリ / 管理 / タグ / ゴミ箱 / エクスポートジョブ / アップロード |
| ホーム → `/settings/profile` | あり | 設定 / プロフィール / セキュリティ / プロンプト / アカウント削除（設定サブナビに切替） |
| 設定 → ホーム（往復で戻る） | あり | ライブラリ / すべてのノート / 保存ビュー / ディレクトリ / 管理 / タグ / ゴミ箱 / エクスポートジョブ / アップロード（ライブラリ Sidebar 復帰） |

ホームではライブラリ Sidebar が表示。設定では設定サブナビに切り替わり、ホームへ戻ると再びライブラリ Sidebar が正しく出る。共通 Header は往復のすべての状態で表示され続け、消えない。
