## 備考

- 項目1のタブ切替時、装飾喪失の確認ダイアログは表示されなかった（本文が段落テキストのみで喪失対象の装飾がないため。仕様どおりの無ダイアログ経路）。
- 項目3について: testing.md の「別タブで同じノートの編集を開くなどして disabled になったとき」という記述に対し、現実装（`NoteEditor.tsx`）にはタブ間・セッション間の編集ロック機構がない。`InlineEditor` の `disabled` prop は保存 transition 中の `isPending` のみで駆動される（`InlineEditor.tsx` の `disabled` effect が `clearEditable(host)` を実行）。そのため本テストは「実際のロック仕様に従う」原則により、(a) 第2セッションでロックが発生しないことの事実確認と、(b) disabled=true 時に `<p><img></p>` を含む全ブロックから `contenteditable` が外れることの検証（本項目の核心の主張）で PASS と判定した。同時編集は last-write-wins であり、これは本 Issue の変更（`InlineEditor.tsx` の decorate ゲート一般化）による回帰ではない。
- 検証中の副次確認: 保存された HTML（読み取り専用ビュー・HTML タブとも）に `contenteditable` は一切漏出していない（AC-4 相当の挙動が WYSIWYG/HTML 経由でも維持）。
