## 問題点（要修正）

問題点ゼロ。

Issue の要件はすべて受け入れ基準に落ちており、基準は（AC-6 を除き）ユニットテスト手順まで具体化された検証可能な形で書かれ、スコープ外の作業の混入もない。以下は精度を上げるための提案に留まる。

## 改善提案（検討推奨）

- **[S-001]** AC-5 の対応ステップ「1, 2」が実際の検証経路とずれている
  - 理由: ステップ2は「既存テストは変更しない（AC-5 は既存テストが pin 済み）」と明記しており、AC-5 の回帰検証が実際に走るのはステップ3（`pnpm test:unit` での既存スイート実行）。現状の表記だと「ステップ2で AC-5 用のテストを書く」と誤読しうる。
  - 提案: AC-5 の対応ステップを「1, 3（既存 `inlineEditor.test.tsx` スイートの green 維持で検証）」に改める。

- **[S-002]** AC-6 の検証方法が「（変更しないことで担保）」のみで、検証アクションが明文化されていない
  - 理由: 「変更がない」こと自体は diff スコープの確認で検証可能だが、受け入れ基準表の建付け上、他の AC と同様に「何をもって合格とするか」が書かれているほうが実装後のセルフチェックが確実になる。ステップ3が挙げる `noteEditorImageButtonWiring.test.tsx` は「ツールバーボタン → file input クリック」の配線しか pin しておらず、wysiwyg 挿入経路（TipTap `setImage`）そのものの検証には弱い。
  - 提案: AC-6 の検証を「(a) diff が `InlineEditor.tsx` とテストファイルのみに閉じていること、(b) `wysiwygEditorImageButton.test.tsx` / `noteEditorImageButtonWiring.test.tsx` が green であること」と明文化し、ステップ3の確認対象テストに `wysiwygEditorImageButton.test.tsx` を加える。

## 良い点

- **現状コードの再調査に基づく問題の再定義が正確。** Issue 起票時の前提（「`<img>` だけのトップレベル要素」）が既に古く、`insertMediaIntoHtml` が `<p>` ラッパ済みであることをテストの pin まで含めて特定し、本当の乖離が `applyEditable` のゲート1箇所であることを突き止めている。Issue の検討事項1を「やる」のではなく「済んでいる」と正しく整理したことで、変更が述語1箇所に閉じた。
- **受け入れ基準が検証手順と1対1で結線されている。** AC-1〜AC-4 はそれぞれステップ2の具体的なテストケース（DOM 操作レベルまで記述）に対応し、AC-5 は既存 pin テストの列挙つき。基準表→ステップ→テストのトレーサビリティが高い。
- **スコープ外の線引きが明示的かつ根拠つき。** 素の `<img>`（発生経路が Issue のゴール外であることまで説明）、`<img>` 削除（ADR-003 #233 の既知制約への帰着）、空 `<p>` のスタイル、wysiwyg/html 経路、spec 同期 — いずれも「なぜ外すか」が書かれており、恣意的な除外がない。
- **ゲート一般化の副産物（空 `<p>`・`<td><img>` 等の decorate 化）を隠さず、テストで pin して意図化している。** 挙動が広がる変更をステップ2-5（空 `<p>` の pin）と真理値表で明示的に固定しており、スコープ拡大が「事故」ではなく「設計判断（ADR-001）」として管理されている。ADR-001 の3案比較（特に案3の「void 要素は contentEditable ホストとして機能しない」という棄却理由）は技術的に正確。
- **ADR-002（キャレット自動配置をしない）で Issue のゴールとの適合を明示している。** 「前後で編集『可能』になる」がゴールであり自動フォーカスは要件外、という切り分けは Issue 本文に忠実。UX 強化を別 Issue に送る判断も resync rebuild の既存設計（ADR-005 #233）と整合する。
- **リスク節が実装時の落とし穴を先回りしている。** O(n²) の計算量評価（rebuild 時のみ・キー入力毎ではない）、rollback 経路・`disabled` トグルとの整合、`<img>` クリック置換時の rollback 挙動まで、4つの `applyEditable` 呼出経路すべてを検討済み。
