# 動作確認計画 — Issue #302: サイドバー「ディレクトリ」セクションの空状態が冗長

**Issue:** #302
**作成日:** 2026-05-30

---

## 確認環境

このIssueの変更を確認するために必要な手順のみ記載。

### 検証環境の起動

```bash
pnpm dev
```

（必要に応じて初回のみ `pnpm db:migrate` でローカル D1 にマイグレーション適用）

### デプロイ方法

なし（検証環境のみで確認できる）。

## 確認項目

### 1. 空状態に CTA ボタンが表示されない

- **目的:** 空状態の `+ ディレクトリを作成` ボタンが削除されていることを確認する。
- **手順:**
  1. ディレクトリが0件のアカウントでログインする（または全ディレクトリを削除する）。
  2. サイドバー左ペインの「ディレクトリ」セクションを見る。
- **期待結果:** `+ ディレクトリを作成` ボタンが表示されず、「まだディレクトリがありません。右上の + から作成できます。」のテキストのみ表示される。
- **確認ポイント:** `+` が縦に2つ並んでいないこと。

### 2. 見出し横の + から作成できる

- **目的:** 空状態でも見出し横の `+` がルート直下作成のエントリーポイントとして機能することを確認する。
- **手順:**
  1. 空状態で「ディレクトリ」見出し横の `+` ボタンを押す。
  2. 開いたダイアログでディレクトリ名を入力して作成する。
- **期待結果:** ルート直下にディレクトリが作成され、ツリーに反映される。

### 3. 階層あり状態が従来どおり

- **目的:** ディレクトリが1件以上ある状態の表示・挙動が変更前と同じであることを確認する。
- **手順:**
  1. ディレクトリが1件以上ある状態でサイドバーを見る。
  2. ノードの展開/折りたたみ、操作メニュー（…）の「子ディレクトリを作成」を試す。
- **期待結果:** 空状態の文言・ボタンは出ず、ツリーと各ノードの操作が従来どおり動作する。

## エッジケース・異常系

### 1. 階層あり → 全削除で空状態へ戻る

- **目的:** ディレクトリを全削除して空状態に戻ったとき、新しい空状態が正しく描画されることを確認する。
- **手順:**
  1. ディレクトリを1件作成し、その後すべて削除する。
- **期待結果:** 空状態のテキストのみが表示され、CTA ボタンは出ない。

## キーボード・スクリーンリーダー確認

- **目的:** 見出し横の `+` が「ディレクトリを新規作成」として読み上げられる既存挙動の維持。
- **手順:** キーボードで見出し横の `+` にフォーカスし、`aria-label` を確認する。
- **期待結果:** 「ディレクトリを新規作成」と読み上げられ、Enter/Space で作成ダイアログが開く。

## 既存機能への影響確認

- 各ノードの操作メニュー（…）「子ディレクトリを作成」が引き続き `createChild` ダイアログを開くこと。
- 見出し横 `+` からのルート作成ダイアログ（`DirectorySidebarSection` 側）が従来どおり動くこと。
