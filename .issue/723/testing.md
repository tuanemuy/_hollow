本 Issue の成果物は静的 HTML デザインモック（`spec/design/pages/P12-editor.html` と `spec/design/pages/mobile/P12-editor.html`）であり、アプリケーションのランタイムやビルドには一切関与しない。確認は各 HTML ファイルをブラウザで直接開くだけで完結する。

### 検証環境の起動

アプリサーバーの起動は不要。ファイルをブラウザで直接開く:

```bash
open spec/design/pages/mobile/P12-editor.html
```

（モバイルモックはデバイス幅を想定しているため、DevTools のレスポンシブモードで幅 375–430px 程度に絞って確認する。）

### デプロイ方法

なし（検証環境＝ブラウザでの静的表示のみで確認できる。ステージング/本番への反映は不要）。

## 確認項目

### 1. 編集モードタブに FrontMatter が無い

- **対応する受け入れ基準:** AC-1
- **目的:** FrontMatter がタブとして残っていないことを確認する。
- **手順:**
  1. デスクトップモックを開き、画面上部の編集モードタブ（`mode-tabs`）を見る。
  2. モバイルモックを開き、同じくモードタブを見る。
- **期待結果:** どちらも `WYSIWYG` / `HTML` の 2 タブのみ。`FrontMatter` タブが存在しない。
- **確認ポイント:** モバイルは以前 `WYSIWYG / FrontMatter / HTML` の 3 タブだった箇所が 2 タブになっていること。

### 2. 本文エディタの下にメタデータ（FrontMatter）編集領域が常設表示される

- **対応する受け入れ基準:** AC-2 / AC-3
- **目的:** FrontMatter エディタが本文の下に常設配置された姿になっているか確認する。
- **手順:**
  1. デスクトップモックを開き、本文エディタ領域を下にスクロールする。
  2. 本文（および内部リンク補完サンプル）の下に「メタデータ」セクション（`fm-panel`）が表示されているか確認する。
  3. モバイルモックでも同様に本文下部を確認する。
- **期待結果:** `aria-label="メタデータ"` の枠付きセクションが常設表示され、内部に
  - `生編集（JSON）` トグルボタン
  - キー/値の行（例: `date` / `description` / `slug` 等）＋各行の `削除` ボタン
  - 末尾に「新しいキー名」入力 ＋ `キーを追加` ボタン
  が揃っている。
- **確認ポイント:** 実装 `FrontMatterEditor.tsx` の構造モード（キー入力は等幅フォント、値入力は通常フォント）と見た目が対応していること。タブ切替に依存せず常に見えること。

### 3. 「別タブ排他」前提のコメントが更新されている

- **対応する受け入れ基準:** AC-4
- **目的:** 古い前提のコメントが残っていないことを確認する。
- **手順:**
  1. `spec/design/pages/P12-editor.html` を開き、`link-suggest` の CSS コメント付近（旧 L651）を確認する。
- **期待結果:** 「FrontMatter は別タブ排他のため…」という排他前提の記述が無い。
- **確認ポイント:** `grep -n "別タブ排他" spec/design/pages/P12-editor.html` が何もヒットしないこと。

### 4. 既存デザイントークンで馴染んでいる

- **対応する受け入れ基準:** AC-5
- **目的:** 新規トークン・浮いたスタイルを持ち込まず既存の視覚言語に馴染んでいるか確認する。
- **手順:**
  1. メタデータ領域のボーダー・背景・角丸・フォントが周囲（`.link-suggest` / `.tag-chip` / `.pill-btn` 等）と一貫しているか目視する。
- **期待結果:** 枠・色・余白が既存要素と調和し、浮いていない。
- **確認ポイント:** `:root` のトークン定義に追加が無いこと（`git diff` で `:root` ブロックが変わっていない）。

## エッジケース・異常系

### 1. HTML の構造破壊がない

- **目的:** モック HTML のタグ対応が壊れていないか確認する。
- **手順:**
  1. ブラウザでモックを開き、レイアウト崩れ（要素のはみ出し・意図しない重なり）が無いか確認する。
  2. 横スクロールがページ全体に発生していないか確認する（特にモバイル）。
- **期待結果:** レイアウトが崩れず、ページ全体の横スクロールが出ない。

## 既存機能への影響確認

- 他ページのモックには影響しない（P12 の 2 ファイルのみ変更）。他モックを開いて回帰が無いことは不要。
- アプリ本体（`app/`）には一切変更が無いため、`pnpm typecheck` / `pnpm build` への影響はない（デザインモックはビルド対象外）。
