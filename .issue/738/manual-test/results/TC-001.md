## 観測値

- provider select（combobox "プロバイダ"）の option は **「OpenAI」と「Deepgram」の2つ**。`get text @e16` の出力も `OpenAI\nDeepgram`。
- 期待どおり OpenAI と Deepgram の2択が表示される → **PASS**。

## 補足（次工程への影響あり）

- 当該環境では provider select が `disabled`、各 option も `disabled`。画面注記に「環境変数 `ADMIN_SPEECH_PROVIDER` で固定されているため変更できません。」とある。
- 同様にモデル欄（textbox "既定モデル" [ref=e21]）も `disabled` で、値は `gpt-4o-transcribe`。注記「環境変数 `ADMIN_SPEECH_MODEL` で固定されているため変更できません。」。
- このため TC-002 のクライアント側 provider 切替（select 操作 → model リセット）は、env 固定により操作不能となる可能性が高い。
