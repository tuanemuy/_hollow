# TC-001: 失効/削除状態の「トップへ戻る」CTA

**結果**: PASS（ただし表示タイミングに注意事項あり）

## 実行ログ

| 手順 | 操作 | 結果 |
| --- | --- | --- |
| 1 | `/share/test-share-revoked-0002` を開く | 初期表示はパスワードゲート（「このノートはパスワードで保護されています」+ 入力フォーム）。STATE3 ではない |
| 2 | snapshot + スクショ（初期＝ゲート） | OK |
| 3 | パスワード欄に任意値を入力し送信（Enter） | サーバが `share_link_revoked` を返却 → STATE3 に切替 |
| 4 | STATE3 を snapshot + スクショ（tc-001-revoked.png） | 「リンクは無効です」見出し + 「リンクが失効しているか、削除された可能性があります。」+「トップへ戻る」リンク。フォームは消失（form count=0） |
| 5 | CTA の href を確認 | `href="/"`（`get attr @e2 href` → `/`） |
| 6 | CTA をクリック | `/` へ遷移（`get url` → `http://localhost:3000/`）、title=`hollow`。tc-001-home.png 取得 |

## 確認できた事実

- STATE3 の CTA は `<Link to="/" data-primary>` で href は `/`。full-width primary スタイル（`GATE_SUBMIT` + `data-primary`）。
- STATE3 ではパスワード入力フォームは描画されない（`isExpiredOrGone` 分岐でフォームを出さない）。
- 見出し「リンクは無効です」、サブテキスト「リンクが失効しているか、削除された可能性があります。」を確認。

## 注意事項（実装挙動）

- revoked リンクは **初回 GET では STATE3 を出さない**。`ShareLinkGate` はクライアントの `useActionState` で、初期 `state.error===null` のためデフォルトでパスワードゲートを描画する。revoked/notFound 判定はサーバの `resolveShareLink` 実行（=フォーム送信）後に返るエラーで初めて発火する（`app/components/public/ShareLinkGate/index.tsx` の `isExpiredOrGone`）。
- そのため STATE3 を観測するには一度フォーム送信が必要。これは実装上の設計どおりであり、CTA・文言・フォーム非表示・href=`/`・トップ遷移はすべて期待どおり。
