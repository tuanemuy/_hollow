## 確認項目

### 1. 既定値が初期表示される（override 無しの状態）

- **目的:** override が一切無い初期状態で、ビルトイン既定値（キー＋値）が全行フォームに表示されることを確認する。
- **手順:**
  1. override が無い状態で `/admin/design` を開く（必要なら「すべてリセット」で空にしてから再読込）
  2. フォームの行を確認する
- **期待結果:** brand / neutral / radius / `--font-sans` / code の curated subset（計27トークン）の各行が、キー名と既定値（例: `--color-accent` = `oklch(37.1% 0 0)`）入りで表示される。各行は「既定」状態として表示され、「上書きトークンは登録されていません」の空表示は出ない。
- **確認ポイント:** 色値の行にはカラースウォッチが出る。`--font-sans` の値が1行で表示される。

### 2. 既定値を編集して保存すると override のみ永続化される

- **目的:** 既定値を上書きして保存した行だけが DB に保存されることを確認する。
- **手順:**
  1. `--color-accent` の値を別の色（例 `#ff0000`）に変更
  2. 「保存」をクリック
  3. ページを再読込
- **期待結果:** `--color-accent` 行は変更後の値で「上書き中」表示。他の行は既定値のまま「既定」表示。再読込後も上書き値が保持される。
- **確認ポイント:** 編集していない行は DB に保存されていない（override のみ永続化）。

### 3. 既定値に戻すと override が消える

- **目的:** 「既定に戻す」操作、または手で既定値と同じ文字列に戻す操作で override が DB から消えることを確認する。
- **手順:**
  1. 項目2で上書きした `--color-accent` 行の「既定に戻す」をクリック（または値を手で既定値 `oklch(37.1% 0 0)` に戻して保存）
  2. ページを再読込
- **期待結果:** `--color-accent` が既定値表示・「既定」状態に戻る。再読込後も既定状態（override が消えている）。
- **確認ポイント:** 既定値と同値の行は DB に書かれていない。

### 4. 「すべてリセット」で全既定表示に戻る

- **目的:** すべてリセットすると全 override が消え、再び既定値が全行表示されることを確認する。
- **手順:**
  1. いくつかの行を上書きして保存
  2. 「すべてリセット」→ 確認ダイアログで実行
  3. ページを再読込
- **期待結果:** 全行が既定値表示・「既定」状態に戻る。

## エッジケース・異常系

### 1. 既定外の任意キーの override（後方互換）

- **目的:** curated subset に無いキー（例 `--accent`）が過去に保存されている場合、その行が「上書き中」として表示され続けることを確認する。
- **手順:**
  1. 「＋ トークンを追加」で既定外キー（例 `--custom-x`）を追加し値を入れて保存
  2. ページを再読込
- **期待結果:** `--custom-x` 行が「上書き中」表示で残る（既定値ラベルは無く、削除操作のみ）。既定キー行と共存して表示される。

### 2. 不正な値の入力

- **目的:** VO 制約に反する値（空値・`;`/`{`/`}` を含む値）の保存が拒否されることを確認する。
- **手順:**
  1. ある行の値を `red;color:blue` のような不正値にして保存
- **期待結果:** バリデーションエラーが表示され保存されない。
