## 確認ポイント
- ownership check が loader 側で機能。owner_id != login user の場合、`findById` の resolver は `null` 扱いとなり、chip は UUID 断片へフォールバック → OK
- 一覧側も owner_id フィルタにより 0 件、X のタイトルは漏出しない → OK
