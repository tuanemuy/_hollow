## 確認項目

### 1. P34 エラーページ 404 の CTA アイコン

- **対応する受け入れ基準:** AC-3
- **目的:** 404 の「ホームへ戻る」に home アイコン、「検索ページを開く」に search アイコンが付くこと。
- **手順:**
  1. `/error?kind=notFound` を開く。
  2. 「ホームへ戻る」「検索ページを開く」の 2 つの CTA を確認する。
- **期待結果:** 「ホームへ戻る」に家アイコン、「検索ページを開く」に虫眼鏡アイコンがラベル左に表示される。
- **確認ポイント:** mock `P34-error.html` の 404 と並べて、アイコンの有無・位置が一致するか。

### 2. P34 エラーページ 403/410/500 にアイコンが波及しないこと

- **対応する受け入れ基準:** AC-4
- **目的:** アイコン追加が 404 限定で、他バリアントの「ホームへ戻る」には付かないこと。
- **手順:**
  1. `/error?kind=forbidden`、`/error?kind=gone`、`/error?kind=system` をそれぞれ開く。
  2. 各ページの「ホームへ戻る」を確認する。
- **期待結果:** いずれも「ホームへ戻る」にアイコンが付かない（mock 通り）。500 の「再読み込み」のリロードアイコンは従来通り表示される。

### 3. P33 共有リンクゲート expired/gone の補足テキスト

- **対応する受け入れ基準:** AC-1
- **目的:** expired/gone 時に「トップへ戻る」CTA の下に補足テキスト（gate-foot）が表示されること。
- **手順:**
  1. `/share/does-not-exist`（存在しないトークン）を開く。
  2. パスワード欄に任意の文字を入れて「閲覧する」を押す（→ notFound = expired/gone 状態）。
- **期待結果:** 「リンクは無効です」見出し＋「トップへ戻る」CTA の下に、上ボーダー区切りで中央寄せ・小さめ・薄色の「共有元に連絡すると、新しいリンクを発行してもらえる場合があります。」が表示される。
- **確認ポイント:** mock `P33-share-link.html` STATE3 の `.gate-foot` と border / 文字色 / 中央寄せが一致するか。

### 4. P33 インラインエラーのアイコン

- **対応する受け入れ基準:** AC-2
- **目的:** パスワード不一致などのインラインエラーでメッセージ先頭にアイコンが表示されること。
- **手順:**
  1. シード（`pnpm seed:dev-admin`）等でパスワード保護された有効な共有リンクを用意し、`/share/{有効なトークン}` を開く。
  2. 誤ったパスワードを入力して「閲覧する」を押す。
- **期待結果:** 入力欄の下に、アイコン（AlertCircle）＋「パスワードが正しくありません。」が並んで表示される。
- **確認ポイント:** アイコンとテキストの間隔（gap-1.5 ≒ 6px）と色（error）が mock の `.gate-error` と一致するか。

## エッジケース・異常系

### 1. ロックアウト時はインラインエラーアイコンが出ないこと

- **目的:** `share_link_locked` 時はインラインエラーではなく従来の案D アラートが出る（インラインエラー分岐に入らない）。
- **手順:** 試行回数上限に達するまで誤パスワードを送信する。
- **期待結果:** 案D アラート（白地＋警告アクセント＋時計アイコン）が表示され、インラインエラー（AlertCircle）は表示されない。

## 既存機能への影響確認

- **ユニットテスト:** `pnpm test:unit` で `ShareLinkGate.test.tsx` / `ErrorPage.test.tsx` が通ること（新規アサーション含む）。
- **404 以外のエラーバリアント:** アイコン追加が 404 限定であることをテストでロック（AC-4）。
- **共有ゲートの解錠成功フロー:** 正しいパスワードで公開ノート（P31）へ遷移する従来挙動が壊れていないこと。
