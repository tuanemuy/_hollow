# TC-002: 読み取り専用ビューのシンタックスハイライト

| 項目 | 内容 |
| --- | --- |
| 結果 | PASS |
| 手順 | 作成したノートの詳細（読み取り専用）画面で、TS コードブロックの色付きと no-lang ブロックの plain を確認 |
| 期待 | TS ブロックは色付き、no-lang ブロックは plain |

## 観察した挙動

`.note-detail-content` 内で `wait --load networkidle` 後に shiki ハイライトが適用された。

- TS ブロック（`pre[0]`, `language-typescript`）: 10 個の `<span>`、`shiki-token-keyword` 7 個を含む。
  - `<span class="shiki-token-keyword">function</span> <span class="shiki-token-function">greet</span>(...)` など。
- 言語クラス無しブロック（`pre[1]`）: `<span>` 0 個（plain）。

トークン種別ごとに異なる色（computed `color`）:

| トークン | クラス | color |
| --- | --- | --- |
| キーワード | `shiki-token-keyword` | `rgb(170, 62, 62)` 赤 |
| 関数名 | `shiki-token-function` | `rgb(91, 61, 161)` 紫 |
| 文字列 | `shiki-token-string` | `rgb(42, 140, 79)` 緑 |
| コメント | `shiki-token-comment` | `rgb(134, 134, 139)` 灰 |
