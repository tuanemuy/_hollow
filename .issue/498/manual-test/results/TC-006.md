# TC-006: 公開 / 履歴ビューのハイライト（任意）

| 項目 | 内容 |
| --- | --- |
| 結果 | SKIP |
| 理由 | 到達不可（追加セットアップが必要） |

## 観察した挙動

- 対象ノートは「公開状態: 非公開」。詳細画面から公開ビュー（PublicNoteDetail）への直接リンクは無く、公開には公開操作（副作用）が必要。
- 履歴ビュー（NoteRevisionDetail）は複数の保存版が前提で、本検証範囲では未到達。

## 判断

- 公開・履歴・法的文書ビューのハイライトは TC-002 で検証した読み取り専用ビュー（NoteDetail）と**同一の shiki ハイライターコンポーネント**（`app/components/note/content/highlighter`）を共有する派生表示。
- TC-002 でコンポーネントの色付け・no-lang フォールバックが実証済みのため、公開/履歴でも同等に動作する蓋然性が高い。
- 本 TC は到達に追加のデータ準備（公開操作・複数版作成）が要るため SKIP とする。
