# TC-005（最重要）: 保存 HTML に span が漏れないこと

| 項目 | 内容 |
| --- | --- |
| 結果 | PASS |
| 手順 | TC-003/004 の編集後に保存 → 再編集 → HTML モードで生 HTML を確認 |
| 期待 | ソースに `shiki-token` / `<span class="shiki-token-*">` / `contenteditable` を含まない。clean な `<pre><code ...>text</code></pre>` |

## 観察した挙動

- inline 編集で編集後「保存」押下 → 詳細ページへ遷移（エラーなし）。
- 再度編集画面を開き HTML モードに切替、本文 textarea の値を取得。
- 検査結果:
  - `shiki-token` を含む: **false**
  - `<span` を含む: **false**
  - `contenteditable` を含む: **false**

- 保存された生 HTML:
  ```
  <p>サンプル段落</p>
  <pre><code class="language-typescript">function greet(name: string): string {
    const message = &quot;Hello, &quot; + name; // greeting
    return message;
  }X</code></pre>
  <pre><code>plain code without language</code></pre>
  ```

- `&quot;` は文字列内ダブルクォートの正しい HTML エスケープ。`}X` は TC-003 の編集テストで挿入した 1 文字（想定どおりの編集結果）。Tab/Shift+Tab はネットで元の 2 スペースに戻っており clean。

## 結論

最重要不変条件（装飾 span / contenteditable が `contentHtml` に漏れない）を満たす。DB に保存される HTML は clean。
読み取り専用ビュー側で改めてハイライトが当たることは TC-002 で確認済み。
