# TC-001: コードブロック入りノートの作成

| 項目 | 内容 |
| --- | --- |
| 結果 | PASS |
| 手順 | `/notes/new` を開く → タイトル入力 → HTML モードに切替 → 本文に TS コードブロック + 言語クラス無しコードブロックを入力 → 作成 |
| 期待 | エラーなく保存できる |

## 観察した挙動

- 新規ノート画面で編集モードタブは `WYSIWYG / FrontMatter / HTML`。
- HTML タブへ切替後、本文 textarea（`本文（HTML）`）に以下を入力:
  ```
  <p>サンプル段落</p>
  <pre><code class="language-typescript">function greet(name: string): string {
    const message = "Hello, " + name; // greeting
    return message;
  }</code></pre>
  <pre><code>plain code without language</code></pre>
  ```
- textarea 値は 224 文字で正しく反映（改行・属性も保持）。
- 「作成」押下後、`/notes/019e9839-509f-727f-b77d-f1c1f396871d` の詳細ページへ遷移。
- 詳細ページに h1 タイトルと 2 つの `<pre>` ブロックが存在。エラーなし。

## 備考（操作手法）

- React の `onClick` が agent-browser の `click` で発火しない既知問題を確認（タブの `click` が成功表示でもモード非切替）。
- 回避策: 対象要素を eval で `.focus()` → `press Space` でアクティベートする手法が確実に動作した。フォーム送信・ボタン押下はすべてこの手法を使用。
