# TC-4（確認項目4 / AC-4）SavedView 適用時は view の displayMode が永続値より優先される

判定: SKIP

## 理由（前提データ未整備）

- 見出しのビュー切替（listbox「ビューを切り替え」）に存在するのは既定の「すべてのノート」のみで、displayMode を持つ SavedView が 0 件。
- SavedView を作るための「ビューとして保存」ボタンは `disabled`（画面表示「条件が設定されていません」）。
  フィルタ条件を設定しないと保存できず、UI から簡単に SavedView を作成できる状態ではない。
- タスク指示に従い、SavedView 作成が UI から簡単に行えないため SKIP とする（必須ではない）。

## 操作ログ

| # | 操作 | 結果 |
| - | --- | --- |
| 1 | 見出しのビュー切替 (e60) を開く | listbox「ビューを切り替え」表示 |
| 2 | option を確認 | 「すべてのノート」[selected] のみ（SavedView なし） |
| 3 | 「ビューとして保存」ボタン (e6) | `disabled`（条件未設定のため保存不可） |
