# TC-04: 相対時刻ヘルパーの表示文言（AC-5）

対象: `formatRelativeTime` が「たった今 / N分前 / N時間前 / N日前」、しきい値超で絶対日付を出すか。

| # | 操作 | 期待 | 実際 | 判定 |
|---|------|------|------|------|
| 1 | 直近活動セッション（現行行） | 「たった今」相当 | `最終アクセス: たった今` | PASS |
| 2 | 数分経過セッション（iPhone） | 「N分前」 | `8 分前` | PASS |
| 3 | 数時間経過セッション（curl / macOS） | 「N時間前」 | `2 時間前` / `3 時間前` | PASS |
| 4 | 数日経過セッション（Windows） | 「N日前」 | `3 日前` | PASS |
| 5 | 「たった今」が違和感ない粒度か（S-004 整合） | 直近活動が「N分前」と出ない | 現行行（updated_at = now 近傍）が「たった今」表示。違和感なし | PASS |

判定: PASS。経過時間に応じた相対表記が全粒度で確認できた。

備考: しきい値（7 日）超 → `toLocaleDateString("ja-JP")` 絶対日付フォールバックは、7 日超の updated_at を持つシード行が無いため実機では未確認（SKIP）。最古の Windows 行が 3 日前で「3 日前」表記となっており 7 日未満の相対表記分岐は正常。絶対日付フォールバックは unit test（relativeTime）でカバーされる範囲。
なお「ログイン日時」は別途 `2026/06/25 1:38` 形式の絶対表示（createdAt）で出ており、最終アクセス（相対）と役割が分離されている。
