# TC-02: デバイス種別ごとのアイコン切替（AC-3）

対象: `/settings/security` 各行の SVG glyph。DOM 上の `<svg>` 子要素の形状（rect 寸法 / line）で判別。

| # | 操作 | 期待 | 実際（SVG 子要素） | 判定 |
|---|------|------|------|------|
| 1 | desktop 行（HeadlessChrome / macOS Safari / Windows Chrome）の glyph 確認 | 横長モニタ glyph、互いに同一 | `rect(20x14 rx2)` + `line(8,21->16,21)` + `line(12,17->12,21)`（モニタ + スタンド）。3 行とも同一 | PASS |
| 2 | mobile 行（iPhone Safari）の glyph 確認 | スマホ glyph（desktop と異なる） | `rect(14x20 rx2)`（縦長端末）+ `line(12,18->12.01,18)`（ホームボタン点）。desktop と明確に別形状 | PASS |
| 3 | unknown 行（curl）の glyph 確認 | 汎用 glyph | `rect(20x14 rx2)` + line×2（= desktop と同じ汎用モニタ glyph） | PASS |
| 4 | desktop と mobile が同一 glyph でないこと | 異なる | desktop=`rect 20x14`(横長) / mobile=`rect 14x20`(縦長) で別物 | PASS |

判定: PASS。desktop / mobile が異なる glyph で描画され、unknown は汎用（モニタ）glyph。

備考: tablet UA はシード未投入のため未検証（コード上は `rect 16x20` の専用 glyph が存在: `deviceGlyph` L60-83）。
unknown が desktop と同一 glyph を再利用するのは **実装上の意図**（`SecurityForm/index.tsx` L55-59 の ADR-001 コメント:「an indeterminate `unknown` device reuses the generic monitor glyph rather than inventing a separate one」）。捏造アイコンを作らない方針であり仕様どおり。バグではない。
