# TC-07: エッジケース2 — IP が null のとき IP 行非表示

対象: ip_address=null のセッション行（現行 HeadlessChrome / curl）。

| # | 操作 | 期待 | 実際 | 判定 |
|---|------|------|------|------|
| 1 | 現行 HeadlessChrome 行（ip_address=null）の meta | IP 行（1行目）省略、2行目「最終アクセス」のみ | meta は「最終アクセス: たった今」+「ログイン日時」のみ。IP 行なし。レイアウト崩れなし | PASS |
| 2 | curl 行（ip_address=null）の meta | IP 行省略 | IP 行なし。「最終アクセス: 2 時間前」のみ。崩れなし | PASS |
| 3 | IP 有り行（iPhone/macOS）との対比 | IP 有り行は IP が出る | iPhone=`203.0.113.77` / macOS=`203.0.113.10` が出る。null 行とで条件分岐が機能 | PASS |

判定: PASS。ip_address=null の行は IP 行が省略され、空表示が崩れない。IP 有り行との出し分けが正しく機能。
