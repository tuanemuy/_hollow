# TC-05: geo（地名）を出さず IP 素出しのまま据え置き（AC-6）

対象: `session-meta` 1 行目。地名ラベル・捏造地域名が出ず、IP が素出し（null は省略）であること。

| # | 操作 | 期待 | 実際 | 判定 |
|---|------|------|------|------|
| 1 | IP 有り行（iPhone）の meta 1 行目 | IP 素出し、地名なし | `203.0.113.77`（IP のみ。「日本」等の地名なし） | PASS |
| 2 | IP 有り行（macOS） | `203.0.113.10` 素出し | `203.0.113.10` | PASS |
| 3 | IP 有り行（Windows、ログアウト前に確認済） | `198.51.100.42` 素出し | `198.51.100.42` | PASS |
| 4 | ページ全体に地名ラベルが無いこと | 「京都」「日本」「Japan」等の地名・地域名が一切出ない | 地名ラベルの描画なし（IP 数値のみ） | PASS |
| 5 | `·` 連結の複合 meta 行（OS·ブラウザ·geo·IP）になっていないこと | device はタイトルへ集約、meta は 2 行構成 | meta は「IP（1行目）」+「最終アクセス（2行目）」の 2 行構成。複合連結なし | PASS |

判定: PASS。地名（geo）は一切出ず、IP は素出しのまま据え置き。#572 の IP 素出し方針と整合し、虚偽表示なし。
