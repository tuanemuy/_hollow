## 発見した注意点

1. **admin-user 自身も「管理者を解除」/「一時停止」アクションが表示される。** seed-data.md の予想「自身は除外される」と異なる。本 Issue のスコープではないため記録のみ。
2. **agent-browser の `click <ref>` コマンドが React 19 の onClick ハンドラを安定して発火させない。** `eval` 経由の `element.click()` で代替したが、UI 上の操作は別途実機で確認推奨。
3. **状態遷移を行うと一部で session が `about:blank` に飛ぶ事象が発生。** 一度再ログインしてから demote を実施することで cleanup 完了。
