## 詳細所見

### アイコン仕様の検証

全ボタンの SVG 属性を eval で確認した結果、すべて `width="16"` / `height="16"` であり、spec §7.1「テキスト併用は `size={16}` / `aria-hidden`」に整合している。

非編集モードの 3 ボタン:
- リネーム: `lucide lucide-pencil`
- 統合: `lucide lucide-merge`
- 削除: `lucide lucide-trash2 lucide-trash-2`

編集モードの 2 ボタン:
- 保存: `lucide lucide-check` + `data-primary=""`
- キャンセル: SVG なし (テキストのみ)

ConfirmDialog の confirm ボタン:
- 削除: `lucide lucide-trash2 lucide-trash-2`

### §7.1 例外 (b) 構成の確認

編集モードは「保存 = アイコン+ラベル / キャンセル = テキストのみ」の構成が完全に実装されており、§7.1 例外 (b) に整合している。

### 機能継続の確認

リネーム・統合 (dialog 表示) ・削除の各操作が機能継続している。リネームでは `issue308-tag-a` を `issue308-tag-a-renamed` に変更、削除では当該タグの除去まで完了。

### MergeTagDialog (本 Issue スコープ外)

「統合」ボタンクリックで MergeTagDialog が開き、統合先タグ選択肢 (`#232`, `#issue308-tag-b`) が表示されることを確認。ボタン形態の検証は本 Issue 範囲外。
