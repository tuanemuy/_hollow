## 補足
- agent-browser のキー入力でも候補ドロップダウンは正常に開いた。候補を開くため、文字列の最後の1文字を `press` で打って input イベントを発火させた（例: `r` fill → `e` press）。
- `aria-activedescendant` の `get attr @ref` 取得は ref 失効により取得できなかったが、ArrowDown 後に `option "#react"` が `[selected]`（aria-selected=true）へ変化したことを accessibility snapshot で確認し、ハイライトの存在を担保した。
- 新規作成インジケータ（`＋「mynewtag123」を新規作成`）は accessibility tree 上では listbox/option として露出しないが、DOM（combobox 親要素配下）にテキストとして存在することを `eval` で確認した。
- combobox 構造: 既存一致時は `listbox "タグ候補"` + `option "#<tag>"`、新規のみの時は `＋「<draft>」を新規作成` 行。既存/新規の区別は接頭の `#` と `＋…を新規作成` で表現される。
