# TC-001: 見た目（コンテナ枠/フォーカス/空状態/chip削除）

**結果**: PASS（TC-001-a PASS / TC-001-b PASS / TC-001-c PASS）

## 実行ログ

| # | 操作 | 期待結果 | 実際の結果 | 判定 |
| --- | --- | --- | --- | --- |
| a-1 | cookie注入後 `/notes/new` を開く | ページ表示 | 「新規ノート」フォーム表示 | PASS |
| a-2 | snapshot でタグ入力フィールド確認 | chip+input が1コンテナ、input は role=combobox | `group "タグ"` 内に combobox（aria-label="新規タグ"）。get attr role=combobox を確認 | PASS |
| a-3 | タグ入力欄をフォーカスし枠/リング確認 | フォーカスでコンテナに枠/ring 可視化 | コンテナ class に `border border-hairline rounded-lg` ＋ `focus-within:border-accent focus-within:shadow-focus`（computed: border 1px solid rgba(60,60,67,0.12), borderRadius 12px）。focus-within でフォーカスリング適用される | PASS |
| b-1 | chip 0件状態で placeholder/ガイド確認 | 空のときガイドあり | combobox の placeholder="タグを追加…" を確認 | PASS |
| c-1 | `react` と入力し Enter で chip 作成 | chip 1件作成 | `group "タグ"` 内に "#" "react" と削除ボタンが出現 | PASS |
| c-2 | chip の削除ボタン確認 | aria-label 付きの × ボタン | button "react を削除"（StaticText "×"）。明示的な aria-label あり | PASS |
| c-3 | 削除ボタンをクリック | chip が消える | クリック後 `group "タグ"` は combobox のみに戻り chip 消失 | PASS |

## 補足
- CDP の `Page.captureScreenshot` がタイムアウトしたためスクリーンショットでの目視は取得できなかったが、コンテナの computed style と Tailwind クラス（`focus-within:border-accent focus-within:shadow-focus`）でフォーカスリングの存在を確認した。
- コンテナ構造: `relative flex flex-wrap items-center gap-1.5 rounded-lg border border-hairline bg-bg px-2 py-1.5 transition-colors focus-within:border-accent focus-within:shadow-focus`（chip と input を1コンテナにまとめている）。
