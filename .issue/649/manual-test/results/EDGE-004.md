# EDGE-004: 一覧クエリ失敗時の境界巻き込み（ADR-002 トレードオフ）

**結果: SKIP（部分実施）**

## 理由

手順の第一案「ローダーへ throw を仕込む」はコード修正にあたるため本検証の制約（コードは修正しない）で実施不可。第二案「オフライン化して再読み込み」は実施したが、クライアント遷移自体がルートレベルで失敗するため、SectionErrorBoundary（見出し + meta-row のセクションエラー表示）の観測には到達しない。セクション境界の発火はサーバー側 usecase の throw が必要で、コード注入なしでは再現できなかった。

## 実行ログ（オフライン代替で確認できた範囲）

| # | 手順 | 結果 |
| --- | --- | --- |
| 1 | ホーム `/` を表示後、`agent-browser set offline on` | OK |
| 2 | 表示モード切り替え（タイル）でクライアント遷移を発火 | ルートレベルの 500 エラーページ「予期しないエラーが発生しました」表示（/tmp/edge-004-error.png）。白画面クラッシュではない |
| 3 | `set offline off` → 「再読み込み」ボタン | 正常復帰。URL `/?display=tile` が保持され、見出し「すべてのノート」・一覧が再描画 |

## 画面状態

- エラー時: 500 ページ（再読み込み / ホームへ戻る / 一つ前に戻る の導線あり）
- 復帰後: display=tile を保持したホームが正常表示

## 補足

回復経路（再読み込みで回復）は確認済み。セクション境界そのものの表示確認は、ローダーへの一時 throw を許可した環境での再実施を推奨。
