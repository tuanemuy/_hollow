## 備考

- 保存直後のサイドバーは即時更新されず、リロード/再ナビゲーションで反映される。`SaveViewDialog.tsx` は保存後に router invalidate を行わない実装で、本ファイルは #649 で未変更（`git diff` 差分なし）のため「従来どおり」の挙動と判断し PASS。
- 競合時の文言は汎用メッセージ「操作を完了できませんでした。時間をおいて再度お試しください」で表示される（serialized error は `business / saved_view_name_conflict`）。既存挙動の範囲。
- クリーンアップ: `DELETE FROM saved_views WHERE name LIKE 'IMPACT003%'` を実行し、シードの保存ビュー 3 件のみが残ることを SQL で確認済み。
