# TC-008: FilterBar のクリア ×（AC-7）

結果: PASS

## 実行ログ

| # | 操作 | 期待結果 | 実際の結果 | 判定 |
| --- | --- | --- | --- | --- |
| 1 | フィルタ未適用のホームを確認 | クリア × が表示されない | `button[aria-label="フィルタをすべてクリア"]` 不在。旧「すべてクリア」pill も不在 | PASS |
| 2 | タグ #design フィルタを適用 | × がチップ列末尾に出現 | URL `?tagNames=["design"]`、× がチップ行の最終要素（`lastElementChild`）として出現 | PASS |
| 3 | デスクトップでの × を検査 | 28px・円形・`aria-label` / `title` | 28×28px、`border-radius: 9999px`、`aria-label` / `title` とも「フィルタをすべてクリア」 | PASS |
| 4 | hover 状態 | surface 背景 + ink 文字色 | hover で `background: rgb(245,245,247)`（surface）、`color: rgb(29,29,31)`（ink）。通常時は透明背景 + ink-tertiary | PASS |
| 5 | focus-visible リング | リングが見える | `:focus-visible` マッチ時 `outline: solid 2px`（accent） | PASS |
| 6 | × をクリック | 全フィルタ解除 | URL のクエリが空になり「11 件のノート」へ復帰、× も消える | PASS |
| 7 | iPhone SE で再適用し × を検査 | 32px・44px 相当の当たり判定・shrink しない | 32×32px、`flex-shrink: 0`、`::after` 43.1×43.1px（44px 相当、fluid root font による rem 換算）。チップ行は `overflow-x: auto` で × は潰れない | PASS |
| 8 | モバイルで × をタップ | 全フィルタ解除 | クエリが空になり解除を確認 | PASS |

## 備考

- `::after` の実測 43.1px は設計値 44px の rem 換算（375px 幅で root font-size 14.75px）によるもので、設計意図（44px 相当）どおり。
