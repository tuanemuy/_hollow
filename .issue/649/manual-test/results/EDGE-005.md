# EDGE-005: 検索 + 保存ビュー同時適用

**結果: PASS**

## 実行ログ

| # | 手順 | 結果 |
| --- | --- | --- |
| 1 | `/?display=list&viewId=...649001&q=test` を直接開く（ビュー + 検索同時適用状態） | 見出し「「test」の検索結果」— 検索文言が優先 |
| 2 | 同状態の見出しトリガー `aria-label` | 「ビューを切り替え」のみ（「現在 …」なし。ADR-005 どおり） |
| 3 | q を外した `/?display=list&viewId=...649001` | 見出しがビュー名「テスト用ビュー design」に戻る |
| 4 | UI 経由: ビュー適用中に検索ボックスで `test` を検索 | 見出し「「test」の検索結果」。URL は `/?q=test`（グローバル検索は viewId を持たない遷移 — 既存の検索仕様） |
| 5 | 検索クリア | 「すべてのノート」へ復帰、エラーなし |

## 備考

- 検索ボックスからの検索は viewId を落とすため「検索解除でビュー名に戻る」のは URL 直指定（viewId+q 併存）状態の場合。併存状態での優先順位・復帰（手順 1〜3）は期待どおり。
