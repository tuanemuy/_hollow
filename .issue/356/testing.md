## 確認項目

### 1. 上部レイアウトが「パンくず → タイトル → アクション」に整理されている

- **目的:** メタ情報の `<dl>` 6行が本文上部から消え、本文がすぐ読み始められること
- **手順:**
  1. ログインしてノート一覧（`/`）を開く
  2. 任意のノート（できれば非ルートディレクトリ配下）を開いて詳細（`/notes/$noteId`）へ
  3. 本文上部の構成を確認する
- **期待結果:** 上部は「パンくず → タイトル → アクションツールバー（公開状態チップ + 編集/公開設定/移動/…）」のみ。作成日 / 更新日 / タグ / バックリンクの `<dl>` は上部に存在しない
- **確認ポイント:** タイトル直後に本文が近く、メタ情報で視線が妨げられないこと

### 2. パンくず（ディレクトリ）の表示とリンク

- **目的:** ディレクトリがパンくずとして上部に表示され、葉ディレクトリでホーム絞り込みできること
- **手順:**
  1. 非ルートディレクトリ配下のノート詳細を開く
  2. パンくず「すべてのノート › 親 › … › 葉ディレクトリ › （ノートタイトル）」を確認
  3. 「すべてのノート」リンク、葉ディレクトリリンクをクリック
- **期待結果:**
  - パンくずに `ChevronRight` 区切りでディレクトリ階層とノートタイトルが表示される
  - 「すべてのノート」クリックでホーム（全件）へ
  - 葉ディレクトリリンクのクリックでホームが当該ディレクトリで絞り込まれる
  - 中間セグメントは非リンク（テキスト）
- **確認ポイント:** タイトルセグメントは `current` 表示（リンクでない）

### 3. 公開状態チップ + P14 導線

- **目的:** 公開状態が独立表示され、その場から公開設定（P14）へ遷移できること
- **手順:**
  1. 公開状態の異なるノート（公開 / 限定公開 / 非公開）をそれぞれ開く
  2. 上部アクションの公開状態チップの色・ラベルを確認
  3. チップ（公開設定リンク）をクリック
- **期待結果:**
  - 公開: success 色、限定公開: warning 色、非公開: tertiary 色でラベルが「公開 / 限定公開 / 非公開」
  - クリックで `/notes/$noteId/publish`（P14 公開設定）へ遷移
- **確認ポイント:** 状態色が SSR 時点で正しく確定している（初回描画でちらつかない）

### 4. 本文下部のプロパティ（作成日 / 更新日 / 公開日 / タグ / バックリンク）

- **目的:** 重要度の低い情報が本文下部に移動していること
- **手順:**
  1. バックリンクのあるノート、公開済みノート（公開日あり）を開く
  2. 本文の下までスクロールする
- **期待結果:**
  - 本文の下に「作成日 / 更新日 / タグ」プロパティ、`publishedAt` があれば「公開日」行、バックリンク（件数 + カード一覧 + 参照ノート一覧リンク）が表示される
  - バックリンクカードのリンク・参照ノート一覧リンクが正しく遷移する
- **確認ポイント:** 上部に公開状態チップ、下部に公開日（重複ではなく役割分担）になっていること

## エッジケース・異常系

### 1. ルート直下ノート（`directoryPath === "/"`）

- **目的:** ルート直下でパンくずが破綻しないこと
- **手順:** ディレクトリに属さない（ルート直下の）ノート詳細を開く
- **期待結果:** パンくずが「すべてのノート › （タイトル）」のみで、葉ディレクトリリンクは出ない

### 2. ゴミ箱（trashed）ノート

- **目的:** trashed 時の上部が崩れないこと
- **手順:** ゴミ箱内のノート詳細を開く
- **期待結果:** 上部アクションは「ゴミ箱を開く」のみ。公開状態チップは出ず、下部メタも崩れない

### 3. 長いディレクトリ名・タイトル

- **目的:** 折返しが効くこと
- **手順:** 長いディレクトリ名 / タイトルのノートを ~375px（モバイル幅）とデスクトップ幅で開く
- **期待結果:** パンくず・タイトルが折返して横スクロールやはみ出しが起きない
