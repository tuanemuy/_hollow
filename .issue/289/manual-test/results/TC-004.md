# TC-004: roving tabindex / Tab でクローズ

**結果**: PASS

## 実行ログ
| # | 操作 | 期待結果 | 実際の結果 | 判定 |
|---|------|----------|------------|------|
| 1 | メニューを開き ArrowDown×2 で「移動」へ | 「移動」にフォーカス | activeElement="移動" | PASS |
| 2 | Tab | メニューが閉じる（role=menu 消失） | document.querySelector('[role=menu]')=false | PASS |
| 3 | Tab 後の trigger aria-expanded | false | aria-expanded="false" | PASS |
| 4 | Tab 後のフォーカス位置 | メニュー内を巡回していない | activeElement はメニュー外の "Frontend" リンク（role=null、menuitem ではない） | PASS |

Tab はメニューを閉じ、フォーカスは通常のタブ順（メニュー外の次要素）へ抜けた。メニュー項目間でのフォーカストラップは発生していない。
