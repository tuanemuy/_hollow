## 判定根拠

- snapshot に `image "LLM 呼び出し数の直近 24 時間の推移"` が存在（「取得失敗」ではない）。
- aria-label は LLM 専用文言「LLM 呼び出し数の直近 24 時間の推移」で正しい。
- SVG `path` の頂点は 26（= 24 バケット + 始終端のベースライン閉じ点 2）。24 バケット構造で描画されている。
- distinctY = [12, 51, 89, 128, 140] と 4 段階の高さがあり、平坦ではなく実データに応じた起伏がある。
  - Y=12（最高ピーク）= 3 件 hour、Y=51 = 2 件 hour、Y=89 = 1 件 hour、Y=128（ベースライン）= 0 件 hour。
  - シード（ピーク3・1・2・1件 + 残り0）と整合。

## 期待 vs 実測

- 期待: LLM 系列が「取得失敗」ではなく描画される / aria-label が LLM 用文言。
- 実測: いずれも一致。PASS。
