# TC-001: P47 限度テーブルの狭幅行積層（本命）

**結果**: PASS

| # | 操作 | 期待 | 実際 | 判定 |
|---|------|------|------|------|
| 1 | `/admin/metrics` を 1280px 幅で開く | 「インスタンス上限」が2列(項目/値)の通常テーブル | `table` が columnheader「項目」「値」を持つ2列テーブルで表示。computed `table-display:table`相当、thead 表示 | PASS |
| 2 | viewport 390x800 にしてリロード | 各行がカード状に積層、各セルに「項目」「値」ラベル(実DOMの span)表示、セル潰れなし | table→`display:block` / thead→`display:none` / row・cell→`display:block`。各セルに `<span>`「項目」「値」が `inline-block` で表示。ラベル色 rgb(134,134,139)=ink-tertiary、fontSize 11.73px=text-xs。セル潰れなし | PASS |

## 補足
- ラベル span の className: `hidden max-md:inline-block max-md:w-[132px] text-ink-tertiary text-xs`（値側は `font-sans` 付き）。`md` 未満でのみ表示される設計を DOM/computed 両方で確認。
- 実 DOM 要素のためスクリーンリーダーで「項目」「値」が読み上げ可能。
- 8行すべてラベル+値が正しく積層。
