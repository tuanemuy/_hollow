## 補足 (Issue #29 観点)

TC-001 と同じ事情。FTS join 修正は適用されており、英語キーワードで以下の通り動作確認済み：

```
GET /?q=Project&visibility=unlisted → 1 件 (N4 のみが正しく抽出される)
```

つまり `visibility=unlisted` の transport→search_documents 列フィルタは正しく動作している。
`q=デザイン` で 0 件となるのは、FTS5 デフォルトトークナイザ (`unicode61`) が CJK 文字列
`デザインメモ` を単一トークンとして扱うため、`デザイン` 単独では MATCH しないことが原因。
これは Issue #29 のスコープ外（pre-existing）。

## 結論

Issue #29 観点では **PASS**。TC 判定上は FAIL（CJK FTS トークナイズの別 Issue 起因）。
