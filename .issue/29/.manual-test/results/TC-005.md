## 詳細
- リスト本体には `公開デザインガイド` (visibility=`公開`) の 1 アイテムだけが描画されており、他の private/unlisted ノートは表示されていない。
- これは Issue #8 で実装された filter 経路（`listNotesByOwner` ベース）の visibility フィルタが Issue #29 の変更後も継続して機能していることを示す。
- ヘッダーの「10 件のノート」は `listNotesByOwner.countByOwner` が返す **総ノート数** （`NoteList.tsx:68` の `count`）。`?q=` 経路 / filter 経路ともに同じ振る舞いで、Issue #29 のスコープ外。

## 結論

Issue #8 のリグレッションは発生していない。filter 経路は Issue #29 の変更（search 経路の visibility 伝達追加）から影響を受けていない。
