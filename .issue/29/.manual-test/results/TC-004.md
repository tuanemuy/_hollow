## 補足

`visibility` 未指定時の後方互換性確認が主眼。本検証から以下が確認できる：

- combobox は `すべて` に戻り、URL にも `visibility` パラメータが付かない → routing/state 制御は正常
- 0 件となるのは TC-001/TC-002 と同じ FTS5 CJK トークナイズ問題（Issue #29 外）

英語キーワードで後方互換性を確認した結果:

```
GET /?q=Project (visibility 未指定) → 3 件（N3 private + N4 unlisted + N5 private）
```

→ visibility 未指定時に全 visibility のノートが返却されており、後方互換性は保たれている。

## 結論

Issue #29 の後方互換性は確保されている。TC のキーワード `デザイン` が 0 件となるのは
FTS5 トークナイザの別 Issue。
