このIssueの変更（フロントエンドの移動先ディレクトリ選択 UI と `flattenDirectoryTree` のパス組み立て）を確認するために必要な手順のみ記載。

ライブのソースを反映する開発サーバーを使う（`pnpm start` はビルド済み dist を配信するため、ソース変更の確認には `pnpm dev` を使う）。

## 確認項目

### 1. パス表示の先頭スラッシュ重複が解消されている（要件2）

- **目的:** ルート（name="")配下のディレクトリパスが `//Work` のような重複ではなく `/Work`、孫が `/Work/2024` のように単一スラッシュ区切りで表示されること。
- **前提シード:** ルート直下に少なくとも1階層、できれば2階層以上のディレクトリ（例: `Documents` > `Work` > `2024`）を作成しておく。
- **手順:**
  1. ノート一覧でノートを1件選び、「移動」操作で `MoveNoteDialog` を開く。
  2. 移動先ピッカーの候補に表示されるパスを確認する。
  3. サイドバーのディレクトリで「移動」操作を行い `MoveDirectoryDialog` を開き、候補のパスを確認する。
- **期待結果:** どの候補も先頭スラッシュが1つだけ（`/Documents/Work`）。`//` が出ない。末尾スラッシュも出ない。
- **確認ポイント:** ルート直下ディレクトリの表示（`/Documents`）と、深い階層（`/Documents/Work/2024`）の両方。

### 2. 移動先ディレクトリ選択がスケーラブルなピッカーになっている（要件1）

- **目的:** `<select>` ドロップダウンが、検索フィルタ付き＋階層が伝わる単一選択ピッカーに置き換わり、件数が増えても操作できること。
- **前提シード:** 10件以上、3階層程度のディレクトリ構成。
- **手順:**
  1. `MoveNoteDialog`（ノート一覧の移動）を開く。
  2. 検索入力にディレクトリ名の一部を入力し、候補が絞り込まれることを確認。
  3. ArrowDown/ArrowUp でハイライトが移動し、Enter で選択が確定することを確認。
  4. マウスで候補をクリックして選択できることを確認。
  5. 選択後「移動」ボタンが活性化し、移動が成功することを確認。
  6. `DirectoryPicker`（ノート編集画面のディレクトリ選択）でも同様にピッカーが機能し、かつ「新規ディレクトリ名入力」の二択 UI が従来どおり残っていることを確認。
  7. `MoveDirectoryDialog`（ディレクトリの移動）でも同様にピッカーが機能することを確認。
- **期待結果:** 3箇所とも検索で絞り込め、キーボード/マウス両方で選択・確定でき、移動が成功する。階層は path 表示とインデントで判別できる。
- **確認ポイント:** スクリーンリーダー利用時に path（祖先連鎖）が読み上げられること。フォーカスが検索入力に自然に入ること。

## エッジケース・異常系

### 1. cyclic 除外が維持されている（MoveDirectoryDialog）

- **目的:** ディレクトリ移動で、移動対象自身とその子孫が移動先候補に出ないこと（循環防止 UX）。
- **手順:**
  1. 子孫を持つディレクトリ（例: `Documents` 配下に `Work`）を移動対象にして `MoveDirectoryDialog` を開く。
  2. 候補一覧を検索・スクロールで確認する。
- **期待結果:** 移動対象（`Documents`）自身とその子孫（`Work` など）が候補に出ない。「（ルート）」は候補に出る（重複表示しない）。

### 2. フィルタ0件・空状態

- **目的:** 検索でヒット0件のとき、適切な空メッセージが `aria-live` で伝わること。
- **手順:**
  1. 移動ピッカーで該当しない文字列を入力する。
- **期待結果:** 0件メッセージが表示され、誤って何も選択されない。

### 3. IME 変換中の Enter

- **目的:** 日本語入力の変換確定 Enter が誤って候補確定にならないこと。
- **手順:**
  1. 検索入力で日本語を入力し、変換中に Enter を押して変換を確定する。
- **期待結果:** 変換確定だけが行われ、ピッカーの選択は確定しない。

## 既存機能への影響確認

- ノート移動（単体・一括）の成功/失敗ハンドリング（`MoveNoteDialog` の batch error 表示）が従来どおり動くこと。
- ノート編集画面の「新規ディレクトリ作成」（`DirectoryPicker` の `allowNestedPath` / 新規名入力）が従来どおり動くこと。
- ingestion プレビュー（`IngestionPreviewForm` / `UploadDialog`）のディレクトリ選択が透過的に動くこと。
