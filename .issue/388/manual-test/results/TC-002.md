## 備考

- 3箇所（MoveDirectoryDialog / DirectoryPicker / MoveNoteDialog）すべてで検索フィルタ・キーボード/マウス選択・「選択中: …」表示・移動ボタンの活性化を確認。
- 階層は path 表示（祖先連鎖）＋インデント（paddingLeft = depth*16）で判別可能。`role=option` は path テキストでアクセシブル名を構成（#388 ADR-001 通り `aria-level` は付与しない設計）。
- 移動の **submit（実行）自体は未実行**。`useServerFn(move*Fn)` の server-fn POST はブラウザ自動操作では cross-origin 403 で弾かれる方針（signup でも同様に確認、後述）。UI・選択・活性化までで要件1は検証可能と判断し PASS。
