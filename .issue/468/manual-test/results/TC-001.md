## 備考

- 取り込みキューに未 commit の重複ジョブ（同じ test-468.pdf、最初のサーバーで滞留していた分。現在「プレビュー可能」）が 1 件残存。source の media_assets 行は commit 時にのみ作られるため本テストの判定には影響しない。不要なら UI から「破棄」可能。
- 検証サーバーは `pnpm build:local` 成果物で `pnpm start --port 8787` を起動中（ログ: scratchpad の tc001-server2.log）。以降のテストケース（pruner 等）もこのビルドを前提にすること。plain `pnpm build` に戻すと inline relay が消えて取り込みが「待機中」で停滞する点に注意。
- ingestion_jobs の `previewing` は「プレビュー生成中」ではなく「プレビュー添付済み・確認待ち」の状態（`app/core/domain/ingestion/entity.ts` の `attachPreview`）。
