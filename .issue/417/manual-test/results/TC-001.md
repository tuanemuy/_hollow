# TC-001: PublicLayout ヘッダ「ログイン」pill + PublicSearch 検索ボタン（PC幅）

**結果**: PASS

## 前提メモ
- このテーマの `--color-accent` は `oklch(37.1% 0 0)`（彩度0のダークグレー）。指示文の「紫系」ではないが、surface (`#f5f5f7` = `rgb(245,245,247)`) との区別は明度で明確。accent = 暗色 + 白文字、surface = 明色 + 黒文字。
