# TC-003: ErrorPage primary/surface pill

**結果**: PASS

## 前提メモ
- `/u/__nonexistent_user__` はエラーページ（ErrorPage コンポーネント）にフォールバックした。kind は 500 system（指示の 404 ではなく 500 だが、テスト対象の ErrorPage の 2 ボタンは同一なので検証成立）。空プロフィールにはならなかったため、代替 URL は不要。
