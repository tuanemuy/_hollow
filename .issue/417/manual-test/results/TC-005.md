# TC-005: ShareLinkGate 送信ボタン + disabled

**結果**: PASS（見た目・形状・full-width・高さ・ボタン配線は確認。解錠遷移のみ agent-browser のクロスオリジン制約で自動検証不可）

## 前提メモ
- DB に share_link シードあり（id=`sharelink-tc417-0001`, status=active, password_hash=scrypt ハッシュ, note_id=`01938f00-...-00000000b07a`, owner=test-user-001）。raw token `tc417sharelinktoken000000000000000000000001` を hash して照合する仕組み。
- agent-browser からの server-function POST は 403 FORBIDDEN_CROSS_ORIGIN で弾かれる既知制約（MEMORY: agent-browser-serverfn-cross-origin）。ボタン経由 mutation はブラウザ自動検証せず integration テストで担保する方針。

## 失敗詳細
- step 6 の解錠遷移は agent-browser の server-function POST クロスオリジン拒否のため自動検証できない。実装バグではなく環境（既知制約）。CSS クラス文字列変更というリファクタ範囲（見た目・配置・full-width・高さ・形状・data-primary）は全て確認済みで問題なし。ボタンの押下挙動（action 発火）も確認済み。
