# TC-002: PublicSearch 検索ボタン モバイル幅（min-h 回帰の最重要確認）

**結果**: PASS

## 前提メモ
- ビューポートは `agent-browser set viewport 375 812` で 375px 幅に設定可能（制約なし）。
- メインの検索フォーム（`SEARCH_FORM` / `#public-search-input`）はモバイルでも表示される（`max-sm:hidden` はヘッダ内の別検索のみ）。

## 実行ログ
| # | 操作 | 期待結果 | 実際の結果 | 判定 |
|---|---|---|---|---|
| 1 | `/search?q=task&limit=20` を 375x812 で開き reload | モバイル幅で描画 | `window.innerWidth = 375` を確認、検索フォーム描画 | PASS |
| 2 | 検索ボタンの min-height/height | `max-sm:min-h-[44px]` で 44px | `min-height: 44px` / `height: 44px`（base のタップターゲット発火を確認） | PASS |
| 3 | input の高さ | h-12 = 48px | `height: 48px` | PASS |
| 4 | ボタン下端が input 下端を超えないか（2px 以内許容） | bottomOverflow <= 2px | input top165/bottom213、btn top167/bottom211。中央寄せ(top-1/2 -translate-y-1/2)で 48px 内に収まり、上下とも 2px 余白。bottomOverflow = -2（はみ出しなし） | PASS |
| 5 | ボタン背景・data-primary | accent + data-primary | `oklch(0.371 0 0)`(accent)・白文字・`data-primary=""` | PASS |
