## 確認項目

### 1. タグ行のチップUI化（AC-1）

- **対応する受け入れ基準:** AC-1
- **目的:** タグ行がモック `.tags-row` / `.tag-chip` / `.tag-input` 準拠のチップUIになっていること
- **手順:**
  1. ノート編集画面を開く（既存タグがあるノートと、無いノートの両方で）
  2. 既存タグがチップ（高さ26px相当・pill 形状・末尾 `×`）として横並び表示され、末尾に borderless の入力欄が**同一行に共存**していることを確認
  3. `spec/design/pages/P12-editor.html` をブラウザで開いて目視比較する（ラベルが無いこと、`mb-5` 相当の下余白）
- **期待結果:** チップ列 + borderless 入力が1行に flex 共存。縦積みラベル付きフォーム（旧UI）になっていない
- **確認ポイント:** チップの色（`accent-ink`）・背景・角丸がモックと近いこと

### 2. タグの追加・削除・保存・autosave（AC-2）

- **対応する受け入れ基準:** AC-2
- **目的:** タグの追加・削除・保存・autosave が壊れていないこと、未確定 draft も確定されて保存されること
- **手順:**
  1. 入力欄にタグ名を入力し **Enter** で確定 → チップが増えることを確認
  2. カンマ区切りで複数タグをまとめて入力・確定 → 複数チップに分割されることを確認（trim・重複排除）
  3. チップの `×` をクリック → 該当タグが削除されることを確認
  4. 入力欄が空の状態で **Backspace** → 末尾チップが削除されることを確認
  5. タグを入力欄に打ち込んだ**まま（Enter を押さず）**保存（または autosave 発火を待つ）→ そのタグが保存されることを確認
  6. 保存後に detail 画面でタグが反映されているか、再度編集画面を開いてチップが復元されるか確認
  7. 日本語入力（IME）でタグを入力し変換確定の Enter で誤ってタグ確定されないことを確認
- **期待結果:** 追加・削除・保存・autosave がすべて従来どおり機能。未確定 draft も保存に含まれる。IME 変換確定の Enter ではタグ確定されない
- **確認ポイント:** submit と autosave のどちらの経路でもタグの保存結果が一致すること（lockstep）

### 3. タイトル入力のフォント・行高（AC-3）

- **対応する受け入れ基準:** AC-3
- **目的:** タイトル入力に見出しフォントが適用され、行高がモック（1.12相当）になっていること
- **手順:**
  1. 編集画面のタイトル入力に長めのテキスト（2行に折り返す程度）を入力
  2. `spec/design/pages/P12-editor.html` の `.title-input` と見出しフォント・行高を目視比較する
- **期待結果:** タイトルが見出しフォント（`font-heading`）で描画され、行間がモックの狭い行高（1.12相当）になっている
- **確認ポイント:** 本文フォントのままになっていないこと

### 4. ディレクトリ行の単一 pill ＋ツリードロップダウン移行（AC-4）

- **対応する受け入れ基準:** AC-4
- **目的:** ディレクトリ行がモックの単一 pill トリガー＋ツリードロップダウン構造に移行していること
- **手順:**
  1. 編集画面のディレクトリ行に、現在の選択パスを表示する**単一の pill**（フォルダーアイコン＋パス＋キャレット）が表示されていることを確認
  2. pill をクリック → ドロップダウンが開き、検索 input・折りたたみ可能なディレクトリツリー・選択ハイライト・「新規ディレクトリを作成…」導線が表示されることを確認
  3. 検索 input にディレクトリ名を入力 → 該当がフィルタされ、ヒット祖先が自動展開されることを確認
  4. ツリーのフォルダーを展開/折りたたみできることを確認
  5. **キーボード操作**: 検索 input にフォーカスしたまま ↑↓ で選択候補が移動（aria-activedescendant）、Enter で選択、Escape でドロップダウンが閉じることを確認
  6. ディレクトリを選択 → pill の表示が更新され、保存後も反映されることを確認
  7. 「新規ディレクトリを作成…」からインライン作成 → 保存時に新規ディレクトリが作成されること（pendingDirectoryName 契約維持）を確認
  8. ドロップダウン外をクリックすると閉じることを確認
- **期待結果:** 2フィールド常時表示（旧UI）ではなく、単一 pill ＋ツリードロップダウン。選択・検索・折りたたみ・新規作成・キーボード操作・保存がすべて機能する
- **確認ポイント:** 既存ディレクトリ選択と新規作成の両方が保存ペイロードに正しく載ること

### 5. 本文エディタのボーダーレス化（AC-5）

- **対応する受け入れ基準:** AC-5
- **目的:** WYSIWYG 本文の editor body から枠線・角丸が外れ、ボーダーレスな原稿キャンバスになっていること
- **手順:**
  1. WYSIWYG モードで編集画面を開く
  2. 本文エリアに `border-hairline` の枠線・`rounded-md` の角丸が無いことを確認
- **期待結果:** 本文が枠なしの原稿キャンバスとして表示される（`p-4` の内側余白は維持）
- **確認ポイント:** フォーカス時の `focus-within` 表現（#692 範囲）は温存されており、本Issueでは枠線撤去のみ行われていること

## エッジケース・異常系

### 1. タグ重複・空入力

- **目的:** 重複タグ・空タグの扱いを確認
- **手順:**
  1. 既に存在するタグ名を再度入力・確定 → 重複追加されないことを確認
  2. 空文字やスペースのみを確定しようとする → タグが追加されないことを確認

### 2. ディレクトリ候補ゼロ時の検索

- **目的:** 検索でヒットゼロのときの表示
- **手順:**
  1. ディレクトリドロップダウンの検索 input に該当しない文字列を入力
- **期待結果:** 候補ゼロ時に listbox / aria-activedescendant が破綻せず、適切に空状態が表示される

## 既存機能への影響確認

- **Ingestion プレビュー画面のディレクトリ欄**: アップロード取り込みプレビュー（`IngestionPreviewForm`）のディレクトリ欄（`variant="fieldset"`）の見た目・機能が**従来どおり**であること（本Issueは row variant のみ変更）。`IngestionPreviewForm` のタグ入力も従来どおり機能すること（`parseTagInput` 依存の非回帰）。
- **ディレクトリのリネーム/削除**: ドロップダウンからリネーム/削除ダイアログを開く動線が機能すること（Popover を閉じてからダイアログを開く順序）。
- **エディターのモード切替**: WYSIWYG ⇔ inline ⇔ HTML 切替が従来どおり動くこと。
- **保存後の遷移と鮮度**: 編集→保存→detail・一覧で最新内容が表示されること。
