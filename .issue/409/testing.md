## 確認環境

このIssueの変更を確認するために必要な手順のみ記載。

### 検証環境の起動

ソース変更を実サーバーで見るには、先にビルドしてから起動する（`pnpm start` は `dist/worker` を配信するため `pnpm build` が必須。`docs/test.md` 参照）。

```bash
pnpm build
pnpm start
```

ローカル D1 にスキーマが無い場合のみ適用する。

```bash
pnpm db:apply:local
```

### ログインユーザーの準備

ブラウザで新規 signup すると user + root directory が自動プロビジョンされる。signup はメール確認必須なので、確認リンクの代わりに以下を流してからログインする（パスワードは 12 文字以上）。

```bash
pnpm wrangler d1 execute hollow-local-d1 --local --command "UPDATE users SET email_verified=1 WHERE email='<signup したメール>'"
```

ログインフォームは password 欄で Enter 送信する（同一オリジン送信。`docs/test.md` 参照）。

### デプロイ方法

なし（検証環境のみで確認できる）。

## 確認項目

### 1. 存在しない noteId で履歴一覧が notFound 表示になる

- **目的:** 非存在 noteId の履歴一覧で「ノートが見つかりません」が表示され、汎用エラー境界（「エラーが発生しました」）が出ないことを確認する。
- **手順:**
  1. ログイン済みの状態にする。
  2. ブラウザで `/notes/00000000-0000-0000-0000-000000000000/history`（実在しない noteId）に直接アクセスする。
- **期待結果:** 「ノートが見つかりません」「削除されているか、アクセス権限がありません。」が表示される。
- **確認ポイント:** 「エラーが発生しました」見出しが出ないこと。`role="alert"` の notFound 表示であること。`notFoundComponent` 削除後も挙動が同一であること。

### 2. 存在しない revisionId で過去版詳細が notFound 表示になる

- **目的:** 実在ノート配下の非存在 revisionId で「過去版が見つかりません」が表示されることを確認する。
- **手順:**
  1. 実在するノートを 1 件用意し、その noteId を控える。
  2. `/notes/<実在 noteId>/history/00000000-0000-0000-0000-000000000000` にアクセスする。
- **期待結果:** 「過去版が見つかりません」「削除されているか、アクセス権限がありません。」が表示される。
- **確認ポイント:** 「エラーが発生しました」見出しが出ないこと。`role="alert"` の notFound 表示であること。

### 3. 既存の履歴一覧・過去版詳細は従来どおり表示される

- **目的:** 正常系の回帰がないことを確認する。
- **手順:**
  1. ログイン後、ノートを 1 件作成し、本文を編集して保存（過去版を 1 つ以上積む）。
  2. `/notes/<実在 noteId>/history` を開き、履歴一覧が表示されることを確認する。
  3. 一覧から「閲覧」を押し、過去版詳細が表示されることを確認する。
- **期待結果:** 履歴一覧・過去版詳細が従来どおり表示される。
- **確認ポイント:** notFound 表示やエラー境界に落ちないこと。

## エッジケース・異常系

### 1. 不正な形式の noteId / revisionId

- **目的:** UUID 形式でない ID でもエラー境界ではなく notFound 表示に落ちることを確認する。
- **手順:**
  1. `/notes/not-a-real-id/history` にアクセスする。
- **期待結果:** 「ノートが見つかりません」が表示される（汎用エラー境界が出ない）。

## 既存機能への影響確認

- ノート詳細 → 履歴一覧 → 過去版詳細への通常遷移が従来どおり動くこと。
- 履歴一覧のページネーション（前へ／次へ）が従来どおり動くこと。
