## 補足

- `buildMatchExpression` の既存サニタイズ（`["\\]` 除去）が trigram 移行後も機能。`"` を含む `"デザイン` は `デザイン` 相当のクエリに正規化され、期待どおり「公開デザインガイド」がヒットした。
- `デザイン:title` はトークンが `デザイン title` の AND クエリ相当に分解されるが、対応する public note が無いため 0 件。FTS5 のカラムフィルタ構文として誤って解釈されることなく、安全にサニタイズされている。
- いずれのケースもサーバー側で 500 を返したり JS 例外がスローされたりすることはなく、Issue #50 の trigram 移行が既存サニタイズロジックを破壊していないことを確認。
