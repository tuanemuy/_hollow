## 補足

- 検索ヘッダの「0 件」表示は visibility=public のみ対象とする公開検索 UI の仕様によるもので、FTS5 トークナイザーの問題ではない。
- DB 直接クエリで `Project AND デザイン` が「Project A デザインメモ」(unlisted) を返すことを確認。CJK と ASCII の混在クエリが `buildMatchExpression` を通って FTS5 まで正しく届いていることが示された。
- パーサーエラー / 500 / クラッシュは発生せず、エンドツーエンドで `Project デザイン` クエリが処理されている。
