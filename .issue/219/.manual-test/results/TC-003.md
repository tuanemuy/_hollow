# TC-003: 確認項目 3 — ローディングのチラつき / 空白が消えていること

**Result:** PASS

## 手順実行

1. `verify-seed` セッションで `/` 上、`MutationObserver` を仕込んで `aria-busy` / `data-loading` / `data-pending` の属性変化と、spinner / `[role=progressbar]` / `aria-busy=true` 要素の追加を全期間で監視
2. リスト → タイル → カレンダー → リスト → タイル → カレンダー → リスト の連続切替を実行
3. 各切替後に空白 / スピナーの瞬間表示が起きていないかスクリーンショットで確認

## 観察結果

- `__loadingEvents` length = **0**（観測期間中、ローディング属性の変化や spinner ノード追加は一度も起きていない）
- 任意のタイミングで `document.querySelectorAll('[aria-busy=true]')` が **0 件**
- 任意のタイミングで `[role=progressbar], .spinner, [class*=skeleton]` が **0 件**
- 中間スクリーンショット (`step-01-tile-to-calendar.png`, `step-02-calendar-to-list.png`) いずれも空白フレームやスピナー無し、コンテンツが直接差し替わっている

## 期待結果との照合

- 期待: 「旧ビュー → 新ビューがチラつき無く差し替わる。ローディング表示（スピナー、スケルトン、aria-busy 表示等）が瞬間的にも出ない」
- 実測: 切替中の loading 関連 DOM 変化なし。スクリーンショットも空白なし → **PASS**
