## 確認環境

このIssueの変更を確認するために必要な手順のみ記載。

### 検証環境の起動
- ローカル D1 マイグレーション: `pnpm db:migrate`（`wrangler d1 migrations apply hollow-local-d1 --local`）
- dev サーバー: `pnpm dev`（`vite.config.cloudflare.ts` の port 3000 固定）。別 worktree と並走するなら `pnpm dev --port 3100`。
- ルートツリー再生成は dev/build の codegen が自動実行する（`routeTree.gen.ts` は手編集しない）。
- ログイン: `pnpm seed:dev-admin` で admin ユーザー + 無期限セッション（token `dev-admin-session-token`）を冪等投入し、cookie `__Host-session` を注入してログイン省略（[[local-browser-verification]] 参照）。検証用ノートが必要なら `scripts/seed-dev-admin.mjs` を雛形に一時 SQL を `pnpm db:execute:local <file>` で投入。

### デプロイ方法
なし（検証環境のみで確認できる）。

## 確認項目

### 1. ピルからモーダルが開く

- **目的:** 「公開設定」ピルがページ遷移ではなくその場でモーダルを開く。
- **手順:**
  1. ログイン済みでノート詳細 `/notes/<id>` を開く。
  2. アクションバーの「公開設定」ピル（地球アイコン + 現在の公開状態ラベル + 状態ドット）をクリック。
- **期待結果:** URL が変わらず、中央にモーダルが開く。背景はスクロールロックされる。
- **確認ポイント:** ピルが `<a>` ではなく `<button>` であること（URL に `/publish` が付かない）。

### 2. 公開ステータス変更

- **目的:** 非公開 / 限定公開 / 公開のラジオ変更が反映される。
- **手順:**
  1. モーダルでラジオを「公開」に変更し「公開状態を更新」を押す。
  2. モーダルを閉じてピルのラベル・状態ドット色を確認。
- **期待結果:** 更新が成功し、ピルのラベルとドット色（public/unlisted/private）が新しい状態に追従する。
- **確認ポイント:** ボタン押下中は「適用中...」表示。

### 3. 限定公開リンクの発行・パスワード・失効

- **目的:** リンクの発行/パスワード設定/解除/失効が一連で機能する。
- **手順:**
  1. ステータスを「限定公開」または「公開」にする。
  2. パスワード（任意）を入力して「リンクを発行」。
  3. 表示された一回限りURLをコピーできることを確認（コピーボタン）。
  4. 一覧の行でパスワードを設定 → 解除 → 失効を順に実行。
- **期待結果:** 各操作後に一覧が更新される。発行直後URLは一度だけ表示され、再表示されない。失効すると行が失効済み表示になる。
- **確認ポイント:** 非公開ステータスでは「非公開ステータスではリンクを発行できません」が表示され発行フォームが出ない。

### 4. 閉じる/戻る手段

- **目的:** モーダルを閉じる手段が必ず存在する。
- **手順:**
  1. モーダルを開き、× ボタンで閉じる。
  2. 再度開き、Esc キーで閉じる。
  3. 再度開き、最下部「閉じる」ボタンで閉じる。
- **期待結果:** いずれの方法でも閉じ、フォーカスがピルに戻る（focus restore）。
- **確認ポイント:** 閉じた後ノート詳細にとどまり、行き止まりにならない。

## エッジケース・異常系

### 1. pending 中は閉じられない

- **目的:** 非同期操作中にモーダルを閉じて中途半端な状態にならない。
- **手順:**
  1. ステータス更新やリンク発行を押した直後（処理中）に Esc / × / 「閉じる」を試す。
- **期待結果:** 処理完了までモーダルは閉じない（`closable=false`）。× ボタンは disabled。

### 2. 旧ルートの直アクセス

- **目的:** ルート廃止が反映されている。
- **手順:**
  1. ブラウザで `/notes/<id>/publish` に直接アクセス。
- **期待結果:** 404（ルート未定義）になる。アプリがクラッシュしない。

## 既存機能への影響確認

- **移動/削除/エクスポート/複製/履歴**: アクションバーの他の操作が従来どおり動く（NoteActions の props 変更の副作用がないこと）。
- **一括公開変更（一覧）**: `/`（ノート一覧）で複数選択 → `BulkVisibilityDialog` が従来どおり動く（`action.ts` の `bulkChangeVisibilityFn` を共有しているため）。
- **公開ノートの公開ページ**: 公開/限定公開に変更したノートが `/share/<token>` や公開URLで閲覧できる。
