## 確認項目

### 1. フィルタ操作の URL 反映（FilterBar）

- **目的:** `homeSearchUpdater` 置換後も、各フィルタの付与・解除で URL search が従来どおり更新されること
- **手順:**
  1. home（`/`）を開く
  2. タグチップをクリックして選択 → 解除する
  3. 期間（開始日 / 終了日）を入力する
  4. 公開状態セレクトを変更する（非公開 / 限定公開 / 公開）
  5. 「内部リンク参照」でノートを選ぶ → ×で解除する
  6. 「クリア」ボタンで全フィルタを解除する
- **期待結果:** 各操作で URL の `?tagNames=...` / `?from=...&to=...` / `?visibility=...` /
  `?referencingNoteId=...` が付与・除去され、一覧が対応して更新される。
  「クリア」後は `display` と `q`（あれば）だけが残り、他のフィルタ paramが消える。
- **確認ポイント:** デフォルトページネーション（`page=1&limit=20`）が URL に**出ない**こと（Issue #215 の挙動維持）。
  内部リンク参照を付与したとき `page` が URL から落ちる（ページリセット）こと。

### 2. 表示モード切替の URL 反映（DisplayModeSwitch）

- **目的:** `homeSearchUpdater` 置換後も表示モード切替が URL に反映されること
- **手順:**
  1. home で「リスト / タイル / カレンダー」タブを順に切り替える
- **期待結果:** URL の `?display=list|tile|calendar` が切り替わり、一覧の表示形式が変わる。
  履歴は `replace`（戻るボタンでモード切替を辿らない）。
- **確認ポイント:** 既存のフィルタ paramを保持したまま `display` だけが更新されること。
