## 確認項目

### 1. アップロードページから「取り込みキュー」見出しが消えていること

- **目的:** Issue項目3「『取り込みキュー』見出しを削除してスッキリさせる」が反映されていることを確認
- **手順:**
  1. ログイン後、サイドバーまたはヘッダー経由で `/upload` を開く
  2. ページ上部のページタイトル「アップロード」と説明文の下に UploadForm が出る
  3. その下のキュー一覧領域を確認する
- **期待結果:** キュー一覧の上に「取り込みキュー」という h2 見出しが**ない**。フォーム → キュー一覧が見出しなしで自然に繋がる。
- **確認ポイント:** 見出しが消えた分の余白が違和感ないか（`<section className="mt-12">` が残っているので UploadForm との縦間隔は保持されるはず）

### 2. サイドバーの「アップロード」が `/upload` への遷移リンクになっていること

- **目的:** Issue項目5「サイドバーからは取り込みキュー画面への単純なリンクで良い」を確認
- **手順:**
  1. `/`（ホーム）等、`/upload` 以外の画面を開く
  2. サイドバー「管理」セクションの「アップロード」項目をクリック
- **期待結果:**
  - `/upload` に画面遷移する（URL が `/upload` になる）
  - URL に `#upload` が付かない（モーダルが開かない）
  - サイドバー「アップロード」項目に `data-active` が付き、現在地としてハイライトされる
- **確認ポイント:** アップロードモーダル（UploadDialog）は開かない。ヘッダー右上の「アップロード」ボタンを押した場合は引き続きモーダルが開くこと（壊れていない確認）。

### 3. ヘッダー右上「アップロード」ボタンでモーダルは引き続き開くこと（回帰確認）

- **目的:** サイドバーから外したモーダル起動動線が、ヘッダー側では維持されていることを確認
- **手順:**
  1. ホーム画面でヘッダー右の「アップロード」CTA をクリック
  2. アップロードモーダルが開く
  3. URL に `#upload` が付くことを確認
- **期待結果:** モーダルが従来通り開く。URL は `#upload` 付き。
- **確認ポイント:** ノート一覧ツールバー（NoteListToolbar）の「アップロード」も同様に動くこと。

### 4. 管理画面のヘッダー〜タブヘッダー〜コンテンツの縦リズム

- **目的:** Issue項目4「中途半端な余白を整える」が反映されていることを確認
- **手順:**
  1. 管理者でログインし `/admin` を開く
  2. 上部の管理ヘッダー（ロゴ + 「管理者モード」バッジ + アバター）と、その直下のタブナビ（ダッシュボード / LLM設定 / ...）の隙間を目視
  3. ページを下にスクロールし、ヘッダーとタブナビが両方 sticky で固定された状態で、両者の境界に隙間ができていないか確認
  4. `/admin/llm`, `/admin/users`, `/admin/jobs` 等にタブで移動し、同様に確認
- **期待結果:**
  - ヘッダー直下にタブナビが隙間なく接している
  - スクロール時もヘッダーとタブナビの境界がぴったり接する（中途半端な数px の余白が出ない）
  - タブナビ下のコンテンツ余白は従来通り保たれている
- **確認ポイント:** ヘッダー内のロゴ・ピル・アバターが垂直中央に並んでいる（高さ固定化で潰れていない）

## エッジケース・異常系

### 1. モバイル幅でも管理ヘッダーが縦リズムを保つ

- **目的:** 旧コードに `max-sm:py-3` で縦パディングを縮める指定があった。`h-[var(--header-height)]` 固定化でモバイル時の見え方が極端に崩れていないことを確認
- **手順:**
  1. ブラウザ DevTools で幅 360px などモバイルサイズに切り替える
  2. `/admin` を開く
- **期待結果:** ヘッダー内コンテンツが横方向に詰まりつつも、縦に潰れていない・はみ出していない。タブナビとの境界に隙間がない。

### 2. アップロードページ未ログイン時の表示は変更されないこと

- **目的:** 認証ガードや loaders には触れていないことの確認
- **手順:** ログアウト状態で `/upload` に直接アクセス
- **期待結果:** 既存と同じ挙動（ログインへのリダイレクトなど）
