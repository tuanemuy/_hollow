# TC-001: AuthHeader backdrop-filter が canonical パターンに統一されている

**結果**: PASS
**セッション**: verify-tc-001
**URL**: http://localhost:5174/login

## 実行ログ

| # | 操作 | 期待結果 | 実際の結果 | 判定 |
|---|------|---------|-----------|------|
| 1 | `/login` を開き `<header>` の className を取得 | `backdrop-blur-xl` が無く、`[backdrop-filter:var(--header-blur)]` + `[-webkit-backdrop-filter:var(--header-blur)]` を持つ | className = `...supports-[backdrop-filter]:[backdrop-filter:var(--header-blur)] supports-[backdrop-filter]:[-webkit-backdrop-filter:var(--header-blur)]`（`backdrop-blur-xl` なし） | PASS |
| 2 | `<header>` の computed `backdrop-filter` を取得 | `saturate(180%) blur(20px)`（= `var(--header-blur)`） | `saturate(1.8) blur(20px)`（= `saturate(180%) blur(20px)`） | PASS |

## 備考

- 本変更の意図的な視覚変化は **Safari(webkit) 側**（`blur(24px)` saturate なし → `saturate(180%) blur(20px)`）。検証環境の agent-browser は Chromium のため webkit 固有描画は観測できない。
- Chromium(standard 経路)は変更前から `var(--header-blur)` 経由であり、本検証で **無回帰**（resolved 値が token と一致）を確認した。
- AC-2（Safari で他ヘッダーと一致）は、他4ヘッダーと**完全同一の className 文字列**に統一したことで担保される（同一スタイル → 同一描画）。
