# TC-EDGE-1（異常系）: 生編集JSONが不正なら保存ブロック

**結果**: PASS

## 操作ログ

| # | 操作 | 結果 |
|---|------|------|
| 1 | FrontMatter付きノート編集画面を開く | OK |
| 2 | 「生編集（JSON）」ボタンをクリック | OK。FrontMatter（JSON）テキストエリアが表示 |
| 3 | JSONを壊れた値 `{ "a": }` に fill 上書き | OK |
| 4 | エラー表示と保存ボタンの状態を確認 | OK。エラー文「JSON が解析できません: Unexpected token '}', "{ "a": }" is not valid JSON」表示、保存ボタンが disabled |
| 5 | （追加確認）正しいJSON `{ "a": "ok" }` に修正 | OK。エラー消失、保存ボタンが再度有効化 |

## 判定

- 不正なJSON入力時にエラーメッセージが表示され、保存ボタンが無効化された。期待どおり。
- 正しいJSONに直すとエラーが消え保存が再有効化されることも確認し、ゲートがJSON妥当性に連動していることを裏付けた。
