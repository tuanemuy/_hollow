## 備考

### 環境制約（バグではない）

TC-005 と同じ。ローカル dev では R2 が未バインドのため `presignMediaUploadFn` server function が 500 で落ちる。Issue #9 で導入された問題ではなく、メディアアップロード全般のローカル dev 制約。

### HTML モードの末尾追記挙動は維持されている

- `mediaInsert.test.ts` の 20 ケース（trim、空入力、alt エスケープ、id 厳格バリデーション、UUIDv7 形状受理、`/`/`.`/空白拒否など）が全 PASS
- `NoteEditor.onMediaInsert` の分岐コード (`state.mode === "wysiwyg"` チェック) で HTML モードでは従来どおり `insertMediaIntoHtml(contentHtml, ...)` → `setContent` パスを通る
- `insertMediaIntoHtml` 関数自体は Issue #9 で変更されていない（git ログ確認）

### 推奨

R2 バインド済みのステージング環境で end-to-end の挙動確認を推奨。本マニュアルテストでは Issue #9 ADR-003 の "HTML モードは末尾追記の従来挙動維持" は壊れていないとみなして PASS とする。
