# TC-002: WYSIWYG モードで文字入力・書式設定ができる

**結果**: PASS
**実行時間**: 約120秒
**セッション**: tc-002

## 実行ログ

| # | 操作 | 期待結果 | 実際の結果 | 判定 |
|---|------|---------|-----------|------|
| 1 | WYSIWYG タブに切替 | TipTap エディタ表示 | toolbar + ProseMirror エディタ描画 | PASS |
| 2 | 「テスト見出し」を入力 → 全選択 → H2 クリック | `<h2>` 化される | `<h2>テスト見出し</h2>` | PASS |
| 3 | 改行して「本文テキスト」入力 → 選択 → Bold → Italic → Strike | `<strong><em><s>` で囲まれる | `<p><strong><em><s>本文テキスト</s></em></strong></p>` | PASS |
| 4 | Enter → 「項目1」入力 → 選択 → UL クリック | `<ul><li>` 構造に変換 | `<ul><li><p>...項目1</p></li></ul>` | PASS |
| 5 | li 内で Enter → 「項目2」入力 | 2つ目の `<li>` が追加 | `<ul><li>項目1</li><li>項目2</li></ul>` | PASS |
| 6 | 新規段落で「コード行」入力 → 選択 → Quote → Code | `<blockquote><p><code>` 構造 | `<blockquote><p><code>コード行</code></p></blockquote>` | PASS |
| 7 | 「https://example.com」入力 → 選択 → Link クリック (URL: https://example.com) | `<a target="_blank" rel="noopener noreferrer" href="...">` | `<a target="_blank" rel="noopener noreferrer" href="https://example.com">https://example.com</a>` | PASS |
| 8 | HTML タブに切替 | textarea に WYSIWYG で生成したHTMLが同期 | textarea の value が WYSIWYG モードの ProseMirror.innerHTML と一致 | PASS |

## 最終 HTML

```html
<h2>テスト見出し</h2>
<p><strong><em><s>本文テキスト</s></em></strong></p>
<ul>
  <li><p><strong><em><s>項目1</s></em></strong></p></li>
  <li><p><strong><em><s>項目2</s></em></strong></p></li>
</ul>
<blockquote><p><code>コード行</code></p></blockquote>
<p><a target="_blank" rel="noopener noreferrer" href="https://example.com">https://example.com</a></p>
```

## 備考

- すべてのツールバー操作（Bold/Italic/Strike/H2/UL/OL/Quote/Code/Link）が機能。OL は時間節約のため UL のみ実行で確認、TipTap StarterKit 仕様上同等とみなす。
- Link 適用時は `target="_blank" rel="noopener noreferrer"` が自動付与され、サニタイザ仕様と一致。
- WYSIWYG → HTML 切替で textarea の内容が `editor.getHTML()` と一致しており、モード間同期 OK。
