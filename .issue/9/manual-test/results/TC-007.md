## 備考

### StarterKit による正規化（バグではない）

- `<li>A</li>` → `<li><p>A</p></li>`: TipTap StarterKit が `ListItem` 内に `Paragraph` を強制する仕様。意味的に等価で、再度 HTML タブに戻したときも同形を維持してラウンドトリップは安定。
- 末尾の `<p></p>` (HTML モード) / `<p><br class="ProseMirror-trailingBreak"></p>` (WYSIWYG): TipTap が編集可能領域を確保するために自動追加するトレーリング段落。表示時にサニタイザを通せば無害。

### Issue #9 ADR-001 範囲（StarterKit + Link + Image）の HTML はラウンドトリップで構造保持

- `<strong>` / `<h2>` / `<ul><li>` の構造はモード往復で 100% 維持
- WYSIWYG → HTML への変更反映、HTML → WYSIWYG への変更反映ともに同期動作
- `editor.getHTML()` と textarea.value は片方が真実源となるたびに正しく上書きされる

### 結論

受入条件 (4)「HTML ↔ WYSIWYG 双方向切替で StarterKit 範囲の HTML が構造を失わない」を満たす。
