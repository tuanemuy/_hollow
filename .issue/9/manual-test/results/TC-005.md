## 備考

### 環境制約（バグではない）

ローカル `pnpm dev` 環境は R2 が wrangler.toml に未バインドで、`createRequestContainer` でも `objectStorage` が wiring されていない（`app/core/application/di/serverCloudflare.ts:142-184` は `R2ObjectStorage` を注入せず `as unknown as RequestContainer` で型キャストのみ）。そのため `presignMediaUploadFn` の server function が 500 で落ちる。これは Issue #9 で新たに導入された問題ではなく、メディアアップロード全般のローカル dev 制約。

### Issue #9 由来の "カーソル位置挿入" ロジックは検証済み

- `NoteEditor.tsx:129-144` の `onMediaInsert` が WYSIWYG モード時に `tiptapEditorRef.current.chain().focus().setImage(...).run()` を呼ぶ仕様を直接実行して検証
- カーソルが段落間にある場合: 段落の**間**に `<img>` を挿入（末尾追記ではない）
- カーソルが先頭/末尾の場合もそれぞれ正しい位置に挿入
- TipTap StarterKit + Image extension が期待どおり動作

### 補足

- end-to-end の orphan purger / `note_media_refs` 確認は今回スコープ外（DB アクセス必要、かつアップロードが通らないため）
- リモートステージング環境（R2 バインド済み）での再検証を推奨
