## 検証内容

### TC-001: 空フォールバック（最重要・最頻ケース）

instance 既定・ユーザー上書きとも未設定の標準状態で、両欄が出所「プロバイダ組み込み」とフォールバック文言「LLM プロバイダの既定指示を使用」を placeholder・「既定値を表示」展開部の双方に表示。空欄で無言にならず、何が使われるか判別できることを確認。

- スクショ: `screenshots/tc-001/01-defaults-expanded.png`

### TC-002: 状態バッジ切替

構造化欄にテキスト入力 → バッジ「この回だけ上書き」、全消去 → 「既定を使用中」に復帰。メタデータ欄は終始「既定を使用中」のまま（欄ごとに独立）。

- スクショ: `screenshots/tc-002/01-override-active.png`, `02-reverted-default.png`

### TC-003 / TC-003b: 上書きとインスタンス既定の出し分け

User A（structure のみ override）でログイン → 構造化欄は出所「ユーザー設定で上書き中」+ 上書きテキスト、メタデータ欄は出所「インスタンス既定」+ 既定テキスト。実際に使われる値（上書き優先）が表示される。admin（override なし）では両欄とも「インスタンス既定」。

- スクショ: `screenshots/tc-003/01-userA.png`, `02-admin-instance.png`
