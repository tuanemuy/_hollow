## 所感

Issue #743 の変更は意図どおり動作している。

- パンくず（navigation "現在のディレクトリ"）はディレクトリ解決成功時のみ、main 直下の h1 より前に描画される。末尾セグメントは非リンクテキスト（aria-current="page"）、祖先はリンクとして機能。
- パンくず末尾の × は廃止済み。
- 解決不能 directoryId の場合はパンくずを出さず、フィルタ行にフォールバックチップ（× 付き）を出す棲み分けが成立。
- ディレクトリ未選択時はパンくず・フォールバックチップともに非表示で、h1 が最上部。レイアウト崩れなし。
- clear-all（フィルタをすべてクリア）が directory 選択時に表示され、押すと directoryId を含む全フィルタが解除される。

## 備考

- find text / CSS :has-text() セレクタは当環境の agent-browser で not found となるケースがあり、snapshot の a11y ref（@eNN）でのクリックに切り替えて検証した。検証結果には影響なし。
