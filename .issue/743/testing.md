## 事前準備（シードデータ）

確認には少なくとも 2 階層のディレクトリ（例: `Documents › Research`）と、その配下のノートが必要。アプリ上でディレクトリを作成し、ノートをそのディレクトリに割り当てておく。フォールバックチップ確認用に「削除済みディレクトリ id を指す状態」を作るため、ディレクトリ選択後にそのディレクトリを削除する操作も用意する。

## 確認項目

### 1. 末尾（現在ディレクトリ）が非リンク化されている

- **対応する受け入れ基準:** AC-1
- **目的:** 末尾セグメントが `<Link>` ではなく `aria-current="page"` の非リンクテキストになっていること。
- **手順:**
  1. ノート一覧で 2 階層目のディレクトリ（例: `Research`）を選択し `?directoryId=...` の状態にする。
  2. ヘッダ上部のパンくずの**末尾**セグメント（現在ディレクトリ名）にカーソルを合わせ、クリックを試みる。
- **期待結果:** 末尾セグメントはリンクではなく、クリックしても遷移しない。`text-ink-secondary` のトーンで現在地として表示される。
- **確認ポイント:** DevTools で末尾要素が `<span aria-current="page">` であり `<a>` でないこと。

### 2. 祖先セグメントはリンクとして機能する

- **対応する受け入れ基準:** AC-2
- **目的:** 末尾以外（祖先）セグメントは従来どおりリンクで、押すとその祖先ディレクトリで絞り込まれる。
- **手順:**
  1. `Documents › Research` を選択した状態にする。
  2. パンくずの祖先 `Documents` をクリックする。
- **期待結果:** `?directoryId={Documents の id}` の一覧へ遷移する。

### 3. 末尾「ディレクトリフィルタを解除」× が消えている

- **対応する受け入れ基準:** AC-3
- **目的:** パンくず末尾の × ボタンが廃止されている。
- **手順:**
  1. ディレクトリを選択した状態でパンくずを確認する。
- **期待結果:** パンくず内に × ボタン（「ディレクトリフィルタを解除」）が存在しない。

### 4. パンくずが見出し（h1）の上に表示される

- **対応する受け入れ基準:** AC-4
- **目的:** 表示位置がフィルタ群の下ではなく、ページ見出しの上（詳細の現在地アンカーと同じ配置）になっている。
- **手順:**
  1. ディレクトリを選択した状態で一覧ページを開く。
  2. パンくず・見出し（h1）・フィルタ群の縦の並びを確認する。
  3. 同じディレクトリのノート詳細ページを開き、`NoteBreadcrumb`（タイトル上）の配置と見比べる。
- **期待結果:** パンくずがページ見出し（h1）の**上**に出る。フィルタ群（タグ/日付/公開状態チップ）の下には出ない。詳細ページの現在地アンカーと対称な配置になっている。
- **確認ポイント:** パンくずの `nav` 直下に `mb-6` 相当の余白があり、その下に h1 が続くこと。

### 5. 「全ノートに戻る」導線（clear-all）が担保される

- **対応する受け入れ基準:** AC-5
- **目的:** root crumb は無いが、ディレクトリ選択時に「フィルタをすべてクリア」が常に表示され、押すと directory を含む全フィルタが消える。
- **手順:**
  1. ディレクトリ（必要ならタグ等も併せて）を選択する。
  2. ツールバーの「フィルタをすべてクリア」を押す。
- **期待結果:** `directoryId` を含む全フィルタが解除され、全ノート一覧（フィルタ無し）に戻る。ディレクトリ選択中は clear-all が必ず表示されている。

## エッジケース・異常系

### 1. 解決不能ディレクトリ（削除済み等）のフォールバックチップ

- **対応する受け入れ基準:** AC-6
- **目的:** id をパンくずに展開できない場合（削除済み等）、フィルタ行に × 付きフォールバックチップが残る。
- **手順:**
  1. あるディレクトリを選択して `?directoryId=...` の状態にする。
  2. 別タブ/操作でそのディレクトリを削除し、`directoryId` が解決不能な状態の一覧を表示する。
- **期待結果:** ヘッダ上にパンくずは出ず、**フィルタ行**に × 付きのフォールバックチップが表示される。× を押すとディレクトリフィルタが解除される。
- **確認ポイント:** location（パンくず）はヘッダ上、filter（フォールバックチップ）はフィルタ行、という棲み分けになっていること。両者が同時に出ないこと。

### 2. ディレクトリ未選択時

- **目的:** `directoryId` 未設定のときは現在地パンくずが描画されない。
- **手順:**
  1. フィルタ無しの全ノート一覧を開く。
- **期待結果:** ヘッダ上にパンくずが出ない（h1 がそのまま最上部）。レイアウト崩れが無い。

## 既存機能への影響確認

- **ノート詳細の `NoteBreadcrumb`**: 揃える「先」であり不変。詳細ページのパンくず（タイトル上・末尾非リンク）が従来どおり動くこと。
- **フィルタ群（タグ/日付/公開状態チップ）の挙動**: パンくず撤去後もフィルタ行のチップ操作・絞り込みが従来どおり動くこと。
- **BulkActionBar**: ディレクトリツリーを使う一括操作が従来どおり動くこと（tree の共有 `treeQuery` 参照化による I/O 変化が無いこと）。
- **ヘッダの境界（#649 ADR-009）**: ツールバー領域が tree 依存を新たに含むため、（再現できれば）ツリー読み込み失敗時にヘッダが fallback に落ちても静的 h1 が残ることを確認。
