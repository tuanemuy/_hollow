# TC-003: CALLOUT_ACTION（確認メール再送ボタン）

**結果: SKIP（環境上 callout 未到達）+ 静的検証で代替確認**

対象: `/login` の「メール未確認」callout 内「確認メールを再送」ボタン（`CALLOUT_ACTION`）。

## 実行ログ

| # | ステップ | 結果 |
|---|---------|------|
| 1 | callout のトリガー条件をソース確認 | `LoginForm/index.tsx` L92-93: `isUnverified = error.kind==="unauthorized" && error.code==="unverified"` の時のみ callout 描画 |
| 2 | `/login` でダミー資格情報（unverified-test@example.com / Password123!）でログイン試行 | エラー応答は「認証が必要です／ログインできませんでした」（generic unauthorized）。callout は **未描画**（DB に該当 unverified アカウント無し） |
| 3 | callout 要素の存在確認（「確認メールを再送」ボタン） | `false`（未到達） |
| 4 | UI 目視 | 環境上トリガー不可のため SKIP |

callout は「DB に存在する未確認メールアカウント」でのログインが必要。本検証環境（シード無し・ログイン不要前提）では再現できないため、指示どおり無理に作り込まず SKIP とする。ログイン試行画面のスクショは `tc-003-login-attempt.png` に保存。

## 静的検証による代替確認（トークン集合一致）

`CALLOUT_ACTION` の装飾は TC-001/TC-002 でライブ検証済みの `textLink` primitive を合成している。

- `app/components/common/styles.ts` L104-105:
  `textLink = "text-accent hover:underline hover:[text-underline-offset:3px]"`
- `app/components/auth/styles.ts` L70:
  `CALLOUT_ACTION = "inline-flex items-center gap-1 ${textLink} font-medium text-sm self-start disabled:opacity-60"`

→ accent 色・hover 下線（3px offset）の装飾トークンは TC-001/002 で実機確認済みの primitive と**静的に同一**。加えて `inline-flex items-center gap-1`（アイコン+文字を gap-1 で配置）・`font-medium`・`disabled:opacity-60`（pending 時 60% 半透明）も合成済み。`pnpm build`（下記サマリー参照）が通り生成 CSS に差分が出ないことも裏取り。
