# TC-004（エッジ）: PUBLIC_TEXT_LINK_SIGNUP 無影響（public ヘッダ）

**結果: PASS**

対象: PublicLayout ヘッダ右側の「サインアップ」リンク（`PUBLIC_TEXT_LINK_SIGNUP`）。

補足: `PublicLayout`（`PUBLIC_TEXT_LINK_SIGNUP` を持つヘッダ）が描画されるのは `/about` `/terms` `/privacy` `/share/$token`。`/`（マーケティング LP）は別ヘッダで「サインアップ」要素は無いため、対象要素のある `/about` で検証した（同一 `PUBLIC_TEXT_LINK_SIGNUP` 定数）。

## 実行ログ

| # | ステップ | 結果 |
|---|---------|------|
| 1 | `http://localhost:5175/about` を open → `wait --load networkidle` | OK（URL 一致・16リンク描画） |
| 2 | ヘッダ「サインアップ」リンク特定 | OK（text=サインアップ, href=/） |
| 3 | computed style 確認（accent 下線リンクでないこと / pill 風であること） | `className="text-sm font-medium text-ink px-2.5 h-9 inline-flex items-center rounded-md ... hover:bg-surface max-sm:hidden"`、`color=rgb(29,29,31)`（=text-ink、accent ではない）、`text-decoration-line=none`、`border-radius=8px`（rounded-md）、`height=36px`（h-9） |
| 4 | hover 挙動確認 | `:hover=true`、`background-color=rgb(245,245,247)`（=surface 色）、`text-decoration-line=none`（下線出ない） |
| 5 | スクリーンショット | 保存済み |

## 確認ポイントの判定

- accent 下線リンクでは**ない**（`text-ink` / decoration none）→ OK
- surface-hover の pill 風（hover で背景が surface 色 `rgb(245,245,247)` に変化、`rounded-md`=8px）→ OK
- 据え置き意匠のまま、`textLink` 統一の影響を受けていない（別 primitive `PUBLIC_TEXT_LINK` を維持）→ OK

死蔵再エクスポート削除は public ヘッダ表示に無影響であることを実機で確認。
