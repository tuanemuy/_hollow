# TC-002: FIELD_LINK（/login パスワードリセットリンク）

**結果: PASS**

対象: `/login` パスワード欄ラベル行の「パスワードを忘れた方」リンク（`<Link to="/password-reset">`, `FIELD_LINK = text-sm ${textLink}`）。

## 実行ログ

| # | ステップ | 結果 |
|---|---------|------|
| 1 | `/login`（TC-001 と同セッション流用） | OK |
| 2 | リンク特定（ref=e6, href=/password-reset, text=「パスワードを忘れた方」） | OK |
| 3 | hover 前の computed style 確認 | `className="text-sm text-accent hover:underline hover:[text-underline-offset:3px]"`、`color=oklch(0.371 0 0)`、`font-size=13px`、`text-decoration-line=none` |
| 4 | hover → 下線確認 | `:hover=true`、`text-decoration-line=underline`、`text-underline-offset=3px`、`font-size=13px` 維持 |
| 5 | スクリーンショット | 保存済み |

## 確認ポイントの判定

- `text-sm`（13px、本文より小さめ）の accent 色リンク → OK（`text-sm ${textLink}` 合成を className で確認）
- hover で 3px offset 下線 → OK
- 色・下線挙動が AUTH_FOOTER_LINK と同質（同一 `textLink` primitive）→ OK
