```
HTTP/1.1 200 OK
content-type: application/xml; charset=utf-8
cache-control: public, max-age=300, s-maxage=600

```

- HTTP 200 ✓
- Content-Type: `application/xml; charset=utf-8` ✓
- Cache-Control: `public, max-age=300, s-maxage=600` ✓

## 本文内容

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url><loc>http://localhost:8787/</loc></url>
  <url><loc>http://localhost:8787/signup</loc></url>
  <url><loc>http://localhost:8787/login</loc></url>
  <url><loc>http://localhost:8787/search</loc></url>
  <url><loc>http://localhost:8787/terms</loc></url>
  <url><loc>http://localhost:8787/privacy</loc></url>
  <url><loc>http://localhost:8787/about</loc></url>
  <url><loc>http://localhost:8787/u/test-user-001</loc></url>
  <url>
    <loc>http://localhost:8787/u/test-user-001/public-design-guide</loc>
    <lastmod>2026-05-09T12:00:00.000Z</lastmod>
  </url>
</urlset>
```

- well-formed XML（`xmllint --noout` パス） ✓
- 静的 `<loc>` 7 件（`/`, `/signup`, `/login`, `/search`, `/terms`, `/privacy`, `/about`） すべて `http://localhost:8787` プレフィックス付きで含まれる ✓
- 公開ノートも 1 件含まれ、`<lastmod>` が ISO 8601 形式 ✓
- 公開ノートを持つユーザーの公開トップ `/u/test-user-001` も含まれる ✓
- 非公開ノートは含まれていない（DB に test-user-001/public-design-guide 以外の公開ノートが無いため網羅検証は限定的） ✓
