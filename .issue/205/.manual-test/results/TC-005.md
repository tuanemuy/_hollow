# TC-005: LandingPage フッターのリンク差し替え

- **Status:** PASS
- **URL:** http://localhost:3000/ (未ログイン、LandingPage 表示)
- **Screenshot:** `.issue/205/.manual-test/screenshots/tc-005-landing-footer.png`

## 確認結果

`/` は `?page=1&limit=20` 付きに正規化されるが、LandingPage が表示されている。

footer 内 `<a>` の href:

| text | href | 期待 | 判定 |
|---|---|---|---|
| 機能 | `#features` | アンカー | PASS |
| 公開検索 | `/?page=1&limit=20` | - | PASS |
| エクスポート | `/?page=1&limit=20` | - | PASS |
| このインスタンスについて | `/about` | `/about` | PASS |
| 運営者情報 | `/about` | `/about` | PASS |
| お問い合わせ | `/about#contact` | `/about#contact` | PASS |
| 利用規約 | `/terms` | `/terms` | PASS |
| プライバシーポリシー | `/privacy` | `/privacy` | PASS |
| 特定商取引法 | `/about#commerce` | `/about#commerce` | PASS |

旧 `to="/"` のリンクは「公開検索」「エクスポート」のような Landing 内ナビ用途のみで、置き換え対象だった「利用規約・プライバシー・このインスタンスについて等」は全て新 URL を指している。
