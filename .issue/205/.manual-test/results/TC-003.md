# TC-003: /about ページの AppConfig 差し込み

- **Status:** PASS
- **URL:** http://localhost:3000/about
- **Screenshot:** `.issue/205/.manual-test/screenshots/tc-003-about.png`

## 確認結果

- HTTP 200 で表示された。
- 警告 blockquote が表示されている。
- `{{` `}}` プレースホルダはページ本文に残っていない（`(text.match(/\{\{|\}\}/g)) === null`）。
- AppConfig 値が差し込まれている:
  - `siteName` → `TanStack Start Template`（複数箇所に表示）
  - `appUrl` → `http://localhost:8787`（複数箇所に表示）
- 「運営者」「連絡先」「特定商取引法 {#commerce}」「お問い合わせ {#contact}」の各セクションが表示されている。
  - 注: `{#commerce}` `{#contact}` の表記が本文中に文字列としてそのまま残っているが、これは Markdown の見出し ID 構文（kramdown 風）が markdown-it のデフォルトでは ID 化されない仕様のため。`{{ }}` プレースホルダではないので Issue #205 の AppConfig 差し込みとは別件。
