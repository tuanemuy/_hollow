# TC-006（エッジ）: 非発火条件（bulk・50件以下・メディアOFF）

判定: PASS

## 手順
1. `/export` で「メディアを埋め込む」(embedMedia) を uncheck。
2. textarea に 3 件の ID（`id1 id2 id3`）を入力。

## 結果
- embedMedia = false、件数 = 3（≤50）。
- バナー ABSENT（role=note +「非同期ジョブを推奨します」要素なし）。
- 発火条件 `bulkCount > 50 || embedMedia` のどちらも満たさないため非表示。仕様どおり。
