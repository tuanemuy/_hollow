# TC-005: P15 件数超過で発火（メディアOFFでも件数>50なら出る）

判定: PASS

## 手順
1. `/export` で「メディアを埋め込む」(embedMedia) を uncheck → checkbox 状態 [FrontMatter=true, embedMedia=false]。textarea 空のためバナー ABSENT を確認。
2. textarea に 51 件のダミー ID（`id1 … id51`、スペース区切り、51 トークン）を入力。

## 結果
- embedMedia = false かつ 件数 = 51（>50）で、バナーが表示された。
  - role="note"
  - タイトル「非同期ジョブを推奨します」
  - 本文「選択中の 51 件は即時 DL 可能ですが、容量が増えるため非同期ジョブを推奨します。完了したら エクスポートジョブ一覧 から確認できます。」
  - code「エクスポートジョブ一覧」
  - accent = `oklch(37.1% 0 0)`（無彩色グレー、chroma 0、青なし）
- 「選択中の 51 件」が正しく表示。
