# TC-003: P13 モーダル 検証バナー

結果: PASS

## 概要
ヘッダーの「アップロード」導線（`<a href="/#upload">`）からアップロードモーダルを開き、未対応形式 `archive.zip` を選択したとき、モーダル内（SelectView）にも `.alert-error` 相当の検証バナーが表示され、進捗ビューへ遷移しないことを確認した。

| 4 | バナー内容・遷移確認 | 期待どおり |

## 確認結果（期待 vs 実際）

- モーダル内バナー種別: 期待 `.alert-error` → 実際 dialog 内 alert が `--color-error` アクセント PASS
- 見出し: 期待「対応外の形式が含まれています」→ 実際 同一 PASS
- ファイル名 code 表示: 期待 `archive.zip` を `<code>` → 実際 `<code>archive.zip</code>` PASS
- 案内文: 「対応形式 (...) のみ取り込めます」表示 PASS
- 進捗ビュー非遷移: 期待 select のまま → 実際 dialog 内に file input が残存（select view 維持）、進捗/アップロードビューへ未遷移 PASS
