# TC-004: P15 bulk 推奨バナー（初期表示 = メディアON）

判定: FAIL（テスト前提と実装の不一致。コードバグではない）

## 前提（テスト手順書）
- `/export` を開いた初期状態（embedMedia ON, textarea 空）で `.alert-info`「非同期ジョブを推奨します」が表示されるはず。

## 実際
- 初期状態（embedMedia ON・textarea 空・対象 0 件）ではバナーは表示されない（role=note 要素 / 「非同期ジョブを推奨します」テキストともに存在せず）。
- 対象ノート ID を 1 件以上入力すると（embedMedia ON）即座にバナーが表示される。3 件入力で確認: role="note"、タイトル「非同期ジョブを推奨します」、本文「選択中の 3 件…」、code「エクスポートジョブ一覧」、accent = `oklch(37.1% 0 0)`（無彩色グレー、chroma 0）。

## 原因
- 実装 `app/components/export/ExportForm/index.tsx` L163-166 の発火条件:
  ```
  showAsyncRecommendation = noteId === null && bulkCount > 0 && (bulkCount > 50 || embedMedia)
  ```
- `bulkCount > 0` 条件があるため、対象 0 件のときは embedMedia ON でもバナーは出ない。
- テスト前提「embedMedia 初期値 true なので初期表示でバナーが出る」は誤り。対象ノートが 0 件の初期状態では出ない（妥当な実装）。

## 補足
- セレクタ注意: バナー要素のクラスは literal `alert-info` ではなく Tailwind arbitrary utility `[--alert-accent:var(--color-info)]`。判定は `[role=note]` + テキストで行うのが正しい。
- バナー自体の文言・role・無彩色グレーは仕様どおり（対象 1 件以上のとき）。
