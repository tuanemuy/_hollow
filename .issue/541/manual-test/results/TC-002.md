# TC-002: P13 ページ サイズ超過バナー

結果: PASS

## 概要
`/upload`（P13）ページで 50MB 超のファイル `large.md`（実体 53MB / 表示 50.5 MB）を選択したとき、`.alert-warning` 相当の検証バナーが表示され、送信前に弾かれることを確認した。

## 実行ログ

| Step | 操作 | 結果 |
| --- | --- | --- |
| 1 | `http://127.0.0.1:3000/upload` を再 open（状態リセット） | alert 0 件を確認（リセット成功）。screenshot step-01 保存 |
| 2 | `input[type=file]` に `/tmp/hollow541/large.md` を upload | onChange 発火 |
| 3 | wait 3000ms 後 snapshot + screenshot step-02 | alert 表示を確認 |
| 4 | バナー内容確認 | 期待どおり |

## 確認結果（期待 vs 実際）

- バナー種別: 期待 `.alert-warning` → 実際 `[--alert-accent:var(--color-warning)]`（warning アクセント） PASS
- 見出し: 期待「サイズ超過のファイル」→ 実際 同一 PASS
- ファイル名＋サイズ code 表示: 期待 `large.md` とサイズ（約 50.5 MB）を `<code>` → 実際 `<code>large.md (50.5 MB)</code>` PASS
- 案内文: 期待「上限 50 MB を超えています」→ 実際「上限 50 MB を超えています。分割するか、個別にアップロードしてください。」 PASS
- アップロード非開始: 期待 進捗表示やノート追加なし → 実際「まだジョブがありません」のまま PASS
