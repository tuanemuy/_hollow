# TC-001: P13 ページ 未対応形式バナー

結果: PASS

## 概要
`/upload`（P13）ページで未対応形式 `archive.zip` を選択したとき、`.alert-error` 相当の検証バナーが表示され、送信前に弾かれることを確認した。

## 実行ログ

| Step | 操作 | 結果 |
| --- | --- | --- |
| 1 | `http://127.0.0.1:3000/upload` を開く（cookie注入済み） | title「アップロード — hollow」、ドロップゾーン表示。screenshot step-01 保存 |
| 2 | `input[type=file]` に `/tmp/hollow541/archive.zip` を upload | onChange 発火 |
| 3 | wait 1500ms 後 snapshot + screenshot step-02 | alert 表示を確認 |
| 4 | バナー内容確認 | 期待どおり |

## 確認結果（期待 vs 実際）

- バナー種別: 期待 `.alert-error` → 実際 `[--alert-accent:var(--color-error)]`（error アクセント） PASS
- 見出し: 期待「対応外の形式が含まれています」→ 実際 同一 PASS
- ファイル名 code 表示: 期待 `archive.zip` を `<code>` → 実際 `<code>archive.zip</code>` PASS
- 案内文: 期待「対応形式 (...) のみ取り込めます」→ 実際「対応形式 (HTML / Markdown / Word / Excel / PowerPoint / PDF / 画像 / 音声 / テキスト) のみ取り込めます。」 PASS
- アップロード非開始: 期待 進捗表示やノート追加なし → 実際「まだジョブがありません」のまま、ジョブ追加・進捗なし PASS
