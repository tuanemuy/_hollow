# 動作確認計画 — Issue #382: テキスト併記が冗長なボタンをアイコンのみに整理する

**Issue:** #382
**作成日:** 2026-06-01

---

## 確認環境

このIssueの変更を確認するために必要な手順のみ記載。

### 検証環境の起動

ライブのソース変更を確認するため Vite 開発サーバーを起動する:

```bash
pnpm dev
```

> 注: `pnpm start`（`wrangler dev`）はビルド済み `dist/worker` を配信するため、ソース変更を即時確認する用途には `pnpm dev` を使う。`pnpm start` で確認する場合は先に `pnpm build` が必要。

ローカル DB のマイグレーションが未適用なら:

```bash
pnpm db:migrate
```

### デプロイ方法

なし（検証環境のみで確認できる。本Issueは表示・a11y のみの変更でDB変更を伴わない）。

## 確認項目

### 1. ノート詳細「編集」ボタンがアイコンのみになる

- **目的:** `Pencil` アイコン単体で表示され、可視テキスト「編集」が消えていること。
- **手順:**
  1. `pnpm dev` でアプリを起動し、ログインする
  2. 任意のノート詳細ページ（`/notes/{id}`）を開く
  3. アクション行（ノート操作ツールバー）の先頭プライマリボタンを確認
- **期待結果:** 鉛筆アイコンのみのプライマリ（アクセント配色）ボタンが表示され、テキスト「編集」は表示されない。
- **確認ポイント:** プライマリ配色（`data-primary`）が維持されている。ホバーで `title="編集"` のツールチップが出る。

### 2. ノート詳細「複製」ボタンがアイコンのみになる

- **目的:** `Copy` アイコン単体で表示されること。
- **手順:**
  1. 同じノート詳細ページのアクション行を確認
- **期待結果:** コピーアイコンのみのボタンが表示され、テキスト「複製」は表示されない。ホバーで `title="複製"` が出る。
- **確認ポイント:** クリックで複製が実行され、複製先の編集ページに遷移する。

### 3. ホームツールバー「新規作成」がアイコンのみになる

- **目的:** デスクトップ幅でも `Plus` アイコン単体で表示されること。
- **手順:**
  1. ホーム（`/`）を開く
  2. 右上のツールバーを確認（デスクトップ幅）
- **期待結果:** プラスアイコンのみのプライマリボタン。テキスト「新規作成」は表示されない。ホバーで `title="新規作成"` が出る。
- **確認ポイント:** クリックで新規ノート作成（`/notes/new`）に遷移する。

### 4. ホームツールバー「アップロード」がアイコンのみになる

- **目的:** デスクトップ幅でも `Upload` アイコン単体で表示されること。
- **手順:**
  1. ホーム（`/`）のツールバーを確認
- **期待結果:** アップロードアイコンのみのボタン。テキスト「アップロード」は表示されない。
- **確認ポイント:** クリックでアップロードモーダル（`#upload`）が開く。

## エッジケース・異常系

### 1. スクリーンリーダーでの読み上げ

- **目的:** アイコンのみ化したボタンが正しいアクセシブルネームで読み上げられること。
- **手順:**
  1. VoiceOver（macOS: Cmd+F5）等を有効にし、各ボタンにフォーカス
- **期待結果:** 「編集」「複製」「新規作成」「アップロード」がそれぞれ読み上げられる（`aria-label` 由来）。アイコン SVG 自体は装飾（`aria-hidden`）として読み飛ばされ、名前が二重化しない。

## 既存機能への影響確認

- 中・低優先度ボタン（公開設定・エクスポート・移動・履歴・削除・復元・完全削除・ゴミ箱へ）は従来どおりテキスト併記で表示される。
- `NoteListToolbar` の「選択」「ビューとして保存」は従来どおり `max-sm` でのみアイコンのみに折りたたまれる（デスクトップではテキストあり）。
- `BulkActionBar` の × ボタン・WYSIWYG 書式ツールバー・ハンバーガーメニューは変更なし。
