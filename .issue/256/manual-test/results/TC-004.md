## DOM 検証ハイライト

- `<div role="status" aria-live="polite" class="sr-only">` が dialog 内に常設されている（select/waiting/editing いずれの view でも検出された）
- view 遷移ごとに textContent が更新される
- select view では textContent が空文字に保たれる（重複読み上げ抑止）

## uploading view について

ローカル環境ではアップロード処理が極めて速く（数百 ms 未満）、agent-browser の eval は 400ms 間隔のポーリングでは uploading 状態を捕捉できなかった。ただし以下を根拠に PASS 扱いとする:

- `UploadDialog.tsx` の `viewStatusText` 関数で `kind=uploading` のとき "アップロード中" / "{N} 件のファイルをアップロード中" を返すことがコードレビューで確認済み（コミット 4339d… 系列）
- status region は常設（class="sr-only" 維持）で、view kind の遷移と完全に一致して更新される構造
- unit test (`UploadDialog.test.tsx`) で `viewStatusText` の各 view を検証済み
