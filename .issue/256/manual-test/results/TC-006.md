# TC-006: ConfirmDialog ネスト（破棄確認）が引き続き機能

**結果**: PASS
**実行時間**: 約 10 秒
**セッション**: verify-tc-004（編集 view 到達後の流れの一部）

## 実行ログ

| # | 操作 | 期待 | 実測 | 判定 |
|---|---|---|---|---|
| 1 | 編集 view で「破棄」ボタンをクリック | ConfirmDialog (`role="alertdialog"`) が開く | alertDialog 表示、heading="ジョブを破棄"、aria-labelledby と heading id 一致 | PASS |
| 2 | ConfirmDialog 内の「破棄」をクリック | UploadDialog が閉じる、URL から `#upload` が消える | dialogOpen=false, url="http://localhost:3000/?page=1&limit=20"（#upload なし） | PASS |

## DOM 検証ハイライト

```json
{
  "alertAriaLabelledBy": "_r_g_",
  "alertDialogOpen": true,
  "alertHeadingText": "ジョブを破棄",
  "dialogOpen": true
}
```

破棄後:
```json
{
  "dialogOpen": false,
  "url": "http://localhost:3000/?page=1&limit=20"
}
```

## 既存挙動への regression

なし。破棄フローは正常動作。focus restore は dialog 外（document.body / URL に戻り）。
