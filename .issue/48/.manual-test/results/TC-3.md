# TC-3: search 結果でカレンダー表示が機能する (ADR-014 解消)

**実行日:** 2026-05-20
**URL:** `http://localhost:3000/?q=uniquekw&display=calendar`
**ユーザー:** `mt48-eve@example.com`
**結果:** **PASS**

## 期待結果

- 日付ごとに見出し（例: `2026年5月20日（水）`）でグルーピングされる
- 「検索結果はカレンダー表示に対応していません」のフォールバック文言が**出ない**
- グルーピング見出しが実日付であること（`1970` でない）

## 実測

- フォールバック文言 `検索結果はカレンダー表示に対応していません`: **なし**（`includes(...) === false`）
- `1970` の出現: **なし**
- `main h2` 見出し数: **12**（12 ノートが 12 個の異なる日付に分散しているため）
- 見出しは曜日付き日本語表記:
  - `2026年2月21日(土)`
  - `2026年3月15日(日)`
  - `2026年4月10日(金)`
  - `2026年4月21日(火)`
  - `2026年4月28日(火)`
  - `2026年5月5日(火)`
  - `2026年5月11日(月)`
  - `2026年5月13日(水)`
  - `2026年5月15日(金)`
  - `2026年5月18日(月)`
  - `2026年5月19日(火)`
  - `2026年5月20日(水)`
- 各見出しの直下に該当ノートのリンクが 1 件ずつ配置されている

ADR-014 で記録されていた制約（search 経路では calendar 表示が機能しない）が解消されている。
