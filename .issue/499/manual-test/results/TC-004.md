# TC-004 アクセシブルネーム

**結果: PASS**

list 表示でアクセシビリティツリー（snapshot）と aria-label を確認。行リンクのアクセシブルネームは note.title のみで、excerpt / タグ / 日時を含まない。

## 確認結果

snapshot 上の行リンク名:
- `link "テスト用ノートB"`
- `link "テスト用ノートA"`
- `link "テスト用ノートC タグなし別日付"`

各行 `<a>` の `aria-label` 実測:

| ノート | aria-label | 行内の子テキスト（名前には含まれない） |
|--------|-----------|----------------------------------------|
| B | `テスト用ノートB` | excerpt, `#日記 #アイデア`, `·`, `非公開`, `2026年6月6日` |
| A | `テスト用ノートA` | `非公開`, `2026年6月5日` |
| C | `テスト用ノートC タグなし別日付` | excerpt, `非公開`, `2026年6月4日` |

`aria-label` が note.title に設定されており、アクセシブルネーム計算上 excerpt・タグ・日時は名前に含まれない。
