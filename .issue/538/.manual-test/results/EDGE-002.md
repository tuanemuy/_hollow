# EDGE-002: 単一アップロード失敗で select に留まりインラインエラー

**結果**: PASS（クライアント検証経路で確認。サーバー失敗の静的再現は不能）

**セッション**: verify-edge-2 / **日時**: 2026-06-13

## 実行ログ

| # | 操作 | 結果 |
|---|---|---|
| 1 | `/#upload` を開き `invalid-binary.bin` を単体送信 | ドロップゾーン（select）に留まり、`alert` で「対応外の形式が含まれています / 次のファイルはアップロードできません: `invalid-binary.bin`」をインライン表示。旧 `failed` ビューには遷移しない |
| 2 | 同じドロップゾーンから `test-note-2.md` を再送信 | 待ち時間なく送信され `queued` ビュー（「1 件中 1 件をキューに追加しました」）に着地 — 再送信可能 |

## 所見

- サーバー側で失敗するファイルの静的再現は seed-data.md の注記どおり不可能（client 検証が先に弾く）。サーバー失敗時に select へ戻りインラインエラー（`RetryableError` / `setError` → `setView({kind:"select"})`）になることは `UploadDialog.tsx` のコードパスとユニットテストで担保。
