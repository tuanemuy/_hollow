# EDGE-004: バッジ取得失敗時（未ログイン / セッション失効）

**結果**: PASS

**セッション**: verify-edge-4 / **日時**: 2026-06-13 / **URL**: http://localhost:3100

## 実行ログ

| # | 手順 | 操作 | 結果 |
|---|---|---|---|
| 1 | 未ログインで `/` | cookie なしの別セッションで `http://localhost:3100/` を開く | 公開ランディングページが表示される（バッジ描画ヘッダーは認証エリア専用のため非表示）。レイアウト崩れ・エラー表示なし — OK |
| 2 | 未ログインで `/upload`（バッジ描画ページ） | cookie なしで直接アクセス | ランディング（`/`）へリダイレクト。クラッシュ・エラー表示なし、console error なし — OK |
| 3 | セッション失効相当 | cookie 注入してログイン → `/` でアプリヘッダー表示確認 → `cookies clear` で失効 → `visibilitychange` を dispatch（バッジ再取得を発火） | アプリがクラッシュせず `/login` へ正常リダイレクト。ヘッダーが壊れた状態で残らない。console error なし — OK |

## 判定理由

バッジ描画ページは認証必須のため「未ログインでバッジが見える」状況はそもそも発生せず、cookie なしアクセスはランディング / ログインへ誘導される。失効後のバッジ再取得（visibilitychange トリガー）でも例外・壊れたヘッダー・導線ブロックは発生しなかった。期待結果「バッジ取得失敗が導線を塞がない・ヘッダーが壊れない」を満たす。
