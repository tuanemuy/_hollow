# EDGE-003: 編集中にジョブが他で確定された場合（クロスタブ）

**結果**: PASS

**Date:** 2026-06-13
**対象:** testing.md エッジケース 3
**セッション:** verify-edge3-a（タブA）/ verify-edge3-b（タブB）、いずれも dev-admin cookie 注入

## 実行ログ

| # | 操作 | 結果 |
|---|---|---|
| 1 | タブA: `/upload` を開き `test-note-1.md` をアップロード | ジョブが `previewing` に到達（タイトル提案 `test-note-1` 表示、ヘッダーバッジ「未処理 1 件」） |
| 2 | タブA: 「編集」クリック → 編集ダイアログ（プレビューを編集: test-note-1.md）が開く | タイトル・タグの AI 提案がフォームに表示 |
| 3 | タブB: `/upload` を開き同ジョブの「破棄」→ 確認ダイアログ「破棄」 | キューから行が消える（破棄成功） |
| 4 | タブA: ダイアログの状態を確認 | ポーリングで行ごと消え、編集ダイアログは閉じていた（無言クローズ） |
| 5 | タブA: コンソールエラー確認 | エラーなし（vite/devtools の debug ログのみ）。アプリはクラッシュせず操作継続可能 |
| 6 | DB 確認 | `ingestion_jobs` は discarded/saved のみ。未処理 0 件 |

## 判定根拠

- 期待結果のうち「キューのポーリングで行ごと消えてダイアログが閉じる」のパスに合致。
- 無言クローズは adr.md ADR-001 の許容トレードオフであり、バグではない（確認ポイントどおり）。
- クラッシュ・コンソールエラーなし。

## 補足

- タブBでの破棄が速くポーリングが先に走ったため、タブAで「保存」を押す前にダイアログが閉じた。フォーム内 conflict エラー表示のパスは本実行では発火せず（期待結果の OR 条件のもう一方で PASS）。
- タブAのヘッダーバッジは閉鎖直後「未処理 1 件」のまま残存（ADR-002 の許容トレードオフ：visibilitychange / 次回ポーリングで更新）。

## クリーンアップ

- 両セッション close 済み。
- 未処理ジョブ 0 件（テストジョブはタブB操作で discarded 済み）。
