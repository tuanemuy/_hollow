# TC-007 エッジケース1: APP_URL 未設定時の相対 `/u/` フォールバック

**確認項目:** testing.md エッジケース1
**結果:** SKIP（ユニットテストで担保）

## 理由

このケースは `APP_URL` env を外してサーバーを再起動する必要があり、本検証の前提（起動済みサーバー・`APP_URL=http://localhost:8787`）では確認できない。指示どおりブラウザ検証ではスキップする。フォールバック挙動（appUrl 空時に相対 `/u/<username>` を出し、ダミードメインを出さない）はユニットテストで担保済み。

## 補足

TC-003 で `APP_URL=http://localhost:8787` 設定時の絶対 URL prefix／プレビュー（`http://localhost:8787/u/...`）が正しく出ること、`//u/` 二重スラッシュが起きないことは確認済み。
