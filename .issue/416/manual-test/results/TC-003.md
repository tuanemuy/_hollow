# TC-003: /admin-signup の primary ボタン

判定: SKIP（DB 状態依存でルートに到達不能）

## 経緯
- `/admin-signup` は存在せず 404（汎用 NotFound ページ）。
- 実際の管理者初期登録ルートは `/setup`（`app/routes/setup.tsx` が `AdminSignUpForm` を描画）。
- `/setup` を開くとページタイトルは「初期管理者セットアップ」だが本文は「404 Not Found / このページは利用できません。」。
  これは route の `notFound()` ガードが発火したもの。dev DB に既存管理者が存在するため初期セットアップ画面は弾かれる（テスト指示どおり SKIP 条件に合致）。

## 補足（コード確認）
`AdminSignUpForm/index.tsx` は送信ボタン（line 399-402）と Link（line 147）の両方で
`className={BTN_PRIMARY}` + `data-primary=""` を使用。到達できれば TC-001/002 と同一合成で
accent 縦長 pill になる（構造的に確認済み）。
