# TC-005: disabled 表示

判定: PASS

## 対象
`/password-reset` 送信ボタンに JS で `disabled=true` を強制付与し computed style を確認
（実フォーム送信は server-function POST 403 制約のため不可）。

## 確認結果（computed style, disabled 時）
- disabled: true
- opacity: `0.55`（仕様どおり opacity 55。従来 60 から軽微変化）
- cursor: `not-allowed`（cursor-not-allowed）
- backgroundColor: `oklch(0.371 0 0)`（accent のまま。hover/active 変化は `not-disabled` ガードで無効）

## 所見
disabled 状態で opacity 55・cursor-not-allowed が適用され、hover/active の色変化が起きないことを確認。
