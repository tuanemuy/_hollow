# TC-001: /login の primary 送信ボタン（BTN_PRIMARY, button）

判定: PASS

## 対象
`/login` の送信ボタン「ログイン」（`<button>`, BTN_PRIMARY + data-primary=""）

## 確認結果（computed style）
- backgroundColor: `oklch(0.371 0 0)` = `--color-accent`（accent。グレー surface `#f5f5f7` ではない）
- color: `rgb(255,255,255)`（白文字）
- height: 48px（h-12）
- width: 440px（w-full = コンテナ全幅）
- borderRadius: 980px（rounded-pill）
- padding: 0px 32px（px-8）
- fontSize: 17px（text-md）
- data-primary: `""`（付与あり）
- hover 時 backgroundColor: `oklch(0.439 0 0)` = `--color-accent-hover`（hover 効く）

## 所見
本テーマの accent はモノクロ（near-black `oklch(37.1% 0 0)`）。送信ボタンは accent の濃色 pill として表示され、light gray の input（surface）と明確に区別できる。surface 化けなし。
