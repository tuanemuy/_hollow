# TC-002: /signup の primary ボタン

判定: PASS

## 対象
`/signup` の送信ボタン「アカウントを作成」（`<button>`, BTN_PRIMARY + data-primary=""）

## 確認結果（computed style）
- backgroundColor: `oklch(0.371 0 0)` = `--color-accent`（accent）
- color: `rgb(255,255,255)`（白文字）
- height: 48px / width: 440px（w-full） / borderRadius: 980px（pill）
- padding: 0px 32px（px-8） / fontSize: 17px（text-md）
- data-primary: `""`（付与あり）

## 所見
- 送信ボタンは accent 濃色 pill。surface 化けなし。
- ヘッダー／フッターの「ログイン」は plain text link（pill ボタンではない）。この画面に surface 系 pill ボタンは存在しない。
