# TC-005: タグフィルタ (`tagNames=["work"]`) で count = 4

- 状態: PASS
- 期待値: `{count} 件のノート` の N = 4（work タグの noteCount と一致）
- 実測値: `4 件のノート` / 該当ノートは "Weekly planning ノート", "Project A キックオフ", "Project B レビュー記録", "Q1 ふりかえり"

## 操作ログ

1. セッション `verify-tc-005` でログイン
2. URL は TanStack Router の zod 配列スキーマに合わせ JSON 配列形式で渡す
   - `open http://localhost:3000/?tagNames=%5B%22work%22%5D`
   - 解決後 URL: `?tagNames=%5B%22work%22%5D&page=1&limit=20`
3. `wait --load networkidle`
4. `document.querySelector(".page-subtitle").innerText` → `"4 件のノート"`
5. `Array.from(document.querySelectorAll("a")).filter(a => a.href.match(/\/notes\/[^/]+$/)).map(a => a.innerText)` → 4 ノート（上記タイトル）
