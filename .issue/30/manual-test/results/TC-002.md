# TC-002: `?visibility=public` で count = 1 (Issue #30 最重要)

- 状態: PASS
- 期待値: `{count} 件のノート` の N = 1（N9「公開デザインガイド」のみ）
- 実測値: `1 件のノート` / 一覧に表示されたノートタイトル「公開デザインガイド」

## 操作ログ

1. セッション `verify-tc-002` でログイン
2. `open http://localhost:3000/?visibility=public` → `?visibility=public&page=1&limit=20`
3. `wait --load networkidle`
4. `document.querySelector(".page-subtitle").innerText` → `"1 件のノート"`
5. ノート一覧の先頭タイトルを `eval` で取得 → `"公開デザインガイド"`
