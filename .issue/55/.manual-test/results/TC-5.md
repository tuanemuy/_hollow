# TC-5: 削除確認ダイアログに「対象ノート: N 件」が事前提示される（noteCount > 0）

**Status:** PASS
**Date:** 2026-05-20
**Session:** verify-delete

## 手順実行

1. `/tags` 画面で `#delete-me`（4 件のノート紐付け）の「削除」ボタンをクリック
2. 開いた `[role=alertdialog]` の description テキストを JS eval で取得
3. キャンセルしてダイアログを閉じる

## 期待結果

- ConfirmDialog の description に「参照ノートからも除去され、同名タグは今後自動抽出されなくなります（再追加するには手動で再作成が必要）。**対象ノート: 4 件**。続行しますか？」が表示される

## 実測結果

JS eval (`document.body.innerText` フィルタ結果):

```
タグ "#delete-me" を削除
参照ノートからも除去され、同名タグは今後自動抽出されなくなります（再追加するには手動で再作成が必要）。対象ノート: 4 件。続行しますか？
```

| 観点 | 期待 | 実測 |
| --- | --- | --- |
| タイトル | `タグ "#delete-me" を削除` | 一致 ✓ |
| 「対象ノート: 4 件」フレーズ | 含まれる | 含まれる ✓ |
| 「続行しますか？」末尾 | 含まれる | 含まれる ✓ |
| 件数（tag.noteCount = 4） | 4 件 | 4 件 ✓ |

「キャンセル」押下後、ダイアログ閉じ、タグ一覧不変。
