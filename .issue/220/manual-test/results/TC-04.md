## 備考
- agent-browser の `upload` コマンドは `LabelText` (`ref=e26`) に対しては失敗（"Node is not a file input element"）。CSS セレクタ `input[type=file]` または ID `#_r_6_` を使うと成功。
- アップロード成功後、`input.files` は即時クリアされるが `/upload` キュー画面で登録結果を確認できた。
- ノート一覧件数 (10) は変動しないが、これは仕様（キュー方式：「ノートとして保存」ボタンで初めて正式ノート化）どおりであり、UI バグではない。
