# TC-005 タグ選択・すべてクリア（既存機能影響）

- **結果:** PASS
- **対応確認項目:** testing.md 既存機能への影響確認（タグ選択／解除、すべてクリア）

## 手順と観察

1. `/` で「#work」タグチップをクリック → ソリッドの濃色（active）状態に変化し、一覧が「3 件のノート」（Work note 1〜3）に絞り込まれた。「すべてクリア」ボタンが右端に出現。
2. 「すべてクリア」をクリック → 全フィルタ解除。一覧が「6 件のノート」に戻り、#work チップが通常状態に戻り、「すべてクリア」も消失。ゴーストトリガー（期間・公開状態・内部リンク参照）も初期状態。
