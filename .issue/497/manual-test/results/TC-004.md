# TC-004 内部リンク参照の選択 → 解除（エッジ）

- **結果:** PASS
- **対応確認項目:** testing.md エッジケース1（ゴーストチップ化後も NotePicker の選択・解除が機能する）

## 手順と観察

1. 「内部リンク参照 ▾」トリガーをクリック → `NotePickerDialog`（「ノートを選択」、タイトル先頭一致オートコンプリート）が開いた。
2. コンボボックスに「Work」と入力 → 候補に Work note 1〜3 が表示（「3 件」）。「Work note 1」を選択。
3. アクティブチップ「参照中: Work note 1 ×」（ソリッドの濃色ピル）に切り替わり、一覧が絞り込まれた（「0 件のノート」＝Work note 1 を参照するノートは無いため空。フィルタは正しく適用されている）。「すべてクリア」が右端に出現。
4. × をクリックして解除 → 一覧が「6 件のノート」に戻り、内部リンク参照トリガーが破線ゴーストチップ（expanded=false）に戻った。「参照中」チップ・「すべてクリア」は消失。

## 備考

選択 → ソリッドのアクティブチップ、× → 破線ゴーストチップへの復帰という期待挙動を完全に満たす。絞り込み結果が0件なのはシードデータ上 Work note 1 への被参照が無いためで、機能不具合ではない。
