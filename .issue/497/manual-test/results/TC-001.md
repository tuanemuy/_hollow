# TC-001 区切り線の廃止（問題1）

- **結果:** PASS
- **対応確認項目:** testing.md 確認項目1（縦区切り線の廃止／折り返し時に行頭へ線が浮かない）

## 手順と観察

1. `/`（ノート一覧）を通常幅 1280×900 で開いた。FilterBar はタグ5件（#archived-only / #idea / #memo / #unused / #work）＋「期間」「公開状態」「内部リンク参照」のトリガーが横一列に描画される。
2. タグ群と「期間」チップの間に縦区切り線（`w-px h-5`）は存在しない。facet 間は gap のみで区切られている。
3. ビューポートを 420×900 に縮小し FilterBar を折り返させた。タグ群が2行に折り返し、3トリガーが次の行へ折り返したが、行頭に縦線だけが浮く表示は出ていない。
