# ADR — Issue #497: ノート一覧 FilterBar の体裁を整える

## ADR-001: 「内部リンク参照」は in-bar トリガーを残しゴーストチップ化する

### Status
Accepted

### Context
Issue 本文の問題3は「未選択時の内部リンク参照セクションがバーを占有して無意味」とし、方針案として「ディレクトリフィルターと同様、選択済みのときだけチップ表示」を挙げていた。一方 `referencingNoteId` はノート詳細の被リンクパネル（`NoteMetaPanel`）からも設定でき、`styles.ts` の ADR-004 コメントは「referencing note は in-bar trigger を持たない」と記述している。

これに対しユーザーは「内部リンク参照はバーに残したほうがわかりやすい」と判断。さらにトリガーの見た目を「ゴーストチップ（期間・公開状態と揃える）／アクションボタン」から選んでもらった結果、**ゴーストチップ**を採用した。

### Decision
- 未選択時トリガーをバーに残す。`pillBtn`（h-9）から `filterChipGhost`（h-7、破線アウトライン）に変更し、`filterChipCaret`（▾）を付けて期間・公開状態のゴーストトリガーと視覚統一する。ラベルは facet 名「内部リンク参照」。
- `NotePickerDialog` を開く挙動・props はそのまま維持し、コンポーネントは削除しない。
- `styles.ts` の ADR-004 コメント（「referencing note は in-bar trigger なし」）は実態と矛盾するため、本変更に合わせて更新する。

### Consequences
- 良い点: 期間・公開状態・内部リンク参照の未設定トリガーが破線ゴーストチップで横並びになり、バー全体が一貫する。問題2（サイズ不揃い）も同時に解消。in-bar からノートを選ぶ導線が維持される。
- トレードオフ: Issue 本文の方針案（未選択時は非表示）とは異なる。未選択でもトリガー1つ分のスペースを占有するが、期間・公開状態と同列であり「無意味に浮いた表示」ではなくなる。受け入れ条件は「不揃い・無意味な表示の解消」の趣旨で満たす。

## ADR-002: facet 見出し（filterLabel）は全廃する

### Status
Accepted

### Context
facet 見出し（`filterLabel`）がタグ・ディレクトリ・内部リンク参照には付き、期間・公開状態にはない。見出し全廃（チップにラベルを内包）と全 facet へ見出し付与の2案があり、ユーザーは全廃を選択した。

### Decision
タグ・ディレクトリ・内部リンク参照の facet 見出し `<span className={filterLabel}>` を削除する。`filterLabel` の export 自体は `DatePopover` 内の「プリセット」「範囲指定」見出しで使うため残す。

### Consequences
- 良い点: 期間・公開状態（チップがラベルを兼ねる）に合わせて全 facet の見出し有無が「なし」で統一される。バーの情報量がすっきりする。
- トレードオフ: 見出しテキストが消えるが、各チップ自体がラベルを内包するため意味は通る。
