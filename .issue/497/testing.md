# 動作確認計画 — Issue #497: ノート一覧 FilterBar の体裁を整える

**Issue:** #497
**作成日:** 2026-06-05

---

## 確認環境

このIssueの変更（ノート一覧 `/` の FilterBar 体裁）を確認するために必要な手順のみ記載。

### 検証環境の起動

```bash
pnpm db:migrate   # ローカル D1 にマイグレーション適用（初回・未適用時のみ）
pnpm seed:dev-admin   # 開発用 admin アカウントを投入（ログイン用）
pnpm dev          # 開発サーバー起動（vite dev / Cloudflare runtime）
```

起動後、ブラウザで開発サーバーの URL（`pnpm dev` の出力に表示）にアクセスし、admin でログインしてノート一覧（`/`）を開く。FilterBar を表示するにはタグが付いたノートが数件必要（タグ facet が表示される条件）。シードデータの整備は manual-test 側で行う。

### デプロイ方法

なし（検証環境のみで確認できる。UI の体裁変更のみでステージング・本番への反映は不要）。

## 確認項目

### 1. 区切り線が折り返しても破綻しない（問題1）

- **目的:** タグ群と期間の間の縦区切り線が廃止され、折り返し時に行頭へ浮く線が出ないこと。
- **手順:**
  1. ノート一覧（`/`）を開き、タグが複数表示される状態にする。
  2. ウィンドウ幅を狭めて FilterBar の要素を折り返させる。
- **期待結果:** 行頭に縦線だけが浮く表示が出ない。facet 間は gap で区切られている。
- **確認ポイント:** タグ群と期間チップの間に縦線（`w-px h-5`）が存在しないこと。

### 2. 内部リンク参照トリガーの高さ・見た目が揃う（問題2・3）

- **目的:** 未選択時の内部リンク参照トリガーが期間・公開状態のゴーストチップと同じ高さ（h-7）・破線見た目になること。
- **手順:**
  1. ノート一覧（`/`）を未フィルタ状態で開く。
  2. 期間・公開状態・内部リンク参照のトリガーを並べて見る。
- **期待結果:** 3つとも破線アウトラインのゴーストチップ（h-7、▾付き）で横並びになり、高さが揃っている。以前の大きい「ノートを選ぶ…」ボタンは無い。
- **確認ポイント:** 内部リンク参照トリガーが `filterChipGhost`（破線・h-7）であること。

### 3. facet 見出しが全廃され統一される（問題4）

- **目的:** タグ・ディレクトリ・内部リンク参照の見出し（uppercase ラベル）が無くなり、全 facet で見出し無しに揃うこと。
- **手順:**
  1. ノート一覧（`/`）を開く。
- **期待結果:** 「タグ」「ディレクトリ」「内部リンク参照」の見出しテキストが表示されない。チップ群だけが並ぶ。
- **確認ポイント:** 期間・公開状態と同様、どの facet にも見出しが付かないこと。

## エッジケース・異常系

### 1. 内部リンク参照の選択 → 解除

- **目的:** ゴーストチップ化後も NotePicker の選択・解除が従来どおり機能すること。
- **手順:**
  1. 内部リンク参照トリガーをクリックし、`NotePickerDialog` でノートを選ぶ。
  2. アクティブチップ（「参照中: …」）の × をクリックして解除する。
- **期待結果:** 選択でソリッドのアクティブチップに切り替わり、一覧が絞り込まれる。× で解除され、トリガーが破線ゴーストチップに戻る。

### 2. ディレクトリ・期間・公開状態フィルタとの共存

- **目的:** 見出し削除・区切り線廃止後も各 facet が正しく描画・動作すること。
- **手順:**
  1. ディレクトリ（外部から設定）・期間・公開状態を設定した状態でバーを見る。
- **期待結果:** 各アクティブチップが見出し無しで並び、「すべてクリア」が右端に出る。レイアウト崩れがない。

## 既存機能への影響確認

- タグの選択／解除（楽観的更新）が従来どおり動くこと。
- 「すべてクリア」で全フィルタが解除されること。
- ノート詳細の被リンクパネル（`NoteMetaPanel`）からの「参照しているノート一覧を見る」導線が従来どおり機能すること。
