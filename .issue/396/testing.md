## 確認項目

### 1. admin プロンプト設定画面（P42）の文言是正

- **目的:** operator に見せる文言が「（プロバイダ既定指示）」から「分析の指示（任意）／追加の指示なし」モデルへ是正され、operator が触るのは②分析の意図だけという作りになっていることを確認する。
- **手順:**
  1. 管理者ユーザーでログインし、プロンプト設定画面（P42）を開く。
  2. 未上書きのプロンプトカード（structure / title / directory / metadata / ocr_assist）の既定値ヒント表示を見る。
  3. textarea の placeholder を見る。
  4. フィールドラベル・各カードの説明文を見る。
- **期待結果:**
  - 既定値ヒントが「（プロバイダ既定指示）」ではなく「（追加の指示なし）」相当の表現になっている。
  - placeholder が既定値ラベルと別文言で、意図記入を促す日本語になっている。
  - フィールドラベルが「分析の指示（任意）」相当に是正されている。
- **確認ポイント:** 「プロバイダ既定／組み込み」というミスリーディングな表現が画面上のどこにも残っていないこと。

### 2. プロンプト上書き → リセットの導線（既存挙動の非回帰）

- **目的:** 文言是正によって既存の保存・リセット導線が壊れていないことを確認する。
- **手順:**
  1. 任意のプロンプトカードの textarea に意図テキストを入力し「保存」を押す。
  2. 「上書き中」バッジが表示されることを確認する。
  3. 「この項目をリセット」を押す。
  4. 「すべてのプロンプトをリセット」の confirm ダイアログを開く。
- **期待結果:**
  - 保存後に「上書き中」バッジが出る。
  - リセットで textarea がクリアされ、未上書きヒントが再表示される。
  - confirm ダイアログの説明文が「プロバイダの既定指示に戻ります」ではなく「追加の指示が削除され、システム既定の動作に戻ります」相当に是正されている。
- **確認ポイント:** 保存・リセットの機能自体は従来どおり動くこと。

### 3. アップロードダイアログの per-upload override 文言（P? 一般ユーザー導線）

- **目的:** UploadDialog の prompt override フィールドの出所ラベル・placeholder の「プロバイダ既定／組み込み」表現が是正されていることを確認する。
- **手順:**
  1. 一般ユーザーでログインし、ノートのアップロードダイアログを開く。
  2. structure / metadata の prompt override フィールドの placeholder と、折りたたみ内の出所ラベルを見る（インスタンス既定もユーザー上書きもない状態）。
- **期待結果:**
  - placeholder・出所ラベルが「LLM プロバイダの既定指示を使用」「プロバイダ組み込み」ではなく「システム既定」相当の表現になっている。
  - override 入力・バッジ表示（「この回だけ上書き」等）の機能は従来どおり。
- **確認ポイント:** 機能変更はなく文言のみの是正であること。

## エッジケース・異常系

### 1. 意図テキストを入れても③出力契約が壊れないこと（unit 担保）

- **目的:** operator が入力した意図文がアダプタ層で *追記* され、JSON 出力契約（③）を置換・破壊できないことを確認する。
- **手順:** ブラウザではなく `pnpm test:unit` で `app/core/adapters/llm/__tests__/prompts.test.ts` を実行（server-function 経由の ingestion mutation はブラウザ自動検証せず unit/integration で担保する方針）。
- **期待結果:** 空 prompt でもロール宣言＋②③が出力され、非空時は前置きラベル付きで意図文が追記され③が末尾に残る、空白のみは追記されない、の各ケースが PASS。

## 既存機能への影響確認

- ingestion の実 system prompt 文字列が「置換」から「追記」へ変わる。3プロバイダ（anthropic/openai/gemini）の既存テスト（②③ substring assert）が回帰しないことを `pnpm test:unit` で確認する。
- `UploadDialog.test.tsx` のコピー assert が文言変更に追従して PASS することを確認する。
