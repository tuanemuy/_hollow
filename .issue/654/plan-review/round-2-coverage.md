- **[P-002 テスト基盤の不整合] → 解消。** step 4 を「`FakeTagRepo`（フル実装ダブル）に空スタブ必須＋ gate 検証は D1 integration に一本化、フェイクユニットは新設しない」に書き換え。`makeTagRepoStub` は部分スタブで無変更と明記。`grep -rn "implements TagRepository"` で D1TagRepository と FakeTagRepo の2つのみであることをコードで確認。publication 既存ユースケース（`listUserPublicNotes` 他）が `setupTestContainer` の integration test のみで検証していることも確認、計画の「integration 一本化」方針と整合。

- **1周目指摘の反映が表層的でなく、コードと整合している。** cap=8 の `.catch(undefined)` 全消失・テストダブルの実体（D1 + FakeTagRepo の2つ）・モック行番号いずれも実コードで裏取りでき、計画の記述に事実誤りが無い。
