# TC-008: 既存機能への影響（影響確認）

**結果**: PASS

発見タグ絞り込み・期間フィルター・ソートのいずれも従来通り機能し、＋chip 追加による既存機能への悪影響は確認されなかった。ソート操作のみ agent-browser の menuitemradio onClick 既知偽陽性で URL が反映されなかったが、URL 直接操作で正常動作を確認済み（実装バグではない）。

## 操作ログ

| # | 操作 | 期待結果 | 実際 | 判定 |
|---|---|---|---|---|
| 1 | `/u/test-public-user` を開く | 表示される | 公開ノート28件・発見タグchip8種・＋chip・期間chip・ソートchip 正常表示 | PASS |
| 2 | 発見タグ chip「#TypeScript」をクリック | URLにtags反映・一覧変化 | URL `?tags=%5B%22TypeScript%22%5D` に反映、一覧が4件に絞り込み、発見タグchipが共起タグ（#設計/#日記）に更新 | PASS |
| 3 | 期間 chip → プリセット「過去90日」 | URL反映・一覧変化、＋chipの影響なし | URLに `from=2026-03-16&to=2026-06-13` 反映、chipが「期間: 3/16–6/13」化、範囲外（2025/9）のノートが除外され一覧変化 | PASS |
| 4 | ソート chip → 「タイトル順」 | ソートが効く、＋chipの影響なし | menu操作ではURL不変（agent-browser 既知偽陽性）。`?sort=title` を URL 直接指定すると chip「タイトル順」化・一覧がタイトル順に並び替わることを確認 | PASS（偽陽性切り分け済み） |

## 補足

- ステップ4の menu クリックが URL に反映されなかったのは、注意書きにある「listbox/menuitemradio の option クリックが React onClick に届かない agent-browser 既知偽陽性」に該当。URL 直接操作で実装が正しく動作することを確認したため実装バグではない。
- ＋chip（「タグを追加」）追加後も、発見タグchip・期間フィルター・ソートはいずれも独立して機能しており、相互干渉・レイアウト破綻は見られなかった。
