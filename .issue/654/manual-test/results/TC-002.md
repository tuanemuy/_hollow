## 検証メモ

- 発見 chips（1ページ目）には 8種のみ表示。ページ2タグ・日記は発見 chips に出ない。
- listbox（母集合）には 10種すべてが列挙され、1ページ目の発見 chips に無い **#ページ2タグ**（最古ノートのみ付与・28番目でページ2送り）と **#日記** が選択肢に含まれることを確認 → 母集合は発見 chips のスーパーセット。
- 母集合10種 = TypeScript / 設計 / 日記 / Rust / Go / データベース / テスト / ブラウザ / アーキテクチャ / ページ2タグ。全件一致。
