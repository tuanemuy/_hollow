# TC-004: ＋chip からのタグ追加と楽観更新／URL反映（AC-5）

**結果**: PASS

## 前提・環境

- セッション: verify-tc-004
- 対象: http://localhost:3000/u/test-public-user
- `AGENT_BROWSER_DEFAULT_TIMEOUT=20000` / `AGENT_BROWSER_IDLE_TIMEOUT_MS=120000`

## 重要な観測（URLフォーマット）

`tags` パラメータは **カンマ区切りではなく JSON 配列のURLエンコード** だった。
例: `?tags=%5B%22Go%22%5D`（= `["Go"]`）、`?tags=%5B%22Go%22%2C%22ページ2タグ%22%5D`（= `["Go","ページ2タグ"]`）。
仕様メモの「カンマ区切り」とは表現が異なるが、複数タグは配列要素として正しく追加・反映される。

## 判定理由

- タグ追加→一覧絞り込み→URL反映→リロード復元という AC-5 の機能要件は全て成立。
- ＋chip option のクリックが反応しなかったのは **agent-browser の click が React 合成イベントに届かない既知の偽陽性**。
  同一手順の発見chipクリックは正常に React へ届き URL を更新したこと、URL直接操作では tags が正しく保持・反映されたことから、**実装バグではない**と判断。
- 結果（タグ追加状態の保持・絞り込み・リロード復元）はすべて期待通りのため PASS。

## 注意

- URLフォーマットが「カンマ区切り」ではなく JSON 配列だった点は、後続TC（cap 8件超のサイレント全消失検証）の `.catch(undefined)` 挙動確認に影響しうるため TC-005 でも JSON 配列形式で検証する。
