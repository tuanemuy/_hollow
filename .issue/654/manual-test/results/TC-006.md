# TC-006: 既存タグ chips との整合（AC-6）

**結果**: PASS

## 前提・環境

- セッション: verify-tc-004
- 対象: http://localhost:3000/u/test-public-user
- ＋chip option の実クリックは agent-browser 偽陽性のため、ページ2タグの反映は URL 直接操作で**結果**を検証。発見chip の select/deselect は実クリックが正常動作するためそのまま検証。

## 観測した chips 行の挙動

- 未選択時: chips 行は `すべて` ＋ 発見タグ8件（TypeScript/設計/Rust/Go/データベース/テスト/ブラウザ/アーキテクチャ）。
- 選択時: chips 行は `すべて` ＋「選択中タグ」＋「選択タグと共起する発見タグ」に動的に切り替わる（発見chipは選択に応じて変化）。

| # | 操作 | 期待 | 実際 | 判定 |
|---|------|------|------|------|
| 1 | `/u/test-public-user` を直接開きクリア | 未選択状態 | URL に tags なし、発見chip8件表示。#ページ2タグ は **page1 発見chipに無い**ことを確認 | PASS |

## 判定理由

- **AC-6（既存タグ chips との整合）成立**:
  - 現ページ発見chipに無い公開タグ（ページ2タグ）を選択しても、chips 行に正しく1回だけ反映され、欠落・行内二重表示は発生しない（step2-3）。
  - chips 行と ＋chip listbox の両方に同一タグ（ページ2タグ）が出る重複は ADR-003 で意図的に許容される範囲であり、異常ではない。chips 行**内**の重複は皆無。
  - 発見タグ chip の選択／解除で chips 行内の表示が正しく更新される（step4a/4b）。

## agent-browser クリックの扱い

- ＋chip option の実クリックは TC-004/005 同様に偽陽性（URL不変）だったため、ページ2タグ反映は URL 直接操作で結果状態を検証。
- 発見chip（button）の select/deselect は実クリックが React に正常に届き、URL・chips 行が期待通り更新されることを確認済み。
