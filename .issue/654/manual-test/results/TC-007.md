# TC-007: 公開タグ0件のユーザーで＋chipが破綻しない（エッジケース）

**結果**: PASS

公開タグ0件の `test-user-001` でもページはエラーなく表示され、＋chip（「タグを追加」）を開いても空状態メッセージ「公開タグはまだありません。」を表示して穏当に振る舞い、クラッシュ・例外画面は発生しなかった。

## 操作ログ

| # | 操作 | 期待結果 | 実際 | 判定 |
|---|---|---|---|---|
| 1 | `/u/test-user-001` を開く | ページがエラーなく表示 | タイトル「テストユーザー001 (@test-public-user)」、公開ノート1件が正常表示。例外なし | PASS |
| 2 | filter-row を snapshot で確認 | ＋chip の有無を確認 | ＋chip（`button "タグを追加" [expanded=false]`）が存在。開く対象あり | PASS |
| 3 | ＋chip を開く | 選択肢が空でもクラッシュせず穏当に振る舞う | クリックで `expanded=true`、`listbox "タグを追加"` 内に StaticText「公開タグはまだありません。」を表示。ノート一覧・ページ崩れなし | PASS |

## ＋chip 0件時の挙動

＋chip は**非表示にはならず表示されたまま**で、開くと listbox 内に空状態メッセージ「公開タグはまだありません。」を表示する（空状態パターン）。例外・クラッシュは一切なし。
