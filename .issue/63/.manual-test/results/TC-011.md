# TC-011 — IME 確定中の Esc で modal が閉じない

**Result:** PASS

## 期待結果との照合

| Step | 期待 | 実際 | 判定 |
|---|---|---|---|
| IME 中 (`isComposing=true`) で Esc | dialog open のまま、IME 変換キャンセルを優先 | dialog 表示維持、入力値 "あ" のまま | OK |
| IME 終了後 (`isComposing=false`) の Esc | modal が閉じる | dialog 消失 | OK |

## 実装側の確認

`Dialog.tsx:117-128`:

```ts
if (event.key === "Escape") {
  if (event.isComposing || event.keyCode === 229) return;
  event.preventDefault();
  event.stopPropagation();
  if (closableRef.current) onCloseRef.current();
  return;
}
```

`isComposing` または `keyCode === 229` のときは Esc を捨てる。これにより IME 変換キャンセル時の Esc で modal が誤閉しない。
