## 備考

`searchInternalLinkTargetsFn` は createServerFn 経由のため fetch ラップでは観測できなかった。
single-flight / debounce の厳密検証は Network タブを直接観測する手段が必要（agent-browser からは取得不可）。
UI 表示としては status "検索中…" → "{n} 件" の遷移を視認できているので、debounce → fetch → 結果反映の流れは動作している。
