# TC-010 — Esc / 背景クリック / × ボタンで close

**Result:** PARTIAL PASS (背景クリック・× ボタンは現実装で未サポート)

## 期待結果との照合

| 操作 | 期待 | 実際 | 判定 |
|---|---|---|---|
| Esc キー押下 | dialog close、focus picker トリガーに復元 | ✓ dialog 消失、`document.activeElement` = "ノートを選ぶ…" ボタン | OK |
| 背景 (overlay) クリック | dialog close | **未サポート**: `Dialog.tsx` の backdrop には onClick ハンドラなし。クリックしても閉じない | NOT SUPPORTED |
| × ボタンクリック | dialog close | **存在しない**: `NotePickerDialog` には `キャンセル` ボタンのみ。`× ボタン` は実装されていない | NOT SUPPORTED |
| キャンセルボタン | dialog close、focus 復元 | ✓ dialog 消失、focus picker トリガーへ | OK |
| body の scroll lock 解除 | overflow が元に戻る | ✓ `document.body.style.overflow = ""` (none) | OK |

## 実装側の確認

- `app/components/common/Dialog.tsx` を読み取り:
  - Esc キー: `useEffect` で keydown を捕捉、`closableRef.current` が true なら `onClose` 呼び出し
  - IME 中は Esc を無視する処理が入っている (`event.isComposing || event.keyCode === 229`)
  - Tab/Shift+Tab で focus trap
  - **backdrop (overlay) には onClick が無く、クリックで close しない**
  - 「× ボタン」は Dialog 内に持っておらず、各コンシューマが必要に応じて配置する設計
- `app/components/note/list/NotePickerDialog.tsx`:
  - `キャンセル` ボタンを `dialogActions` に配置（×ボタンは未実装）
