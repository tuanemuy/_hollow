# TC-013 — スクリーンリーダー読み上げ (ARIA 構造確認)

**Result:** PASS (ARIA 属性が WAI-ARIA 1.2 combobox + listbox パターンに準拠)

実環境 SR (VoiceOver / NVDA) での読み上げは agent-browser で起動できないため、DOM + ARIA 属性の確認のみ実施。

## 期待結果との照合

| 要素 | 期待 ARIA | 実際 ARIA | 判定 |
|---|---|---|---|
| picker トリガーボタン | `aria-haspopup="dialog"`, `aria-expanded` 動的 | `aria-haspopup="dialog"`, `aria-expanded="false"` (open 時 "true") | OK |
| Dialog | role="dialog", aria-modal="true", aria-label="ノートを選択" | 同上、すべて一致 | OK |
| 入力フィールド (combobox) | role="combobox", aria-autocomplete="list", aria-expanded 動的, aria-controls=listbox-id, aria-busy 動的, aria-activedescendant 動的 | すべて一致。idle 時 ariaExpanded=false / ariaControls=null、ready 時 ariaExpanded=true / ariaControls=listbox-id / ariaActivedescendant=option-id | OK |
| 候補リスト (listbox) | role="listbox", aria-label="ノート候補", id (combobox から aria-controls で参照) | role="listbox", ariaLabel="ノート候補", id `_r_3_` (combobox.ariaControls と一致) | OK |
| 各候補 (option) | role="option", aria-selected 動的 (true/false), id (activedescendant 参照用) | すべて一致 | OK |
| 件数 / loading / 0 件 / エラー文言 | `aria-live="polite"` | `<p aria-live="polite">`、エラー時のみ `role="alert"` 追加 | OK |
