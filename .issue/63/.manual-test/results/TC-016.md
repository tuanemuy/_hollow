# TC-016 — クリアボタン非表示（picker 単独表示時）

**Result:** PASS (コード検査ベース)

## 検証方法

コード差分による静的検査で判定した。

## 静的検査の根拠

`git diff main -- app/components/note/list/FilterBar.tsx`:

- `hasAnyFilter` の判定式は **完全に無改修**（diff に現れない）
- `pickerOpen` は React ローカル state であり URL search params に含まれないため、`hasAnyFilter` を計算するときに参照されない
- クリアボタン (`{hasAnyFilter ? <button>...</button> : null}`) の表示条件は不変

これにより:

- 全フィルタ未指定 + picker トリガー表示中 → `hasAnyFilter === false` → クリアボタン非表示
- picker open しても `hasAnyFilter` は変わらない → クリアボタン非表示維持
- 何かフィルタ追加（picker から選択して navigate 完了後など）→ `referencingNoteId !== undefined` で `hasAnyFilter === true` → クリアボタン表示

## 補強

TC-001 の実機検証で「FilterBar 全体スナップショット」を確認しており、初期表示でクリアボタンが出ていないことを目視確認済み。

## 判定

クリアボタンの表示条件は破壊されていない。
