# TC-015 — 他フィルタとの干渉なし

**Result:** PASS (コード検査ベース)

## 検証方法

コード差分による静的検査で判定した。

## 静的検査の根拠

`git diff main -- app/components/note/list/FilterBar.tsx` を確認:

- タグフィルタ（`onToggleTag`）、期間フィルタ（`fromId` / `toId` の input）、公開状態フィルタの操作ロジックは無改修
- 「内部リンク参照」セクションのレイアウト変更（ラベル `内部リンク参照` を常時表示するように三項分岐の外に移動）は他フィルタの DOM ツリーに影響しない
- `pickerOpen` は **URL state ではない** ローカル React state なので、`router.navigate` の `search` callback には現れず、他フィルタへの干渉経路がない
- `NotePickerDialog` は `Dialog` プリミティブ経由で portal にレンダリングされるため、FilterBar 内の他コンポーネントと DOM 階層的にも独立

## 補強

TC-001〜013 の実機検証で picker トリガーを表示しても他フィルタの状態が壊れていないことを観察済み（特に TC-001 の初期表示で他フィルタセクションが正常レンダリング）。

## 判定

他フィルタとの干渉なし。
