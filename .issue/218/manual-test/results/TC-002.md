## 補足
- 初回 `click` コマンドで save action が発火しなかった事象あり。`eval` 経由の `button.click()` で発火確認。
  - これは agent-browser の click が React の controlled state を更新する前に発火していた可能性があり、テスト手法上の問題で実装の問題ではない。
  - DB を直接確認すると save 後の値が persist されている。
- 「上書き中」バッジは reload で確実に表示される（楽観更新は限定的）。
