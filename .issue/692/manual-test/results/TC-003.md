# TC-003: 通常 input の 2px リング細線化（AC-3, AC-7）

結果: **PASS**

## 概要
認証済み（管理者）の `/notes/new` 内にある通常 input（検索バー `<input placeholder="ノートを検索">`）を
キーボードフォーカス（`:focus-visible`）して computed box-shadow を実測。
さらに実際の Tab キーナビゲーションでフォーカスが移った要素（ヘッダーのリンク `<a>`）でも追検証。

## 実行ログ

| 対象 | focusVisible | boxShadow | caretColor |
| --- | --- | --- | --- |
| 検索 input（placeholder「ノートを検索」） | true | **`oklch(0.371 0 0) 0px 0px 0px 2px`** | `rgb(29, 29, 31)` |
| Tab で到達したリンク `<a class="inline-flex ... rounded-pill ...">` | true | **`oklch(0.371 0 0) 0px 0px 0px 2px`** | - |

検索 input className（抜粋）: `... outline-none transition-colors ... focus:shadow-focus`（実体は `focus:bg-surface-hover focus:shadow-focus`）。

## 判定
- box-shadow は `oklch(0.371 0 0) 0px 0px 0px 2px`。
  - spread = **2px**
  - 色 = `oklch(0.371 0 0)`（= `--color-accent`、不透明・alpha 無し）
- 旧値（`4px` / `oklch(... / 0.28)` 半透明）の痕跡なし。
- 実際の Tab キー操作による `:focus-visible` でも同一の 2px 不透明リングを確認（プログラム的 focus による偽陽性ではないことを担保）。
- AC-3 / AC-7 を満たす → PASS。

備考: 当ブラウザは computed box-shadow の色を `rgb(...)` ではなく `oklch(...)` 形式でシリアライズする。
値の意味（accent・不透明・2px）は期待値と一致。
