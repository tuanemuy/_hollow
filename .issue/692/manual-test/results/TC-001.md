# TC-001: エディタ本文の caret-only 化（AC-1）

結果: **PASS**

## 概要
新規ノート作成画面（http://localhost:3000/notes/new）のエディタ本文（`.tiptap.ProseMirror`）および
外側 wrapper（`.min-h-[480px]`）にフォーカスを当て、computed style を実測。

## 実行ログ

| 項目 | 値 |
| --- | --- |
| URL | http://localhost:3000/notes/new |
| activeElement | `<div class="tiptap ProseMirror ProseMirror-focused">`（編集領域にフォーカス済み） |
| ProseMirror boxShadow | `rgba(0, 0, 0, 0) 0px 0px 0px 0px, ...`（全て透明・リング無し） |
| ProseMirror caretColor | `oklch(0.371 0 0)`（accent グレー） |
| ProseMirror outline | `none 3px`（outline-none） |
| wrapper(.min-h-[480px]) boxShadow | **`none`** |
| wrapper borderColor | `rgb(29, 29, 31)` |

## 判定
- 編集領域・wrapper のいずれにも箱リング（box-shadow）が出ていない（caret-only）。
- caretColor が accent 系グレー（`oklch(0.371 0 0)`）。
- AC-1 を満たす → PASS。

実装根拠: `WysiwygEditor.tsx` の wrapper で `[&_.ProseMirror]:focus-visible:shadow-none` + `[&_.ProseMirror]:caret-accent`。
