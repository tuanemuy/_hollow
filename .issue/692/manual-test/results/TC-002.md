# TC-002: タイトル入力の caret-only 化（AC-2）

結果: **PASS**

## 概要
エディタ画面のタイトル入力（`<input placeholder="無題のノート">`, `text-3xl font-heading`, `titleInput`）に
フォーカスし computed style を実測。`:focus-visible` が真であることも確認。

## 実行ログ

| 項目 | 値 |
| --- | --- |
| 対象 | `<input placeholder="無題のノート">`（タイトル入力） |
| focusVisible (`matches(':focus-visible')`) | **true** |
| boxShadow | `rgba(0, 0, 0, 0) 0px 0px 0px 0px, ...`（全て透明・リング無し） |
| caretColor | `oklch(0.371 0 0)`（accent グレー） |
| outline | `none 3px`（outline-none） |
| className（抜粋） | `... outline-none ... text-3xl font-heading ...`（`focus-visible:shadow-none` 適用） |

## 判定
- `:focus-visible` 発火状態（focusVisible=true）でも boxShadow は全て `rgba(0,0,0,0)`（透明）で箱リング無し。
- caretColor が accent 系グレー。
- `focus-visible:shadow-none` によるグローバル `:focus-visible` 箱リングの打ち消しが正しく機能。
- AC-2 を満たす → PASS。

実装根拠: `app/components/note/editor/styles.ts` の titleInput に `caret-accent focus-visible:shadow-none`。
