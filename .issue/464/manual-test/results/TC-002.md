# TC-002: 公開ステータスのラジオカード

| # | 操作 | 期待 | 実際 | 判定 |
|---|------|------|------|------|
| 1 | 3ラジオ表示確認 | 非公開/限定公開/公開がカード状 | 3つのラジオがカード状（枠付き）で表示 | PASS |
| 2 | 初期選択強調確認 | private なので「非公開」が強調 | 非公開カードが背景強調（accent）。checked=true | PASS |
| 3 | ステータスドット確認 | 各カードにドット | 非公開=グレー / 限定公開=オレンジ / 公開=グリーン のドットを確認 | PASS |
| 4 | 限定公開ラジオをクリック | 限定公開カードが強調に切替 | クリック直後に限定公開カードが濃いアクセント枠＋明背景に切替、非公開は強調解除 | PASS |
| 5 | submit前 has-checked 追従 | クリックで即追従 | submit せず即時に視覚強調が追従（has-checked / data-active CSS 機能） | PASS |

スクリーンショット: `.issue/464/manual-test/screenshots/tc-002-radio-unlisted.png`

判定: **PASS** — ラジオがカードスタイル。選択カードが視覚的に強調され、クリックで即追従。
