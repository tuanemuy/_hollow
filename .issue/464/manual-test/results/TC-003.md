# TC-003: 限定公開リンク発行フォーム

前提: TC-002 で限定公開を選択後、「公開状態を更新」を押下しサーバーへ反映（限定公開へ永続化）。これによりリンク発行フォームが表示される。

| # | 操作 | 期待 | 実際 | 判定 |
|---|------|------|------|------|
| 1 | フォームのスタイル確認 | リンク発行ボタン/パスワード欄がスタイリング済み | パスワード（任意）label + input + リンクを発行 button すべてスタイル適用 | PASS |
| 2 | 「リンクを発行」クリック → networkidle | リンク発行成功 | 発行成功 | PASS |
| 3 | URL ボックス表示確認 | 「一度だけ表示」ボックスに URL | 「発行されたリンク（一度だけ表示）」ボックスに share URL を code 表示（枠付きカード） | PASS |
| 4 | 一覧に行追加確認 | 有効リンク行が増える | 一覧に行追加: URL(monospace) + 「有効」緑バッジ + 新しいパスワード入力 + パスワードを設定(disabled) + 失効させる ボタン | PASS |
| 5 | バッジ/操作ボタンのスタイル | スタイリング済み | 「有効」がピル型バッジ。操作ボタン群もスタイル適用 | PASS |

スクリーンショット: `.issue/464/manual-test/screenshots/tc-003-issue-form.png`, `tc-003-issued.png`, `tc-003-issued-scrolled.png`

判定: **PASS** — フォーム・発行後 URL ボックス・有効リンク行すべてスタイリング済み。発行も成功。
