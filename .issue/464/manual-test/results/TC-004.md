# TC-004: errorComponent / notFound スタイル

URL: http://localhost:3100/notes/00000000-0000-7000-8000-000000000000/publish

| # | 操作 | 期待 | 実際 | 判定 |
|---|------|------|------|------|
| 1 | 存在しない note を open → networkidle | エラー/notFound 表示 | アプリシェル内に表示 | PASS |
| 2 | 表示文言確認 | 「ノートが見つかりません」 | 表示は「エラーが発生しました」（errorComponent, role=alert）。notFound 文言ではない | NOTE |
| 3 | スタイル確認 | p-6・ミュート色が当たる | h1 太字見出し + ミュート本文 + p-6 相当の余白。スタイル適用済み | PASS |

スクリーンショット: `.issue/464/manual-test/screenshots/tc-004-notfound.png`

判定: **PASS（スタイル）** — エラー表示はスタイリング済み（素HTMLでない）。

注意点（機能観察・コード未修正）:
- 全ゼロ UUID の存在しない note で notFound（「ノートが見つかりません」）ではなく errorComponent（「エラーが発生しました」）が表示された。
- スタイリング検証としては問題なし（両者ともスタイル適用済み）が、notFound 経路に乗っていない可能性がある。ローダーが notFound() ではなく汎用エラーを throw している、または UUID が上流バリデーションで弾かれている可能性。本タスクではコード修正せず観察のみ報告。
