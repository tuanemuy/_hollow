## 確認環境

このIssueの変更を確認するために必要な手順のみ記載。変更は className 文字列と JSX の `<br />` 削除のみで、DB スキーマ変更・マイグレーションは不要。

### 検証環境の起動

ライブのソースをそのまま確認できる Vite dev サーバーを使う（`pnpm start` は dist 配信のため、ソース変更の確認には `pnpm dev` を使う）。

```bash
pnpm dev
```

ランディング・認証ページは DB なしで表示できる。プロフィールページ（`/u/$username`、PROFILE_BIO 確認用）のみシードデータが必要 → ローカル D1 にマイグレーションとシードを適用する場合:

```bash
pnpm db:apply:local
```

### デプロイ方法

ステージングへの反映（必要時のみ）:

```bash
pnpm deploy:staging
```

本番への反映:

```bash
pnpm deploy:production
```

## 確認項目

### 1. ランディング HERO 見出し・本文

- **目的:** `ch` 撤去後、HERO_TITLE が不自然に折り返さず、HERO_SUBTITLE が適切な読み幅に収まる。
- **手順:**
  1. `/`（ランディング）を 1280px / 1024px で開く
  2. HERO_TITLE「散らかった頭の中に、静かな置き場所を」の行数を確認
  3. HERO_SUBTITLE の折り返しを確認
- **期待結果:** タイトルが 3 行にバラけず、`text-balance` で行長が均等。1文字オーファンなし。サブタイトルが画面幅いっぱいに広がらず読みやすい幅。
- **確認ポイント:** HERO_TITLE が 1 行で間延びして見えないか（間延びするなら plan ステップ1の通り緩い rem 上限を再付与）。

### 2. ランディング SECTION 見出し・本文

- **目的:** SECTION_TITLE「書いたものを、ちゃんと残す」の最終行「す」1文字オーファンが解消されている。
- **手順:**
  1. `/` を 1280px / 1024px で開き `#features` セクションへスクロール
  2. SECTION_TITLE / SECTION_LEAD / TEASER_BODY の折り返しを確認
- **期待結果:** 「す」のような1文字オーファンが出ず、`text-balance`/`text-pretty` でバランスが取れている。
- **確認ポイント:** TEASER_BODY が中央寄せで適切な幅に収まっているか。

### 3. ランディング フッターの段落分割

- **目的:** FOOTER_TAGLINE の `<br />` 削除と2段落化が正しく表示される。
- **手順:**
  1. `/` のフッターを確認
- **期待結果:** 「散らかった頭の中に、静かな置き場所を。」と「個人のための、ひっそりとしたノートサーバーです。」が 2 段落で表示され、段落間に適切な間隔（`mt-2`）がある。行間が詰まっていない。

### 4. 認証ページの `<br />` 削除

- **目的:** VerifyEmail（expired / used）と PasswordResetRequestForm の説明文が `<br />` なしで自然に折り返す。
- **手順:**
  1. `/password/reset`（PasswordResetRequestForm）を開きサブタイトルを確認
  2. メール確認ページ（`/verify-email` 系）の expired / used ステータス表示を確認（直接の URL アクセスまたは該当状態を再現）
- **期待結果:** 説明文がカード幅内で自然に折り返し、不自然な改行位置がない。

### 5. プロフィール bio の読み幅

- **目的:** PROFILE_BIO の `60ch`→`--content-max`(760px) 置換後、bio が破綻しない。
- **手順:**
  1. シード済みユーザーの `/u/$username` を開く
  2. 長文 bio で 1 行あたりの文字数を確認
- **期待結果:** bio が読みやすい幅（760px 上限）に収まり、極端に長い行にならない。

## エッジケース・異常系

### 1. 英語ダミーテキストでの破綻チェック

- **目的:** 見出し・本文を英語に差し替えても破綻しない（AC）。
- **手順:**
  1. devtools で HERO_TITLE / SECTION_TITLE / 本文を同程度の長さの英語ダミーに一時的に書き換える
  2. 1024〜1280px で表示を確認
  3. 確認後は元に戻す（コミットには含めない）
- **期待結果:** 行長・はみ出し・カード突き抜けがない。`rem` 幅は readable レンジ内。

## 既存機能への影響確認

- ランディング・認証・プロフィールページのレイアウト全体（変更したスタイル定数は各ページ専用のため、他ページへの波及はない想定だが念のため目視）。
- `text-balance`/`text-pretty` は初導入ユーティリティのため、`pnpm build` でビルドが通り該当 CSS が生成されることを確認。
