**対象:** モバイル（max-sm, 375px）のノート一覧フィルター — 横スクロール依存から集約トリガー + ボトムシートへの変更

## 確認できたこと

- **AC-1/AC-2:** モバイル375px でフィルターバーに横スクロールが無く、「絞り込み」集約トリガー（`aria-haspopup="dialog"` / `aria-expanded`）からボトムシート（`role="dialog"`、アクセシブル名「絞り込み」）を開いて、タグ / 期間 / 公開状態 / 内部リンク参照のすべてに横スクロールなしで到達できる。
- **AC-5:** ESC・×（閉じるボタン）の両経路でシートが閉じ、いずれも絞り込みトリガーへフォーカスが復帰する。背景オーバーレイのクローズ構造も確認。
- **AC-6:** 件数バッジが適用中フィルター数を加算反映（0→1→2…）、全クリアで0に復帰。`hasAnyFilter`（クリア×表示）と件数>0 が一致。
- **AC-2:** シート内のタグ / 期間 / 公開状態操作が URL search パラメータ（`tagNames` / `from`+`to` / `visibility`）と一覧に反映。内部リンク参照は「シート内は適用中チップ + 解除のみ、新規選択はシートを閉じて picker を開く別動線」の設計（ネスト Dialog 回避）どおり。解除後もシートは開いたまま維持。
- **AC-4:** デスクトップ1280px では集約トリガー・ボトムシートが visible にならず、従来のインラインフィルターバー（タグチップ列 + 期間/公開状態/タグ/内部リンク参照の各トリガー + 全クリア×）が不変。

## 注記

テスト中に遭遇した障害はすべて agent-browser のツール特性（実装バグや偽陽性ではない）で判定に影響なし:
- `set viewport` が `open` でリセットされるため reload 後に再設定で対処。
- 「すべてのフィルタをクリア」が TanStack Router Devtools ボタン（fixed 左下、本番ビルドでは非表示）と重なりネイティブクリックがブロックされたため eval 経由 click で実行。
