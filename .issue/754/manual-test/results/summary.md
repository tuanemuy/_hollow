# Issue #754 マニュアルテスト結果サマリー

**実施日:** 2026-06-18
**環境:** http://localhost:3000/（dev / 認証 cookie `__Host-session=dev-admin-session-token`）/ agent-browser 0.28.0

## 主な確認内容

- モバイル（375px）でフィルターバーに横スクロールが無く、「絞り込み」集約トリガー（aria-haspopup=dialog）からボトムシート（role=dialog, 名「絞り込み」）を開いて全フィルター（タグ/期間/公開状態/内部リンク参照）に横スクロールなしで到達可能。
- シートは ESC・×（閉じる）で閉じ、いずれも絞り込みトリガーへフォーカス復帰。背景クリッククローズは onclick 付きのフルスクリーンオーバーレイとして構造的に確認。
- 件数バッジが適用中フィルター数（タグ+公開状態など）を加算反映し、全クリアで 0 に戻る。
- シート内のタグ/期間/公開状態操作が URL search パラメータ・一覧に反映。内部リンク参照は「シート内は適用中チップ+解除のみ／新規選択はシートを閉じて picker を開く別動線」という設計どおりの挙動。解除後もシートは開いたまま維持。
- デスクトップ（1280px）では集約トリガー・ボトムシートが非表示で、従来のインラインフィルターバー（タグチップ列 + 各トリガー + 全クリア×）が不変。

## 所見（FAIL 無し）

- 実装バグは検出されなかった。
- agent-browser 由来の注意点（偽陽性ではなくツール特性）:
  - `eval` がオープン状態の dialog を断続的に検出できない事象あり（実行コンテキスト由来）。snapshot / wait を正として判定し、結果に影響なし。
  - `set viewport` が `open` でリセットされるため、reload 後は viewport 再設定が必要だった。
  - 「すべてのフィルタをクリア」ボタンが TanStack Router Devtools ボタン（fixed 左下）と重なりネイティブクリックがブロックされたため eval 経由 click で実行（本番ビルドでは devtools 非表示のため実害なし）。
