# TC-005: デスクトップ不変（AC-4）

**結果**: PASS

## 実行ログ

| # | 操作 | 期待結果 | 実際の結果 | 判定 |
|---|------|----------|-----------|------|
| 1 | viewport 1280x900 でホーム表示 | デスクトップ幅で一覧表示 | innerWidth=1280 / innerHeight=900、ノート一覧表示 | PASS |
| 2 | フィルターバーがインラインチップ列で描画されるか | タグチップ + 期間/公開状態/タグ/内部リンクの各トリガーがインライン表示 | タグチップ（#538, #database, #design ... 多数）がインライン表示。「タグで絞り込み」「期間▾」「公開状態▾」「内部リンク参照」トリガーがインライン表示 | PASS |

## 備考

- デスクトップでは集約「絞り込み」トリガー・ボトムシートが出ず、従来のインラインフィルターバー（タグチップ列 + 期間/公開状態/タグ/内部リンク参照の各トリガー + 全クリア×）が変わらず描画・動作することを確認（AC-4 充足）。
- 集約トリガーは DOM には存在するが CSS で非表示（モバイル専用表示）であり、デスクトップ UI には影響しない。
