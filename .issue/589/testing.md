## 確認項目

各画面は SSOT である `spec/design/pages/mobile/{name}.html` と突き合わせる。共通の合否判定は「各幅で横スクロールが発生しない（`document.documentElement.scrollWidth <= document.documentElement.clientWidth`）」「高密度テーブルがカード/縦積みに畳まれている」。

### 1. P45 ユーザー一覧 — テーブル→カード化（主対象）

- **目的:** 高密度ユーザーテーブルが狭幅でカードに畳まれること
- **手順:**
  1. admin で `/admin/users`（P45）を 390px で開く
  2. テーブルがカードの縦積みになり、各カードがユーザー見出し（アバター+名前/メール）+ 補助属性（登録日/ロール/状態に実DOMラベル）+ アクション行に分かれていることを確認
  3. 行アクションのボタンが全幅・44px 高で縦積みになっていることを確認
  4. 320px / 430px でも横スクロールが発生しないことを確認
  5. **lg 幅へ広げ**、従来の高密度テーブル（`min-w-[880px]` 横スクロール込み、thead 表示）に戻ることを確認（非回帰）
- **期待結果:** `mobile/P45-admin-users.html` の `tr.row-main`/`td.user-td`/`.row-actions` に追従。横スクロールなし
- **確認ポイント:** thead が mobile で非表示・補助セルのラベル span 表示、アクション 44px 床、lg 非回帰

### 2. P46 ジョブ監視 — テーブル→カード化 + 操作セクション縦積み（主対象）

- **目的:** 取り込み/エクスポート/Cleanup テーブルと操作セクション群が畳まれること
- **手順:**
  1. admin で `/admin/jobs`（P46）を 390px で開く
  2. 取り込み・エクスポートの各テーブルがカード化（ジョブ見出し + 種別/所有者/更新/エラーの補助属性 + アクション行）されていることを確認
  3. 所有者ID・エラーコードが長くてもカード内で折り返し（`break-words`）され溢れないことを確認
  4. 操作セクション群（検索インデックス/バックフィル/再暗号化）が縦積み + ボタン全幅・44px になっていることを確認
  5. 320px / 430px でも横スクロールが発生しないことを確認
  6. **lg 幅で**従来の高密度テーブル（`min-w-[920px]`）に戻ることを確認（非回帰）
- **期待結果:** `mobile/P46-admin-jobs.html` の `job-card`/`job-actions`/`.op-row` と視覚的に等価。横スクロールなし

### 3. P47 メトリクス — 数値カード1カラム + limits テーブル（既対応の非回帰確認）

- **目的:** 既存の `max-md:block` リフロー・メトリクスカード1カラムが維持されること（変更なし想定）
- **手順:**
  1. admin で `/admin/metrics`（P47）を 390px で開く
  2. メトリクス数値カードが1カラム縦積み、limits テーブルがカード化されていることを確認
  3. 320px / 430px でも横スクロールなし
- **期待結果:** `mobile/P47-admin-metrics.html` に追従（既存実装の維持）。横スクロールなし

### 4. P43 デザイントークン — 行縦積み + 入力/ボタン44px床

- **目的:** トークン行が縦積みになり、220px 固定列が溢れず、入力・削除ボタンが44px床になること
- **手順:**
  1. admin で P43（デザイントークン設定）を 320px で開く
  2. 各トークン行が縦積み（キー / スウォッチ+値入力 / 操作）になり、220px 固定列由来の横溢れがないことを確認
  3. キー入力・値入力・削除ボタンが 44px 高、削除ボタンが全幅であることを確認
  4. 390px / 430px でも横スクロールなし
- **期待結果:** `mobile/P43-admin-tokens.html` の `.token-row`/`.token-input`/`.icon-action` に追従。横スクロールなし

### 5. P40/P41/P42/P44 — 非回帰確認（変更なし想定）

- **目的:** テーブルを持たない画面が引き続き 390px で破綻しないこと
- **手順:** P40(dashboard)・P41(llm)・P42(prompts)・P44(registration) を 390px で開く
- **期待結果:** 各画面が1カラム/グリッド対応済で横スクロールなし。溢れる要素があればその要素だけ `max-sm:` で最小修正

## エッジケース・異常系

### 1. P45/P46 の空状態

- **目的:** テーブルが空（`<td colSpan>`）のときにカード化分岐がカードを崩さないこと
- **手順:** ユーザー/ジョブが0件の状態（または絞り込みで0件）を 390px で表示
- **期待結果:** 「該当なし」テキストが中央表示され、補助セル用の flex/ラベルが当たらずレイアウトが崩れない

### 2. P43 上書き中バッジ・ad-hoc 追加行

- **目的:** 「上書き中」バッジ付き行・「+トークンを追加」で増えた空行も縦積みカードで破綻しないこと
- **手順:** トークンを上書き → バッジ表示、「+トークンを追加」で空行追加、各々を 320px で確認
- **期待結果:** バッジ・空行とも縦積みで溢れない

## 既存機能への影響確認

- **デスクトップ幅（lg 以上）の admin テーブル**: UsersTable/Jobs/Metrics の高密度テーブルが従来通り（横スクロール込み・thead 表示・24px 密度ボタン）であること。
- **トークン編集機能**: P43 のキー入力 disabled・削除/既定に戻す・保存・全リセットがモバイルレイアウトでも従来通り動作すること（className 変更のみでロジック不変）。
