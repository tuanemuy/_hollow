## 確認項目

### 1. 未保存の編集があると公開設定モーダルに警告が出る

- **対応する受け入れ基準:** AC-2 / AC-4
- **目的:** エディタで編集して保存を待たずに detail へ遷移し、公開設定を開くと「未保存の変更があります」警告が表示されることを確認する。
- **手順:**
  1. dev-admin ログイン状態で、シードノートの編集画面 `/notes/{noteId}/edit` を開く
  2. タイトルか本文を編集する（autosave の保存完了を**待たずに**）
  3. すぐにそのノートの詳細 `/notes/{noteId}` へ遷移する
  4. ツールバーの「公開設定」を開く
- **期待結果:** URL preview と「公開状態を更新」ボタンの間に、`AlertTriangle` アイコン付きの黄系警告ボックスが表示され、タイトル「未保存の変更があります」と本文が出る。
- **確認ポイント:**
  - 警告ボックスの配色・余白・アイコンが `spec/design/pages/P14-publish-settings.html:963-973` の `.safety-check` / `.alert-warning` と視覚一致するか。
  - 警告が公開範囲（公開／限定公開／非公開）に依らず表示されるか。
  - 文言がモック `:969-970` と一致しているか。

### 2. autosave 完了後は警告が出ない

- **対応する受け入れ基準:** AC-3 / AC-5
- **目的:** 編集後に autosave が完了してから遷移すると警告が出ないことを確認する。
- **手順:**
  1. `/notes/{noteId}/edit` でタイトルか本文を編集する
  2. `AutosaveIndicator` が「保存済み」相当の表示になるまで待つ
  3. 詳細 `/notes/{noteId}` へ遷移し、公開設定を開く
- **期待結果:** 警告ボックスが表示されない。
- **確認ポイント:** autosave 完了（dirtyKeys が空に戻る立ち下がり）でフラグがクリアされていること。

### 3. 手動保存後は警告が出ない

- **対応する受け入れ基準:** AC-3 / AC-5
- **目的:** 保存ボタンで明示保存した直後に detail へ遷移しても警告が残らないことを確認する（手動保存は reducer の dirtyKeys をリセットしないため、明示 clear で補う設計の検証）。
- **手順:**
  1. `/notes/{noteId}/edit` でタイトルか本文を編集する
  2. 保存ボタンで手動保存する（成功で detail へ自動遷移）
  3. 詳細 `/notes/{noteId}` で公開設定を開く
- **期待結果:** 警告ボックスが表示されない。
- **確認ポイント:** 手動保存成功時の明示 `clearNoteUnsaved` が効いていること（これが無いと恒常的に誤検知する）。

### 4. 未編集で開いた場合は警告が出ない

- **対応する受け入れ基準:** AC-5
- **目的:** 編集していないノートの公開設定には警告が出ないことを確認する。
- **手順:**
  1. 編集していないシードノートの詳細 `/notes/{noteId}` を直接開く
  2. 公開設定を開く
- **期待結果:** 警告ボックスが表示されない。

## エッジケース・異常系

### 1. 未編集オープンが既存フラグを誤消去しない

- **目的:** 別のノートを未編集で開閉しても、未保存フラグが立っているノートの警告が消えないことを確認する（初回マウントの `0→0` 誤 clear 回避の検証）。
- **手順:**
  1. ノートAを編集（autosave 完了前）→ フラグを立てる
  2. ノートB の編集画面を未編集で開いてすぐ閉じる（または detail に戻る）
  3. ノートA の詳細で公開設定を開く
- **期待結果:** ノートA の警告は依然として表示される（ノートB の未編集オープンで巻き込み消去されない）。

### 2. 公開設定の再オープンでフラグが再読込される

- **目的:** 公開設定を一度閉じて再度開くと、その時点のフラグ状態が再評価されることを確認する。
- **手順:** 警告が出ている状態で公開設定を閉じ、別タブ等で保存を完了させてから再度開く（同一セッション内）。
- **期待結果:** open のたびに `readNoteUnsaved` が再読され、状態に応じて警告の有無が切り替わる。
