# TC-002: 未編集で開くと警告が出ない

結果: PASS

## 概要

新規 session で編集を行わず詳細を直接開いた場合、公開設定モーダルに「未保存の変更があります」警告が表示されないことを確認した。

## 実行ログ

| ステップ | 操作 | 結果 |
| --- | --- | --- |
| 1 | session `verify-583-tc2` で認証し、編集せず `/notes/.../202` を直接 open（networkidle 待ち） | 遷移成功。dirty フラグ = `null`（未設定） |
| 2 | ツールバー「公開状態: 非公開」ボタン (ref=e28) を click | モーダル「公開設定」が開く |
| 3 | モーダル内 snapshot で警告の有無を確認 | 「未保存の変更があります」警告は表示されない |

## 補足

- TC-001 とは別 session のため sessionStorage は分離されており、TC-001 の dirty フラグは引き継がれない（正しい分離挙動）。
