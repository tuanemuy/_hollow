# TC-008: 確認ダイアログのアイキャッチ（ConfirmDialog）

**結果**: PASS
**実行時間**: 約20秒

## 実行ログ

| # | 操作 | 期待結果 | 実際の結果 | 判定 |
|---|------|---------|-----------|------|
| 1 | ノート詳細「削除」をクリック | ConfirmDialog 表示 | `role="alertdialog"` のダイアログが表示 | PASS |
| 2 | タイトル左のアイコンを確認 | `AlertTriangle` (lucide-triangle-alert) 20x20 | class=`lucide lucide-triangle-alert text-warning`, 20x20 | PASS |
| 3 | アイコンの `aria-hidden` を確認 | `aria-hidden="true"` | aria-hidden=`true` | PASS |
| 4 | ダイアログの accessible name を確認 | タイトル文字列のみ | `aria-labelledby` で参照される `<h2>` のテキスト = 「このノートをゴミ箱に移動」のみ。「AlertTriangle」「警告」等のアイコン由来テキスト混入なし | PASS |
| 5 | タイトル行のレイアウト | `flex items-center gap-2` で縦中央揃え | スクリーンショットで縦中央揃え確認 | PASS |

## 備考
- AlertTriangle は 20px、`text-warning` トークンで描画。スクリーンリーダー向けの accessible name にはタイトル文字列のみが含まれ、a11y契約を満たす。
