# 動作確認計画 — Issue #749: モバイル表示をモックに合わせる（チップ32px / チェック24px / 床除去）

**Issue:** #749
**作成日:** 2026-06-18

---

## 確認環境

このIssueの変更を確認するために必要な手順のみ記載（プロジェクト全体のセットアップは省略）。本Issueの in-scope 変更は P10 ノート一覧（`/`）のフィルターチップと選択チェックボックスのモバイル寸法のみ。

### 検証環境の起動

```bash
pnpm db:migrate         # ローカル D1 (hollow-local-d1) にマイグレーションを適用
pnpm seed:dev-admin     # 決定的な admin ユーザー + セッション（cookie: dev-admin-session-token）を投入
pnpm dev                # vite dev (workerd) を http://localhost:3000 で起動
```

- ノート一覧（`/`）はログインユーザーのノートを表示する。`seed:dev-admin` のセッションでログイン状態にする。
- フィルターチップを描画させるには、タグ付きノートが複数必要（チップ列が横スクロールするくらいの本数が望ましい）。選択チェックボックスは一覧上部の「選択」トグルで選択モードに入ると描画される。シードデータは manual-test 実行時にブラウザ操作または `pnpm db:execute:local --file <sql>` で投入する。

### デプロイ方法

検証環境（ローカル D1 + `pnpm dev`）のみで確認できるため、ステージング/本番へのデプロイは本確認には不要。

## 確認項目

### 1. フィルターチップの高さがモバイル32px / デスクトップ28px

- **対応する受け入れ基準:** AC-1, AC-2
- **目的:** チップが mock 寸法になり、44px 床で膨張しない。
- **手順:**
  1. devtools をモバイル幅（375px）にして `/` を表示。
  2. フィルターチップ（タグ／期間／公開状態など）の高さを計測。
  3. 幅をデスクトップ（1280px 等）に戻して再計測。
- **期待結果:** モバイルで 32px、デスクトップで 28px。モバイルで 44px に膨張していない。
- **確認ポイント:** ghost チップ（点線・期間/公開状態の未設定）も同じ高さか。

### 2. 選択チェックボックスの寸法がモバイル24px / デスクトップ20px

- **対応する受け入れ基準:** AC-3, AC-4
- **目的:** チェックボックスが mock 寸法になり、44px 正方形床で潰れない。
- **手順:**
  1. モバイル幅（375px）で `/` を表示し「選択」トグルで選択モードに入る。
  2. 各行のチェックボックス（円）の表示寸法を計測。
  3. デスクトップ幅で同様に計測。
- **期待結果:** モバイルで 24px×24px、デスクトップで 20px×20px。縦長に潰れていない。
- **確認ポイント:** チェック ON 時の accent 塗り・チェックアイコンが中央に収まるか。

### 3. 横スクロール・折り返し・選択トグルの維持（回帰防止）

- **対応する受け入れ基準:** AC-5
- **目的:** 先行コミットで入れた横スクロール行・折り返し抑止・選択挙動が壊れていない。
- **手順:**
  1. モバイル幅でチップ合計幅がビューポートを超える状態にし、チップ列を横スクロール。
  2. チップ内テキストが折り返さない（縦スクロールが発生しない）ことを確認。
  3. チェックボックス／行タップで選択トグルが従来どおり動くことを確認。
- **期待結果:** チップは1行のまま横スクロール、テキスト折り返しなし、選択トグル正常。

## エッジケース・異常系

### 1. mock と並べた重ね合わせ

- **目的:** 数値計測だけでなく見た目が mobile mock（`spec/design/pages/mobile/P10-home.html`）と一致するか。
- **手順:** 375/390px で mock と実画面を並べ、チップ・チェック周りのサイズ感・余白を目視比較。
- **期待結果:** 体感差がない。

## 既存機能への影響確認

- `NoteCheckbox` は List/Tile/Calendar の3ビュー共有。Tile/Calendar ビューでも選択チェックがモバイル24px / デスクトップ20px になり、選択挙動が従来どおり動くこと。
- `filterChip` / `filterChipGhost` は FilterBar のみで使用。FilterBar の全チップ種別（タグ／期間／公開状態／内部リンク／directory フォールバック）で高さが揃うこと。
