# 失敗分析 — TC-007（ソートボタンのモバイル高さ）

**分類**: デザイン差異（許容・Issue 起票なし）

- 期待: モック `P32-public-search.html` の `.sort-btn` はモバイルで `height: 44px`（px リテラル）。
- 実際: 375px 幅で 40.56px。`SEARCH_SORT_BTN` の `max-sm:h-11`（2.75rem）が、プロジェクトのフルードな root font-size（`clamp(14px, 1vw+11px, 16px)` → 375px で 14.75px）に追従するため。
- 判断: 同一ツールバーの既存絞り込みチップ（`app/components/public/styles.ts:240`）もまったく同じ `max-sm:h-11` を使っており、実機ではソートボタンと同じ高さに揃う。実装はアプリ全体の rem ベースのフルード慣習と一貫しており、px リテラルのモックとの数 px 差はプロジェクト全体の既存差異であって本 Issue の回帰ではない。タッチターゲットも 40px 超を維持。
- 対応: 起票せず本記録のみ。モック px とフルード rem の全体的な突き合わせはプロジェクト横断の課題で、本 Issue のスコープ外。
