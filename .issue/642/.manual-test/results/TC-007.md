## 失敗詳細（FAILの場合）

- 実装の sm 未満の高さは `max-sm:h-11`（2.75rem）で指定されている（`app/components/public/styles.ts` の `SEARCH_SORT_BTN`）。
- ルートフォントサイズがトークン `--text-base: clamp(14px, 1vw + 11px, 16px)` でフルードなため、375px 幅では root = 14.75px となり、2.75rem = 40.56px。モックは `height: 44px` の px リテラルで 44px。
- 幅 500〜639px では root が 16px に張り付くため 44px ちょうどになる。375px 等の狭い幅でのみ 44px を下回る（タッチターゲット 44px 基準にも未達）。
- 修正案: `max-sm:h-11` → `max-sm:h-[44px]` 等の px 指定。なお同パターンが他コンポーネントにも存在する可能性あり。
