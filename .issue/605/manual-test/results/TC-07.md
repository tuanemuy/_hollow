# TC-07 — 既存機能への回帰確認

Status: PASS

## Checks
1. **既存ソート軸 (タイトル順 / 更新日順)**: `/u/alice?sort=title` renders without
   error and reorders by title; `?sort=updatedAt` reorders by updatedAt (TC-01).
   The non-publishedAt axes (note-column sorts via `noteRepository`) still work.
2. **カレンダー表示 (display=calendar)**: `/u/alice?display=calendar` renders the
   date-grouped calendar (headings「2025年2月1日(土)」etc.) without error. The
   default-sort change to publishedAt did not break date_for_calendar grouping.
3. **公開ノート詳細**: `/u/alice/apple-note` renders (heading "Apple Note") with
   valid seed. (An earlier failure was a seed-data defect — a trashed note
   without `trashed_at` — not an implementation bug; fixed in the seed.)
4. **公開検索のキーワード絞り込み**: `/search?q=zorptest` returns 6 hits with
   `<mark>` highlight; the period JOIN did not break MATCH scoring/highlighting.
5. **username サジェスト (tag prefix path unaffected)**: user prefix suggest works
   (TC-06); the tag combobox is present in the same drawer and renders.

## Verdict
No regressions observed in existing sort axes, calendar grouping, note detail,
or keyword search. The #605 period-JOIN and published_at sort additions are
additive.
