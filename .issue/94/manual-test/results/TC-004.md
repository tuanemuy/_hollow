## 動作分析

存在しない viewId（UUID v7 prefix `01938f00-0000-7000-8000-000000000000`）を URL クエリパラメータで指定した場合、以下のいずれかの経路で 200 + 全件表示が実現されている：

- `validateSearch` が UUID 形式を満たす viewId はそのまま通し、loader 側で `loadSavedViewById` が `view=null` を返したケース → `baseSearch = search` のまま `loadOwnedNotes` で全件取得
- もしくは presentation/loader が view=null を検知して viewId フィルタを無視

いずれにしても、期待された「500 や error 画面にならない、ノート一覧が表示される、全件にフォールバック」という挙動が確認できた。
