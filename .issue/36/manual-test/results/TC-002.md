- The "ref_kind=title / ref_target=Helsinki" entry confirms `INTERNAL_LINK_PATTERN` extracted the inserted text.
- `resolved_note_id` is NULL because resolution to a concrete note id appears to be performed by an async event consumer (outbox `note.content_updated` event is pending; relay/consumer worker is not running in `pnpm dev`).
- Therefore the `/?referencingNoteId=…` filter shows `0 件` (it joins on `resolved_note_id`). This is an async / worker-runtime concern, not a Suggest UI defect.
