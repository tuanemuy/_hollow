## 確認項目

### 1. WYSIWYG モードで `[[` トリガにより候補ポップアップが表示される（主要受入条件 1）

- **目的:** Issue 受入条件 1 — `[[` 入力でタグ・ノート候補のポップアップが表示される
- **手順:**
  1. ノート A の詳細画面または編集画面を開き、エディタを WYSIWYG モードに切り替える
  2. 本文に `[[Hel` と入力する
  3. ポップアップが表示されることを確認する
- **期待結果:** ポップアップに以下の候補が出る
  - ノート候補: `Hello World`, `Helsinki`
  - 別ユーザー X の `Heliopolis` は **出ない**
- **確認ポイント:** kind アイコン（`N` = ノート、`#` = タグ）が表示され、note と tag が区別できる

### 2. 候補を選択するとテキスト挿入され、保存後バックリンクとして抽出される（主要受入条件 2）

- **目的:** Issue 受入条件 2 — 選択結果が `[[note-title]]` 相当のテキストで挿入され、サーバー側 `INTERNAL_LINK_PATTERN` がバックリンクとして抽出する
- **手順:**
  1. ノート A の編集画面で本文に `[[Hel` と入力 → ポップアップ表示
  2. ↓キーで `Helsinki` を選択 → Enter で確定
  3. 本文に `[[Helsinki]] ` （末尾に半角スペース）が挿入されることを確認
  4. autosave 完了まで待つ（既存の autosave 表示で完了を確認）
  5. ノート Helsinki の詳細画面（`/notes/<B.id>`）を開く
  6. バックリンクパネルに「Hello World」（ノート A）が表示されることを確認
- **期待結果:** 挿入テキストがサーバー側でバックリンクとして抽出されている
- **確認ポイント:** 既存の `INTERNAL_LINK_PATTERN` がそのまま動作している（HtmlSanitizer も allow-list 変更不要）

### 3. タグ候補を選択すると `#tagname` 形式で挿入され、タグとして紐づく

- **目的:** ADR-002 — タグ候補は `#tagname` 形式で挿入
- **手順:**
  1. ノート A の編集画面で本文に `[[dra` と入力 → ポップアップ表示
  2. `draft` タグ候補（`#` アイコン付き）を Enter で選択
  3. 本文に `#draft ` （末尾に半角スペース）が挿入されることを確認
  4. autosave 完了まで待ち、画面リロード
  5. ノート A の詳細画面でタグ一覧に `draft` が含まれることを確認
- **期待結果:** タグが既存 `TagService.extractFromHtml` 経路で `note_tags` テーブルに紐づく
- **確認ポイント:** `[[draft]]` ではなく `#draft` 形式で挿入される

### 4. キーボードナビゲーション（↑↓Enter/Esc）が機能する（主要受入条件 3）

- **目的:** Issue 受入条件 3 — ↑↓Enter/Esc のキーボード操作
- **手順:**
  1. WYSIWYG モードで `[[Hel` と入力 → ポップアップ表示（候補 2 件以上想定）
  2. ↓キー: 選択が次の候補に移動することを確認
  3. ↓キー（末尾で）: 先頭にラップすることを確認
  4. ↑キー（先頭で）: 末尾にラップすることを確認
  5. Esc キー: ポップアップが閉じ、本文に `[[Hel` のテキストだけが残ることを確認
  6. 再度 `[[Hel` を打って Enter で選択 → テキストが挿入されることを確認
- **期待結果:** 4 つのキーすべてが想定通り動作
- **確認ポイント:** aria-selected 属性が現在選択中の項目だけに付く（DevTools で確認）

### 5. マウスクリックで候補を選択できる（onMouseDown 罠の回帰防止）

- **目的:** ADR-003 — `onMouseDown + preventDefault` でクリック前 blur 罠を回避
- **手順:**
  1. WYSIWYG モードで `[[Hel` と入力 → ポップアップ表示
  2. マウスでポップアップ内の候補をクリック
- **期待結果:** クリックが効き、候補のテキストが挿入される
- **確認ポイント:** クリック時にエディタが blur して候補が消える、という挙動になっていないこと

### 6. 自分のノートのみが候補に出る（主要受入条件 4）

- **目的:** Issue 受入条件 4 — visibility 制約
- **手順:**
  1. メインユーザーで WYSIWYG モードに入り、`[[Heli` と入力
  2. 候補に別ユーザー X の `Heliopolis` が出ないことを確認
  3. ログアウト後、別ユーザー X でログイン
  4. X のノートを WYSIWYG で開き、`[[Hel` と入力
  5. 候補に メインユーザーの `Hello World` / `Helsinki` が出ないことを確認
- **期待結果:** owner スコープが port シグネチャレベルで強制されている
- **確認ポイント:** 双方向で他オーナーのデータが漏れない

## エッジケース・異常系

### 7. trashed ノートは候補に出ない

- **目的:** trashed 除外
- **手順:**
  1. ノート B（`Helsinki`）をゴミ箱に移動
  2. ノート A の WYSIWYG で `[[Hel` と入力
  3. 候補に `Helsinki` が **出ない** ことを確認（`Hello World` のみ）
  4. ノート B を復元
  5. 再度 `[[Hel` で `Helsinki` が候補に出ることを確認

### 8. NoteTitle に `[`/`]`/`|` を含むノートは候補から除外（ADR-008）

- **目的:** 破綻リンク防止
- **手順:**
  1. WYSIWYG で `[[foo` と入力
  2. ノート D（`foo|bar`）が候補に **出ない** ことを確認
- **期待結果:** タイトルに `|` を含むノートが除外される
- **確認ポイント:** 該当ノート以外（同じ prefix を持つ正常なノート）は候補に出ること

### 9. 空クエリで候補なし表示

- **目的:** `[[` 直後（query が空）でも候補一覧が出ること
- **手順:**
  1. WYSIWYG で `[[` だけを入力（直後）
  2. ポップアップが表示されるか、または「候補なし」が表示されることを確認
  3. 続けて 1 文字入力すると候補が更新されることを確認
- **期待結果:** いずれにせよクラッシュしない

### 10. 該当ヒットなしで「候補なし」表示

- **目的:** ヒット 0 件時の UX
- **手順:**
  1. WYSIWYG で `[[zzz_no_match` と入力
  2. ポップアップに「候補なし」が表示されることを確認

### 11. HTML モードでは Suggest が起動しない（S-002 / requirements 反映）

- **目的:** スコープ確認 — Mention 拡張は WYSIWYG モードにのみ組み込まれている
- **手順:**
  1. エディタを HTML モード（`HtmlEditor`）に切り替え
  2. 本文に `[[Hel` と入力
  3. ポップアップが **表示されない** ことを確認

### 12. 連続入力時のリクエスト抑制（debounce / abort）

- **目的:** クライアント側 100ms debounce + AbortController が機能
- **手順:**
  1. DevTools の Network タブを開いて XHR/Fetch を絞り込む
  2. WYSIWYG で `[[Helsinki` と素早く（連続で）入力
  3. `searchInternalLinkTargetsFn` のリクエスト数が 1〜2 回程度に抑制されていることを確認（タイプ毎に発火していないこと）
- **期待結果:** 連続タイピング中は前回 in-flight が abort され、最新入力でのみリクエストが完了

### 13. 編集ロック / autosave との共存

- **目的:** Suggest による editor 再生成リスク（P-004 対応）の実機確認
- **手順:**
  1. WYSIWYG で複数回 `[[Hel` → Enter → テキスト挿入を繰り返す
  2. autosave 表示が継続して動いており、エディタが unmount/remount されていないこと（カーソル位置が消えない、`lastEmittedHtmlRef` ガードが効いている）を確認
- **期待結果:** `[[` 補完操作で editor 再生成が起きない

## 既存機能への影響確認

- **既存 `tagRepository.findByOwner`（ADR-006/007 で SQL 変更）:** タグ一覧画面（`/tags`）で検索を行い、既存の挙動が保たれていること（特に `%` / `_` を含むタグ名がないことが既存挙動だが、検索結果が変わらないことを確認）
- **既存 WYSIWYG エディタの基本機能:** bold/italic/list/link/image 等の StarterKit 機能、Link 拡張、Image 拡張が引き続き動作すること
- **autosave:** WYSIWYG モードで普通にテキスト編集 → autosave が継続的に走ること
- **HtmlSanitizer:** 保存された HTML に Mention ノード由来のカスタム要素・属性が含まれないこと（getHTML 出力をブラウザ DevTools で確認、`<span data-internal-link>` 等が出ないこと）
