# 動作確認計画 — Issue #608: ヘッダー/フッターのロゴ(BrandLockup)の左・下が途切れて表示される

**作成日:** 2026-06-09

## 確認環境

このIssueの変更を確認するために必要な手順のみ記載。変更は表示コンポーネント（SVG ロゴ）のみで、DB マイグレーション・シードは必須ではない。ただし App ヘッダー・admin ヘッダーは認証後の画面のため、それらを確認する場合のみログイン用シードが必要。

### 検証環境の起動

```bash
pnpm dev
```

Vite 開発サーバー（Cloudflare 構成）が起動する。表示される URL（既定 `http://localhost:5173` 付近）をブラウザで開く。

### ログイン用シード（認証後の画面を確認する場合のみ）

App ヘッダー・admin ヘッダーを確認するときだけ実行する。Landing/Public/Auth の確認には不要。

```bash
pnpm db:apply:local
pnpm seed:dev-admin
```

### デプロイ方法

なし（検証環境のみで確認できる）。

## 確認項目

### 1. ロゴの途切れが解消されている（Landing ヘッダー・フッター）

- **目的:** マーク（左の重なる円）の左端・上端・下端が欠けずに完全表示されること。
- **手順:**
  1. `pnpm dev` で起動し、ルート（Landing ページ）を開く。
  2. ページ上部のヘッダーロゴを拡大して確認する。
  3. ページ最下部のフッターロゴも同様に確認する。
- **期待結果:** マークの2つの円が左側・上下とも途切れず、完全な円として描画される。
- **確認ポイント:** 特に左端の円の左輪郭と、円の上端・下端の stroke がクリップされていないか。

### 2. Public ヘッダー・フッターのロゴ

- **目的:** Public レイアウトのヘッダー/フッターでも途切れがないこと。
- **手順:**
  1. 公開ページ（Public レイアウトを使う画面、例: 公開ノート閲覧などログイン不要の公開動線）を開く。
  2. ヘッダー・フッターのロゴを確認する。
- **期待結果:** マークが完全表示され、途切れがない。
- **確認ポイント:** ヘッダー（上部）とフッター（下部）の両方。

### 3. Auth ヘッダーのロゴ

- **目的:** ログイン/サインアップ画面のヘッダーロゴが途切れないこと。
- **手順:**
  1. ログイン画面（`/login` 等の Auth レイアウト画面）を開く。
  2. ヘッダーのロゴを確認する。
- **期待結果:** マークが完全表示される。

### 4. App ヘッダー・admin ヘッダーのロゴ（要ログイン）

- **目的:** 認証後の App ヘッダー・admin ヘッダーでも途切れがないこと。
- **手順:**
  1. シード（上記）を投入し、開発用管理者でログインする。
  2. App 画面のヘッダーロゴを確認する。
  3. admin 配下の画面のヘッダーロゴを確認する。
- **期待結果:** いずれもマークが完全表示される。

### 5. ロゴサイズがモック相当に縮んでいる

- **目的:** ロゴの文字高さがモック（glyph ≈15px）相当（実装 ≈15.7px）になっていること。
- **手順:**
  1. 任意のヘッダーでロゴの高さを確認する（DevTools で SVG の描画高さを測ってもよい）。
  2. 修正前（height=20, glyph ≈20px）と比べて約2割小さくなっていることを確認する。
- **期待結果:** ロゴが以前より小ぶりになり、周囲のナビ要素と自然なバランスになっている。
- **確認ポイント:** SVG 要素の `height` が 16 になっていること、文字が以前より小さいこと。

## エッジケース・異常系

### 1. ダーク/ライトテーマでの色追従

- **目的:** マーク stroke・ワードマーク fill が `currentColor` を維持し、テーマ切替で色が追従すること（今回の変更で壊れていないこと）。
- **手順:**
  1. テーマ切替が可能な画面でライト/ダークを切り替える。
- **期待結果:** ロゴの色が前後の文字色に追従し、消えたり固定色になったりしない。

## 既存機能への影響確認

- 全使用箇所（Landing/Public/Auth/App ヘッダー、Landing/Public フッター、admin route 3箇所）が `BrandLockup` のデフォルトを共有するため、いずれかでレイアウト崩れ（折り返し・はみ出し・縦位置ズレ）が起きていないかを横断的に確認する。
