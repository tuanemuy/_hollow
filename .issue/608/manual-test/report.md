# ブラウザ検証レポート — Issue #608

**Issue:** #608 ヘッダー/フッターのロゴ(BrandLockup)の左・下が途切れて表示される
**実行日時:** 2026-06-09
**テストソース:** .issue/608/testing.md
**サーバー:** http://localhost:3001/（pnpm dev）

## 結論

**全 PASS（4/4）。** 途切れ不具合は解消され、ロゴサイズもモック相当に縮小された。起票した Issue: なし。

## 検証内容

### 1. 途切れの解消（最重要）

ヘッダーロゴを 10 倍に拡大し、背景・アウトラインを付けて目視（`02-logo-header-10x.png`）。マーク（左の2つの重なる円）の**左端・上端・下端すべてが欠けず完全に描画**されることを確認。修正前は stroke 半幅（≈4.37 user units）がワードマーク基準 `viewBox`（0 0 473.84 84.48）の外に出て `overflow:hidden` でクリップされていたが、新 `viewBox="-5 -1 480 86"` で全周が内側に収まった。

### 2. 全使用箇所へのカバレッジ

`BrandLockup` は単一の共有コンポーネント。レンダリング DOM で `viewBox="-5 -1 480 86"` / `height="16"` の適用を、Landing(ヘッダー/フッター)・Auth(login) の3コンテキストで確認。Public・App/admin（要ログイン）も同一コンポーネント・同一幾何のため同じ描画結果になる。

### 3. サイズ調整

`height` のデフォルトが 16 に変更され、ワードマーク glyph が ≈15.7px で描画される（新 viewBox 高さ 86 × 84.48/86 × 16）。修正前（height=20, glyph≈20px）より約2割小さく、モックの仮テキスト glyph ≈15px に整合。ログインページ（`05-login-page.png`）で周囲ナビとのバランスも自然。

## 既知の制限・補足

- フッターロゴの拡大スクショ（`03-footer-logo-10x.png`）は currentColor 継承で白地に淡色のため視認性が低いが、DOM 属性で修正済み viewBox を確認済み。フッターの幾何はヘッダーと完全同一。
- App/admin ヘッダーはログインが必要なため実画面の撮影は省略。共有コンポーネントの幾何が同一であることをもって PASS とした。
