# 動作確認計画 — Issue #787: fix(note): shrink note-detail action toolbar on mobile (gap / margin / icon density)

**Issue:** #787
**作成日:** 2026-06-30

---

## 確認環境

このIssueの変更（モバイルのノート詳細アクションツールバー縮小）を確認するために必要な手順のみ記載。

### 検証環境の起動

```bash
pnpm dev
```

`vite dev`（Cloudflare 設定）でローカル開発サーバーが起動する。起動後に表示される URL をブラウザで開き、DevTools のデバイスツールバーでモバイル幅（例: 390px）に設定して確認する。

モックの目視確認はサーバー不要で、`spec/design/pages/mobile/P11-note-detail.html` をブラウザで直接開けばよい。

### デプロイ方法

なし（ローカル検証環境のみで確認できる純粋な表示スタイル変更）。ステージング反映が必要なら `pnpm deploy:staging`。

## 確認項目

### 1. モバイルモックの縮小

- **対応する受け入れ基準:** AC-1, AC-6
- **目的:** モックが意図するモバイルレイアウト（gap/縦マージン/アイコン密度の縮小）を表現していることを確認する。
- **手順:**
  1. `spec/design/pages/mobile/P11-note-detail.html` をブラウザで開く（または DevTools で 390px 幅）。
  2. `.action-toolbar` の gap・上下マージン・アイコングリフ寸法を確認する。
- **期待結果:** gap が `--space-1`(4px)、margin が `--space-3 0 --space-4`(上12/下16px)、icon-only ピル内のグリフが 18px に縮小されている。横スクロールレールは引き続き機能する。
- **確認ポイント:** デスクトップモック `spec/design/pages/P11-note-detail.html` は変更されていないこと。

### 2. 実装とモックの一致（モバイル幅）

- **対応する受け入れ基準:** AC-3, AC-6
- **目的:** モバイル幅の実画面でツールバーのフットプリント（gap・縦マージン・アイコン密度）がモックと一致して縮小されていることを確認する。
- **手順:**
  1. `pnpm dev` でサーバー起動 → ブラウザで開く。
  2. DevTools のデバイスツールバーで幅 390px に設定する。
  3. 任意のノート詳細ページを開き、アクションツールバー（`NoteActions`）を表示する。
  4. ツールバーの gap・上下マージン・アイコン寸法を DevTools で測定し、確認項目1のモックと比較する。
- **期待結果:** gap 4px / 縦マージン 上12・下16px / icon-only グリフ 18px。3レバーがモック値と一致する。
- **確認ポイント:** AC-6 の判定は3レバー（gap/縦マージン/アイコン密度）の意図値一致のみ。編集(Pencil)ボタンの有無や rail 先頭の構成差は本Issue対象外なので誤判定しないこと。

### 3. タッチターゲット床の維持

- **対応する受け入れ基準:** AC-4
- **目的:** アイコングリフ縮小がタップ当たり判定を縮めていないことを確認する。
- **手順:**
  1. モバイル幅で各 icon-only ピルを DevTools の要素検査で選択する。
  2. ボックスサイズを測定する。
- **期待結果:** 各 icon-only ピルが 44×44px 以上を維持している（グリフは 18px でもボタンの当たり判定は不変）。
- **確認ポイント:** `min-h-[44px]` / `min-w-[44px]` 床が効いていること。

### 4. アクセシビリティ・レール挙動の維持

- **対応する受け入れ基準:** AC-5
- **目的:** 既存の横スクロールレール隔離とアクセシビリティ属性が維持されていることを確認する。
- **手順:**
  1. モバイル幅でツールバーを表示する。
  2. DevTools で `role="toolbar"` と各アクションの `aria-label` が残っていることを確認する。
  3. レール内のピル群が画面幅を超える場合に横スクロールできることを確認する。
- **期待結果:** `role="toolbar"` / `aria-label` が残り、`MENU_RAIL` の横スクロールが機能する。

## エッジケース・異常系

### 1. trashed（ゴミ箱）状態のツールバー

- **目的:** ゴミ箱状態の単一ラベル付きピルを持つツールバー分岐でも縦マージン縮小が正しく適用されることを確認する。
- **手順:**
  1. ゴミ箱に入れたノートの詳細をモバイル幅で開く。
  2. ツールバーの上下マージンを確認する。
- **期待結果:** active 分岐と同様に縦マージンが縮小されている（gap は単一ピルにつき無影響でよい）。

## 既存機能への影響確認

- **デスクトップ非回帰:** `sm` 以上の幅でノート詳細を開き、gap(8px) / 縦マージン(上16・下24px) / アイコン(20px) がデスクトップ値のまま据え置かれていることを確認する。
- **`Icon` 共有コンポーネントの他利用箇所:** `Icon` の本体ロジックは未変更（JSDoc のみ更新）のため、他画面のアイコン表示に影響がないことを確認する。
