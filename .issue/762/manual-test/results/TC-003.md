# TC-003: 自動保存でも minify 済み HTML が永続化される (AC-3)

**結果**: PASS

## 実行ログ
| # | 操作 | 期待 | 実際 | 判定 |
| --- | --- | --- | --- | --- |
| 1 | 編集画面 HTML タブで本文編集（`（手動保存編集）`→`（自動保存編集）`）、保存操作はしない | 自動保存が走る | — | PASS |
| 2 | 保存インジケータ（aria-live）の遷移をポーリング | 未保存→保存中→保存しました | `未保存の変更があります` → `保存中…` → `保存しました` を確認 | PASS |
| 3 | DB の content_html を確認 | 編集反映 かつ minified | `（自動保存編集）` 反映、`<ul><li>項目その1</li><li>項目その2`（ブロック間インデント無し） | PASS |

## 備考
- 既存ノート編集画面では自動保存が armed（standby）。新規作成画面の「自動保存はオフ」とは異なり、編集画面では HTML タブ編集が確実に自動保存に乗ることを確認。
- pre/code 内部 WS・隣接 `<a>` 語間スペース・`[[別のノート]]` は自動保存後も保持。
