# TC-005: brokenConditions の警告表示 + 適用可

| 項目 | 内容 |
|------|------|
| 操作 | `/views` の「壊れたビュー」行を確認 → 「適用」を実クリック |
| 期待 | 行内に警告バナー（警告配色・「壊れた条件があります」）。適用リンクは無効化されない。クリックで一覧へ遷移し結果 0 件。警告の二重表示なし |
| 実際 | 行内に警告バナー（オレンジ配色 + 警告アイコン）「壊れた条件があります / 削除済みの参照（1件）を含みます。…」を表示。加えて「壊れた条件: 1 件」チップ。適用リンクは `aria-disabled=null` / `pointer-events: auto` / 負の tabindex なしで**無効化されていない**。クリックで `/?display=list&viewId=019e816a-1195-780c-...` へ遷移、「0 件のノート」+「該当するノートがありません」空状態。エラーなし |
| 判定 | PASS |

補足: テスト手順の「バナー + チップは設計上OK」を確認。

注記（レビュー反映）: 本検証はブラウザ検証時点の実装（broken-banner に `role="alert"` あり）で実施した。その後 PR レビュー（review-001 → ADR-005）で、静的に描画される broken-banner からは `role="alert"` を除去した（動的な validation/server エラー `<p role="alert">` のみ alert ロールを維持）。バナーが可視・適用リンクが無効化されない・適用で 0 件という機能面の検証結果は変わらない。
