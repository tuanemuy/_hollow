# TC-005: brokenConditions の警告表示 + 適用可

| 項目 | 内容 |
|------|------|
| 操作 | `/views` の「壊れたビュー」行を確認 → 「適用」を実クリック |
| 期待 | 行内に警告バナー（`role="alert"`・警告配色・「壊れた条件があります」）。適用リンクは無効化されない。クリックで一覧へ遷移し結果 0 件。警告の二重表示なし |
| 実際 | 行内に `role="alert"` 警告バナー（オレンジ配色 + 警告アイコン）「壊れた条件があります / 削除済みの参照（1件）を含みます。…」を表示。加えて「壊れた条件: 1 件」チップ。`role=alert` は **ページ全体で1個のみ**（二重表示なし）。適用リンクは `aria-disabled=null` / `pointer-events: auto` / 負の tabindex なしで**無効化されていない**。クリックで `/?display=list&viewId=019e816a-1195-780c-...` へ遷移、「0 件のノート」+「該当するノートがありません」空状態。エラーなし |
| 判定 | PASS |

補足: テスト手順の「バナー + チップは設計上OK」を確認。`role=alert` バナー自体は1個のみで二重出力なし。
