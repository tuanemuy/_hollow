# TC-006: レスポンシブ（< 1024px）

| 項目 | 内容 |
|------|------|
| 操作 | viewport を 900x1000 に設定して `/views` を開く |
| 期待 | view-row が2段組になり row-actions が折り返す。レイアウトが崩れない |
| 実際 | 900px 幅で各 view-row が2段組化: 上段にアイコン枠+名前+チップ（マーク）、下段に row-actions（適用/名前変更/既定/削除）が折り返して横並び。警告バナー・公開マーク・既定マークも崩れずに収まる。オーバーフロー・重なりなし |
| 判定 | PASS |
