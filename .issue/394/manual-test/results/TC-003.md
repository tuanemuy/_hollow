# TC-003: 適用導線（タグ絞り込み）

| 項目 | 内容 |
|------|------|
| 操作 | `/views` の「エッセイ」（tag=essay）行の「適用」を実クリック |
| 期待 | ノート一覧が essay タグで絞り込まれ NoteEssay が表示される（tagId→tagName 解決がホーム loader 経由で効く）。空でない |
| 実際 | URL: `/?display=tile&viewId=019e816a-1195-7746-b6fd-9a1bb6a3e05f`。一覧「1 件のノート」= NoteEssay、`#essay` チップ（解決済みタグ名）・公開・2026年6月3日。空でない |
| 判定 | PASS |

補足: タグチップが id ではなく `#essay`（タグ名）で表示され、tagId→tagName 解決が loader 経由で効いていることを確認。display=tile に正規化。
