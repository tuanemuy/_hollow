# TC-002: 適用導線（正常系・visibility）

| 項目 | 内容 |
|------|------|
| 操作 | `/views` の「未公開の下書き」行の「適用」リンク（`/?viewId=019e816a-1195-7df5-...`）で遷移 |
| 期待 | `/?viewId=...` へ遷移し、private 扱いの3件（NoteDraft / NoteJournal / NotePlain）が表示される。URL に viewId が載る。エラー画面でない |
| 実際 | URL: `/?display=list&viewId=019e816a-1195-7df5-ac16-c43bf5e49e1c`（displayMode=list に正規化）。一覧「3 件のノート」= NotePlain / NoteJournal / NoteDraft。public な NoteEssay は除外。エラーなし |
| 判定 | PASS |

補足: 適用リンクは実クリックでも SPA 遷移する（初回の URL 即時読み取りは遷移完了前で false negative だったが、wait 後は正しく遷移）。本 TC は seed-data の期待（3件）と一致。
