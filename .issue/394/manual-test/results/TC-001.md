# TC-001: 一覧UIのスタイル表示

| 項目 | 内容 |
|------|------|
| 操作 | `/views` を開き snapshot + フルページ screenshot |
| 期待 | ページヘッダ（タイトル+サブタイトル）、個人/共有セクション（説明+件数）、各行に表示モードアイコン・名前・既定マーク・公開マーク・チップ・アクション。MVP ベタ表示でないこと |
| 実際 | ヘッダ「保存ビュー」+サブタイトル表示。個人ビュー（4 件）/共有ビュー（1 件）セクションに説明文と件数。各行に表示モードアイコン枠、名前、チップ（表示モードチップ）、適用/名前変更/既定/削除アクション。「未公開の下書き」に「既定」星マーク+「既定を解除」。「エッセイ（公開）」に緑「公開」マーク。「壊れたビュー」に「壊れた条件: 1 件」チップ + 警告バナー。整ったカンプ準拠デザイン。 |
| 判定 | PASS |
