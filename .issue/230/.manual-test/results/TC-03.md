# TC-03: タグサジェストから `tags` が除外されている

**結果:** PASS

## 手順と結果

1. ノート 2301 の編集ページ → FrontMatter タブ
2. `<datalist>` の option を JS で抽出:

```json
["date", "description", "title", "slug"]
```

3. 期待通り `date`, `description`, `title`, `slug` の 4 件のみ。`tags`, `aliases`, `publish` は含まれない
4. 「追加するキー名」入力欄に `tags` を手動で入力 → 「キーを追加」ボタンが有効化（自由入力は妨げられない）
