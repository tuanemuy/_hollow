# TC-01: 既存任意キーの後方互換（mood, project）

**結果:** PASS

## 手順と結果

1. ログイン → ノート `01938f00-0000-7000-8000-000000002301` の編集ページを開く
2. FrontMatter タブをクリック
3. `mood: tired`, `project: alpha` の 2 行が順序通り表示されていることを確認
4. `mood` の値を `focused` に変更し「保存」ボタンをクリック
5. ページをリロード → `mood: focused`, `project: alpha` がそのまま残ることを確認
6. 「生編集（JSON）」ボタン押下 → raw mode の JSON に以下が含まれることを確認:

```json
{
  "mood": "focused",
  "project": "alpha"
}
```

## 確認ポイント

- 任意キー (mood, project) が消えていない
- キー順序が初期ロード時のまま `mood → project` で保たれている
- 値編集後の persist が成功
