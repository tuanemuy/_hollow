# TC-06: キー rename (順序保持)

**結果:** PASS

## 手順と結果

1. ノート 2303 (`a:1, b:2, c:3`) を開く → FrontMatter タブ → a/b/c 順で表示
2. `b` のキー入力欄に `xyz` を fill → Tab で blur
3. 表示が `a → xyz → c` の順序のまま (末尾飛び無し) `xyz: 2`
4. 「保存」 → リロード → `a:1, xyz:2, c:3` の順序で persist

## 確認ポイント

- rename 後もキー順序が保持される
- 値 (b: 2) が新キー xyz に正しく引き継がれる
