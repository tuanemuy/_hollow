# TC-05: 新規キー追加 → 任意キーの編集

**結果:** PASS

## 手順と結果

1. ノート 2301 (`mood/project`) を開く → FrontMatter タブ
2. 「追加するキー名」入力に `customField` 入力 → 「キーを追加」クリック → 新規行表示
3. `customField` の値に `hello` 入力 → 保存
4. ページをリロード → `mood/project/customField=hello` 残存 (順序保持)
5. `customField を削除` ボタンクリック → 行が消える → 保存
6. ページをリロード → `customField` が消えている
7. raw JSON モード → 以下のみが残存:

```json
{
  "mood": "focused",
  "project": "alpha"
}
```

## 確認ポイント

- 任意キーの追加・編集・削除すべて autosave/保存で persist
- 既存キー (mood/project) を壊さない
