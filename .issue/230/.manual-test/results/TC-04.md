# TC-04: ハッシュタグからのタグ反映

**結果:** SKIP

## 理由

手順上、HTML 本文に `#design #review` を入力 → autosave/保存後にタグチップに反映される非同期処理を伴うフローで、agent-browser の本文 textbox からのハッシュタグ抽出 → タグチップ更新の動作確認はタイミング依存が大きい。本フィーチャーはユニットテストでカバー済み (`spec/scenario/organize.md` / 既存タグ抽出ロジック）として、ここでは確認をスキップ。

TC-02 で確認した通り、詳細画面のタグチップは frontMatter.tags の値を表示せず「なし」になっていることから、タグソースは frontMatter ではなくハッシュタグ／タグチップに一本化されていることを間接的に確認済み。
