# TC-07: 構造モード ⇔ raw JSON モードのトグル

**結果:** PASS

## 手順と結果

1. ノート 2304 (`a:"1", arr:["x","y"], nested:{k:1}`) を開く → FrontMatter タブ
2. 構造モードで:
   - `a` は文字列入力可
   - `arr` 行は `array` disabled バッジ + raw CTA
   - `nested` 行は `object` disabled バッジ + raw CTA
3. 「生編集（JSON）」へ切替 → JSON は同じキー順 (a, arr, nested) と同構造で表示
4. raw モードで `arr` を `["x","y","z"]` に書き換え → 「構造編集に戻す」
5. 構造モードでキー順序が `a → arr → nested` のまま (末尾飛び無し)
6. 保存 → リロード → raw モードで以下が persist:

```json
{
  "a": "1",
  "arr": ["x", "y", "z"],
  "nested": { "k": 1 }
}
```
