# TC-02: 既存 `frontMatter.tags` の残置と表示（ADR-002）

**結果:** PASS

## 手順と結果

1. ノート `01938f00-0000-7000-8000-000000002302` の編集ページを開く
2. FrontMatter タブをクリック
3. `tags` 行が表示されることを確認:
   - `array` disabled バッジ
   - 「複雑な値です。生編集（JSON）で編集してください。」CTA
   - 行末の「tags を削除」ボタンが有効 (disabled なし)
4. `description` キーを追加 → 値 `test-desc` 入力 → 保存
5. ページをリロード → FrontMatter タブで `tags` と `description` 両方残存
6. 「生編集（JSON）」へ切替 → `{"tags":["legacy","old"],"description":"test-desc"}` (キー順保持)
7. `/notes/{id}` 詳細画面を開く → FrontMatter セクション `<dl>` に `tags` と `description` が並ぶ
8. タグチップは「なし」表示（frontMatter.tags の `legacy/old` はチップに反映されない）

## 確認ポイント

- `tags` 配列値は raw モード CTA 付き disabled 表示
- 削除ボタンだけは有効
- 別キーを追加・保存しても `tags` は壊れない
- タグチップソースは frontMatter.tags ではない (期待通り)
