# 残存課題 — Issue #619

実装・ブラウザ検証で確認した、本 Issue のコア完了条件の外にある既知の課題。いずれも #619 のコア機能（プロフィール構造・ソート選択式化・楽観更新・期間フィルター・公開日/相対日付）は満たしており、別 Issue で追跡する。

## 1. 存在しない/非公開ユーザーで 404 でなく 500 が表示される（既存・#619非起因）

- **内容**: `/u/<存在しないusername>` を開くと `notFoundComponent`（404）ではなく `errorComponent`（system/500「予期しないエラー」）が表示される。
- **原因**: `UserPublicTop.tsx:46` の `throw notFound()` が `renderUserPublicTop` server function の RSC ストリーム内で投げられるため、ルーターの notFound シグナルに伝播しない。`/notes/public/$noteId` の既存 Issue #599 と同一クラスの根本原因。
- **影響**: 表示が 404 でなく 500 になる UX 退行のみ（存在・内容の露出はない）。
- **#619 との関係**: #619 は RSC/notFound 構造に触れていない（search param / loaderDeps / 公開日・期間追加のみ）ため pre-existing。
- **追跡**: #599 にコメント追記済み（両ルートをまとめて対応する想定）。

## 2. 共有 Popover が垂直ビューポート処理を持たない（#619で露出）

- **内容**: 短いビューポート（高さ ~633px 等）でソートメニューを下方向に開くと、末尾項目「タイトル順」が画面外にはみ出し、実マウスクリックが外れて選択できない（キーボード・通常ビューポート・URL直接では成功）。
- **原因**: 共有 `usePopover`（`app/components/common/usePopover.ts`）が水平クランプ（`shiftX`）のみで、垂直のフリップ/クランプ/スクロールインを持たない。auth 側メニューも同構造の潜在課題。
- **影響**: 短い/スクロールされたビューポートでの下端メニュー項目のマウス選択に限定（緊急度 中）。
- **#619 との関係**: 新設の `SortPopover` で露出したが、根本は共有インフラ。app全体のポップオーバーに影響するため #619 内での修正は回帰リスクが大きく見送り。
- **追跡**: #652 として新規起票（共有 Popover の垂直ビューポート対応 + auth 側回帰確認）。
