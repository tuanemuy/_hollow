## 確認ポイント

- Note 集約と PublicationState 集約が実装レベルでも独立: FrontMatter に `publish: public` を保存しても `PublicationState.visibility` は `private` のまま。
- 保存時に何の確認ダイアログも出ない（旧仕様で想定されていた「公開ステータスが即時変更されます。続行しますか？」のような UI は実装にも存在しない）。
- `publish: public` は単なる任意キーとして FrontMatter パネル / エディタの双方に round-trip 可能（Edge Case 1 の検証も兼ねる）。
