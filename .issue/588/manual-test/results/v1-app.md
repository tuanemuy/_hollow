## モバイル固有導線の詳細所見

### P10
- 下部固定 CTAバー: `position:fixed`, x=0, width=390, bottom=844（全幅・下端固定）。「新規作成」ボタン＋アップロードアイコンボタン。
- フィルタバー: チップ（期間/公開状態/内部リンク参照）の親 DIV が `overflow-x: auto`。390px では3チップが収まり scrollWidth=clientWidth=342 だが、横スクロール帯として構成済み。
- BulkActionBar 排他: 「選択モード」ボタン→ノート2件をチェック→ `<section>` が fixed 全幅(390)・bottom=844 で出現。テキスト「2 件選択中 移動 公開設定 エクスポート ゴミ箱へ」。同時に fixed な「新規作成」CTAバーは消失（`ctaCreateBarPresent: false`）。排他動作を確認。

### P11
- アクションツールバー: 横スクロール可能な DIV（overflow-x、sw=400 > cw=389）。編集/公開状態/移動/URLコピー/エクスポート/その他の操作が並び、狭幅では「…」その他メニューへ折りたたみ。
- メタ・バックリンク: プロパティ（作成日・更新日・場所・タグ）→バックリンク の順に縦積み単一カラム。

### P12
- 編集ツールバー: `flex flex-wrap gap-1` の DIV が横スクロール（sw=492 > cw=340）。B/I/S/H2/H3/箇条書き/番号付きリスト。
- FrontMatter: タグ入力 → ディレクトリ（既存検索・新規名）が1カラム縦積み。WYSIWYG/FrontMatter/HTML タブ切替あり。

## 備考 / 観察事項

- **P15・P16（エクスポート系）の意匠未適用疑い**: 両画面とも横スクロール overflow=0 で本検証の PASS 基準は満たすが、他の app-shell 画面（P10/P11/P13/P17/P18/P20）と比べてフォーム/一覧が素のHTMLコントロール表示で、モバイルレイアウト/デザイントークン適用が未対応に見える。Issue #588 の追従対象に含まれるか要確認。コード修正は本タスク範囲外のため未対応。
- **TanStack Router Devtools バッジ**が全画面の左下に固定表示され、下端の CTAバー/BulkActionBar の左端を一部隠す（dev 環境のみの devtools オーバーレイで、レイアウト自体には影響なし）。
- P14 公開設定はノート詳細内のボタンから到達でき、モバイルではボトムシート/ダイアログとして全幅縦積み表示。スキップ不要で検証完了。
- overflow 計測で `documentElement.scrollWidth - clientWidth` は全ルート 0。`getBoundingClientRect().right` ベースで右端を超える要素は P10 等で検出されたが、いずれも react-hot-toast 系の portal コンテナ（`go339260511` 等）でドキュメント横スクロールには寄与せず（over=0）、PASS 基準に影響なし。
