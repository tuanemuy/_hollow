## モバイル固有導線の確認詳細

- P30 トップバー/著者ミニ: ロゴ + ログインが横並びで幅内に収まり。著者ヘッダー（アバター → 表示名 → @handle → 公開ノート数/開始月）は単一カラムで縦積み。問題なし。
- P32 フィルタツールバー: 検索バーと「検索」ボタンが 1 行内に収まり、結果リストは 1 カラム。空状態・結果ありの両方で over=0。
- P33 フッター縦積み: フッターの hollow ロゴ + リンク群（利用規約/プライバシー/このインスタンスについて）が 1 カラムで縦積み表示。ゲートカードも 1 カラム。
- P34 アクションボタン縦積み: 「ホームへ戻る」「検索ページを開く」がフル幅で縦に並び、その下に「一つ前に戻る」。縦積み確認。

## 備考・観察事項（レイアウト以外、参考）

- P31 の overflow スキャンで `visibility:hidden` の DIV（react-hot-toast 由来のオフスクリーン計測ノード、hashed class `go...`）が right=400 と検出されたが、いずれも非表示かつ `document` の over=0 のため横スクロールは発生しない（無害）。390/320/430 すべて over=0。
- P32 検索結果のスニペットでハイライト用の `<mark>...</mark>` がタグ文字列のまま表示されている（例: `短い<mark>テスト</mark>本文。`）。これはレイアウト overflow ではなく、スニペットのエスケープ/レンダリングに関する観察事項であり本レイアウト検証の対象外。必要なら別途確認推奨。
- P34 `/error` は `/error?kind=notFound` に正規化され 404 画面を表示。TanStack Router Devtools のフローティングウィジェットが画面下部に重なるが、これは開発時オーバーレイでありレイアウトの問題ではない（全画面で同様）。
