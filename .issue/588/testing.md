## 確認項目

各画面は SSOT である `spec/design/pages/mobile/{name}.html` と突き合わせる。共通の合否判定は「390px で横スクロールが発生しない（`document.documentElement.scrollWidth <= clientWidth`）」「モック固有のモバイル導線に追従している」。

### 1. P10 ホーム — 下部固定CTAバー / FilterBar / BulkBar

- **目的:** Step1 の基盤消費が正しく動くこと
- **手順:**
  1. ログイン後 P10（ノート一覧/ホーム）を 390px で開く
  2. 下部に固定CTAバー（新規作成 primary + アップロード icon-only）が表示され、ヘッダーの同CTAが消えていることを確認
  3. lg 幅へ広げ、ヘッダーCTAが復帰し下部CTAバーが消えることを確認
  4. フィルタバーの各 Popover を開き、狭幅でフルワイドシートになることを確認
  5. ノートを複数選択し、BulkActionBar が下端フルワイドで固定表示され、選択中は下部CTAバーが消える（排他）ことを確認
- **期待結果:** `mobile/P10-home.html` の `.cta-bar` / `.filter-bar` / `.bulk-bar` に追従。横スクロールなし
- **確認ポイント:** cta-bar(z40) と bulk-bar(z45) の排他表示、ヘッダーCTAの退避/復帰

- **目的:** `sm:`/`lg:` 以上で既存挙動が変わらない

- **期待結果:** デスクトップレイアウトが従来通り（中央モーダル/ヘッダーCTA/sticky中央ピル等）

- **Dialog 全波及**: `dialogBackdrop`/`dialog` は #587 で全ダイアログに波及済。本Issueの変更で desktop の中央モーダルが崩れないこと
