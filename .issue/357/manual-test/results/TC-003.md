# TC-003: ディレクトリ空状態の文言

**結果: PASS**

## 目的

ディレクトリが0件のときの空状態文言が簡潔か。

## 操作ログ

| # | 操作 | 結果 |
| --- | --- | --- |
| 1 | ログイン直後、ディレクトリ未作成の状態でサイドバーのディレクトリセクションを表示 | サイドバー表示OK |
| 2 | スクリーンショット取得 | `screenshots/tc-003/step-01.png` |
| 3 | 空状態テキストを正確に取得（葉ノードの textContent） | `"ディレクトリがありません"` |

## 取得した文言（正確）

```
ディレクトリがありません
```

サイドバーのディレクトリセクション全文:
```
ディレクトリ
+
ディレクトリがありません
```

## 判定

- 期待文言「ディレクトリがありません」程度の簡潔な文言 → **一致**。
- 旧文言「まだディレクトリがありません。右上の + から作成できます。」のような長文では **ない**。
- 作成導線は見出し横の「+」ボタン（`button "ディレクトリを新規作成"`）に委ねられており、依然として作成手段が分かる。

→ PASS
