# TC-002: ライブラリ/管理ナビの構成

**結果: PASS**

## 目的

サイドバーのナビが spec 準拠の構成になっているか、各リンクが正しく遷移するか。

## 操作ログ

| # | 操作 | 結果 |
| --- | --- | --- |
| 1 | サイドバーのライブラリ/管理セクションを確認 | 下記リンク構成を確認。`screenshots/tc-002/step-01-sidebar.png` |
| 2 | 各リンクの href を取得 | 下表 |
| 3 | 「保存ビュー」クリック | `/views?kind=personal` へ遷移、H1「保存ビュー」、404/エラーなし。`screenshots/tc-002/step-02-views.png` |
| 4 | 戻って「エクスポートジョブ」クリック | `/exports?offset=0` へ遷移、H1「エクスポートジョブ」、404/エラーなし。`screenshots/tc-002/step-03-exports.png` |
| 5 | （回帰確認）/tags・/trash を開く | /tags → H1「タグ管理」、/trash → H1「ゴミ箱」、いずれも 404 なし |

## サイドバー構成

ライブラリセクション:
- すべてのノート
- 保存ビュー

管理セクション:
- タグ
- ゴミ箱
- エクスポートジョブ
- アップロード

→ testing.md の期待構成（ライブラリに「すべてのノート」＋「保存ビュー」、管理に「タグ」「ゴミ箱」「エクスポートジョブ」「アップロード」）と一致。

## リンク href 一覧

| ラベル | href | 遷移確認 |
| --- | --- | --- |
| すべてのノート | `/` | （ホーム） |
| 保存ビュー | `/views?kind=personal` | OK（H1「保存ビュー」） |
| タグ | `/tags` | OK（H1「タグ管理」） |
| ゴミ箱 | `/trash` | OK（H1「ゴミ箱」） |
| エクスポートジョブ | `/exports?offset=0` | OK（H1「エクスポートジョブ」） |
| アップロード | `/#upload` | ホーム内アンカー |

## 判定

- ライブラリは「すべてのノート」1件だけの空疎な状態ではなく「保存ビュー」が追加されている。
- 管理セクションに「エクスポートジョブ」が追加されている。
- 「保存ビュー」→`/views`、「エクスポートジョブ」→`/exports` が **パラメータ不足エラーにならず正常表示**（それぞれ `?kind=personal` / `?offset=0` のデフォルトクエリ付きで遷移）。
- タグ・ゴミ箱も含めデッドリンク（404/エラー）なし。

→ PASS

## 備考

- サイドバーの「アップロード」リンクの href は `/#upload`（ホーム内アンカー）であり、testing.md 手順3が言及する `/upload` 単独ルートではない。ヘッダー側にも別途「アップロード」リンクがある。本TCの主眼（保存ビュー/エクスポートジョブの追加と遷移）には影響なし。デッドリンクでもない（ホームに留まる）ため PASS とした。`/upload` 専用ルートの要否は本Issueのスコープ外として記録に留める。
