## 確認項目

### 1. ディレクトリツリーのハイライト幅統一

- **目的:** ディレクトリ treeitem の選択時ハイライトとホバー時ハイライトが、同じ行ボックス幅で表示されること。
- **手順:**
  1. ログインし、ディレクトリを2つ以上作成する（サイドバーのディレクトリ見出し横「+」）。
  2. ディレクトリの1つをクリックして選択状態にする。
  3. 別のディレクトリ行にマウスオーバーする。
  4. 選択行のハイライトとホバー行のハイライトの左右の広がり（caret 列・アクション「︙」列を含む行全体かどうか）を見比べる。
- **期待結果:** 選択時もホバー時も**行全体（caret 列・アクション列を含む同一の横幅）**がハイライトされ、幅が一致する。
- **確認ポイント:** 以前は選択ハイライトが Link 部分だけで caret/アクション列を欠いていた。両者の左右端が揃っているか。

### 2. ライブラリ/管理ナビの構成

- **目的:** サイドバーのナビが spec の導線（保存ビュー / タグ管理 / ゴミ箱 / エクスポートジョブ）に沿った意味ある構成になっていること。
- **手順:**
  1. サイドバーの「ライブラリ」セクションを見る。「すべてのノート」に加え「保存ビュー」リンクがあること。
  2. 「管理」セクションに「タグ」「ゴミ箱」「エクスポートジョブ」「アップロード」があること。
  3. 各リンクをクリックして遷移先を確認する（保存ビュー→`/views`、エクスポートジョブ→`/exports`、タグ→`/tags`、ゴミ箱→`/trash`、アップロード→`/upload`）。
  4. 各リンクが現在地のときアクティブ表示（`data-active`）になること。
- **期待結果:** ライブラリが「すべてのノート」1件だけの空疎な状態ではなくなり、全リンクが正しい画面へ遷移し、デッドリンク（404）が無い。
- **確認ポイント:** `/views`・`/exports` がパラメータ不足エラーにならず正常表示されるか。

### 3. ディレクトリ空状態の文言

- **目的:** ディレクトリが0件のときの空状態文言が簡潔になっていること。
- **手順:**
  1. ディレクトリを1つも持たないユーザー（または全ディレクトリ削除後）でサイドバーのディレクトリセクションを見る。
- **期待結果:** 「まだディレクトリがありません。右上の + から作成できます。」のような長い文言ではなく、「ディレクトリがありません」程度の簡潔な文言が表示される。作成導線は見出し横の「+」ボタンに委ねられている。
- **確認ポイント:** 文言が短く、かつ作成手段（見出し横「+」）が依然として分かること。

## エッジケース・異常系

### 1. ディレクトリ rename 中のハイライト

- **目的:** treeitem のリネーム編集中に表示崩れが無いこと。
- **手順:**
  1. ディレクトリのアクションメニュー「︙」から「リネーム」を選び、編集状態にする。
- **期待結果:** 編集 input が表示され、レイアウト崩れや背景ハイライトの不整合が無い（編集中は Link 非表示のため行の選択ハイライトは消えるが許容）。
