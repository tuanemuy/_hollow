# TC-03 ヘッダー / ツールバー CTA のアイコン化（sm 境界 = 640px）

| 操作 | 期待 | 実際 | 判定 |
|---|---|---|---|
| 幅375 ヘッダー CTA | 新規作成/アップロードがアイコンのみ（44px / aria-label） | 両ボタン 48×44px、SVGアイコンあり、ラベル span は `max-sm:hidden`→display:none、aria-label="新規作成"/"アップロード" 保持 | PASS |
| 幅375 ツールバー CTA | 新規作成/アップロード/ビュー保存/選択 がアイコンのみ | 選択(48×44 aria="選択モード")、ビューとして保存(48×44 aria="条件が設定されていません" ※未保存時 disabled)、新規作成(48×44)、アップロード(48×44)。全てSVG+ラベル非表示、aria-label保持 | PASS |
| タッチターゲット | 44px 以上 | 全CTA高さ44px、幅44〜48px | PASS |
| 幅1280 | ラベル表示 | ヘッダー「新規作成」「アップロード」、ツールバー「選択」「ビューとして保存」「新規作成」「アップロード」全てラベル付き表示（span display:block） | PASS |

## 判定: PASS

aria-label がアイコンのみ状態でも常時付与されており、スクリーンリーダー/ツールチップ相当の操作意図が保たれている。
