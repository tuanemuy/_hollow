# TC-05 明示的な選択モード

幅1280 で List / Tile / Calendar 各 view を検証。

| 操作 | 期待 | 実際 | 判定 |
|---|---|---|---|
| 選択モード OFF（初期）List | チェックボックス非表示、行クリックで詳細遷移 | checkboxCount=0、BulkActionBar非表示。ノートタイトルは `/notes/<id>` リンクでクリックで詳細へ遷移（pathname確認済み） | PASS |
| ツールバー「選択」を ON | チェックボックス表示 + BulkActionBar 出現 | 4チェックボックス表示。`section.sticky.bottom-4.z-40` の BulkActionBar「0 件選択中 / 移動 / 公開設定 / エクスポート / ゴミ箱へ / ×」出現 | PASS |
| ノートを2件チェック（List） | 「2 件選択中」表示 | bar が「2 件選択中」、先頭2チェックボックス aria-checked=true | PASS |
| BulkActionBar の × | 選択モード終了（mode OFF + ids clear） | × (aria-label「選択モードを終了」) で checkboxCount=0、bar非表示、トグル「選択」aria-pressed=false | PASS |
| Tile 表示で ON + 選択 | チェックボックス + 選択トグル + BulkActionBar | 4チェックボックス、カード選択で枠ハイライト+チェック、「1 件選択中」表示（スクショ tc05-03） | PASS |
| Calendar 表示で ON + 選択 | 同上 | 日付グループ化リストに4チェックボックス、選択で「1 件選択中」+ BulkActionBar（スクショ tc05-04） | PASS |

## 判定: PASS

mode OFF は閲覧（リンク遷移）、mode ON で選択（checkbox + BulkActionBar）。× で mode 終了し選択クリア。List/Tile/Calendar 全 view で一貫動作。

## 補足

BulkActionBar の各アクション（移動 / 公開設定 / エクスポート / ゴミ箱へ）は表示・有効化を確認。実データへの破壊的操作（実際の移動・削除）は本検証では実行していない（一覧表示確認が主目的のため）。
