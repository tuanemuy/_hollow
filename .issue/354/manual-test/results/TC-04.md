# TC-04 FilterBar のモバイル最適化 + タグ折りたたみ

タグ総数 14 件のアカウントで検証（幅375）。

| 操作 | 期待 | 実際 | 判定 |
|---|---|---|---|
| 幅375でタグファセット表示 | 上限件数で打ち切り「もっと見る (+N)」 | タグ12件表示で打ち切り、「もっと見る (+2)」表示（aria-expanded=false） | PASS |
| 「もっと見る」をタップ | 残りタグが展開 | 14件全表示、トグル文言「閉じる」に変化（aria-expanded=true） | PASS |
| 「閉じる」をタップ | 再び折りたたみ | 12件に戻り「もっと見る (+2)」再表示 | PASS |
| 期間/公開状態/内部リンク参照コントロール | モバイル幅で折り返し、画面外に溢れない | document.scrollWidth=375=window幅、横スクロールなし。各コントロールが縦に折り返して収まる（スクショ tc04-03） | PASS |
| active タグ chip 色 | デザイン準拠（bg-ink 濃色 + 白文字） | `#test` クリックで bg=rgb(29,29,31)=`--color-ink #1d1d1f`、color=白、data-active=true / aria-pressed=true。結果「1 件」に絞込み | PASS |
| クリアボタン | フィルタ解除 | 「クリア」で 4 件に復帰 | PASS |

## 判定: PASS

横スクロールバーは本文に出ない。active chip 色は `--color-ink` トークンと完全一致しデザイン準拠。
