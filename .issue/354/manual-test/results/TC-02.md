# TC-02 サイドバードロワー化（lg 境界 = 1024px）

| 操作 | 期待 | 実際 | 判定 |
|---|---|---|---|
| 幅375で `/` を開く | ヘッダー左にハンバーガー表示、サイドバーは画面外（本文上に縦積みされない） | ハンバーガー「メニューを開く」(44px) がヘッダー左に表示。aside は x=-280 で off-canvas。本文に縦積みなし | PASS |
| ハンバーガーをタップ | ドロワーが左からスライドイン、backdrop 表示 | aside が x=0(幅280) にスライドイン、aria-expanded=true。`button.fixed.inset-0 z-[90] bg-black/0.2` の backdrop が出現 | PASS |
| ドロワー展開中の背面スクロール | スクロールロック | `body { overflow: hidden }` を確認 | PASS |
| ドロワー内ナビ | ライブラリ/ディレクトリ/タグ/ゴミ箱が機能 | ドロワー内に全ナビ項目を表示（スクショ tc02-02） | PASS |
| backdrop をタップ | ドロワーが閉じる | aside x=-280 に戻り aria-expanded=false、body overflow=visible（ロック解除） | PASS |
| Esc キー | ドロワーが閉じる | Esc で aside x=-280、aria-expanded=false、overflow=visible | PASS |
| 幅1280に広げる | ハンバーガー消失、サイドバー常時表示(sticky) | ハンバーガーは display:none（lg:hidden）で不可視。aside x=0 表示、position=sticky | PASS |

## 判定: PASS
