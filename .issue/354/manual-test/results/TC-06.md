# TC-06 デザイン準拠チェックボックス

選択モード ON で List のチェックボックスを検証（Tile/Calendar も同一 NoteCheckbox コンポーネント）。

| 操作 | 期待 | 実際 | 判定 |
|---|---|---|---|
| 未選択チェックボックス | リング表示 | bg=透明、border=`rgba(60,60,67,0.18)` 1px のリング、チェックマーク非表示 | PASS |
| 選択チェックボックス | accent 背景 + 白チェック | bg=`oklch(0.371 0 0)`=`--color-accent`、内部に白(rgb(255,255,255)) SVG チェックマーク | PASS |
| キーボード操作 | フォーカス可・Space/Enter でトグル | `button[role=checkbox]`、focus 可能、Space で aria-checked が true にトグル | PASS |
| 44px タッチターゲット（幅375） | 44px 確保 | チェックボックスのヒット領域 44×44px（視覚ボックスは 20×20px） | PASS |
| 統一性 | List/Tile/Calendar で同一見た目 | 全 view で同一 NoteCheckbox（tc05-02/03/04 のスクショで同形状を確認） | PASS |

## 判定: PASS

選択=accent(`--color-accent oklch(37.1%)`)背景+白チェック、未選択=リング でデザイン準拠。`button[role=checkbox]` でキーボード操作可、44px タッチターゲット確保。
