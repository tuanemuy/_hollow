## 確認項目

### 1. FrontMatter 例示文言が新モデルに沿った表現になっている

- **目的:** 旧モデル前提の `title, date, tags, status を検出` が、Issue #230 / ADR-001・002 の方針に沿った表現に置き換わっていることを確認する
- **手順:**
  1. ブラウザで `spec/design/pages/P13-upload.html` を開く
  2. アップロードキューのテーブル領域、Row 4（`note-on-design-language.md` の行）まで縦スクロールする
  3. メタ行（`#design` `#essay` `#apple` のチップが並ぶ行）の右端の文言を確認する
- **期待結果:** 文言が `FrontMatter: date / title / description などを検出` になっている
- **確認ポイント:**
  - `tags` / `status` の語が含まれていないこと
  - メタ行のレイアウト（チップ群との横並び、右寄せ）が崩れていないこと

### 2. 旧文言が他箇所に残っていない

- **目的:** リポジトリ全体で旧例示が他に残っていないことを確認する
- **手順:**
  1. 以下のコマンドを実行する
     ```
     grep -rn "title, date, tags, status" spec/
     ```
- **期待結果:** マッチ 0 件
- **確認ポイント:** 仮に残っていれば同じく更新対象とする
