# TC-003: directory インライン rename の即時表示

判定: **PASS**

左サイドバーのディレクトリツリーで「検証ディレクトリP」をインライン rename し、即時表示を確認。

## 手順と結果

| 操作 | 期待 | 実際 | 判定 |
| --- | --- | --- | --- |
| サイドバーツリー表示 | Root 配下に 検証ディレクトリP / Q | 検証ディレクトリP・検証ディレクトリQ が treeitem として表示 | PASS |
| P の操作メニュー →「リネーム」 | インライン入力欄が開く | textbox「ディレクトリ名」が `検証ディレクトリP` 既定値で出現 | PASS |
| 「検証ディレクトリP2」に変更 → Enter 確定 | 確定直後に新名表示・旧名のちらつきなし | 確定直後 treeitem が `検証ディレクトリP2`（link）に切替。input が閉じた瞬間に旧名は再表示されず、ちらつきなし | PASS |
| ページ再読込で収束確認 | sidebar 再取得後も新名で収束 | 再読込後も `検証ディレクトリP2` で収束（DB 反映） | PASS |

## 観測ポイント

- rename 確定 → sidebar invalidate 完了までの表示名つなぎ（optimistic）が効いており、input close 直後に旧名へ戻るフリッカーは観測されず。
- 再取得後も新名で安定。
