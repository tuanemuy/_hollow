# TC-002: tag のリネーム / 削除の即時反映

判定: **PASS**

`/tags`（タグ管理）で rename・delete の楽観的即時反映を確認。

## 手順と結果

| 操作 | 期待 | 実際 | 判定 |
| --- | --- | --- | --- |
| `/tags` を開く | 「検証タグX/Y/Z」+「3 件のタグ」 | `#検証タグX` `#検証タグY` `#検証タグZ`・各行 リネーム/統合/削除・「3 件のタグ」表示 | PASS |
| 検証タグX を「リネーム」→「検証タグX2」で保存 | 保存直後に `#検証タグX2` 表示 + 編集モード即 close | 保存 click 直後に行が `#検証タグX2` に切替、入力 UI が閉じ リネーム/統合/削除 ボタンに復帰 | PASS |
| 検証タグZ を「削除」→ 確認ダイアログで確定 | 確定直後に行が即時に消え、件数 3→2 | 確認ダイアログ `タグ "#検証タグZ" を削除` → 削除確定直後、Z 行が消失し「2 件のタグ」へ即時減少（残り X2・Y） | PASS |
| ページ再読込で収束確認 | loader 再取得後も新名・件数で収束 | 再読込後も「2 件のタグ」「#検証タグX2」「#検証タグY」で収束。二重表示・崩れなし | PASS |

## 観測ポイント

- rename：optimistic で即座に新名表示 + 編集モード close。loader 往復を待たない。
- delete：確定の瞬間に行が消え、件数表示も同時に即減。
- 収束：DB 反映後の再取得でも表示が崩れず一致。
