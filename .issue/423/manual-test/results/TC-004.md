# TC-004: directory 移動/削除は楽観化しない（操作中フィードバック維持）

判定: **PASS（軽確認）**

## 手順と結果

| 操作 | 期待 | 実際 | 判定 |
| --- | --- | --- | --- |
| 検証ディレクトリQ の操作メニュー →「削除」 | 確認ダイアログが出る（楽観削除しない） | `「検証ディレクトリQ」を削除しますか？` の alertdialog が表示。ツリーから Q が即座に消えることはない（gate されている） | PASS |
| ダイアログで「キャンセル」 | 削除されず Q が残る | キャンセル後も 検証ディレクトリQ が treeitem に残存 | PASS |

## 観測ポイント

- 削除は楽観化されず確認ダイアログで gate される（確定前に行が消えない）= 設計どおり「楽観化しない」挙動。
- 実削除は seed 破壊を避けるため実行せず（任意項目）。移動ダイアログの pending 表示は未検証（時間配分のため SKIP）。
