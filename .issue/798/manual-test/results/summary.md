## 主な所見

- WYSIWYG ツールバー（role=toolbar, aria-label="書式"）に `aria-label="画像"`/`title="画像"` のボタンが、リンクボタンの直後・末尾に1つ追加されている。`aria-pressed` 属性を持たず（単発アクション）、enabled。AC-1/AC-7 を満たす。
- 画像ボタンのクリックでコンソールエラーや画面破壊は発生しない。OSネイティブのファイル選択ダイアログ起動は agent-browser で観測不可のため自動検証対象外。
- HTML モードには書式ツールバーも画像ボタンも無く、本文下のファイル入力（メディア追加）は健在。AC-5 のうち HTML 分は PASS。
- 既存の書式ボタン（太字/斜体/取り消し線/見出し2/見出し3/箇条書き/番号付きリスト/引用/インラインコード/リンク）は画像ボタン追加後も全て健在。回帰無し。

## 注意・要メイン確認

- 現在の編集モード切替（EditorModeSwitch）の tablist は「WYSIWYG」「HTML」の2モードのみで、テストソースが想定する「インライン」モードのタブが UI 上に存在しない。そのため TC-3 のインラインモード分は自動検証対象外とした（FAIL ではない）。実装側でインラインモードが提供されているか（あるいは廃止されたか）の確認を推奨。
