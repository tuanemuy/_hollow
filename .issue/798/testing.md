## 確認項目

### 1. WYSIWYG ツールバーに「画像」ボタンが表示される

- **対応する受け入れ基準:** AC-1, AC-7
- **目的:** ツールバーにモック（P12）どおりリンクボタンの直後に画像ボタンが出ること
- **手順:**
  1. ログインして `/notes/new` を開く
  2. エディタのモード切替で「WYSIWYG」を選ぶ
  3. 書式ツールバーの末尾（リンクボタンの右隣）を見る
- **期待結果:** 画像アイコンのボタンが1つ表示される。ホバー/フォーカスで他のツールバーボタンと同じ見た目（円形・36×36）。トグルされる見た目（背景反転）にはならない（単発アクション）。
- **確認ポイント:** ボタンに `aria-label="画像"` / `title="画像"` が付くこと（ホバーで「画像」ツールチップ）。`aria-pressed` を持たないこと（DevTools で確認）。

### 2. 画像ボタンでファイル選択が開き、カーソル位置に挿入される

- **対応する受け入れ基準:** AC-2, AC-3
- **目的:** 画像ボタン → 本文下 MediaUploader のファイル選択起動 → 既存アップロードフローでカーソル位置に挿入
- **手順:**
  1. WYSIWYG モードで本文に数行テキストを入力し、途中にカーソルを置く
  2. ツールバーの画像ボタンをクリック
  3. OS のファイル選択ダイアログで画像ファイルを選ぶ
  4. アップロード完了を待つ
- **期待結果:** クリックでファイル選択ダイアログが開く。選択後、本文下の MediaUploader に「アップロード中…」（進捗）が出て、完了すると **カーソル位置** に画像が挿入される（末尾追記ではない）。
- **確認ポイント:** 挿入された `<img>` の src が `/media/<id>` 形式であること。本文下の MediaUploader の dropzone（クリック選択 or ドラッグ&ドロップ）からの直接選択でも同じく挿入されること（経路が二つあっても結果が同じ）。

### 3. HTML / inline モードには画像ボタンが無く、従来どおり動く

- **対応する受け入れ基準:** AC-5
- **目的:** ツールバーを持たない html / inline モードが無改修で従来どおり動作すること
- **手順:**
  1. モード切替で「HTML」を選ぶ → ツールバーの有無を確認
  2. 本文下の MediaUploader の dropzone（「メディアを挿入」）から画像を選ぶ
  3. モード切替で「インライン」を選び、同様に本文下の dropzone から画像を選ぶ
- **期待結果:** html / inline には書式ツールバー自体が無く、画像ボタンも無い。各モードの本文下 MediaUploader の dropzone から従来どおりアップロード→挿入できる（HTML は文字列末尾追記、inline も従来挙動）。
- **確認ポイント:** モード切替を WYSIWYG ↔ HTML ↔ inline と往復しても各モードのアップロード入口が壊れないこと。

## エッジケース・異常系

### 1. アップロード中の二重起動

- **目的:** アップロード進行中に画像ボタンを押しても二重アップロードが起きないこと
- **手順:**
  1. WYSIWYG で画像を選びアップロードを開始する（進捗バー表示中）
  2. 進捗中にツールバーの画像ボタンを再度クリックする
- **期待結果:** uploading 中は dropzone（file input を含む）がアンマウントされ進捗 UI に差し替わるため `mediaInputRef.current` が null になり、画像ボタン経由のクリックは no-op（新たなファイル選択ダイアログは開かない）。さらに `runUpload` 先頭の uploading ガードが二重起動を防ぐため、アップロードは1件のまま完了する。
- **確認ポイント:** （既知の許容事項）アップロード中はボタンが見た目 enabled のままだが、対応する file input が非マウントで ref が null のためクリックしても何も起きない。これは設計上の意図（ADR-002）であり不具合ではない。

### 2. エディタ未準備 / disabled 時

- **目的:** 保存処理中などエディタが disabled のとき画像ボタンも無効になること
- **手順:**
  1. WYSIWYG で本文を編集し「保存」を押す（保存中＝disabled の瞬間）
  2. 保存中にツールバーの状態を見る（短時間ウィンドウ）
- **期待結果:** 保存中は他の書式ボタン同様、画像ボタンも disabled（操作不可・薄い表示）になる。
- **確認ポイント:** disabled 中にクリックしてもファイル選択は開かない。

## 既存機能への影響確認

- WYSIWYG の他の書式ボタン（Bold / Italic / 見出し / リスト / リンク 等）が従来どおり動くこと（ツールバーに要素を1つ足しただけで配列・レイアウトが崩れていないか）。
- 本文下の MediaUploader 単体（dropzone のクリック選択／ドラッグ&ドロップ）からのアップロードが全モードで従来どおり動くこと。
- WYSIWYG ↔ HTML ↔ inline のモード切替、未保存変更の確認ダイアログ、自動保存などエディタ全体の挙動が回帰していないこと。
