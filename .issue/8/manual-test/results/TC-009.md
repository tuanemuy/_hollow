# TC-009: 複合フィルタ AND（visibility + referencingNoteId）

- **Issue:** #8
- **実行日時:** 2026-05-17
- **検証者:** Claude Code (agent-browser session `verify-tc-issue8-b`)
- **対象 URL:** `http://localhost:3000/?visibility=public&referencingNoteId=01938f00-0000-7000-8000-00000000b074`
- **結果:** **PASS**

## 目的

`visibility` と `referencingNoteId` を同時指定した際に AND で合成されることを確認する。

シード:
- N9「公開デザインガイド」: `visibility=public`, 内部リンクで N4 を参照
- N9 以外の public はなし
- N4 を参照しているのは N9 のみ

よって `visibility=public AND referencingNoteId=N4` は N9 のみが返るのが期待。

## 手順

1. シードユーザーでログイン
2. `/?visibility=public&referencingNoteId=01938f00-0000-7000-8000-00000000b074` にアクセス
3. 一覧と FilterBar UI を確認

## 期待結果

- 一覧に N9「公開デザインガイド」のみ（1 件）
- 公開状態 select: 「公開」
- 内部リンク参照 chip: 「参照中: 01938f00」表示

## 実際の結果

- URL: `http://localhost:3000/?visibility=public&referencingNoteId=01938f00-0000-7000-8000-00000000b074&page=1&limit=20`
- 一覧: 「公開デザインガイド」（N9）の 1 件のみ
- 公開状態 select: 「公開」が selected
- 内部リンク参照 chip: 「参照中: 01938f00」表示
- 件数表示: `10 件のノート`（ADR-009 既知挙動）
