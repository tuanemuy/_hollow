- **Issue:** #8
- **実行日時:** 2026-05-17
- **検証者:** Claude Code (agent-browser session `verify-tc-issue8-b`)
- **対象 URL:** `http://localhost:3000/?referencingNoteId=01938f00-0000-7000-8000-00000000b079`
- **結果:** **PASS**

## 目的

FilterBar に表示される内部リンク参照 chip の × ボタンで `referencingNoteId` クエリが URL から除去され、一覧が全件に戻ることを確認する。

## 手順

1. TC-005 の状態から chip の × ボタン（`button "内部リンク参照フィルタを解除"`）をクリック
2. URL と一覧件数の遷移を確認

## 期待結果

- URL から `referencingNoteId` が除去される
- chip が消える
- 一覧が全 10 件に戻る

## 実際の結果

- クリック前 URL: `http://localhost:3000/?referencingNoteId=01938f00-0000-7000-8000-00000000b079&page=1&limit=20`
- クリック後 URL: `http://localhost:3000/?page=1&limit=20`
- 一覧: 全 10 件表示（N1〜N10）
- chip 表示なし
- 件数表示: `10 件のノート`
