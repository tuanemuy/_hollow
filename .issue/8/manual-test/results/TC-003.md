# TC-003: `?visibility=unlisted` で限定公開のみ表示

- **Issue:** #8
- **実行日時:** 2026-05-17
- **検証者:** Claude Code (agent-browser session `verify-tc-issue8-a`)
- **対象 URL:** `http://localhost:3000/?visibility=unlisted`
- **結果:** **PASS**

## 目的

`visibility=unlisted` パラメータで限定公開ノートのみ絞り込まれ、badge も「限定公開」を反映することを確認する。

## 手順

1. シードユーザーでログイン済み
2. `http://localhost:3000/?visibility=unlisted` にアクセス
3. 一覧と badge を確認

## 期待結果

- N4「Project A デザインメモ」のみ表示（1 件）
- badge: 「限定公開」
- 公開状態 select: 「限定公開」が selected

## 実際の結果

- 一覧に表示されたノート: N4「Project A デザインメモ」1 件のみ
- badge: 「限定公開」(unlisted) — 期待どおり
- 公開状態 select: 「限定公開」が selected
- 件数表示: `10 件のノート`（ADR-009 既知挙動）
- URL: `http://localhost:3000/?visibility=unlisted&page=1&limit=20`
