# TC-004: フィルタ未指定で挙動が retrograde しない

- **Issue:** #8
- **実行日時:** 2026-05-17
- **検証者:** Claude Code (agent-browser session `verify-tc-issue8-a`)
- **対象 URL:** `http://localhost:3000/`
- **結果:** **PASS**

## 目的

受入条件「フィルタ未指定で `listNotesByOwner` の挙動が retrograde しない」を検証する。既存挙動（全件表示、件数表示、`status: 'active'` フィルタ）が visibility 関連の変更で壊れていないことを確認。

加えて、`NoteListItemDTO.visibility` が実値（private/unlisted/public）を反映している（ADR-001 解消）ことも併せて確認する。

## 手順

1. シードユーザーでログイン済み
2. `http://localhost:3000/`（クエリパラメータなし）にアクセス
3. 件数 / 表示ノート数 / 各カードの badge を確認

## 期待結果

- 全 10 件が表示
- 件数表示も 10 件
- 各カードの badge が実値（private/unlisted/public）を反映
  - N9「公開デザインガイド」のみ「公開」
  - N4「Project A デザインメモ」のみ「限定公開」
  - 残り 8 件は「非公開」
- 公開状態 select の現在値: 「すべて」
