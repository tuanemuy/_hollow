# TC-001: `?visibility=public` で結果が絞られる

- **Issue:** #8
- **実行日時:** 2026-05-17
- **検証者:** Claude Code (agent-browser session `verify-tc-issue8-a`)
- **対象 URL:** `http://localhost:3000/?visibility=public`
- **結果:** **PASS**

## 目的

filter 経路（`q` 空）で `visibility=public` パラメータが効き、公開済みノートのみ表示され、各カードの公開状態 badge が `public`（「公開」）を反映していることを確認する。

## 手順

1. シードユーザー（`test-user-001@example.com`）でログイン
2. `http://localhost:3000/?visibility=public` にアクセス
3. 一覧と公開状態 select の現在値、ヘッダー件数表示を確認

## 期待結果

- 一覧に表示されるのは N9「公開デザインガイド」のみ（1 件）
- 当該カードの公開状態 badge が「公開」
- 公開状態 select の現在値が「公開」

## 実際の結果

- 一覧に表示されたノート: 「公開デザインガイド」（N9）の 1 件のみ
- badge: 「公開」(public) — 期待どおり
- 公開状態 select: 「公開」が selected
- 件数表示: `10 件のノート`（ADR-009 既知挙動。filter 適用後も count は全件のまま）
- URL: `http://localhost:3000/?visibility=public&page=1&limit=20`

## 補足

- Issue #1 ADR-013 で抑制されていた visibility badge が公開状態を実値で表示している点を確認した。
- 件数表示「10 件のノート」はフィルタ適用後も総件数のままという ADR-009 既知挙動どおり。本 TC のスコープでは PASS。
