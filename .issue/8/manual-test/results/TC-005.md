# TC-005: `?referencingNoteId=<id>` で内部リンク参照フィルタが効く

- **Issue:** #8
- **実行日時:** 2026-05-17
- **検証者:** Claude Code (agent-browser session `verify-tc-issue8-b`)
- **対象 URL:** `http://localhost:3000/?referencingNoteId=01938f00-0000-7000-8000-00000000b079`
- **結果:** **PASS**

## 目的

filter 経路で `referencingNoteId` パラメータに参照「先」ノート N9（公開デザインガイド）の id を指定したとき、それを参照している from 側ノートのみが一覧に出ることを確認する。

シードでは `note_internal_links` に `from=N1, resolved=N9` が 1 件あるので、N1（Weekly planning ノート）のみが返るのが期待。

## 手順

1. シードユーザーでログイン
2. `http://localhost:3000/?referencingNoteId=01938f00-0000-7000-8000-00000000b079` にアクセス
3. 一覧と FilterBar の chip を確認

## 期待結果

- 一覧に表示されるのは N1「Weekly planning ノート」のみ（1 件）
- FilterBar に「参照中: 01938f00」chip が表示される

## 実際の結果

- URL: `http://localhost:3000/?referencingNoteId=01938f00-0000-7000-8000-00000000b079&page=1&limit=20`
- 一覧に表示されたノート: 「Weekly planning ノート」（N1）の 1 件のみ
- 「参照中: 01938f00」chip と × ボタン（`内部リンク参照フィルタを解除`）が表示
- 件数表示: `10 件のノート`（ADR-009 既知挙動・filter 適用後も count は全件のまま）

| # | タイトル                  | badge  |
