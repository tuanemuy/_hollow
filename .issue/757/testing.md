# 動作確認計画 — Issue #757: モバイルフィルターのモック（P10-home.html）を集約シート方式に同期

**Issue:** #757
**作成日:** 2026-06-18

---

## 確認環境

本 Issue の変更対象は `spec/design/` 配下の単体 HTML モック（インライン CSS 完結・依存ビルドなし）。アプリのビルド・サーバー起動（`pnpm dev` 等）は不要で、ブラウザでファイルを直接開いて確認する。

### 検証環境の起動

ブラウザでモックファイルを直接開く（`file://`）:

```
open spec/design/pages/mobile/P10-home.html
open spec/design/pages/P10-home.html
```

`P10-home.html`（デスクトップ）のモバイル該当部は、ブラウザのウィンドウ幅を 640px 未満に狭めて確認する（DevTools のレスポンシブモードで 375px 等）。

### デプロイ方法

なし（ドキュメントモックのみ。検証環境＝ローカルブラウザで完結）。

## 確認項目

### 1. モバイルのフィルタ行が集約トリガーになっている

- **対応する受け入れ基準:** AC-1
- **目的:** 横スクロールのチップ行が撤去され、集約トリガー「絞り込み」+ 件数バッジ + クリア× に置き換わっていることを確認。
- **手順:**
  1. `mobile/P10-home.html` をブラウザで開く。
  2. ノート一覧ヘッダー直下のフィルタ領域を見る。
- **期待結果:** 横スクロールするチップ列ではなく、スライダーアイコン + 「絞り込み」+ 件数バッジの pill と、その右にクリア× が並ぶ。
- **確認ポイント:** 横スクロールバーや、はみ出すチップ列が無いこと。

### 2. 集約フィルターのボトムシート（開いた状態）が表現されている

- **対応する受け入れ基準:** AC-2
- **目的:** 集約シートの中身（タグ / 期間 / 公開状態 / 内部リンク参照 / 全クリア）がモックに表現されていることを確認。
- **手順:**
  1. `mobile/P10-home.html` を下までスクロールし、フィルターシート showcase を見る。
- **期待結果:** 下端寄せのボトムシート（グラバー + 「絞り込み」見出し）に、タグチップ群・期間（プリセット + 範囲入力）・公開状態（ラジオ群）・内部リンク参照・すべてクリアが並ぶ。
- **確認ポイント:** 公開状態がデスクトップの menu ではなく fieldset ラジオで表現されていること（ADR-001 のシート内ロール方針）。

### 3. デスクトップモックのレスポンシブ切替

- **対応する受け入れ基準:** AC-3
- **目的:** `P10-home.html` で幅 640px 未満時にインラインチップ行が隠れ、集約トリガーが出ること。デスクトップ見た目は不変。
- **手順:**
  1. `P10-home.html` を開き、幅を 1000px 程度（デスクトップ）で見る。
  2. DevTools レスポンシブで幅を 375px に狭める。
- **期待結果:** デスクトップ幅ではチップ列（タグ + ゴーストチップ + クリア×）が従来どおり。375px ではチップ列が消え、集約トリガー「絞り込み」が表示される。
- **確認ポイント:** デスクトップ幅でレイアウト・チップ寸法が一切変わっていないこと。

### 4. #749 ADR-001 前提更新のコメント反映

- **対応する受け入れ基準:** AC-4
- **目的:** 横スクローラ前提が #754 で更新された旨がモック内コメントに残っていることを確認。
- **手順:**
  1. 両ファイルのフィルタ関連コメントを読む。
- **期待結果:** 「#749 ADR-001（横スクローラ）を #754 が集約シート方式に更新」相当の記述がある。

## エッジケース・異常系

なし（静的モックのため動的な異常系は無い）。レイアウト崩れ（はみ出し・重なり）が無いことを各幅で目視する。
