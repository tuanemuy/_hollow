## 補足
- 28 バイトの小さなファイルではアップロードが極めて高速で、中間状態 (`select` → `uploading` → `waiting`) の捕捉は browser 自動化で困難。仕様 (`spec/pages/index.md` の「即時フィードバック」要件) は実装コード上で確認できるため PASS とする。
- `UploadDialog.tsx:432-461` に `UploadingView`（"アップロード中..."）と `WaitingView`（"LLM がタイトルとメタデータを提案中..."）が定義され、いずれも `aria-live="polite"` + `SkeletonBlock`（`motion-safe:animate-pulse`）を含む。
