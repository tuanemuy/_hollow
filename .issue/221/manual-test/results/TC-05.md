## 補足

`app/components/ingestion/IngestionQueue.tsx`:
- `POLL_INTERVAL_MS = 4000`（pending/processing がある時）
- `POLL_IDLE_MS = 16000`（previewing / failed / saved のみ＝idle）
- `setJobs(nextJobs)` 経由の state 更新のみで `router.invalidate()` や全ページ navigation を行わない。observation の通り画面チラつきなし。

エラー文言マッピングは `app/components/ingestion/IngestionJobRow.tsx:140` で `displayJobErrorCode(job.errorCode)` を呼び `role="alert"` に描画。`errorDisplay.ts:13-58` の `renderIngestionBusinessMessage` を共有しており、モーダルとキュー双方で同じ日本語マップが使われる。
