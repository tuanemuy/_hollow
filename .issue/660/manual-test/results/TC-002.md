# TC-002: 公開トップ キーボード操作検証

**対象:** http://localhost:3000/u/dev-admin（確認項目3/4/5・AC-3/4）
**結果**: PASS

## 実行ログ

| # | 操作 | 期待結果 | 実際の結果 | 判定 |
|---|------|----------|-----------|------|
| 1 | 選択中 radio に .focus() | リストにフォーカス | focused=リスト | PASS |
| 2 | ArrowRight | タイルへ移動、aria-checked移動、focus追従、?display=tile | checked=タイル, focused=タイル(tabindex=0), URL=?display=tile | PASS |
| 3 | ArrowLeft | リストへ戻る、URL=?display消える（既定list） | checked=リスト, focused=リスト, URL=/u/dev-admin | PASS |
| 4 | End | カレンダーへ、?display=calendar | checked=カレンダー, URL=?display=calendar | PASS |
| 5 | ArrowRight（末尾でラップ） | 先頭リストへラップ | checked=リスト, URL=/u/dev-admin | PASS |
| 6 | ArrowLeft（先頭でラップ） | 末尾カレンダーへラップ | checked=カレンダー, URL=?display=calendar | PASS |
| 7 | Home | 先頭リストへ | checked=リスト, URL=/u/dev-admin | PASS |

## 所見

矢印キー（Right/Left）・Home/End・両端ラップが全て実機で機能。移動と同時に aria-checked が移り、URL の `?display=` が即時更新され、フォーカスが選択中 radio に追従（roving tabindex）。focus-visible outline も付与（TC-001 #5）。
