# TC-004: ホーム キーボード操作検証

**対象:** http://localhost:3000/（認証あり・確認項目2/3/4・AC-2/3/4）
**結果**: PASS

## 実行ログ

| # | 操作 | 期待結果 | 実際の結果 | 判定 |
|---|------|----------|-----------|------|
| 1 | 選択中 radio に .focus() | リストにフォーカス | focused=リスト | PASS |
| 2 | ArrowRight | タイルへ、aria-checked移動、?display=tile、履歴増えない | checked=タイル, focus=タイル(tab=0), URL=?display=tile, history.length=3(不変) | PASS |
| 3 | End | カレンダーへ、?display=calendar、履歴不変 | checked=カレンダー, URL=?display=calendar, history.length=3 | PASS |
| 4 | ArrowRight（末尾ラップ） | 先頭リストへ | checked=リスト, URL=?display=list | PASS |
| 5 | ArrowLeft（先頭ラップ） | 末尾カレンダーへ | checked=カレンダー, URL=?display=calendar | PASS |
| 6 | Home | 先頭リストへ、history.length不変 | checked=リスト, URL=?display=list, history.length=3 | PASS |
| 7 | focus-visible outline | accent outline | outlineWidth=2px solid oklch(0.371 0 0), :focus-visible=true | PASS |

## 所見

矢印キー・Home/End・両端ラップが実機で機能。移動と同時に aria-checked が移り、URL `?display=` が即時更新。`history.length` が全操作を通じて 3 のまま（replace:true、履歴非増加）を確認。フォーカスは選択中 radio に追従（roving tabindex）。

なお公開トップは既定値 list 時に `?display=` を消すのに対し、ホームはラップ後も `?display=list` を明示的に保持する（挙動差はあるが checked 状態はどちらも正しい）。
