# TC-003: ホーム radiogroup/radio 属性検証

**対象:** http://localhost:3000/（認証あり・確認項目1/2・AC-1/AC-5）
**結果**: PASS

## 実行ログ

| # | 操作 | 期待結果 | 実際の結果 | 判定 |
|---|------|----------|-----------|------|
| 0 | cookie 注入 + `/` を開く | `/` のまま（ログイン未リダイレクト） | URL=`http://localhost:3000/` | PASS |
| 1 | container の role/aria-label | radiogroup / 表示形式（1件） | rgCount=1, role=radiogroup, label=表示形式 | PASS |
| 2 | 各 radio の aria-checked/tabindex | 選択中のみ checked=true & tabindex=0 | [true,0][false,-1][false,-1] | PASS |
| 3 | 旧 tablist/tab/aria-selected の不在 | 0件 | tablistCount=0, tabCount=0, ariaSelectedCount=0 | PASS |
| 4 | radio のアクセシブル名 | リスト/タイル/カレンダー | aria-label="リスト","タイル","カレンダー"（title も同値） | PASS |
| 5 | focus-visible outline | accent outline 付与 | outlineWidth=2px solid oklch(0.371 0 0), :focus-visible=true | PASS |

## 所見

ホームの表示モード segmented も radiogroup 化済み。アイコンのみのボタンだが各 radio に aria-label/title でアクセシブル名が付与されている。roving tabindex・旧 tablist 除去を確認。
