# TC-001: モバイル幅でログイン画面が表示できる / viewport-fit=cover が反映される

**結果**: PASS
**実行時間**: 約 20 秒
**セッション**: verify-tc-001

## 実行ログ

| # | 操作 | 期待結果 | 実際の結果 | 判定 |
|---|------|---------|-----------|------|
| 1 | `pnpm dev` でローカル dev サーバー起動 (http://localhost:3000) | サーバーが ready 状態 | VITE v8.0.12 で 3.3s で ready、`/` が 307 で `/?page=1&limit=20` にリダイレクト | PASS |
| 2 | `curl -s http://localhost:3000/login` で HTML 取得 → viewport meta 確認 | `<meta name="viewport" content="...viewport-fit=cover">` が含まれる | `width=device-width, initial-scale=1, viewport-fit=cover` を確認 | PASS |
| 3 | agent-browser で `http://localhost:3000/login` を開きスクショ | ログイン画面がモバイル幅で表示される | snapshot で `heading "ログイン"`, `textbox メール / パスワード`, `button "ログイン"` を確認 | PASS |

## 備考

- viewport-fit=cover は実装ステップ 3（ADR-003）通り iOS Safari で `env(safe-area-inset-*)` を有効化するための前提条件。HTML 出力に含まれることを確認した
- agent-browser 0.27.0 には `viewport` サブコマンドが存在しないため、ブラウザのデフォルト ビューポートでスクショ撮影（実物の 375 幅エミュレーションは行えなかった）。Chrome の DevTools レスポンシブモード or Playwright の deviceScaleFactor 指定での手動再確認を PR レビュー段階で推奨
