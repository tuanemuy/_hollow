```bash

```

`pnpm dev` の `predev` で `wrangler types` が自動実行される。起動後に表示される localhost の URL をブラウザで開く。

### デプロイ方法

なし（検証環境のみで確認できる。クラス文字列の変更のみで、DB/サーバー挙動には影響しない）。

## 確認項目

### 1. ノート詳細: メタ情報パネル（NoteMetaPanel）の境界

- **目的:** パネル（`bg-surface-elevated`）とページ白背景・内部チップ（`bg-surface`）の境界が視認できることを確認する。
- **手順:**
  1. ノートを 1 件開く（ノート詳細画面）。
  2. 「ノートのメタ情報」パネル（作成日・更新日・ディレクトリ・公開状態・タグ・バックリンク）を見る。
- **期待結果:** パネルがページ白背景からほんのり沈んだ明るいグレーで浮き、内部のタグチップ・非公開ステータスチップ（`bg-surface`）がパネルより一段暗く判別できる。
- **確認ポイント:** タグチップ／非公開チップとパネルの境界。彩色チップ（公開=success / 限定公開・ゴミ箱=warning）との視覚的一貫性（彩色チップは浮き、surface 系チップは沈む）も自然か。

### 2. ノート詳細: FrontMatter パネル（FrontMatterPanel）の境界

- **目的:** パネルと内部の `bg-surface-hover` 子要素（配列項目・オブジェクト行）の階調が破綻しないことを確認する。
- **手順:**
  1. FrontMatter（メタデータ）を持つノートを開く。
  2. FrontMatter パネルとその中の配列/オブジェクト表示行を見る。
- **期待結果:** パネル（明）> 内部の配列/オブジェクト行（`bg-surface-hover`、暗）の順で明度差があり、ネストした項目が判別できる。
- **確認ポイント:** パネル端のヘアラインと内部行の境界。

### 3. ノート編集: FrontMatterEditor パネル内ボタン・入力欄の境界

- **目的:** パネル（`bg-surface-elevated`）上の `pillBtn`（`bg-surface`）・`fieldControl` 入力欄がデフォルト（hover 前）状態で判別できることを確認する。
- **手順:**
  1. ノート編集画面を開き、FrontMatter エディタのパネルを表示する。
  2. パネル内の「生編集」「キーを追加」「削除」等の `pillBtn` ボタンと、入力欄（`fieldControl`）を、マウスを乗せていない状態で見る。
- **期待結果:** ボタン・入力欄がパネル背景から一段暗いグレーとして判別でき、hover 前でも境界が消えない。
- **確認ポイント:** 入力欄に focus したとき背景が白（`bg-bg`）になり、白 > elevated（パネル）> surface（コントロール）の階調が自然に見えるか。

## エッジケース・異常系

### 1. 低コントラスト環境での見え方

- **目的:** elevated と surface の明度差（約 4%）が控えめなため、視認性が極端に落ちないか確認する。
- **手順:**
  1. 上記 1〜3 の画面を、輝度を下げた画面 / 明るい室内など条件を変えて見る。
- **期待結果:** ヘアライン（`border-hairline`）と明度差の併用で、いずれの条件でもパネルと内部要素の境界が判別できる。

## 既存機能への影響確認

- **共有ボタン定数（`pillBtn` / `chip` / `fieldControl`）は無改変** — 白ページ上のボタン（ノート一覧ツールバー、ログイン、ランディング等）の見た目が従来通りであること。
- **admin デザイントークン設定画面**（白カード `bg-bg`）が従来通りで、本変更の影響を受けていないこと。
