# TC-005: ボタンのサイズ/バリアント

結果: PASS

## 概要

リネーム/統合は小型（btn-xs 密度）の surface ボタン。削除は常時赤塗りではなく透明基調（ghost-danger、hover 時のみ error 色）。モック P18-tags.html と一致。

## 実行ログ

| ステップ | 操作 | 期待 | 結果 |
| --- | --- | --- | --- |
| 1 | 1280幅でタグ行を hover し screenshot | 小型ボタン + 削除 ghost-danger | PASS |

## 確認できた実装詳細

- リネーム/統合ボタン: `bg-surface` + `data-sm`（→ `data-[sm]:h-7 data-[sm]:px-3 data-[sm]:text-xs`）。実測 height=28px = btn-xs 密度の小型 surface ボタン。
- 削除ボタン: `data-ghost-danger` + `data-sm`。computed: color rgb(110,110,115)=ink-secondary、background transparent（rgba(0,0,0,0)）。常時赤塗りではない。
  - クラスに `data-[ghost-danger]:bg-transparent data-[ghost-danger]:text-ink-secondary data-[ghost-danger]:hover:...:bg-error-surface data-[ghost-danger]:hover:...:text-error` を確認 → hover 時のみ error 色。
- モック P18-tags.html の `.btn-xs` / `.btn-destructive`（透明基調・hover で error）と挙動一致。
