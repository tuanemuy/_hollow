# TC-009: 限定公開リンクの link-card

- **対象:** P14 公開設定モーダル（testing.md 確認項目 9）
- **ノート:** [MT542] 限定公開リンク検証ノート（unlisted, `/notes/01950542-0000-7000-8000-000000000031`）
- **ビューポート:** 1280x900
- **結果:** **PASS**

## 期待結果

- head 行に有効チップ + 最終アクセス（`lastAccessedAt` が非 null のときのみ、`ml-auto` で右寄せ）、その下に URL 行 + コピーボタン。
- 未アクセスのリンクは最終アクセスが出ない。
- コピーボタンを押せる（押下後にエラーが出ない）。

## 確認内容

発行済みリンク 2 件。リスト（`li`）で表示。

### カード 1（未アクセス）

- head 行: 「有効」チップのみ。**最終アクセスの表示なし**（期待どおり）。
- URL 行: `code` = `http://localhost:8787/share/by-id/01950542-0000-7000-8000-000000000061` + 「リンクをコピー」ボタン。
- 下段: 新しいパスワード入力 + 「パスワードを設定」（空欄のため disabled）+ 「失効させる」。

### カード 2（最終アクセスあり）

- head 行: 「有効」チップ + 「最終アクセス: 6月5日 01:20」が右寄せ（`ml-auto`）で表示。
- URL 行: `code` = `http://localhost:8787/share/by-id/01950542-0000-7000-8000-000000000060` + 「リンクをコピー」ボタン。
- 下段: 新しいパスワード入力 + 「パスワードを設定」（disabled）+ 「失効させる」。

→ 最終アクセスありの行のみ日時表示、なしの行は非表示。期待どおり。

### コピーボタン

- カード 1 / カード 2 のコピーボタンをそれぞれ押下。両方ともエラーなし（`role=alert` 出現なし、モーダル状態安定）。クリップボード内容の検証は対象外。

### モック突合

- モック `P14-publish-settings.html` の `.link-card`（head 行に link-chip + last-access、その下に link-row + コピー、さらにパスワード/失効の mini-row）と構成が整合。
- チップ「有効」、最終アクセスの右寄せ配置、URL の等幅表示 + コピーアイコンボタンとも大きな乖離なし。
- 備考: モックには QR コードブロックがあるが、これはモック側コメントで「実装は QR 未対応 → 別Issue引き渡し」と明記されており、本 TC の対象外（実装に QR なしは想定どおり）。
