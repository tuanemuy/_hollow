# TC-007: 統合ダイアログ（回帰）

結果: PASS

## 概要

タグ「統合」押下で統合ダイアログ「タグを統合」が開く。統合先 select（自タグを除外した候補）、統合先選択時に「対象ノート: N 件」を含む説明文が表示。統合ボタンは未選択時 disabled、選択で enabled。モック P18-merge-tag-dialog.html 相当の機能を確認。

## 実行ログ

| ステップ | 操作 | 期待 | 結果 |
| --- | --- | --- | --- |
| 1 | #bug 行の「統合」を押す | ダイアログ表示 | PASS（dialog "タグを統合"、role=dialog、aria-modal） |
| 2 | ダイアログを snapshot + screenshot | 統合先 select・キャンセル/統合ボタン | PASS（combobox「統合先タグ」、option は自タグ #bug を除く #archived/#design/#frontend/#llm/#unused。統合ボタン初期 disabled） |
| 3 | 統合先に #design を選択 | 説明文「対象ノート: N 件」表示 | PASS（「#bug を #design に統合します。 **対象ノート: 1 件**。 #bug は削除され、参照ノートは #design を持つよう更新されます。」件数 1 はシードと一致） |
| 3 | 選択後の統合ボタン | enabled | PASS（disabled=false） |
| 3 | キャンセル | ダイアログ閉、データ不変 | PASS（dialogOpen=false、6タグ全て維持） |

## 確認できた実装詳細

- 統合先 select は自タグを候補から除外（#bug 統合時に #bug が出ない）。
- 説明文は `<p>` 内で「対象ノート: N 件」を `<strong>` で強調。モックの DIALOG_DESCRIPTION と一致。
- progressbar（実行中の indeterminate バー）は MergeTagDialog.tsx の `isPending && sourceNoteCount > 0` で `role="progressbar"`（progressTrack / progressBarIndeterminate）として実装済みを コードで確認。本TCではシードデータ保全のため実行（破壊的マージ）は行わず、progress 表示の動的描画は未取得。
