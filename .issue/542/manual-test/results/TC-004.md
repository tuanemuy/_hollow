# TC-004: 行アクションの hover/focus 表示と狭幅ケバブ

結果: PASS

## 概要

広い画面（1280px）では行アクション（リネーム/統合/削除）が hover/focus で出現し、lg未満（800px）ではアクション列・件数が隠れてケバブ（操作メニュー）が表示される。ケバブからリネーム/統合/削除が選べ、削除は danger 表示。

## 実行ログ

| ステップ | 操作 | 期待 | 結果 |
| --- | --- | --- | --- |
| 1 | Cookie 注入 → 1280幅で /tags を開く | 6タグ表示 | PASS（#archived 0 / #bug 1 / #design 2 / #frontend 4 / #llm 2 / #unused 0 件。シードと一致） |
| 2 | アクション群の初期 opacity 確認 | hover 前は非表示 | PASS（group クラス `opacity-0 group-hover:opacity-100 group-focus-within:opacity-100`、初期 opacity=0） |
| 2 | タグ行に hover | アクション出現 | PASS（hover 後 group opacity=1） |
| 2 | focus 出現の仕組み | focus-within で出現 | PASS（クラスに `group-focus-within:opacity-100` あり。コード上確認） |
| 3 | 800幅にリサイズ → reload | アクション列・件数が隠れケバブ表示 | PASS（アクション group `display:none`、tag-count `display:none`、ケバブ `aria-label=操作メニュー` が `inline-flex` で表示） |
| 4 | ケバブを開く | リネーム/統合/削除が出る、削除は danger | PASS（menu に menuitem リネーム / 統合 / separator / 削除。削除 menuitem は `data-danger`、color rgb(196,62,62)=error 色） |

## 確認できた実装詳細

- 行 `<li>` は `group grid grid-cols-[1fr_auto] ...`。アクション群は `inline-flex ... max-lg:hidden opacity-0 transition-opacity group-hover:opacity-100 group-focus-within:opacity-100`。
- 800px（lg未満）でアクション群・tag-count とも `display:none`、ケバブ（操作メニュー）が出現 → モック P18-tags.html の `max-width:1023px` 挙動と一致。
- ケバブメニューの削除は `data-[danger]:text-error` で error 色（赤）表示。
