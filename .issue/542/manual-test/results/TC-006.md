# TC-006: inline rename ブロック

結果: PASS

## 概要

リネーム押下で編集ブロックが展開。input の上に「#{name} をリネーム（{件数} 件のノートに反映）」見出しが表示され、編集領域は accent-surface 背景。保存で楽観反映され、元に戻す操作も成功。

## 実行ログ

| ステップ | 操作 | 期待 | 結果 |
| --- | --- | --- | --- |
| 1 | 1280幅で #design 行の「リネーム」を押す | 編集ブロック展開 | PASS |
| 2 | 編集ブロックを snapshot | 見出し + input + 保存/キャンセル | PASS |
| 3 | 見出し文言 | 「#design をリネーム（2 件のノートに反映）」 | PASS（件数 2 はシードと一致） |
| 3 | 編集領域の背景 | accent-surface | PASS（内側 div `bg-accent-surface`、computed oklch(0.97 0 0)＝--color-accent-surface トークンと一致） |
| 4 | 名前を「design-qa」に変えて保存 | 楽観反映 | PASS（リスト上で `#design` → `#design-qa`、件数 2 維持） |
| 4 | 元の名前「design」に戻す | 復元 | PASS（再度リネームし「design」で保存 → `#design` 2 件に復元） |

## 確認できた実装詳細

- 編集ブロックの構造: `<li>` 内に `[grid-column:1/-1] -mx-3 -my-4 px-3 py-4 bg-accent-surface flex flex-col gap-1.5` の wrapper。その中に見出し `<p>`「#design をリネーム（2 件のノートに反映）」→ input（タグ名）→ 保存/キャンセル。
- 見出しは input の上に配置され、件数を含む文言を表示。モック `.tag-editing-block`（accent-surface 背景）と一致。
- 保存後の楽観反映でリスト表示が崩れず、件数も保持。
