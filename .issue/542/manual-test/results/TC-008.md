## 確認内容

### ラジオ説明文（3 種すべて表示）

- **非公開**: 「本人のみが閲覧できます。共有リンクは発行されません。」
- **限定公開（リンクを知っている人のみ）**: 「共有リンクを知っている人だけが閲覧できます。任意でパスワードを設定できます。検索対象にはなりません。」
- **公開**: 「同一インスタンス内で誰でも閲覧でき、検索対象になります。ユーザー名のネームスペース URL で公開されます。」

いずれもモック `P14-publish-settings.html` の `.radio-desc` 文言と一致。

### 公開時 URL プレビュー

- ラジオ状態: private=false / unlisted=false / **public=true（選択済み）**。
- 見出し「公開時の URL」+ `code` 要素に URL 表示:
  `http://localhost:8787/u/dev-admin/mt542-public-roadmap`
- パス形式 `/u/dev-admin/<slug>` を満たす（期待どおり。実装値の origin は localhost:8787）。

### モック突合

- ラジオカード（status-dot + タイトル + 説明）レイアウト、選択カードの強調（枠/背景）、URL プレビュー枠とも大きな乖離なし。
- 公開ステータスセクション → URL プレビュー → 「公開状態を更新」ボタン → 限定公開リンクセクションの構成順もモックと整合。
