- 結果: **PASS**

## 判定理由

LIKE 経路で `limit=1` ページネーションが機能。1ページ目に 1 件＋次ページ cursor リンク（`cursor=b2Zmc2V0OjE` = offset:1）が存在。2ページ目で別の Go ノート「Golang tips」が重複なく表示され、最終ページに到達。PASS。

## 備考

ページャは aタグリンク（cursor ベース、offset エンコード）。Known Issue の React click 非到達を避けるため、href を eval で取得して直接 open した。
