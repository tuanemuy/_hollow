## 確認環境

このIssueの変更を確認するために必要な手順のみ記載。

### 検証環境の起動

```bash
pnpm db:migrate   # ローカル D1 にマイグレーション適用（未適用の場合）
pnpm dev          # 開発サーバー（vite dev、ライブソース配信）起動
```

起動したら表示された URL をブラウザで開く。

### 検証用アカウントの用意

このリポジトリに seed スクリプトは存在しない（`pnpm db:seed` は無い）。検証用アカウントは画面の `/signup` から新規作成する（dev ではメール認証不要でそのままログイン状態になる）。アカウント削除は不可逆なので、必ず使い捨てアカウントで実施する。

### デプロイ方法

なし（検証環境のみで確認できる）。

## 確認項目

### 1. アカウント削除後のホーム遷移

- **目的:** `router.clearCache` 化後も削除フローが正常に完了し、`/` へ遷移すること
- **手順:**
  1. `/signup` で使い捨てアカウントを作成しログイン状態にする
  2. `/settings` を開き「アカウント削除」セクションへ移動する
  3. 「続けて削除する」ボタンを押す
  4. 確認ダイアログで自分のユーザー名を入力し「アカウントを完全に削除する」を押す
- **期待結果:** 削除が成功し `/`（ホーム）へ遷移、ログアウト状態（公開ホーム）が表示される
- **確認ポイント:** 一瞬ログイン済みレイアウト（旧 userDto）が残るチラつきが無いこと

## エッジケース・異常系

### 1. 遷移後の状態の安定性

- **目的:** clearCache → navigate の順序で race が起きないことを確認
- **手順:**
  1. 上記削除を実行した直後の遷移を観察する
- **期待結果:** エラー画面・無限リダイレクト・コンソールエラーが出ず、`/` で安定する

## 既存機能への影響確認

- ログイン/ログアウト・通常ナビゲーション（削除以外の `_app` 配下画面遷移）が従来どおり動くこと
