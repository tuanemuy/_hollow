# TC-002: admin/jobs テキストのみ→アイコン付与

**結果:** PASS（部分検証）
**実施日:** 2026-05-29
**セッション:** verify-tc-002

## 確認対象

`/admin/jobs` の「再実行」「再構築を実行」ボタンが `RefreshCw` アイコン + ラベル表示になっていること。

## 実施手順

1. `http://localhost:3000/login` にアクセス
2. admin@example.com / Password123! でログイン
3. `/admin/jobs` に遷移
4. ボタンの DOM 構造を確認

## 結果

### 「再構築を実行」ボタン（SearchIndexSection）

ブラウザ DOM 検査結果:
```html
<button type="button" class="inline-flex items-center gap-1.5 h-7 px-3 rounded-pill bg-surface text-ink text-xs font-medium ...">
  <svg ... class="lucide lucide-refresh-cw" ...>...</svg>
  再構築を実行
</button>
```

- アイコン: `lucide-refresh-cw` (RefreshCw) class が確認できた
- ラベル: 「再構築を実行」
- 結果: **PASS**

### 「再実行」ボタン（IngestionJobRow / ExportJobRow）

現在のシードデータでは ingestion ジョブの状態が `プレビュー中` / `破棄` のため、行アクションセルが空でランタイム表示は確認できなかった（再実行ボタンは completed/failed 状態でのみ表示される設計と推定）。

ソースコードレベルでの確認:
- `app/components/admin/Jobs/index.tsx`
  - L5: `import { Download, RefreshCw, Search, Sparkles, Upload } from "lucide-react";`
  - L225-226 (ingestion 行): `<Icon icon={RefreshCw} />{isPending ? "再実行中…" : "再実行"}`
  - L311-312 (export 行): `<Icon icon={RefreshCw} />{isPending ? "再実行中…" : "再実行"}`
  - L426 (SearchIndexSection): `<Icon icon={RefreshCw} />`

ソース上で 3 箇所すべて `RefreshCw` アイコン + ラベルの構造であることを確認した。
