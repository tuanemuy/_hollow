# TC-004: NoteActions の削除確認ダイアログ + 通常ツールバー視認

**結果:** PASS
**実施日:** 2026-05-29
**セッション:** verify-tc-002

## 確認対象

- ノート詳細画面の NoteActions ツールバー全体が「アイコン+ラベル」で揃っていること
- 「削除」押下時の ConfirmDialog confirm ボタンが `Trash2` アイコン + 「ゴミ箱へ」ラベルであること

## 実施手順

1. admin としてログイン
2. `/`（ノート一覧）から「最初のノートを作成」→ タイトル `TC-292-Test-Note` で作成
3. ノート詳細 `/notes/{id}` に自動遷移
4. NoteActions ツールバーをスクリーンショット
5. 「削除」ボタン押下 → ConfirmDialog DOM を検査

## 結果

### ツールバー視認（PASS）

`toolbar "ノート操作"` に以下のボタン/リンクが並ぶ:

- 編集 (link)
- 公開設定 (link)
- 移動 (button)
- URLコピー (button)
- 複製 (button)
- エクスポート (link)
- 履歴 (link)
- 削除 (button)

すべて accessible name 通りのラベルテキスト + アイコン（テキスト併用）で揃っている。混在なし。

### 削除確認ダイアログ（PASS）

「削除」ボタン押下後、`role="alertdialog"` が開く:

```json
{
  "dialogText": "このノートをゴミ箱に移動キャンセルゴミ箱へ",
  "buttons": [
    { "t": "キャンセル", "svgClass": null },
    { "t": "ゴミ箱へ", "svgClass": "lucide lucide-trash2 lucide-trash-2" }
  ]
}
```

- confirm ボタン: ラベル「ゴミ箱へ」+ `Trash2` アイコン（`lucide-trash2` クラスで確認）
- cancel ボタン: テキストのみ「キャンセル」（spec §7.1 primary/secondary 例外通り）

「キャンセル」を押してダイアログを閉じ、ノートはそのまま残した（後続 TC のため削除を実行せず）。

## 所見

- ConfirmDialog の `confirmIcon={Trash2}` がランタイムでもアイコンとして描画されている（`lucide-trash2` SVG class が検出された）。
- ツールバー全体の「アイコン+ラベル」混在禁止ルールに準拠している。
- `role="alertdialog"` には close × が存在しないため、後続 TC-006 の Dialog × ボタン検証は別 Dialog（URLコピー等）を使用する必要がある。
