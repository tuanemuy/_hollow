# TC-005: TrashList 空状態 CTA

**結果:** PASS
**実施日:** 2026-05-29
**セッション:** verify-tc-002

## 確認対象

`/trash` 空状態 CTA「すべてのノートに戻る」リンクが `ArrowLeft` アイコン + ラベルで表示されていること。

## 実施手順

1. admin としてログイン済み（TC-002〜TC-004 同セッション）
2. `/trash` に遷移
3. 空状態の CTA リンクの DOM を検査

## 結果

ゴミ箱は空（「ゴミ箱は空です」「削除したノートはここに表示されます。」表示）。

CTA リンク検査:
```json
[
  {
    "t": "すべてのノートに戻る",
    "svgClass": "lucide lucide-arrow-left"
  }
]
```

- アイコン: `lucide-arrow-left` (ArrowLeft) を確認
- ラベル: 「すべてのノートに戻る」
- 結果: **PASS**

## 所見

ArrowLeft アイコン+ラベルの CTA は §7.1「空状態 CTA はアイコン+ラベル」ルールに準拠している。EMPTY_STATE のアイキャッチ（既存）と CTA リンクが連続的に視認できる。

TrashRowActions の削除確認ダイアログは、ゴミ箱が空のため今回検証できなかった。ソース上は他の ConfirmDialog 呼び出しと同じ `confirmIcon={Trash2}` パターンであり、TC-004 で本体実装の妥当性は確認済み。
