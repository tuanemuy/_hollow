# TC-006: Dialog 閉じるボタンのモバイル viewport

**結果:** PASS
**実施日:** 2026-05-29
**セッション:** verify-tc-002

## 確認対象

Dialog primitive の "×" 閉じるボタンが:
- デスクトップで 32×32px
- モバイル (375×667 viewport) で 44×44px
- `aria-label="閉じる"` が常に維持される

## 実施手順

1. `/?upload=open` ... ではなく `/#upload` で UploadDialog を開く（プロジェクトのハッシュ駆動マウントに合わせる）
2. デスクトップ (1280×720) で `getBoundingClientRect()` 計測 + スクリーンショット
3. viewport を 375×667 に切替 → 同ボタンを再計測 + スクリーンショット
4. ボタンの `aria-label` を検証

## 結果

### デスクトップ (1280×720)

```json
{
  "title": "アップロード",
  "closeRect": { "w": 32, "h": 32 },
  "closeClass": "absolute top-3 right-3 inline-flex items-center justify-center w-8 h-8 max-sm:min-w-[44px] max-sm:min-h-[44px] rounded-full ..."
}
```

- 実描画サイズ: **32×32px** ✅
- クラス: `w-8 h-8` (= 32px) ベース + `max-sm:min-w-[44px] max-sm:min-h-[44px]` (= sm 未満で最小 44px)

### モバイル (375×667)

```json
{
  "viewportW": 375,
  "closeRect": { "w": 44, "h": 44 },
  "ariaLabel": "閉じる"
}
```

- 実描画サイズ: **44×44px** ✅（`max-sm:` メディアクエリが効いて min が適用）
- `aria-label="閉じる"` 維持 ✅

## 所見

- デスクトップ 32px / モバイル 44px の挙動を実測で確認。
- `aria-label="閉じる"` はサイズ変化に関係なく維持される。
- ダイアログタイトル「アップロード」と "×" ボタンの視覚的重なりはモバイルでも発生せず（タイトルが短いため）。spec §3 44×44px 要件に準拠。
