# TC-003: AppShell-Impacting Mutation (Directory Create)

**Status:** PASS
**Date:** 2026-05-29
**Session:** verify-tc-003
**Account:** existing@example.com (seed)

## Purpose
ディレクトリ作成は AppShell に影響する mutation として扱われ、生 `router.invalidate()` 経由で `_app` route も invalidate 対象になり Sidebar の directory tree が更新されることを実機で確認する。期待: 新規ディレクトリが Sidebar の tree に出現する。AppShell の wrapper DOM 自体は持続。

## Method
- ホーム `/` で `aside` / `header` / `[role=tree]` に `data-tc-marker` 付与、tree outerHTML を記録
- Sidebar の「ディレクトリを新規作成」ボタンをクリック → `CreateDirectoryDialog` 表示
- 名前 `verify-dir-299` を入力 → 「作成」クリック
- 作成後、marker 残存と tree に新規ディレクトリが出現することを確認

## Conclusion
- ディレクトリ作成 mutation は AppShell に影響する（`router.invalidate()` で `_app` も invalidate）
- Sidebar の directory tree が再フェッチされ、新規ディレクトリが反映された
- 同時に AppShell wrapper の DOM (`aside` / `header` / `[role=tree]` 要素自体) は **同一インスタンスのまま** — React が children を差し替えただけで wrapper は再マウントされていない（Issue #293 の持続化と両立）
- Issue #299 の「AppShell 影響 mutation は素の `router.invalidate()` を使う」設計が機能している
