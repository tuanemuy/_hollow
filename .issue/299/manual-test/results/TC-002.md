# TC-002: AppShell Non-Impacting Mutation (Note Edit)

**Status:** PASS
**Date:** 2026-05-29
**Session:** verify-tc-002
**Account:** existing@example.com (seed)
**Note:** `01938f02-0000-7000-8000-000000000101` (seed ノート `Foo配下の検証用ノート 1`)

## Purpose
note 編集（タイトル変更 → 保存）が AppShell に影響しない mutation として扱われ、`routerInvalidate(router)` 経由で `_app` route が invalidate 対象から除外されることを実機で確認する。期待: Sidebar の directory tree が再フェッチされず DOM が変化しない。

## Method
- ノート編集画面で `aside` / `header` / `[role=tree]` に `data-tc-marker` 付与、tree の outerHTML を保存
- タイトルを変更して「保存」
- 保存後の DOM / 残存 marker / tree outerHTML 一致を比較
- ネットワークログで `_app` route loader 再フェッチが発生していないことを確認（POST のみ）

## Conclusion
- ノート編集 mutation は AppShell に影響を与えない（`routerInvalidate(router)` で `_app` が除外される）
- Sidebar の directory tree DOM は **byte 単位で同一**（再マウントも内容差し替えも発生していない）
- Issue #299 の「AppShell 非影響 mutation は `_app` invalidate しない」設計が機能している
