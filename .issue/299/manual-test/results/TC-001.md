# TC-001: AppShell Persistence Across Leaf Navigations

**Status:** PASS
**Date:** 2026-05-29
**Session:** verify-tc-001
**Account:** existing@example.com (seed)

## Purpose
Issue #293 で確立した「ログイン後、リーフページ間遷移で AppShell (Sidebar/Header) が再マウントされない」不変条件が Issue #299 の `routerInvalidate(router)` フィルタ化後も維持されていることを実機で確認する。

## Method
- ホーム `/` でログイン直後、`aside` / `header` / `[role=tree]` の DOM ノードに `data-tc-marker` 属性を JS で付与
- Sidebar の「タグ」リンクで `/tags` へ遷移
- 戻る (`back`) で `/` に復帰
- 各ステップで marker が DOM 上に残存しているかを `eval` で確認（再マウントされていれば marker は失われる）

## Evidence
- `screenshots/tc-001/01-home-initial.png` — ログイン直後のホーム（Sidebar + directory tree 表示）
- `screenshots/tc-001/02-tags-page.png` — `/tags` 遷移後、Sidebar は引き継がれている
- `screenshots/tc-001/03-back-home.png` — `back` 後、Sidebar の見え方が継続

## Conclusion
- `aside` / `header` / `[role=tree]` の DOM ノードが `/` → `/tags` → `/` の遷移を通じて同一インスタンスのまま維持された（marker 残存）
- Issue #293 / #299 の AppShell 持続化不変条件は維持されている
